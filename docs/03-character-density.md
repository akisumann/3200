# 人物を一人ぶん書くときの型

**[[char:nasu-mio]] が、この repo で人物一人ぶんの基準になった。**

**十数回の指摘を通して形が決まったので、そこで効いたものと、外したものを残す。**

**残り11人**（→ [[concept:a-rank]] の神社旧家枠と民間枠）**を、ここまで持っていく。**

## 順序

**この順で書く。** **入れ替えると、毎回同じところで詰まる。**

| | |
|---|---|
| **1** | **何ができるか。** 技の名前と、それが何をするか |
| **2** | **出どころ。** その力をどこから得たか |
| **3** | **育ち。** 昔できなかったことと、今できること |
| **4** | **立場。** 役職、家、所属 |
| **5** | **既存の記述との噛み合い** |

**4から書き始めない。**

> **役職と立ち位置だけ書いて、A級として何ができるかがどこにも無い、という状態になる。**
> **一度そうなった。**

**そして、材料が無いところは飛ばす。** **節が空いているから何か書く、をやらない**（下記）。

## 効いたもの

### 技が、一つのところに集まっている

**[[char:nasu-mio]] は、呼ぶ・祓う・射る・縫い止める・核を抜く、全部が弓一張りに乗っている。**

**能力を並べるのではなく、一つの道具か、一つの由来に集めると、人物として立つ。**

### 出どころに、経路がある

**「なぜか持っている」で止めない。**

| | |
|---|---|
| **[[char:nasu-mio]]** | **隣の天狗の里から教わった** |
| **[[char:kamo-gen]]** | **血族的契約で先祖から渡っている** |
| **[[char:kurosawa-akira]]** | **神から借りている** |

**経路が違えば、制約も違ってくる。** **継承なら血が要る。教育なら要らない。借り物なら返却と許可がある。**

### 育ちが、能力の形を決めている

**[[char:nasu-mio]] が弓なのは、子供のときに他に何も届かなかったから。**

**「強いから弓が上手い」ではなく、「他が全部無理だったから弓だけ残った」。**

> **今できることの理由が、昔できなかったことの側にある。**

### 何かを書くなら、中身を書く

**「決め手が無い」「終わらない」のような、書かずに済ませる言い回しをしない。**

**書けないなら、その項目ごと落とす。**

### 危ないところが、設定から出てくる

**作らない。** **能力の向きを変えるとどうなるかを見る。**

**[[char:nasu-mio]] は妖怪を誘引できるので、封印へ寄せることもできる。** **祭事ができるので、祀ってはいけないものを祀ることもできる。**

**どちらも新しく足した設定ではない。** **既にある能力の、向きを変えただけ。**

### 既存の記述にぶら下げる

**新規の発明は最小にする。**

**[[char:nasu-mio]] で新しく作ったのは、家の由来と技の名前くらい。**

**残りは全部、[[concept:core-layer]]、[[concept:jugu]]、[[concept:youkai-samples]]、[[concept:youkai-land]]、[[concept:grades]] に既にあるものへ繋いだ。**

> **繋ぐほど、確認が通りやすくなる。**
> **確認する側は、既に通っているものと照らして読むから。**

## 外したもの

**全部、一度やって指摘されたもの。**

### 立場を劇的にしすぎた

**「交代が利かない」「離れられない」「一箇所にいることが性能の前提」。**

**実際は、殺生石の管理は概ね形だけで、普通に神社の家として回っている。**

> **重要な役目に見えるものほど、日常の側を先に置く。**

### 弱点の節を置いて、そこを埋めた

**これが一番よくなかった。**

**「弱点」という節を毎回置いて、埋めるために制約を発明していた。**

| 作ったもの | |
|---|---|
| **「運動能力が低い」「懐に入られたら終わる」** | A級の基礎スペックはある、と [[concept:grades]] に既に書いてあった |
| **「近距離で仕留める手段が無い」** | 誰も言っていない |
| **「動いているものは封じられない」** | 弱点を作るために発明した機構 |

**指摘はこう。**

> **弱点とかいらないんだよ。**

**この repo は世界設定であって、能力の釣り合いを取る場所ではない。**

**強弱の勘定は `projects/` の側の話**（→ `00-repository-guide.md`）。**`world/` には、その人が何をするかだけ書く。**

> **できないことは、できることを書いた結果として出てくるなら書く。**
> **枠を埋めるために作らない。**

**この文書の順序からも、弱点の項を外した。**

### 時系列を混ぜた

**子供の頃の節に、今のスペックを書いた。**

> **昔と今は、別に書く。**

### 曖昧な決着で済ませた

**「押し切られるのではなく、決まらない」。**

**中身を書かずに済ませていただけだった。**

### 未確認のものを足場にした

**→ `02-canon-policy.md` の「未確認のものを、説明の足場にしない」。**

### 弱点の表を、名簿にまで作った

**[[concept:a-rank]] の一覧表に「弱点」の列を置いていた。**

**十二人ぶん、全員に一つずつ書いていた。** **ほぼ全部、その場で作ったもの。**

**列ごと落とした。**

### 型を、埋めにいった

**そして、この文書そのものにも危険がある。**

**二人目**（[[char:mononobe-akari]]）**で、[[char:nasu-mio]] の形をそのまま当てはめた。**

| 埋めにいった節 | 中身 |
|---|---|
| **危ないところ** | 「開けられる」を、返し矢の穴の焼き直しとして置いた |
| **育ち** | 「蔵で数を数えていた」を、天狗と遊んだ育ちの型だけ真似て作った |
| **家の由来** | 「滅んだ氏族が役目に引きずられて残った」を、[[char:kamo-gen]] で使った理屈のまま流用した |
| **名前** | 「物部」に、封印と繋がる理由が無い |

**指摘はこう。**

> **封印系はジャンルはそれでいいとして、他は話にならんな。**

**分野の機構は repo の材料から出たので通った。** **その上に乗せたものは、全部この文書の節を順に埋めただけだった。**

> **この文書は、書く順序であって、埋める枠ではない。**
> **節があるから何か書く、をやると、二人目以降が一人目の影になる。**

**[[char:nasu-mio]] が成立したのは、能力も育ちも道具も、全部外から与えられた材料だったから。**
**そこが無い人物では、機構だけ決めて、残りは未決のまま置く。**

## 一人にかかる分量

**[[char:nasu-mio]] で 1000行前後。**

**そのうち新規の発明は一割ほどで、残りは既存の記述との接続と、そこから出てくる読み。**

> **長いのは、材料が多いからではない。**
> **既にあるものと繋いだ結果として、そうなる。**

## 書き足しを重ねたら、構造を直す

**節を足し続けると、順序が崩れる。**

**[[char:nasu-mio]] も一度組み直した。** **能力の中に祭事と家業が混ざり、殺生石の話が二箇所に分かれていた。**

> **一人ぶん書き終わったら、見出しを並べて読む。**
