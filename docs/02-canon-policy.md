# 正典（カノン）の扱い

## status の4段階

すべての `world/` 配下のファイルは、frontmatter に `status` を持つ。

| status | 意味 | 他所から参照してよいか |
|---|---|---|
| `draft` | 名前と断片だけ。思いつきの置き場 | 参照可。ただし内容は当てにしない |
| `wip` | 書きかけ。方向は決まっているが未完 | 参照可 |
| `canon` | **確定**。作品を作るときの前提にしてよい | 参照可 |
| `dropped` | 没。もう使わない | **参照しない**（`check.py` が警告する） |

## なぜ4つあるか

「完成に近い世界設定がある」状態でも、実際には項目ごとに固まり具合が違う。全部を同じ扱いにすると、二種類の事故が起きる。

1. **固まっていないものを前提に作品を作ってしまう** — 後で設定が変わり、作った物が壊れる
2. **固まっているのに、変わるかもしれないと思って使えない** — 手が止まる

`status` はこの境界を明示するためだけにある。**`canon` を付けたものは、以後うかつに変えない**という自分への約束が本体。

## canon を変えたくなったら

変えてよい。ただし手順を踏む。

1. `tools/check.py` を実行し、その ID を参照している箇所を洗い出す
2. 参照元の記述が矛盾しないか確認する（`projects/` 以下も含む）
3. 変更内容と理由をコミットメッセージに書く

`git log -- world/characters/aria.md` で、その項目が「いつ・なぜ変わったか」を後から追える。これが正典を git で管理する一番の利点なので、コミットメッセージは丁寧に書く価値がある。

## dropped の扱い

没にしたものは**削除せず** `status: dropped` に変える。

- 削除すると、なぜ没にしたかが失われ、数か月後に同じ案を思いついて同じ理由で没にすることになる
- 本文の末尾に `## 没理由` を足しておくと、その再発を防げる
- どうしても消したくなったら消してよい。git 履歴には残る

## 二つの印

決まっていないことにも種類がある。混ぜない。

| 印 | 意味 | 扱い |
|---|---|---|
| **未決** | まだ決めていない。決めるべきこと | いずれ潰す宿題 |
| **保留** | **決まっているが、説明を要するので後回し** | 未決ではない。作者が書くのを待つ |

### 二度と聞かないこと — 個体ごとの関係

**妖怪一体ごとの契約・関係・扱い・在り方について、「どうなっているのか」と一般則を聞かない。**

**答えは常に十人十色。** これは未確定なのではなく、**そういう世界だという確定した性質。**

具体的には、以下は**もう聞かない**。

- 契約の中身に型はあるのか
- 手続きに至る道はどうなっているのか
- 式神の同意は要るのか、雇用なのか使役なのか
- 討伐でどこを狙うのか
- 領域型の核はどこにあるのか
- 妖怪はどう思っているのか（一般として）

- 新しく湧いたA級はどう見つかるのか

**すべて「個体による」「さまざま」で終わる。** 何度も同じ形で聞いて、何度も同じ答えが返っている。

**見分け方の目安。** 「〜はどうなっているのか」と一般を問う形になっていたら、それはこの類。**具体的な事実（数、場所、名前、誰がやるか）を聞いているなら別。**

**書くときも同じ。** 一般則として書かない。**具体例を一つ二つ置いて、「あとは個体による」と書けば足りる。** 体系化しようとすると嘘になる。

### 答えが「色々」であることが答え、という場合がある

個別の事情で千差万別なもの、一般則が存在しないものを、無理に体系化すると嘘になる。**具体例が一つあれば足りて、その先は書かないほうが正しい。**

## 現実の未解明を、謎として積まない

**この世界は、現実にある「よくわからないもの」に説明をつける形で作られていることがある。**

**そういう場合、それは設定が作った謎ではない。** **現実の側が先にそうなっていて、設定はその答えのほうを持っている。**

| 現実にある事実 | この世界での説明 |
|---|---|
| **「bug」の語源が、初期計算機に入り込んだ一匹の蛾** | [[char:bug]] の核はその一匹 |
| **1999年に世界規模で終末が語られた** | [[char:nostradamus]] が一時的にA級へ到達した |
| **花子さんの伝説に発祥が無く、しかも全国で細部まで揃っている** | [[char:hanako-san]] は伝播していない。**全部が本体で、最初から全国にいた** |

### やってはいけないこと

**現実の未解明を、そのまま `未決` に積むこと。**

**それは「まだ決まっていない」のではなく、「もう答えが出ている」場所。** 未決に積むと、**後から誰か（自分）が答えを作ろうとして、設定の入口を潰す。**

### 見分け方

**現実にも同じ不思議がある**なら、まずこう疑う。

> **その不思議さそのものが、この世界の設定の入口になっていないか。**

**なっているなら、掘るのではなく、そこから逆算する。**

### 逆に、作った伝承は作ったと書く

**この repo のやり方は「現実にある伝承が、この世界ではこう働く」を積むこと。** **強いのは、読む側が現実と突き合わせて確かめられるから。**

**だから、実在しない妖怪を実在の伝承と同じ形で書くと、その確認ができなくなる。** 名前があり、土地があり、数百年の伝承があると書いてあれば、**現実に無いことは書いてある側からは分からない。**

**現在の例。** [[concept:youkai-samples]] の**影送り** —— サンプルデータとして作られた妖怪で、元の民間伝承は無い。**一伝承一能力の見本として残してあるが、項目の冒頭にその旨を書いてある。**

**作例を入れること自体は問題ない。** **黙って混ぜないだけ。**

## 要約してはいけないもの

**この repo の基本方針は「原文を貼らず、読めるように再構成する」。** ただし**例外がある。**

### 例外の条件

**価値が細部の積み重ねそのものにあり、まとめると役目が消えるもの。**

**要約は、要点を残して枝葉を落とす作業。** ところが**枝葉の量そのものが中身になっている**ものがあり、それを要約すると**主張が成立しなくなる。**

### 現在の例外

| 対象 | 理由 |
|---|---|
| `world/characters/kazama-shiro.md` | **C級退魔師が条件戦で高位怪異に食い込む**という世界法則の実例。対怪異戦術が一個ずつ小さく、**束ねて初めて意味を持つ。** まとめると「変わった人」だけが残り、実例としての役目が消える |

### 例外にするときの手順

1. **ファイルの冒頭に、方針が違うことと理由を明記する**
2. **repo 側の追記（`関係` や `未決`）は、本文と分けて後ろに置く**
3. **本文には手を入れない**

### 自分への注意

**要約は無意識にやる。** 特にやりがちなのが以下。

- **箇条書きを一文にまとめる** — 項目数そのものが情報である場合、数が消える
- **具体例を「など」で畳む**
- **キャラクターの奇行を性格の話に還元する** — なぜそれが有効なのかという理屈が落ちる
- **重複を整理する** — 繰り返しが強調である場合、強調が消える

**例外ファイルに手を入れるときは、元の小見出しと項目数を対照して、落ちていないか確認すること。**

## やってはいけないこと

**印**（未決／保留）が「決まっていないこと」の扱いを分けるのに対して、こちらは**書く内容そのものの禁止**。

**世界を狭めるための決まりではない。** **土台が壊れないようにするためのもの。**

### インフレさせない

- **A級を雑に増やさない**
- **特殊A級を便利な強敵にしない**
- **未分類超高位存在を戦闘力ランキングにしない**

**A級・特殊A級を新しく立てること自体は禁止ではない。** この世界は、それを複数抱えられる規模で作ってある。

**禁じるのは、根拠の作り方のほう。** 新しく高位存在を立てるなら、**長期的・広域的・社会的な認識基盤**が要る（→ [[concept:grades]]、[[concept:shinen]]）。

**二つの型がある。**

| | 例 | 要るもの |
|---|---|---|
| **長期定着型** | [[char:hanako-san]] | 世代継承、実空間定着、生活文化への浸透、継続的な感情集積、学校・地域・祭祀・職業・生活習慣への根付き、長期的な認識安定、社会制度や空間との接続 |
| **短期認識災害型** | [[char:nostradamus]] | 世界規模認知、終末恐怖、社会不安、マスメディア拡散、明確な象徴性、時代精神との接続 |

**後者は例外的な成立方式。** **短期流行・局地的人気だけで高位存在を乱立させない。** 目安の一言が現場にある —— **「ノストラダムスに知名度勝てるの？」**

### 万能化させない

**どれも「そういう勢力・そういう思想が存在すること」は禁止していない。** **成功させないだけ。**

| 禁じること | 理由 |
|---|---|
| **国家による完全支配** | 超常は未知・認識依存・妖怪性・土地性・感情凝集を含み、神格・旧家・古社・地域社会・妖怪社会の利害が絡む。**国家は強いが万能ではない**（→ [[event:lupin-incident]]） |
| **科学による超常の完全再現** | 現場が混濁したまま運用している以上、完全な再現性には届かない（→ [[concept:powers]]） |
| **妖怪の完全絶滅** | 妖怪は均衡構造の内側にいる。**局所的な排除はできるが根絶はできない**（→ [[concept:overseas]]） |
| **神格の万能解決装置化** | 神格は実在するが、現代への直接介入は極めて限定的（→ [[concept:kami]]） |
| **主人公の世界法則免除** | 得意・不得意、相性不利、社会的制約、他者の専門性、装備制限、法制度、生活、失敗と後処理を必ず残す |
| **退魔師を通常兵器の上位互換にすること** | 退魔師は安全装置でもある（→ [[concept:supernatural-war]]） |

### 等級で勝敗を決めない

**等級は勝敗保証ではない。** 危険度・対処難度・社会的重要度・国家的警戒度の目安。

**A級であっても、相性・条件・初見殺しで即死する。**

**だからこう書かない。** 「強いからA級」。**「知られていないが最強」。「世界の外から来たから最強」。「全てを無効化する」。**

### 世界最強を作りたくなったら

**新規に最上位存在を立てること自体は禁止ではない。** **ただし、ヤハウェ・仏陀・ガイア・地獄を上回ると主張するなら、条件がある。**

人類史規模の認識基盤。**数千年単位の長期文明定着。** 複数の文化圏・宗教圏への影響。**死生観・信仰・世界観・文明構造への深い浸透。** 現代における継続的な認識。**その存在を失うことで文明側の意味体系が揺らぐほどの象徴性。** 広域伝承・思想体系・社会制度・儀式・言語への長期的な刻印。

**これを欠いたまま最強にする言い訳は、全部禁止。** 設定上そうだから。世界の外側から来たから。**全てを無効化するから。誰にも知られていないから。作者が決めたから。能力説明が強いから。**

> **匂わせることはできる。確定・序列化・ランキング化はしない。**

### 現実の歴史を書き換えない

**この世界の歴史は、現実とほぼ変わらない**（→ [[faction:reimusho]] の成り立ち）。**有史以来ずっと妖怪がいて、A級退魔師がいて、それでも筋が動いていない。**

**第二次世界大戦も概ね現実準拠。**

**理由は世界の側にある。** **戦争で退魔師を強く使わないというのは、制度より古い共通認識で、戦争の趨勢を変えるほど使った国は一度も無い**（→ [[concept:supernatural-war]]）。

#### だから、超常で歴史の分岐を作らない

**「この戦争は超常で決まった」「あの条約は妖怪のせいで結ばれた」という書き方をしない。**

**超常は、歴史の裏側に居ることはできる。** **表側を動かしてはいけない。**

**書けるのは、現実の歴史の隙間。** **記録に残らなかった交戦。表向き別の理由がついている出来事。焼失したことにされた文化財**（→ [[concept:relics]] の御手杵）。

> **現実の出来事の「なぜそうなったか」を超常で置き換えない。**
> **現実の出来事の脇で、何が起きていたかを書く。**

### 語の大きさから、規模を補わない

**この repo で一番よく起きている事故。**

**大きそうな名前の能力が出てくると、書き手が勝手に上限を外して読む。**

| 出てきたもの | やった誤読 |
|---|---|
| ルパンの「**上限が確認されていない**」 | 出力の上限だと読んだ。**実際は再現できる対象の側** |
| 天使の「**完全解放時には特殊A級相当**」 | 等級で測れると読んだ。**実際は制度がそう呼んでいるだけで、目盛りが足りていない** |
| 「**現実改変**」 | 世界規模だと読んだ。**実際は能力者の中でも世界規模は更に稀で、一般レベルはもっと小さい** |

**どれも、書かれていない上限を名前から補っている。**

#### 手順

**規模・射程・数は、書かれていなければ書かない。**

- **等級から考える。** A級なら「技一個が山破壊級」の段で、しかもそれは平均。**搦手型にはビル破壊すら無い**（→ [[concept:grades]]）
- **「稀」には段がある。** **稀な類型の中で、さらに稀な上澄み**という構造がよくある。**類型に属していることは、上澄みであることを意味しない**
- **迷ったら未決に置く。** **数字と射程は、聞いてから書く**

### 怖さで等級を上げない

**書くときに一番やりやすい事故。**

**演出の不気味さ、ホラー性、空間の歪み、失踪、異常な映像。** **これらは等級を上げる根拠にならない**（→ [[concept:battle]]）。

> **「怖いか」ではなく、「制度上どの等級で処理されるか」で決める。**

**特に、下位等級の担当が被害を受けたことだけで一気に高等級化しない。** **この世界は分業のピラミッドで回っている。** 「D級がやられた」の次に来るのは、B級ではなく**C級専門家**。

**そして、D級以上を「不気味なだけ」「現象が怖いだけ」の存在にもしない。** **怪談型でも生活圏型でも、D級以上は一般人にとって十分致命的。** 逆向きの事故もある。

### 新参を、古参のように強くしない

**能力の説明文が立派でも、支えが無ければ出力は出ない**（→ [[concept:core-layer]]）。

**伝承の厚み、認識の継続、土地定着、世代継承、蓄積、名前の安定。** **これらが無い妖怪は弱い。**

**書きながら「強そうな能力」を先に思いついたときは、順序が逆になっている。** **先に、誰がどれだけの期間そう思ってきたかを決める。**

### 伝承拘束から外して万能化させない

**「伝承通りだから強い」と書いたなら、必ず「伝承通りにしか強くない」も効かせる。**

**高位ほど再現度が高く、高位ほど様式に縛られている。** **強い存在を出すたびに、その存在が何をやらないかを一緒に決める。**

## 外に出ていないと書いてあるものを、推測で埋めない

**世界の側で「分かっていない」「概要すら知られていない」と書いてあるところへ、機構を作らない。**

### 何が起きたか

**[[faction:shrines]] に「A級相当への封印は秘術の領域で、概要すらシークレット」とある。**

**そこへ、封印の中身を書いた。**

> **核には触らない。外殻へ「出られない」という定義を一つ刻む。**

**[[concept:core-layer]] の核と外殻から引いた、という形にしてあった。** **だから既存に繋いだつもりでいた。**

**繋いだのではなく、埋めた。**

**そして埋めた一点の上に、人物一人ぶんを組み立てていた。** 討伐ではない理由、等級を問わない性質、動いているものは封じられない制約、器の格が封印の格を決める話、開けられるという危なさ。**全部そこにぶら下がっていた。**

> **指摘はこう。**
> **刻むとかはお前の発想だろ。**

### どうするか

| 書ける | 書かない |
|---|---|
| **何が封じられているか** | **どう封じたか** |
| **封印の出来がいいこと** | **なぜ出来がいいのか** |
| **手入れが要るか要らないか** | **手入れとは何をすることか** |

**「既存の概念から引ける」は、埋めていい理由にならない。**

> **引けるということは、そこが埋められるということでしかない。**

## 未確認のものを、説明の足場にしない

**repo 側で作ったものを、確認を通す前に他の記述の前提として使わないこと。**

### 何が起きたか

**A級18人のうち12人を、名前と分野だけで一度に作った。**

**そのあと一人ずつ確認する流れになり、最初の一人を詰めていった。**

**そこで、まだ確認していない残り10人を、確認中の一人の説明にそのまま使っていた。**

| 書いたもの | 問題 |
|---|---|
| **「柏木蓮のような相手には〜」** | **柏木蓮が何者か、まだ確認されていない** |
| **「鵜飼睦とは役の大きさが違う」** | 同 |
| **「斎木惺とは向きが逆」** | 同 |
| **「物部灯が呼ばれることになる」** | 同 |

**指摘はこう。**

> **知らん人との比べ方とかされても、知らんとしか言えん。**

**そのとおり。** **確認する側から見ると、比較の片側が空欄になっている。** **判断のしようがない。**

### なぜやってしまうか

**書いている側からすると、全部同じ repo の中身に見えるから。**

**自分が数十分前に作ったものと、確認を通ったものの区別が、書く手の中では消える。**

> **repo の中にあることと、通っていることは別。**

### どうするか

**比較や参照の相手は、次のどちらかに限る。**

| | |
|---|---|
| **出典から来ているもの** | 元資料に書いてある |
| **確認を通したもの** | 会話の中で見せて、通っている |

**それ以外を使いたくなったら、人名ではなく仕組みの側で書く。**

| 悪い | よい |
|---|---|
| 「柏木蓮のような相手には」 | 「呪具で殴ってくる相手には」 |
| 「斎木惺とは向きが逆」 | 「逃しポイントという仕組みとは向きが逆」 |
| 「鵜飼睦とは役が違う」 | 「高位交渉という分野とは役が違う」 |

**分野と機構は既に確認されている。** **人名だけが未確認なので、そこを外せば通る。**

> **書けることは何も減らない。**
> **むしろ人名に寄りかかっていたぶんが落ちる。**

### まとめて作ったものには、印を残す

**一度にまとめて作った箇所には、その旨をファイルに書いておくこと。**

> **[[concept:a-rank]] の神社旧家6人と民間6人には、「まだ一人ずつの確認を通していない。他のファイルから前提として引かないこと」と書いてある。**

**印が無いと、次に読んだときに区別がつかない。**

## 表向きの記録と、真相

**この世界には、公式の記録と実際に起きたことが違う出来事がある。**

**両方を書く。** **そして、どちらの層かを必ず明示する。**

### 既にあるもの

|---|---|---|

### 書き方

- **表向きの記録を消さない。** **世間が信じている内容そのものが、世界の一部**
- **ファイルの冒頭で層を明示する。** 途中まで読んだ人が、表向きを事実として持ち帰らないように
- **真相は別の節にまとめる。** 表向きの記述に真相を混ぜ込まない
- **「表向きが嘘」とは限らない。** [[event:hyakki-yako-attempt]] は**起きた出来事としては記録どおり**で、**なぜそうなったかが違う**

### なぜ隠されているかも書く

> **何が隠されているかと同じくらい、なぜ隠せているかが効く。**

## 確定してはいけないこと

**決められるが、決めてはいけないもの。**

**ここを開けたままにしておくことが、世界の安全装置になっている。**

### UNKNOWN は、作中でも未知

**これは repo の都合ではなく、世界の側の事実でもある。**

**既存の理論、分類、等級、契約体系では説明しきれない領域が、作中に実在する。** 未確認の存在。禁則知識。**説明不能な現象。特殊災害。認識外の存在。未整理の神秘。**

**そして誰も把握していない。** **人類側も、行政も、旧家も、民間も、そして妖怪側も。**

**妖怪側も知らない、というのが効いている。** **「聞けば分かる相手がいる」という逃げ道が無い。** [[faction:shrines]] の神降ろしですら届かない場所がある、ということになる。

**対応は決まっている。** **情報管理。封鎖。監視。接触制限。専門家への引き継ぎ。**

**解明ではない。** [[concept:relics]] のアカシック・レコードで**UNKNOWN領域を深く読むと観測者が壊れる**のと、同じ扱い。

#### 万能概念にしない

> **UNKNOWN は、既存設定を無効化するための概念ではない。**
> **現代超常社会の、外側と限界を示す領域。**

**「UNKNOWNだから何でもあり」は逆。** **積み上げた仕組みが届かない場所がある、という話であって、仕組みのほうを取り消す札ではない。**

### 未決に積んではいけない

**未決は「いずれ潰す宿題」だが、ここは潰してはいけない場所。**

> **未決は、まだ決めていないこと。**
> **ここは、決められるが決めないこと。**

**書くときは、仮説・伝承・秘匿情報の形で置く。** [[concept:relics]] のパンドラの箱がその型 —— **見つかっていない、開いていない、中身も分からない。それでも警戒され続けている。**

## 曖昧なままにしておく権利

**すべてを決める必要はない。** 決めていないことは `## 未決` 節に書いて放置してよい。

未決を潰さないまま先に進めるのは悪いことではなく、むしろ「決めなくても作品が作れる」ことの確認になる。作品を作る過程で必要になったものだけ決めれば、決めた設定が必ず使われる。逆に、使われる当てのない設定を先回りして全部決めると、その大半は死蔵される。
