# まだ分かっていない語

資料の中で、説明なしに使われている語。別のところで定義済みという前提で書かれている。

**推測で `world/` に書かない。聞くか、資料を待つ。**

- **媒体** — 妖怪が依り憑く物。核・外殻と並ぶ基礎語として扱われている
- **条件戦** — C級以上の戦い方。条件を踏む／遮断する
- **領域存在** — 恐怖の館系のことか
- **空核** — 呪具の部品らしい
- **霊脈** — 土地の側の何か
- **認識干渉 / 精神汚染** — 効かされると進路が変わるほどのもの
- **違法民間 / 裏市場** — 呪具の闇市場と繋がるはず
- **禁則領域 / UNKNOWN** — 触れてはいけない何か
- **式神**
- **群体存在**
- **標準霊装 / 身代わり呪具** — 生徒の装備か
- **特殊A級** — [[char:bug]] が該当。保留中

数値側の語（**ステータス**、**HP**、**人間性**）は `world/` ではなく `projects/` の話。
`world/` に書くのは現象だけ（例：縄張りの中にいると人が削られる）。
