# source — 元資料

**ここは原資料の置き場。`world/` とは役割が違う。**

| | |
|---|---|
| **`world/`** | **本筋。** 再構成された設定。ここが正 |
| **`source/`** | **元資料。** 加工していない原文を節ごとに分割しただけ |

## 原則

- **`source/` の文章を `world/` へそのまま持ち込まない。** 読んで、噛み砕いて、主題側のファイルへ配る
- **`world/` と食い違ったら `world/` が正。** 原文の記述より、後から確定した設定が優先する
  - 例：`LSC-05` に「卒業時にD級相当の実務資格を目指す」とあるが、実際は支援職はE級のまま卒業する（→ [[concept:taimashi-school]]）
- **`source/` は増える。** 資料が足りないと感じたら、まずここを検索する
