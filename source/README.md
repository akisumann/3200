# source/ — 一次資料

**作者が自分の形式で書いた設定ファイルを、そのまま置く場所。**

## ここが正典の本体

`world/` は、この `source/` を読み解いて整理・相互参照した**派生物**。**食い違いがあれば、常に `source/` が正しい。**

`world/` 側の記述は、`source/` を読まなくても全体像が掴めるようにするための索引・要約・横断整理として扱う。

## LIGHT ファイル形式

作者の形式。番号付きで、各ファイルが以下を持つ。

- **TAGS** — そのファイルが扱う主題
- **ROLE** — このファイルが何のためにあるか
- **LHI-xx** のような節番号
- **記述方針** — このファイルを書き足すときの禁則

**この形式は AI に読ませる文脈ファイルとして設計されている。** 事件の派手さより「制度・思想・社会運用へ何を残したか」を書く方針が明記されており、`world/` を書くときもその姿勢に従う。

## まだ受け取っていない資料

ファイル内で言及されているもの。**あれば渡してもらう。**

- `41_LIGHT_RELIC_HISTORY` — 歴史的遺物、神器、特殊A級遺物、禁書、国家基盤遺物
- 番号から見て **00〜39 にも相当数あるはず**

## 扱いの注意

- **原文を書き換えない。** 誤字であっても直さない（直すなら作者が直す）
- 引用するときは出典（ファイル名と節番号）を添える
- `world/` 側で解釈や補足を書くのは構わないが、**一次資料の記述と混ぜない**
