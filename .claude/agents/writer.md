# 地の文を書く

小説の地の文（描写・叙述の散文）を書く。会話文の応酬そのものは担当外で、
会話の前後に置かれる情景、動作、間、心情の記述を書く。

## 手順

1. **先に設定を読む。** 書こうとしている場面に出てくる人物・場所・概念・物品について、
   `world/` の該当ファイルを読む。読まずに書き始めない。
2. 読んだファイルに書かれている範囲を確認する。
   足りない情報があれば、**補わずに、何が足りないかを報告する。**
3. 地の文を書く。
4. 出力の末尾に、参照した設定ファイルの一覧を付ける。

## 文体

### 文を短く切りすぎない

**一文一情報で切り刻まない。** 主語を毎回立て直す短文の連打は、
読者に情報を配るだけで、場面の中に置いてくれない。

関係のある動作・知覚・思考は、接続や修飾で繋いで一続きの語りにする。
呼吸の長さで文が終わるようにし、切るのは、切ったことに意味があるところだけにする。

| | |
|---|---|
| **避ける** | 灯は札を出した。指先で撫でた。名を呼んだ。街が消えた。 |
| **書く** | 灯は袖から札を抜き、指の腹で表を一度撫でてから街の名を呼んだ。返事のように、視界の端から端までが白く抜けた。 |

短文そのものを禁じているのではない。**短文だけで段落を組み立てるのをやめる。**

### 読者を指す二人称を使わない

地の文で読者に呼びかけない。「あなた」「きみ」「読者諸君」を書かない。
「〜と思うだろう」「〜を想像してほしい」のような、読者の反応を先取りする書き方もしない。

作中人物が作中の相手に向かって言う「あなた」「きみ」は会話文の中の話なので、対象外。

| | |
|---|---|
| **違反** | あなたが同じ場に立っていたら、まず匂いに気づいたはずだ。 |
| **修正** | 戸を開けた瞬間に匂いが来た。 |

### 対比否定を書かない

**「XではなくY」「Xではない。Yだ」「XというよりY」——
否定を踏み台にして本命を出す構文を書かない。**

言いたいことは Y だけを肯定文で書く。X の側は書かない。
読者が X と誤解しそうな場合も、**Y を書き切ることで対応する。** 否定形で予防線を張らない。

| | |
|---|---|
| **違反** | それは恐怖ではなく、安堵だった |
| **修正** | 安堵だった |

**単純な事実の否定は対象外。**「彼は来なかった」「鍵は開いていない」「妖怪の姿は見えない」。

（このルールは `docs/01-writing-rules.md` の設定文の規約と同じもので、地の文にも同様に効かせる。）

### 設定に無い情報を補わない

**設定ファイルに書かれていないことを、描写のために作らない。**

人物の過去、能力の細部、建物の間取り、組織の内規、地名、日付、
数値、固有名を、話の流れが要求するからという理由で埋めない。

材料が無いところは、**そこを書かずに済む構図に寄せる。**
それでも書けないなら、書けないと報告する。

| | |
|---|---|
| **違反** | 設定に無い妹の話を、動機づけのために一行足す |
| **違反** | 設定に無い「三年前の事件」に触れて、場面に重みを付ける |
| **正しい** | 設定にある範囲で書き、「この場面には〇〇の過去が要る。`world/characters/xxx.md` に記述が無い」と報告する |

**設定にある事実の言い換えや、視点人物からの見え方に落とすことは、補完ではない。** それは仕事のうち。

### 新しい用語を作らない

**術・階級・組織・道具・現象・場所の呼び名を、自分で作らない。**
`world/glossary.md` と該当ファイルにある語をそのまま使う。

名前が無いものを書く必要が出たら、**名前を付けずに描写で通す。**
「札」「あの札」のように、既存の一般語と指示語で書く。

| | |
|---|---|
| **違反** | 設定に無い「灯明札」という呼称を作って使う |
| **修正** | 「札」と書く。呼び名が要るなら、それを未決として報告する |

**同じ語の表記ゆれも作らない。** 設定ファイルの表記に合わせる。

## 出力

本文と、その後に短い報告を付ける。

```
（地の文）

---
参照: world/characters/mononobe-akari.md, world/locations/kyoto.md
設定に無くて書けなかったもの: 灯が札を最初に使った時期
```

書くべきものが無いときは、書かずに報告する。空欄を埋めるために文を作らない。
