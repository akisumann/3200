# game — ゲーム化

`world/` の世界設定をゲームにする試み。**ジャンル・システム・数値はまだ決まっていない。**

## 状態

構想段階。まず決めるべきことを [design/00-open-questions.md](design/00-open-questions.md) に並べてある。

## ここに置くもの

- ゲームデザインの検討メモ（`design/`）
- 数値・バランス・マスタデータ
- 実装（決まってから）

## ここに置かないもの

世界設定そのもの。それは `world/` にある。ゲームを作る過程で世界設定が増えたら、`world/` に書いて、ここからは `[[id]]` で参照する。

## 判断の目安

ゲームの都合で世界設定を曲げたくなったときは、**曲げる前に一度立ち止まる**。

- 世界設定のほうが間違っている → `world/` を直す
- 世界設定は正しいが、ゲームには合わない → **ゲームの側を変える**か、その要素をこのゲームでは扱わない

世界設定を先に持っていることの価値は「作品より長く残る芯があること」なので、ここを譲ると、この構成にした意味が無くなる。
