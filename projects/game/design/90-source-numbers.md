## 同格の敵の耐久

| 等級 | HP |
|---|---|
| E級相当 | 5〜19 |
| D級相当 | 20前後 |
| C級相当 | 40前後 |

**基準の考え方。** 同格帯の敵は、PCと同程度の基礎耐久を持つ。

**弱点看破・核特定・媒体直撃に成功しても、同格の敵を一撃で瀕死や即決着にしない。** 弱点直撃はこう扱う。

- HPの大幅減少
- 外殻破損
- 能力低下
- 移動制限
- 条件発動の弱体化
- **封印・交渉・追撃の解禁**

**撃破には、原則として2〜4手程度の有効行動が要る。**

**一撃決着を認めてよい例外。** 未定着存在。E級以下。非戦闘型妖怪。事故呪物。**核が極端に脆い。** 事前準備が十分。上位者や特効装備による処理。**戦闘ではなく後始末として扱う場面。**

**例外を使う場合は、なぜ一撃で崩れたのかを描写の中で示す。**

## 接敵後の圧力

**同格帯の敵は、接敵後にPCへ実害を与える。** D級相当ならHPダメージ、拘束、侵食、妨害で行動選択に圧力をかける。

**同格の敵を、PCが一方的に解析・攻撃・封印できる存在として扱わない。**

> **接敵前は情報戦でよい。接敵後は、敵も能動的に行動する。**

## 出現比率

### D級以下

| | |
|---|---|
| 物理妖怪・害獣型 | **45%** |
| 認識怪異・ホラー主題型 | **25%** |
| 群体・縄張り型 | 15% |
| 呪具事故・民間事故 | 10% |
| 共存ズレ・契約ズレ | 5% |

**認識怪異を25%に抑えているのが趣旨。** 低級案件がホラー型へ偏りすぎるのを防ぐための比率。**世界設定の側では「D級以下は危険生物の延長」として `world/concepts/grades.md` に入れてある。**

### C級以上

**比率ではなく条件で縛っている。**

- 妖怪能力を必ず中心に置く
- 縄張り・媒体・条件・伝承要素を持たせる
- **伝承全部盛りはB級以上から**
- **C級は一要素だけが尖る**
- 等級相応の基礎スペックまたは対処難度を必ず持たせる

## 等級別の身体能力

**`world/concepts/grades.md` の火力の階段と、ほぼ同じ内容。** 表現が現場寄りになっている分だけ、こちらに残す。

| 等級 | |
|---|---|
| **F級** | 一般人でも注意すれば対処できる小動物・弱霊障程度 |
| **E級** | プロボクサー、格闘家、高度訓練警備員並み。**一般人が素手で対応するのは危険** |
| **D級** | 大型猛獣に属性攻撃・毒・外殻・突進・弱い霊障が乗った程度。**「少し怖いだけの低級怪異」として扱わない** |
| **C級** | 車両、コンクリート壁、道路設備、建物構造の一部を破壊し得る。**通常の遮蔽物を信用しすぎない** |

| **A級** | 条件が噛み合えば山破壊級、または山岳級地形を不可逆的に変質させ得る。**ただし常時その火力を出せるとは限らない** |
| **特殊A級** | **単純な身体能力では測らない。**文明・信仰・歴史・認識・災害性を含めて扱う |

## 使うときの注意

**この数値をそのまま採用するかは未定。** [00-open-questions.md](00-open-questions.md) の 1〜6 が決まる前に数値へ寄りかかると、**この数値の形にゲームが決まってしまう。**

**特に、レベルとHPが存在すること自体が一つの設計判断になっている。** 世界設定の側は「等級は勝敗保証ではない」「相性ひとつで等級差は何段でも飛ぶ」で通っているので、**HPを削り合う形にすると、その部分が表現できない。**

**逆に、ここで拾える発想もある。**

- **弱点直撃を「即死」ではなく「封印・交渉・追撃の解禁」にしている**のは、世界設定の「倒すことと調伏することは別」と噛み合う
- **接敵前は情報戦、接敵後は相互行動**という分け方は、`world/concepts/battle.md` の三猿・条件提示・口八丁とそのまま繋がる
- **「なぜ一撃で崩れたのか」を毎回説明させる**のは、消失反応の扱いと同じ姿勢
