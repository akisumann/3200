# projects/ — 派生物

`world/` の設定を素材にして作るもの。ゲーム、小説、TRPG、公開用 Wiki など、何でもここに1ディレクトリずつ増やす。

```
projects/
  game/       ゲーム
  novel/      小説（例。まだ無い）
  trpg/       TRPG（例。まだ無い）
```

## 原則

**`projects/*` は `world/` を読むだけ。**

- 数値、仕様、システム、演出、章立て — 特定の作品でしか意味を持たないものはすべてここ
- `world/` の内容と食い違う記述をここに書かない
- `world/` の記述が間違っていると気づいたら、`world/` を直す（`projects/` で上書きしない）

## 「この作品での解釈」

`world/` は決めきっていないことがあり、それは正しい状態です（→ [docs/02-canon-policy.md](../docs/02-canon-policy.md)）。作品を作るには決めざるを得ないので、そのとき決めたことは各作品のディレクトリに **「この作品での解釈」** として書きます。

やがて複数の作品で同じ解釈に落ち着いたら、そのとき `world/` に昇格させればよい。逆に、一作品の都合で決めたことを最初から `world/` に入れると、次の作品がその制約を引きずります。

## 増やすとき

新しい方面を始めるときは、ディレクトリと README を1つ作るだけで十分です。構成を先に決める必要はありません。
