## 概要

**[[concept:taimashi]] の「民間は、産業そのもの」を、名前のある会社として置いたもの。**

**一次から三次まで、超常はあらゆる産業に薄く乗っている。** **その中で、A級が所属している規模の会社をここに並べる。**

> **全部 repo 側で作ったもの。** **出典に社名は一つも出ていない。**
> **[[concept:taimashi]] にある業種の一覧から、実在しそうな形に起こした。**

## 前提 — 超常だけの産業は、ほとんどない

**術が使えるのはE級以上の約22万人**（→ [[concept:grades]]）。**この人数であらゆる産業に散っている。**

**だから「超常企業」という独立した業界があるわけではない。** **普通の会社の中に、超常部門がある。あるいは普通の業界の中に、超常を扱う会社が数社ある。**

> **大量生産は普通の技術でやる。**
> **力が入るのは、量が要らないところ。**

**以下の会社も、看板は普通の業種で出ている。**

## 雷紋通信

**通信霊障とネット怪異の最大手。**

| | |
|---|---|
| **表の看板** | 通信インフラの保守 |
| **中身** | **回線上の怪異対処と、ネット系妖怪の運用** |
| **A級** | **有坂 湊**（→ [[concept:a-rank]]） |

**社名は雷獣に由来する**（→ [[char:raiju]]）。**1990年代から2000年代初頭の『通信霊障管理計画』で、[[faction:reimusho]] が雷獣群の半管理化に成功している。** **その周辺で立った会社。**

**[[concept:taimashi]] の「ネット系妖怪を使った情報系」がここ。** **現代の思念から湧いた妖怪は歴史が浅く弱いが、弱いことと使えないことは別。**

> **生まれたばかりの妖怪が、生まれたばかりの産業で働いている。**

**そして [[char:nostradamus]] のような認識災害が起きたとき、最初に見えるのはこの会社の観測網になる。**

> **repo 側の読み。** **国の側に同じ規模の観測網があるのかは書かれていない。**

| | |

**[[concept:daily-life]] の一般人が住んでいる建物にも、たいていどこかで関わっている。**

## 宵市

**妖怪向け興行の会社。**

| | |
|---|---|
| **表の看板** | 芸能事務所・イベント興行 |
| **中身** | **妖怪社会向けの巡業、配信、イベント** |
| **A級** | **宗像 累**（→ [[concept:a-rank]]） |
| **所属** | **[[char:shinigami-idol]]** |

**[[event:hyakki-yako-attempt]] の主導者だった死神の巡業を、この会社が回している。**

**[[faction:reimusho]] が直接抱えているのではない。** **監視は国、興行は民間。**

> **[[faction:reimusho]] は統治者ではなく調整者**（→ 同）。
> **ガス抜き装置を、国が自分で運営していない。**

**そして [[concept:taimashi]] の三次産業一覧に「観光、芸能、配信」「契約妖怪サービス」がある。** **制度としては、その枠に収まっている。**

### 観客が妖怪なので、普通の興行会社にはできない

**古参の大妖怪が集まる会場を運営することになる**（→ [[event:hyakki-yako-attempt]]）。

**だからA級が要る。**

> **repo 側の読み。** **なぜ民間に投げているのかは書かれていない。**
> **国が芸能事務所をやるより外に出したほうが早い、という話にも読める。**
