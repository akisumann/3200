## 概要

日本にある、霊的なものを扱う**省庁**。現実の日本にはないが、この世界の日本にはある。

「現実世界プラスアルファ」のアルファを、行政の側で担っている部署。

**妖怪が特殊な権利を得るための公的手続きを管轄するのは、この霊務省。** → [[concept:legal-status]]

日本の人間A級は**二十人弱**で、国・神社旧家・民間におおむね三分の一ずつ散っている → [[concept:a-rank]]。霊務省側では、**六地区長がA級戦力の中核**になる。

## 相手が人間でないことを分かっている役所

**霊務省は、妖怪が人とは違う価値観・感情・感覚を持っていると知っている。そのうえで、それを踏まえた契約をきちんと結ぶ** → [[concept:legal-status]]

融通の利かない役所でも、妖怪を人間扱いして失敗する組織でもない。**噛み合わない相手と契約を結ぶ実務の蓄積を持っている。**

手続きの中身は千差万別で、個体ごとに条件が違う。つまりこの官庁の仕事は、**書類を受け付けることではなく、相手を見て条件を組み立てること**になる。

## 成り立ち

有史以来ずっと妖怪がいる世界であり、日本の歴史そのものは現実とほぼ変わらない。

**この省を作ったのは [[faction:shrines]] と [[faction:old-houses]]。** 元々は退魔のすべてをあちらが担っていて、そこから国の側が分かれた。**霊務省は、伝統の側が自ら作った器**ということになる。

だから国と伝統は、監督する側とされる側という関係ではない。**作った側と作られた側**。

いつ・どういう経緯で今の形になったかは未決。

## 統治者ではない。調整者

**日本超常社会を完全統制していない。**

> **統治者というより、現代日本超常社会の巨大な調整者、規制者、緊急介入者、最後の責任者。**

**古社、旧家、地方勢力、民間超常企業、契約妖怪、協力妖怪、地域祭祀組織が、強い独立性を持って存在している。**

**だから運用が命令一本ではない。** 契約、利害調整、相互監視、委託、協力関係で成立している。

**そしてこの認識は、霊務省の内部でも共有されている。**

> **国家が管理しているのは超常社会全体ではなく、その一部である。**

### 前に出る条件

**公共性、危険度、法規、広域性、国家責任が絡む時。**

| 直接関与しやすい | |
|---|---|
| 公共安全 / 超常災害 / 危険存在の監視 / 危険呪物の規制 | |
| **等級認定** / 公的結界網の監督（→ [[concept:barrier-network]]） | |
| **学校、病院、駅、行政施設など公共性の高い場所の霊障** | |
| 複数自治体へまたがる広域案件 / 違法超常行為 | |
| **国家機密級呪物 / 特殊A級案件 / 国際超常外交 / 戦略級危機管理** | |

**一般家庭の軽微な霊障、店舗の通常霊障対策、企業施設の霊的保守、民間依頼の除霊、地域祭祀補助は、必ずしも直接担当しない。**

### 独占していない領域

**呪具市場、神秘素材流通、超常物流、企業霊障対策、民間結界施工、妖怪警備、超常技術の商業利用、契約存在を用いた民間サービス、要人護衛、超常コンサルティング、地域祭祀、産業超常調査、民間除霊業務。**

**認可、監督、規制、公的委託、緊急介入で関与するだけで、自ら運営しているわけではない。**

> **万能国家による完全管理社会ではない。**
> **現代社会の制度、市場、契約、利害、労働問題の上で、超常を無理やり運用している社会。**

#### 線は、はっきり引かれている

**「たまたま手が回っていない」ではなく、方針として引いてある。**

> **国は、民間超常産業を事業主体として運営しない。**

**国が関与するのはこの範囲。**

**公共安全。規制。認可。監督。犯罪の取締り。災害対応。緊急介入。戦略級の危機管理。**

**強力な中央行政機関ではあるが、超常社会全体の事業主体ではない。**

**そして行政運用そのものも、超常だから特別なのではない。** **権限の境界、手続き、記録、責任、委託、監査、補償、事後処理 —— 現代行政の延長で動いている。**

**[[concept:taimashi]] の民間産業が一次から三次まで広がっているのは、この線があるから。** **国が抱え込まないので、市場が成立している。**

### 不正が出たら、それは行政の腐敗

**この社会には第三勢力が無い**（→ [[concept:taimashi]] の三系統、[[concept:overseas]]）。

**表向き第三勢力や独立勢力や超国家組織を名乗っていても、制度上・分類上は行政か民間のどちらかから逃れられない。** **裏社会も、大分類では民間の違法領域。**

**だから霊務省の内部で不正が起きた場合、それは「別の勢力」ではない。**

> **行政組織の内側の、腐敗と逸脱。**

**[[concept:taimashi]] の「犯罪者A級は三系統の内側に普通に潜んでいてよい」が、行政の側でも同じ形で成り立っている。** **外に敵の陣営があるのではなく、中に混じっている。**

### 省内にも、知っている層と知らない層がある

**[[event:hyakki-yako-attempt]] の真相を知っているのは、省の全員ではない。** **「真実を知るトップ層」という限定された層がいる**（→ 同）。

**この事件では、地区長の一人が黒幕で、決着をつけたのは民間だった。** **どちらも表の記録には残っていない。**

**その記録を維持しているのは、維持すると決めた層が省内にいるから。**

> **対外的な情報統制の話ではない。**
> **省の内側にも同じ線が引かれている。**

事件後、トップ層は決着をつけた民間の現実改変能力者 [[char:shibasaki-kei]] に地区長就任を打診し、断られている。

**ただし、断られたから地区長の席を空けるわけではない。** 特定の一人を強制的に就任させないことと、地区長を無人にしないことは両立する。柴崎が断った後、別のA級である斎木惺をすぐに据えた。

## 標準神秘と、非標準神秘

**霊務省が持っているのは、標準術式、制式呪具、一般封印技術。** **教育・量産・継承・運用効率を重視した、国家標準の神秘体系。**

**一方で、家系秘術、古代祭祀、特殊契約、神格関連術式、条件依存型の秘術、高危険呪物は、今も [[faction:shrines]] や [[faction:old-houses]]、地域の封印蔵へ分散して保管されている。**

**この二つが並立している。**

| | 役割 |
|---|---|
| **霊務省** | **標準化で社会を回す** |
| **古社・旧家** | **非標準神秘で穴を埋める** |
| **民間企業** | **商業と実務で現場を支える** |

> **この三者は対立することもあるが、相互依存している。**

**[[event:lupin-incident]] がその実演になっている。** 国家標準の認証体系が全滅した後、**穴を埋めたのは非標準の側**（地方の古社の巫女の神託）だった。

## 地区長

**各地区における霊務省側の最高責任者。必ずA級を据える。**

> **六地区あるなら、A級の地区長を六人置く。ここだけは戦力不足を理由に一段下へ落とさない。**

地区長は行政責任者であると同時に、その地区の**最終防衛戦力**でもある。そこが崩れたら後ろが無い。

### 欠員は最優先で埋める

死亡、封殺、失踪、引退などで地区長が抜けた場合、**まずA級を暫定で据える。** 正式な人事や所属整理は後からやる。

霊務省内に適任がいなければ、神社・旧家や民間のA級へ打診し、転籍・出向・兼任を含めて確保する。

> **A級の人事で一番先に守るのが、六地区長の六席。**

このため、A級全体が三系統に「だいたい三分の一ずつ」いても、**国側が常にきっちり六人とは限らない。** 地区長補充のたびに所属人数は動く → [[concept:a-rank]]。

### 順序は、強さが先

専門も地区の性格も、先に見ない。

**まずA級であること。** その上で、地区長として置ける者を選ぶ。

中部が山岳信仰の土地だから山向きのA級を選ぶ、という決め方ではない。**A級の中から人を据え、その人物の専門を地区運用へ組み込む。**

### 要件は、A級であることの次

戦闘能力だけでは務まらない。

指揮能力。**結界管理能力。政治的安定性。対外交渉能力。** 広域対応能力。**封印管理能力。** 民間・古社・旧家との調整能力。**高位妖怪との接触判断。災害時の被害抑制判断。**

公職側では、これらを教育・訓練で埋める。

#### クリアしていない者は、落とされずに缶詰にされる

実力だけで上がってきた者がいた場合、認定を取り消すより先に教育する。

> **まず座学の缶詰である。**

[[concept:taimashi-school]] が「強い退魔師を作る学校」ではなく「危険なことをしない学生を作る学校」であるのと、同じ姿勢。

**[[event:belzebub-war]] の後にフランスから来て、来日してすぐ地区長になった術者**（→ [[concept:a-rank]]）も、日本の指揮系統や結界網を覚えるため座学に詰められている。

**世間の認識は「地区長＝その地域最強格」。** 正確には、

> **その地域最強格であり、同時に一番面倒な責任を背負っている人間。**

### 地区長の下 — B級専門家

**各地区長の下に、B級を中心とした上位実働部隊が配備されている。霊務省保有で一地区に十人ほど。**

**そして全員が同じ仕事をできるわけではない**（→ [[concept:battle]]）。**海域封印のB級は地下侵食案件の代替にならない。認識災害対策のB級は群体制圧の代替にならない。**

**だから各B級は、自分の専門に該当する案件が出るたび、地区内の広域を駆け回る。**

> **ブラックである。**

**地区長の実務が、ここに出る。** **どこへ回すか、誰を休ませるか、誰を無理にでも呼ぶか。**

> **上位戦力の運用は、戦闘よりも勤務表と優先順位で地獄を見る。**

## 地域常駐 — D級とC級

**各都市・地域に常駐して、通常業務と初動対応を担う。**

地域怪異の対処、結界維持、初動対応、呪物管理、地域監視、通報対応、民間業者との連絡、神社・学校・病院・駅との連携、低〜中危険度案件の処理、**高危険度案件の上申。**

**常駐組が全部を解決するわけではない。** **仕事は、初動で被害を抑え、情報を集め、必要なら上位専門家へ繋ぐこと。**

> **現場で一番偉いのは、必ずしも一番強い人間ではない。**
> **その場で一番早く正しい部署へ電話できる人間であることも多い。**

## 資格も免許も、全部ここが出す

**当たり前のこととして、国が出している。**

| | |
|---|---|
| **[[concept:grades]] の判定** | 人にも呪具にも妖怪にも等級を振る |
| **[[concept:jugu]] の免許** | 呪具の購入・所持の免許 |
| **[[concept:taimashi]] の資格** | D級からの戦闘用退魔師の資格 |
| **妖怪の公的手続き** | → [[concept:legal-status]] |

**運転免許も医師免許も国が出すのと同じ。** 超常が公然と存在して省庁まである国で、これらが業界団体や神社の手にあるほうがむしろ不自然。

**ここにこの世界の温度が出ている。** 力は秘伝でも特権でもなく、**行政が扱う対象**として完全に制度に組み込まれている。妖怪が見えることも、呪具を買うことも、退魔師になることも、**役所の管轄**。

そして [[concept:grades]] の判定が「大体みんな肌感覚で分かる」ものである以上、この役所は**社会が既に知っていることを追認して記録している**のに近い。判定機関がなければ誰にも分からない、という制度ではない。
