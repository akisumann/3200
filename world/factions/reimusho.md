## 概要

日本にある、霊的なものを扱う**省庁**。現実の日本にはないが、この世界の日本にはある。

「現実世界プラスアルファ」のアルファを、行政の側で担っている部署。

**妖怪が特殊な権利を得るための公的手続きを管轄するのは、この霊務省。** → [[concept:legal-status]]

**日本のA級18人のうち6人が霊務省に属する** → [[concept:grades]]

## 相手が人間でないことを分かっている役所

**霊務省は、妖怪が人とは違う価値観・感情・感覚を持っていると知っている。そのうえで、それを踏まえた契約をきちんと結ぶ** → [[concept:legal-status]]

**ここがこの官庁の性格を決める。** 融通の利かない役所でも、妖怪を人間扱いして失敗する組織でもない。**噛み合わない相手と契約を結ぶ実務の蓄積を持っている。**

手続きの中身は千差万別で、個体ごとに条件が違う。つまりこの官庁の仕事は、**書類を受け付けることではなく、相手を見て条件を組み立てること**になる。

## 成り立ち

有史以来ずっと妖怪がいる世界であり、日本の歴史そのものは現実とほぼ変わらない。**この省の前身は相当古いはず**だが、いつ・どういう形で今の姿になったかは未決。

## 構造

### 全国を6つの地区に分けている

| 地区 |
|---|
| **東北** |
| **関東** |
| **中部** |
| **近畿** |
| **中国四国** |
| **九州** |

**この6区分が、この国の超常行政の骨組みになっている。** 霊務省は地区ごとに分かれて動いており、[[concept:taimashi-school]] の6校も**地区に一つずつ**。学校が6校なのは偶然ではなく、**行政の区割りがそのまま教育の区割りになっている**。

**中国と四国が一つになっているのが特徴的。** 現実の官庁でも中国四国をまとめて一管区とする例はあるので、行政区画としては素直な線。

### 地区で分けることの意味

**妖怪は土地に紐づく。** 逃しポイントも（→ [[concept:release-points]]）、土地神も（→ [[concept:land-god]]）、古社も旧家も、すべて場所から動かない。**だから超常行政は地区単位でしか組めない。**

これは警察が都道府県単位であるのと似ているが、**霊務省の区割りはもっと粗い**。47ではなく6。相手が県境で切れるものではないからこう置いた、と読める。

### ただし6区分は人口に対して均等ではない

**関東と東北では、人口が5倍近く違う。** それでも地区は一つずつ、学校も一校ずつ。

しかも**学校の定員は6校とも同じ450人**で、毎年出るD級も**どこも150人**（→ [[concept:taimashi-school]]）。**供給は人口に比例していない。**

つまり**関東地区の霊務局は、東北の数倍の人と妖怪を、同じだけの新人で捌いている**ことになる。**関東は慢性的に足りず、東北は相対的に手厚い。**

**この不均衡は制度の欠陥ではなく、土地を単位にした以上どうしようもないもの**として扱える。県ごとに割れば細かすぎ、全国一つでは土地に届かない。6という数はその間で落ち着いた線ということになる。

### 何を担っているのか

妖怪の手続きは確定。**では、これらもここか。**

- **[[concept:grades]] の判定** — 人と呪具に等級を振っているのは誰か
- **[[concept:jugu]] の免許** — 呪具の購入免許を出しているのは誰か
- [[concept:taimashi]] の資格
- 妖怪の登録・統計・危険な個体への対処
- [[faction:shrines]] や [[faction:old-houses]] との関係（監督するのか、協力するのか、頭が上がらないのか）

**これが全部ここなら、霊務省は権限を持ちすぎている。** 権利を与え、格付けを決め、免許を出し、資格を出す。そのどれか一つでも他所にあるなら、そこに権限争いが生まれる。**どちらでも物語になるので、決めどころ。**
