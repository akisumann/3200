## 概要

現実の日本にもある神社だが、この世界では**霊力・呪力の担い手として強い**。宗教施設であると同時に、実効的な力を持つ存在。

**日本のA級18人のうち6人が、神社と旧家の側にいる**（[[faction:old-houses]] と合わせて6人）→ [[concept:grades]]

**そして祀られている神は、制度上は妖怪である** → [[concept:kami]]。神と妖怪は同じもので、呼び方が違うだけ。出雲大社レベルの有名どころに至ってはA級相当の [[concept:land-god]] にあたる。

**神社とは、高位の妖怪を祀り、その思念を供給し続けている施設**ということになる。この世界で神社が強いのは、信仰の権威があるからだけではない。

**そして参拝者は、そこで普通に会える。** 一般人に姿は見えないが、**そもそも強さの桁が違うので、見えなくても何かしらでがっつり実感できる**。**初詣は、B級以上の妖怪に会いに行く行事でもある** → [[concept:daily-life]]

**「霊験あらたか」がこの世界では文字どおりの意味を持つ。** 同じことは**寺**にも言える（神社仏閣）。

## ここが源流

> 以下は [[faction:old-houses]] にも共通する内容。**重複を避けるため**、こちらに書いて向こうから指している。**二つがどう違うかは未決。**

> **これは「ひとまとめにした場合」の役割と歴史の話。** 神社も多少ばらばらで、旧家も相応にばらばら。**まとまった一つの組織があって、それが以下を担っている、という意味ではない。**

**元々、退魔のすべてを神社と旧家が担っていた。**

そして今ある他の二系統は、どちらもここから出ている。

| | |
|---|---|
| **[[faction:reimusho]]（国）** | **今の霊務省を作ったのが、ここ** |
| **民間の [[concept:taimashi]]** | **民間が結構多いのも、元はここが源流** |

**つまり三系統は横並びではない。** A級18人が6・6・6で均衡しているのは、対等な三者が拮抗しているからではなく、**一つの源流と、そこから分かれた二つ**がその形に落ち着いているということ（→ [[concept:grades]]）。

### そして今も、才能はここから出てくる

**分かれたのは組織であって、人の出どころではない。**

> **力のある人間は、歴史を辿れば大抵このあたりに行き着く。**

**だから国の側にも民間の側にも、たどれば神社旧家に届く人間が普通にいる。** **今どこに所属しているかと、何を受け継いでいるかは別。**

**判明している地区長二人がそれ。** [[char:suwa-shizuka]] は諏訪大社系の神降ろしを使い、[[event:hyakki-yako-attempt]] の催眠系術者は旧家の秘匿術式を使う。**国の最上位が伝統側の術で戦っているが、これは越境でも例外でもない。**

**そしてこれが、6・6・6が崩れずに戻ってくる理由にもなっている。** [[concept:taimashi]] の引き抜き合戦で人はいくらでも動くが、**動いている人間の多くが、元をたどれば同じところから出ている。** **三つに分かれた先で混ざっても、供給源が一つなら比率は戻る。**

### 今も一手に担っているもの

分家を出したあとも、手放していないものが山ほどある。

| | |
|---|---|
| **秘匿技術・高等技術** | 山ほどある |
| **[[concept:land-god]] との密接な関係** | |
| **[[concept:taimashi-school]] の設立** | 退魔学校を作ったのもここ |
| **[[concept:release-points]] の管理** | 逃し場の管理 |
| **気難しい妖怪たちとの干渉役** | 話が通じにくい相手との間に立つ |
| **妖怪の里との交流** | → [[concept:youkai-land]] |
| **封印されている高位妖怪の管理** | いくつかある。ド級に有名なのが [[char:tamamo-no-mae]]（殺生石）。**手入れの要否はものによる** |
| **古い文献の管理** | |

**技術も、土地も、教育も、封印も、記録も、対妖怪の外交も、ここにある。**

ただし**どれも一箇所に集まってはいない。** ばらばらな神社とばらばらな旧家に散らばっていて、**合計するとこうなる**というだけ。窓口も、司令塔も、名簿もない。

国が作られ、民間が広がったあとも、**根の部分は動いていない**。霊務省は制度と権限を持ち、民間は数と自由を持っているが、**元手を持っているのはここ**ということになる。

**「しがらみが強くて面倒」**（→ [[concept:taimashi]]）の中身も、これで見えてくる。ここに属するということは、**秘匿技術と、土地神との縁と、封印と、妖怪との約束を引き受ける**ということ。面倒なのは人間関係だけの話ではない。

## 神社の本業は、対話

**特に神社は、妖怪との対話をメインでやっている。**

[[concept:youkai-land]] との交渉役がそれ。**代理人として妖怪の集団と話をつけ、契約を取ってきて、国の権利と保護を適用させている。**

> **これは神との交信の技術と同じ。**

**神と妖怪は同じもの**（→ [[concept:kami]]）なのだから、当然そうなる。**祀るために磨いてきた技術が、そのまま交渉の技術**になっている。

**神社が「強い」ことの中身が、ここで一つ具体化する。** 火力ではない。**話が通じない相手と話せること**が、この勢力の本業。

そして [[faction:reimusho]] が「相手が人間でないことを分かっている役所」であるのは、**元をたどればここの技術**ということになる。国を作ったのが神社と旧家である以上（上記）、**役所の対妖怪の作法は、祭祀から降りてきている。**

### 神降ろしは、その極北にある

**対話の先にあるのが、降ろすこと。**

[[char:suwa-shizuka]] の扱う高位の降神儀式がそれ（詳細は秘匿指定）。**神と話をつける技術を突き詰めると、神を身に入れるところまで行く。**

**そして降ろした神格を、即死級の攻撃の受け皿として差し出すという運用まである。** 俗に「神様に押し付ける」。

**神と妖怪を分ける線が無い**（→ [[concept:kami]]）以上、これは**妖怪と契約して力を借りるのと構造が地続き**ということになる。神社が対妖怪の技術を持っているのではなく、**同じ一つの技術が両方に効いている。**

### 照合ではなく、教えてもらう

**[[event:lupin-incident]] がその実例。** 国家の認証技術が全滅した相手を、最後に捕まえたのは地方の古社の巫女だった。**神託で対象を特定し、確認もせずに殴った。**

> **「神があれだと言ったので殴った」**

**照合は「本物かどうかを手続きで確かめる」技術で、それは全部破られた。** 通ったのは**「あれだ」と教えてもらう**という別の筋で、**確かめていないから偽装のしようがない。**

**制度化された技術が全滅した場面で、制度化されていない古い関係だけが残った。** 神社が今も源流であり続けている理由の一つがここに出ている。

## 非標準神秘を抱えている側

**[[faction:reimusho]] が持っているのは、標準術式・制式呪具・一般封印技術。** 教育と量産と運用効率のために標準化された体系。

**そこから外れたものが、こちら側にある。**

**家系秘術、古代祭祀、特殊契約、神格関連術式、条件依存型の秘術、高危険呪物。** **地域の封印蔵へ分散して保管されている。**

> **霊務省は標準化で社会を回す。古社・旧家は非標準神秘で穴を埋める。**

### 持っていることと、売れることは別

**秘匿神秘は、原則として市場に流れない。**

**家、土地、祭祀、血統、契約、封印条件と強く結びついているから。** 市場に流すことは技術の売却ではなく、**家の義務、土地の均衡、封印維持、妖怪契約、地域共同体の安全を崩す行為になり得る。**

> **秘匿神秘は、売り物ではなく、継承物、封印責任、契約責任。**

**そして国家が無理に回収・標準化しようとしても崩れる。** 封印条件、土地契約、血統制約、祭祀継承、地域妖怪との均衡。**だから [[faction:reimusho]] は、最も危険な秘匿神秘へ常に直接介入できるわけではない。**

**平時は古社・旧家・地域主体による管理が維持され、霊務省は監督、連絡、記録、協力要請、緊急介入にとどまる。**

#### 市場に出てきたら、それ自体が異常事態

**秘匿神秘が市場へ流れる時、背景にあるのはだいたいこれ。**

**相続争い、旧家の没落、盗難、裏取引、封印の破損、管理者の不在、非合法な流出。**

**問題なのは国家承認の有無ではない。** **責任主体が消えること。本来の継承者や管理者を無視すること。封印条件を破ること。危険性を偽装すること。盗品として流通すること。事故時に補償も後処理もできないこと。**

**国家の側が届かない場所を埋めているので、対立することはあっても切り離せない。** [[event:lupin-incident]] で国家の認証体系が全滅した後に通ったのが神託だったのは、**この分担がそのまま出た形。**

## 秘匿技術は、本当に秘匿されている

**封印を例に取ると、二段になっている。**

| | |
|---|---|
| **規格化された封印法** | **今も使える。** 一定レベルまでなら現代の人間でも掛けられる |
| **秘術の領域** | **A級相当まで来ると、規格化された方法では届かない。** ここは秘術であり、**そもそも概要すらシークレット。外からは不明** |

**「概要すら」というのが要点。** 手順が秘密なのではなく、**何をどうする類のものなのかという枠組みごと外に出ていない。**

だから [[char:tamamo-no-mae]] を封じた殺生石が**どうやって作られたのかも分からない**。今の人間に同じことができるのかも、外からは判断がつかない。

> **秘術の中身も、その概要も、外から知る手立てがない。** **知られていないことが、この世界の状態そのもの。**

**これが「秘匿技術・高等技術が山ほどある」（上記）の実際の重さ。** 死蔵しているのでも出し惜しみしているのでもなく、**外形すら開示しないという形で保持されている。**

### 隠れているのは技術だけ。出来事はむしろ一番有名

**A級相当の被害は、この世界で最も分かりやすく、最も有名。**

何が起きたか、どれだけの被害が出たかは、**誰もが知っている**。[[char:tamamo-no-mae]] のように、名前だけで通じる。等級が肌感覚で共有されている社会（→ [[concept:grades]]）で、**その頂点の事例こそ最もよく知られている。**

**外に出ていないのは、収めた側の技術だけ。**

| | |
|---|---|
| **何が起きたか** | **一番有名。誰でも知っている** |
| **どう収めたか** | **秘術。概要すら出ていない** |

**この世界では、被害が語り草になり、対処が語られない。** 玉藻前の名は誰でも知っているのに、殺生石をどう作ったかは誰も言わない。

そしてこれは**思念の話にも繋がる**（→ [[concept:shinen]]）。A級妖怪が有名なのは、大勢が同じ像を共有しているからで、**その知名度こそが強さの由来**。被害が語り継がれることと、その妖怪が強いことは、同じことの表と裏になっている。
