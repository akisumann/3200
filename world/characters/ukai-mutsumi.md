## 概要

**A級退魔師。神社・旧家を中心とする伝統側の一人**（→ [[concept:a-rank]]）。**台帳上の分野は高位交渉。**

**歌が、そのまま交渉の手段になっている。** 高位の妖怪へ物を言う形として噛み合っているので、**分野名はここで合っている。**

**歌で、相手も、飛んでくる攻撃も、世界の決まりも封じる。**

**通称「歌詠み」「古今の人」。**

> **一曲で済ませましょう。**

## 封じ歌 — この人の全部が一つの歌から出ている

**言霊に近い、封印に寄った術。** **特殊な歌で、相手を縛り、封じる。**

**耳で聞く音ではない。** **言葉そのものの力で届いている。**

| | |
|---|---|
| **届く距離** | **大声が届く程度。半径約200m** |
| **真空の中** | **届く。**音が伝わらなくても、その距離までは効き続ける |
| **できること** | **封じる。**止める、閉じる。**世界に新しい決まりを足すことはしない** |

**攻めも、守りも、地形を割るのも、全部この一つの歌の別の出口。**

### 近いほど、深く封じる

**歌は、相手や封じる場所に近ければ近いほど、封印の精度と出力が上がる。**

> **間近で歌ったときが、一番強い封印になる。**

**だからこの人は、最後に歩いて寄っていく。**

## 力の出どころ

**長良川の流域で、鵜飼を家業にしてきた旧家**（→ [[faction:old-houses]]）。**封印の歌を、家の秘術として伝えている。**

**家では、古今和歌集仮名序のこの一文を、歌の効き目を書いたものとして扱っている。**

> **力をも入れずして天地を動かし、目に見えぬ鬼神をもあはれと思はせ**

**技の名前は、ここから取られている。**

| 仮名序 | 技 |
|---|---|
| **力をも入れずして** | **封印防御** |
| **天地を動かし** | **天地の歌** |
| **目に見えぬ鬼神をもあはれと思はせ** | **鬼神の歌** |

## 鬼神の歌 — 妖怪への本命

**妖怪を縛って、封じる。**

**封じるのは、力を丸ごとでも、行動の一部だけでもいい。**

- **暴れる力**
- **襲いかかる力**
- **「この谷から出る力」**

**選んで、それだけを封じられる。**

> **相手は相手のまま。封じられたことだけが、できなくなる。**

**だから、戦わせずに終わらせられる。**

### 息がかかる間合いで歌う

**A級を一番深く封じるときは、目の前まで行く。**

**封印防御で身を守ったまま歩み寄り、息がかかる間合いで歌う。**

**真空にした河原で、A級の鬼が音のない歌に膝をついた。**

## 力をも入れずして — 封印防御

**歌っている間、飛んでくる攻撃を全部封じる。**

**術も、呪も、物理も問わない。** **届く前に、封じられて無力化する。**

> **攻めの歌と、守りの歌が、同じ一曲。**

**歌い続けている限り、この人には何も届かない。**

## 天地の歌 — 世界の決まりを封じる

**物理法則の一部を選んで、封じる。**

**範囲は、歌の届く半径約200mの内側。**

| 封じるもの | 起きること |
|---|---|
| **重力** | **無重力になる** |
| **空気** | **真空になる** |

**河原に展開した敵の術者部隊を、歌の届く範囲の重力ごと封じて、宙に浮かせたまま一曲を歌い終えた。**

### 山を割る光と爆発

**天地の歌の使い方の一つ。**

**封じるのは、歌の届く200m以内だけ。** **ただし、その結果として起きた光の柱や爆風は、そこから先へ物理的に飛んでいく。**

> **足元の200m内で何かを封じた一節ののち、光の柱が飛び出して稜線を抜き、向こうの尾根を粉砕した。**

**本人は封印防御の中にいるので、無傷。袖には塵一つ付いていない。**

**何を封じているのかは、本人が説明しない。** **物理に詳しい者によれば、何を封じればこうなるかの候補はいくつもあるらしい。** **どれが正しいかは分からない。**

## 使い分け — 物理は人と土地に、歌は妖怪に

**思念でできた妖怪には、物理だけの攻撃は効きが薄いことが多い**（→ [[concept:youkai]]）。

**だから光と爆発は、使う先が決まっている。**

| | |
|---|---|
| **対人戦** | **そのまま効く** |
| **地形破壊** | **土地が外殻になっている領域型の妖怪は、その土地を消せば体の一部を削れる**（→ [[concept:core-layer]]） |
| **妖怪の本体** | **鬼神の歌で縛って封じる** |

### 地図から消して、それから歩いて寄る

**敵対A級の領域になっていた廃村の入口に立って歌った。**

**村の中から謎の爆発が弾け、廃村は地図から消えた。**

**外殻を削られて縮んだ本体に歩み寄り、鬼神の歌で「この谷から出る力」を封じて帰った。**

> **爆発で削り、歌で封じる。**
