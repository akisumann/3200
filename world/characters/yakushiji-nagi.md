## 概要

**A級退魔師。奈良・西ノ京で薬師信仰に仕えてきた在地の旧家、薬師寺家の当主筋**（→ [[faction:old-houses]]）。寺そのものではない。**式神系の名家**で、神社・旧家を中心とする伝統側の一人（→ [[concept:a-rank]]）。**台帳上の分野は医療・浄化。**霊務省の区分では近畿地区の在地A級（→ [[faction:reimusho]]）。

**芯の術式は、外殻の塗り替えによる強制式神化。**照らした相手の外殻を一唱えで塗り替え、その場で自分の式神にする。名簿にある「戻す。呪い、変質、憑依、汚染を巻き戻す」は、この術式の使い道の一つ。

## 何ができるか

### 芯：外殻の塗り替えによる強制式神化

- 外殻への書き込み口は思念と命名。命名は外殻に直接刻まれ、名は上書きされうる（→ [[concept:shinen]]）。
- 凪は相手の外殻に薬師の名を上書きして塗り替え、そこに自分を繋ぐ。契約とは相手を自分の外殻として扱うことなので（→ [[concept:core-layer]]）、塗り替えが終わった時点で相手は凪の式神になっている。
- 同意は要らない。力で調伏して式神登録する道は、制度の中にある（→ [[concept:legal-status]]）。

### 技（すべてこの芯から出る）

| | |
|---|---|
| **日光** | 照らして、相手の外殻に今何の名と縁が刻まれているかを読む。塗り替える下地を見る工程。届くのは約10km |
| **瑠璃戻し（本技）** | 照らした相手の外殻を、一唱えで瑠璃色に塗り替える |
| **月光** | 式にした相手を鎮めて、大人しくさせておく |
| **瑠璃の帳** | 七仏の名の七席に、塗り替えたA級の妖怪を座らせた守り |
| **薬壺** | 鎮めた病み筋の式神を納めておく器 |

- **瑠璃戻し**：重い名を刻むときは、**七仏薬師**（薬師瑠璃光如来と、その本誓を分けて持つ七仏）の名を使う。善名称、宝月、金色宝光、無憂、法海雷音、法海勝慧、瑠璃光の七つ。七仏薬師法として千年修されてきた名なので、元の名ごと上書きできる。名を付けずに式にするだけなら、数に上限はない。家では「病んだものを元へ戻す技」として伝わってきたので、塗り替える技の名が「戻し」のまま残っている。
- **月光**：操作していない式神は同時使役数に数えない（→ [[concept:legal-status]]）ので、何百体でも抱えておける。場に出して同時に動かすのは、現代の最上位と同じ4体。
- **瑠璃の帳**：七仏の名の七席に、これまで塗り替えてきたA級の妖怪が何体も座り、いつも凪の身のまわりを固めている。**一体で小国を滅ぼしうる相手が、今は七仏の名を刻まれて凪の護衛として控えている。**「何を守るか」は契約が固定するので、席にいる間は操作しなくても守りとして動き、同時使役の4枠を食わない。
- 作中の十二天将とも、実在の十二神将とも別物。

### 「戻す」はこの術式の使い道

- 呪い・憑依・変質・汚染の主が妖怪なら、主を塗り替えて式にする。契約はどこへ干渉でき、何を拒むかを固定するので、主として「退け、引き上げろ」と命じれば、憑依は解け、呪いと汚染は引き戻され、書き込まれた変質は戻る。
- 戻すのは憑いたもの・撒かれたものまでで、生死は扱わない（死者蘇生は [[char:kamo-gen]] の分野）。

### 戦いの絵

- **町一つを寝込ませていた敵対A級の疫神を10km先から照らし、一唱えで金色宝光の名に塗り替えて、町中の病をその場で引き上げさせた。**
- **大病院一棟に憑いていた数百の病み筋を一晩で式にし、薬壺一つに納めた。**
- **戦場で、照らされたA級妖怪の外殻が一秒で瑠璃色に変わり、凪の四枠の一体として元の味方へ向かっていった。**
- **凪に近づくには、先に、かつて自分たちと同じ側にいたA級の護衛たちを抜かなければならない。**

## 人物

- 通称：「瑠璃の人」「戻し屋」（病院筋では「お薬師さん」）。
- 口癖：「元は、どうでした？」（答えを聞く前に、日光でもう主を照らしている）。

## 来歴

- 家の起こり：天武天皇が后の病の平癒を願ったとき、この家は「病を連れてきた主を照らし、式にして退かせた」。この発願の一件が、家の術式の原型になっている。
- 年中行事：花会式の時期（三月末）に、一年分の薬壺を納める。

## 世界への刺さり方

- **医療の最終段**：病院の検査呪具・回復呪具で落ちない憑依や霊障が、最後に回ってくる先（→ [[concept:daily-life]]）。
- **協調路線**：危険な疫神を殺さず封じもせず、式神登録で法の内側に入れて鎮めておく。
- **国外**：ベルゼブブ型の疫病と汚染の群体を相手に信仰備蓄を燃やした欧州（→ [[event:belzebub-war]]）に対し、「照らして、うちの式にする」日本型の極端な実例。
- **台帳**：式神になったA級は、基本的に把握数から外れる（→ [[concept:grades]]）。**瑠璃の帳の七席は、いずれもその形で台帳から下りている。**
