## 概要

**B級退魔師。民間の協力術師。** 大型の**人工式神**を五体運用する。

**本人の自認が「災害対応屋」。**

**封鎖区域での戦闘、災害級の怪異対応、地下侵食の案件で極めて高い評価を受けている。**

## 五体の人工式神

**空・地中・水中を網羅している。** 広域制圧型。

| | 名 | 担当 |
|---|---|---|
| **一号** | **大鷲** | 空輸・偵察・高所制圧。**全長10m級の飛行式神。**荒牧戦術の中核で、式神投下戦法に頻用される |
| **二号** | **大鎧獣**（通称アルマジロ） | 高質量突撃・転圧制圧。**爆速の召喚と送還**を利用した連続突撃を得意とする |
| **三号** | **大蛸** | 水域制圧・拘束・水中作業。**港湾の霊障や海難系の案件**での投入率が高い |
| **四号** | **大土竜** | 地下侵入・地盤破壊・埋設物探索。**地下存在の探査に優れ、対地下神域案件で成果を持つ** |
| **五号** | **大蜘蛛** | 索敵・拘束・罠構築。**糸による拘束と制圧で、五体の中では最も市街地適性が高い** |

### 身体能力だけを持たせてある

**保有式神はいずれもB級妖怪相応の身体能力を持つ。**

**そして特殊能力・現象性を持たない、純身体能力型として設計されている。**

**ここが効いている。** C級から上の妖怪は条件や現象を抱えた相手になる（→ [[concept:grades]]）が、**荒牧の式神はそこを持っていない。** B級相当の質量と力だけがある。

**作れるのは、身体まで。**

### 五体持っているが、同時に五体は出ていない

**式神操作には、同時使役数の上限がある**（→ [[concept:a-rank]]）。**現代日本の最上位で3〜4体。**

**荒牧もその枠の中にいる。** **保有しているのが五体で、同時に展開できるのはそれより少ない。**

**等級では差がつかない部分。** **B級の荒牧も、A級の式神操作系も、同時使役数はほぼ変わらない。** **違うのは一体ずつの格のほう。**

### 召喚と送還が異常に速い

**戦況に応じた瞬間的な戦力配置の変更**が得意。**そしてこの速さそのものが戦術になっている。**

**そして同時使役数に上限があることが、この速さの意味を決めている。**

**枠が埋まっているなら、新しく出すには何かを消すしかない。** **送還は、引っ込めることであると同時に、枠を空けることでもある。**

> **「消せる」ことが手数になっている**（下記）**のは、消した瞬間に次を置けるから。**

**五体を持ちながら枠が3〜4なら、常に一体以上が控えにいる。** **どれを出してどれを引くかの入れ替えが、そのまま戦術の中身になる。**

> これは repo 側の読み。**同時使役数に上限があることまでが確定で、荒牧の速さがそこから来ているとは書かれていない。**

## 代表戦術

| 名 | 中身 |
|---|---|
| **アルマジロ流星群** | 大鷲で高高度まで運搬し、アルマジロを**自由落下**させる。**着弾直前に送還し、再召喚を繰り返す**ことで疑似的な隕石攻撃を行う。**封鎖区域専用** |
| **連続装甲突撃** | 爆速の召喚と送還を利用したアルマジロの連続突撃。**回避された直後に再召喚することで突撃の軌道を強制変更できる**ため、単純な機動回避が通らない |
| **ターザン待ち蜘蛛** | 大鷲から蜘蛛糸を広域展開し、敵の高機動行動に対して強制拘束・迎撃を行うカウンター |
| **地下トラップハウス** | 大土竜による地下空洞の形成と、蜘蛛糸による補強を組み合わせた地形制圧 |

**送還が防御にも攻撃にも使われている。** 落下中のものを消して撃ち直す、避けられたものを消して角度を変える。**「消せる」ことが、そのまま手数になっている。**

## 出していい場所かどうかが先

**市街地戦闘への適性は低い。**

**召喚式神はいずれも単独でビル破壊級の被害を発生させうる**ため、都市部での運用には **[[faction:reimusho]] の許可、または封鎖承認**が必要になる場合が多い。

**だから本人の口癖がこうなる。**

> **勝てるかどうかより、出していい場所かどうかが先だ。**

**B級術師でありながら、現場到着直後にまず確認するのが以下。**

- 地図
- 避難範囲
- 地盤
- 水道管
- 地下施設
- 送電網

**倒し方より先に、壊していい範囲を調べている。**

**これは [[concept:taimashi]] の「勝利条件は討伐だけではない」と同じ側にある話。** 荒牧の場合は逆向きで、**討伐できることが前提で、問題は討伐の後に何が残るか**になっている。

### 事務方からは恐れられている

**[[faction:reimusho]] の実働部隊からの評価は高い。** 一方、**行政・保険・インフラ復旧の部門からは恐れられている。**

**荒牧の投入案件では、怪異被害そのものは短時間で収束することが多い。**

**しかし副次被害が出る。**

- 道路陥没
- 地下配管の破断
- 港湾設備の損傷
- ビル外壁の破壊
- 地盤沈下
- 送電設備の破損

**事務部門の冗談。**

> **荒牧さんを呼ぶ時点で復旧予算は諦めろ。**

## 標準体型式神未作成疑惑

**荒牧ほどの式神運用技術があれば、人間大から小型妖怪程度の人工式神を作ることも理論上は可能**と考えられている。**市街地戦、屋内戦、人質救助、精密な封印補助などへ対応できるはず。**

**しかし本人は現在に至るまで、標準体型の戦闘式神をほとんど運用していない。**

**表向きの理由。**

- 大型式神群の維持だけで手一杯
- 自分の専門は災害対応
- 器用な仕事は専門家に任せるべき

**一方、一部職員の間ではこう疑われている。**

> **標準体型式神を作ったら、市街地案件・屋内案件・護衛案件まで回されるから、わざと作っていないのではないか。**

**本人は疑惑を否定している。**

**ただし、標準体型式神の研究資料だけは、なぜか毎年更新されている。**

**そのため霊務省内では、こう言われている。**

> **作れないのではなく、作ると仕事が増えるから作らない。**

## 位置づけ — B級は下位互換ではない

**荒牧は、B級術師が単なる中ボスやA級の下位互換ではなく、代替困難な専門職であることを示す例。**

**A級を呼べば片付く、という話にならない。** 封鎖区域戦、災害級怪異への対応、地下侵食の案件は、**空・地中・水中を同時に押さえられる者にしかできない。**

**これは [[concept:taimashi]] の「A級は大企業の社長、E級は町工場のベテラン職人」と同じ構図が、B級にも当てはまるということ。** 等級は動かす力の規模を表すだけで、**その人にしかできない仕事があるかどうかとは別。**

## 未決

### 人工式神とは何か

**ここが repo にとって大きい。** [[concept:legal-status]] の**式神登録**は「**退魔師に使役されて登録される**」制度で、**中身は【掘らない】**（個体による）。

**しかし荒牧の式神は人工。作ったもの。**

**つまり「式神」には少なくとも二種類ある。**

| | |
|---|---|
| **式神登録された妖怪** | もともと存在した個体が、制度に入る。**関係の中身は十人十色【掘らない】** |
| **人工式神** | **作られたもの。**関係も何も、最初から作り手のもの |

**後者は【掘らない】の対象外のはず。** 個体ごとの関係の話ではなく、**製造の話**だから。

- **何から作るのか。** 素材は。呪具の系列なのか、別の技術か → [[concept:jugu]]
- **知性はあるのか。** 純身体能力型とあるので、たぶん道具に近い
- **一体作るのにどれくらいかかるのか。** 五体を維持するだけで手一杯とあるので、**維持にも継続的な手間がかかる**
- **送還したものはどこへ行くのか。** 消えているのか、どこかに待機しているのか
- **人工式神を作れる術者はどれくらいいるのか。** 荒牧が「式神運用特化型」と呼ばれるのは、**珍しいからなのか、突き詰めているからなのか**
- **B級妖怪相応の身体能力を持つものを、B級術師が作れる。** これは等級の理屈としてどうなっているのか → [[concept:grades]]
