## 概要

**A級退魔師。旧家**（→ [[faction:old-houses]]）。**神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。

**分野は特殊A級近傍監視**（→ [[concept:battle]] のA級の分野一覧）。

**[[char:tamamo-no-mae]] を封じている殺生石を、代々見ている家の当主。**

## 何ができるか

**弓。** **見ることと、当てることが、同じ一つの技術になっている。**

| | |
|---|---|
| **広域観測** | **那須野原一帯を、常時見ている。** 目で見ていない。**範囲内の異常を、距離に関係なく検知する** |
| **単射** | **一射がA級火力。** ただし**点**であって、面ではない。射程は数十キロ |
| **縫い止め** | **当てた対象を、土地へ固定する。** 倒すのではなく、動けなくする |

### 面を焼けない

**[[concept:grades]] の「A級は技一個が山破壊級」の段にはいる。** **ただし一射ぶんの、点で。**

**[[char:naruse-cecile]] の超火力爆撃とは、同じ火力量でも形が違う。**

| | |
|---|---|
| [[char:naruse-cecile]] | **面を焼く** |
| **この人物** | **一点を貫く** |

**[[char:suwa-shizuka]]、[[char:kamo-gen]] に続いて、面を焼けないA級が三人目になる。**

### 近接がほぼゼロ

**懐に入られたら終わる。**

**そして見えていないものには撃てない。** **観測が先で、射がその後。** **順序が崩れると何もできない。**

**土地を離れると、広域観測を失う。** **那須野原の外では、ただ射程の長い術者になる。**

> **一箇所にいることが、この人物の性能の前提になっている。**

### 縫い止めが、監視の実体

**「A級一人分の足止め」の中身がこれ。**

**特殊A級を倒すことはできない。** **ただし縫い止めの矢を撃ち続けるあいだ、その場から動かせる幅を削れる。**

**[[faction:reimusho]] が到着するまでの時間を、それで作る。**

## 那須という家

**那須野原の在地の家。** **[[char:tamamo-no-mae]] が逃げ込んだ土地の、もともとの領主筋にあたる。**

**だから封印を掛けた家ではない。** **掛けられた土地に、もとからいた家。**

> **repo 側の設定。** **殺生石を誰が封じたかは【掘らない】**（→ [[char:tamamo-no-mae]]）。
> **その掘らない部分を避けるために、「封じた家」ではなく「見ている家」にした。**

### 一度、この土地で止めた家

**なぜこの家が見張りなのか。**

**逃げた九尾を、この土地で止めた側だから。**

**射て、縫い止める技術は、その一件のためのものだった。** **そして相手はまだそこにいる。**

> **家の技が、見張っている対象に対して作られている。**
> **だから他の家では代わりが利かない。**

**[[concept:core-layer]] の伝承拘束が、人間の側にも同じ形で効いていることになる。** **[[char:tamamo-no-mae]] が伝承どおりの姿でいるように、この家も伝承どおりの役をやり続けている。**

> **repo 側の読み。** **人間の家系に伝承拘束がかかるとは書かれていない。**
> **ただし「先祖から技術と力を継承する契約」の例が既に一つある**（→ [[char:kamo-gen]]）。

## 仕事は、見ていること

**殺生石の封印は出来が死ぬほどよく、基本的に手入れが要らない**（→ [[char:tamamo-no-mae]]）。

**何百年も手を入れずに保っている。**

**だからこの人物の仕事は、封印を維持することではない。**

> **見ている。**
> **それだけ。**

**[[concept:relics]] の三種の神器と同じ形が、人の側にも一つある。** **持っているが動かさない。** **動く時点で、通常の事態ではない。**

### 直せないほうの見張り

**ここが重い。**

**封印を掛けた技術は、この家に伝わっていない。**

**A級相当への封印は秘術の領域で、概要すらシークレット**（→ [[faction:shrines]]）。**掛けた者が誰かも分かっていない。**

**つまり、もし殺生石が緩んだ場合、この人物にできるのは掛け直すことではない。**

| できること | |
|---|---|
| **見る** | 何百年も、そうしてきた |
| **気づく** | 誰よりも早く |
| **知らせる** | [[faction:reimusho]] へ |
| **足止めする** | **縫い止めの矢で、動ける幅を削る**（上記） |

> **日本で二体しかいない特殊A級の一体を、直せない人間が見張っている。**

**[[concept:a-rank]] の物部灯（国家級封印）が呼ばれることになる。** **ただしその人物にも、この封印は掛け直せない。** **同じ秘術を持っているとは書かれていない。**

### だからA級が要る

**手入れの要らない封印を、なぜA級が一人張り付いて見ているのか。**

**気づくのが遅れたときの、最初の一人だから。**

**[[faction:reimusho]] が動くまでの時間を、誰かが持たなければならない。** **相手が特殊A級である以上、その誰かはA級でないと数分も保たない。**

> **repo 側の読み。** **なぜA級を充てているかは書かれていない。**

## 場所の問題

**殺生石があるのは栃木。** **[[faction:reimusho]] の区分では関東地区。**

**そして関東の校地は [[loc:nikko]] で、これも栃木。**

> **同じ県に、六校のうち一校と、日本最大級の封印がある。**

**関東地区長は [[char:mimura-sumi]]。** **[[char:shinohara-kyo]] が封殺されて以来、東北を兼務している**（→ [[concept:a-rank]]）。

> **日本で一番危ない封印がある地区を、二地区を掛け持ちしている人間が見ている。**

**そのぶん、在地のこの家が持っている部分が大きくなる。**

> **repo 側の読み。** **兼務と封印の距離が近いことは、配置から出てくるだけで、書かれていない。**

## 六人の中での位置

**[[concept:a-rank]] の神社旧家枠は、土地と家に紐づいている側。**

**その中でも、この人物は一番動けない。** **見る対象が動かないので、見る側も動けない。**

| | |
|---|---|
| **[[concept:a-rank]] の忌部遥**（広域結界） | 網を張る。範囲が仕事 |
| **同・鵜飼睦**（高位交渉） | 出向く。相手のところへ行く |
| **同・斎木惺**（逃しポイント） | 全国を回る |
| **この人物** | **一箇所にいる** |

> **A級18人のうち一人は、ほぼ一つの石から離れられない。**
