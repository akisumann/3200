## 概要

**A級退魔師。神社系の家の次期当主**（→ [[faction:shrines]]）。**神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。**台帳上の分野は特殊A級近傍監視。**

**家はそこそこの規模の神社。** **氏子がいて、年中の祭事があり、下に神職が何人もいて、地域の超常行政に普通に組み込まれている。**

**そして家の役目として、[[char:tamamo-no-mae]] を封じている殺生石の監視と、近くの天狗の里の外部窓口を持っている。**

> **石の役目は、ほぼ形だけ**（下記）。
> **この家は「石の番人」ではなく、石の番も持っている神社の家。**

## 何ができるか

**天眼通と、弓。** **見る手段と、当てる手段が別々にあって、組になっている。**

| | |
|---|---|
| **天眼通** | **見る。**距離も、遮蔽も、隠形も通らない |
| **梓弓** | **呼ぶ。**あたり一帯の妖怪を、無意識のうちに誘導し、誘引する |
| **鳴弦** | **祓う。**浄化と退魔を、広範囲に物理的に撒く |
| **指向性** | **呼ぶ側も祓う側も、向きを付けられる。**だから祭事もできる |
| **単射** | **当てる。**音速を超える相手にも当たり、山だろうが大地だろうがそのまま通過する |
| **核抜き** | **領域の外から核を見抜いて射る。**超遠距離、条件無視の退魔 |
| **縫い止め** | **当てた対象を、土地へ固定する。**倒すのではなく、動けなくする |

**射る二つ以外は、弦を鳴らすだけ。** **矢を使わない。**

> **一張りの弓で、呼ぶ・祓う・射るが揃っている。**

**使うのは [[concept:jugu]] のA級呪具、天之麻迦古弓**（下記）。

### 天眼通

**六神通の一つ。** **遠くのものが見える。壁も土も抜けて見える。隠れているもの、化けているもの、そこにあると思われていないものが見える。**

**目で見ていない。**

**出どころは、隣の天狗の里**（下記）。

#### 未来は見えない

**「天眼通」を広く取ると過去未来まで含む説明が付くことがあるが、この人物のそれは今の話だけ。**

**[[event:hyakki-yako-attempt]] には未来を見る能力を持った妖怪が別にいる**（→ 同）。**そちらと混ざらないようにする。**

### 弓のほう

**天眼通で見えたものへ撃つ。** **観測が先で、射がその出口。**

**射程は天眼通の届く範囲。** **数十キロ。**

#### 遮蔽が、意味を持たない

**矢は、間にあるものを通過する。** **山でも、大地でも、そのまま抜ける。**

> **見る側と当てる側が、同じ性質で揃っている。**

**射線という概念が、この人物に対しては働かない。** **間に何を置いても、地面に潜っても、届く。**

#### 当たらない相手がいない

**音速を超えて動く相手にも当てられる**（→ 下記の育ち）。**[[concept:youkai-samples]] の鴉天狗は「音速で襲撃してくる」。** **その速度が、そのまま基準になっている。**

> **隠れられず、遮れず、逃げ切れず、避けられない。**

### 核抜き — 領域の外から、核を射る

**相手が何であっても、退魔がそのまま通る。**

**[[concept:core-layer]] の核を天眼通で見抜き、そこへ矢を通す。** **領域の中へ入らずに。**

**普通は領域へ入り、中で条件を探し、それを崩す。** **この技は入らない。** **外から核を見て、射る。**

> **超遠距離からの、条件無視の退魔。**

**届く理由は、矢が山も大地も通過するから**（上記）。**領域の壁も、その延長で越えている。**

**核がどこにあるかは個体による**（→ [[concept:core-layer]]）。**毎回、見つけている。**

**そして核は「その妖怪が何であると想われたか」の層で、外から見て分かるものではない。** **距離も遮蔽も隠形も通らない目と、当てる腕の両方が要る。**

### 梓弓 — 呼ぶ

**弦を鳴らして、寄せる。**

**梓弓は、もともと霊を呼ぶための道具。** **弦を弾いて口寄せをする巫の作法が、そのまま技になっている。**

**あたり一帯の妖怪が、無意識のうちに誘導され、誘引される。**

> **本人たちに、寄せられている自覚がない。**

**相手の条件を読んで崩すのではなく、相手が判断する前に足を動かさせる。**

**那須野原は広い。** **湧いたものを一箇所へ集めて、そこで祓うという運用が、何百年ぶんそこにある。** **[[concept:release-points]] が外へ逃がす仕組みなのに対して、こちらは内へ寄せる。**

### 鳴弦 — 祓う

**弦を鳴らして、祓う。**

**鳴弦も実在の作法。** **矢をつがえずに弦を打ち、邪を退ける。**

**追い払うだけではない。** **物理的な浄化と退魔の効果を、広範囲に撒く。**

> **近寄った時点で、祓われている。**

**だから距離を詰められるほど、相手が祓いの中に入ってくる。**

**面としても成立している。** **[[char:naruse-cecile]] の超火力爆撃が焼く面なら、こちらは祓う面。**

### 指向性がある

**梓弓の「呼ぶ」も、鳴弦の「祓う」も、ある程度は向きを付けられる。** **撒きっぱなしではない。**

| | 向きを付けるとは |
|---|---|
| **呼ぶ** | **何を呼ぶか、どこへ呼ぶか**を選べる |
| **祓う** | **何を祓うか、どこを祓うか**を選べる |

**これが無いと、そもそも運用できない。**

**この国の妖怪の大半は、敵ではない。** **妖怪には罪がなく**（→ [[concept:legal-status]]）、**土地神との調整、協力妖怪との関係、里との契約、逃しポイントの維持**（→ [[concept:cooperation-policy]]）**は、どれも祓う相手ではない。**

> **祓えることより、祓わずに済ませられることのほうが要件になる。**

### 縫い止め

**当てた対象を、土地へ固定する。** **射抜くのとは別に、動きのほうを止める使い方がある。**

### 三つを繋ぐと、罠として完結している

| 手順 | |
|---|---|
| **1** | **天眼通で、どこに何がいるか見る** |
| **2** | **梓弓で、寄せる** |
| **3** | **鳴弦で、祓う** |
| **4** | **祓いきれないものだけ、射る** |
| **5** | **それでも落ちないものは、縫い止める** |

> **一人で、集める側と、処理する側の両方をやっている。**

**[[faction:reimusho]] の実務は「その分野のB級を呼ぶ」で回っている**（→ 同）。**この人物は、呼ぶ手前で完結してしまう。**

### 土地を離れても使える

**天眼通は本人に付いている。** **ただし「あたり一帯を常時見ている」ほうは、土地に馴染んでいるぶんの上乗せ。**

| | |
|---|---|
| **那須野原** | **勝手に入ってくる。**見ようとしなくても分かる |
| **よその土地** | **見える。**ただし向けた先だけ |

> **離れられないわけではない。** **地元のほうが早いというだけ。**

## 天之麻迦古弓

**A級呪具**（→ [[concept:jugu]]）。**あめのまかこゆみ。**

**記紀の弓。** **天若日子が葦原中国の平定を命じられたときに、天から与えられたもの。**

**分類は恒常型。** **自分で条件を持っていて、自分でそれを執行する。**

### 返し矢

**伝承のとおり。**

**天若日子は八年帰らず、下界で妻を娶り、任を捨てた。** **そして問いに来た雉を、この弓で射た。** **矢は天まで届き、投げ返され、寝ていた本人を貫いた。**

| | |
|---|---|
| **任のために撃つ** | **通る** |
| **任を裏切って撃つ** | **返ってくる** |

**[[concept:core-layer]] の伝承拘束が、道具の側にも同じ形で出ている。**

> **伝承どおりに強い。そして、伝承どおりにしか強くない。**

### 天之波々矢

**あめのはばや。** **この弓から出る矢。** **記紀で、天若日子が射て、投げ返されて死んだ矢。**

**条件付きの必中。** **神判に近いとされている。** **そして、外部からは条件が分からない。**

| | |
|---|---|
| **条件を満たすと、必ず当たる** | 外れない |
| **神判に近い「とされている」** | **外からの評価** |
| **条件が何かは不明** | **外部から見て、読めない** |

**本人や家の側でどう把握しているかは、書かれていない。**

#### 外から対策が立てられない

**相手の側からすると、たまに外れない矢が飛んでくる。** **いつそうなるのかが読めない。**

> **避けられる矢と、避けられない矢の区別が、撃たれる側からは付かない。**

**[[concept:battle]] の条件戦の裏返し。** **相手の条件を読んで崩すのがこの世界の戦い方だが、こちらの条件は読ませていない。**

#### 普段の命中とは、出どころが別

| | 当たる理由 |
|---|---|
| **普段の射** | **腕。**本人のもの |
| **天之波々矢** | **条件。**満たされていれば |

**必中も返し矢も、「射手の意思では決まらない」という一点で同じ。** **矢の行き先を決めているのが、射手ではない。**

### 見張りに、裏切ると自分に返る弓を持たせてある

**この家の仕事は、何百年も一つの石を見ていること。** **そして持たされているのが、任を裏切った者を撃ち殺した弓。**

> **見張りが寝返らないことを、制度ではなく伝承が保証している。**

**[[concept:taimashi]] に「三系統のどれにも安全な側が無い」とある。** **[[char:shinohara-kyo]] は公職A級のまま二百年隠れていて、制度の側に止める仕組みは何も無かった。** **この席にだけ、それがある。**

#### そして、この人物は寄せられる

**梓弓は誘引の技**（上記）。**向きを変えれば、そのまま殺生石へ寄せられる。**

> **日本最大級の封印の隣に、そこへ妖怪を集められる人間が一人立っている。**

**[[char:tamamo-no-mae]] は封印されて何百年経っても、名前も個体性も薄まらない**（→ 同）。**封じられているのは体であって、名前は外にある。** **そこへ思念や妖怪を寄せ続けたら何が起きるのかは、書かれていない。**

**そして弦を鳴らすのは、射ることではない。** **返し矢が見ているのがどちらなのかで、安全装置の意味が変わる。**

### 等級は、弓で上がっていない

**この人物はA級で、その上に恒常型のA級呪具が乗っている。**

**弓が無くても天眼通は残る。** **弓が無くても、A級の基礎スペックは残る。**

> **本人が本体で、弓は出力の出口。**

### 台帳上はA級呪具になっている

**記紀に名前が出ている弓が、栃木の一軒の家にある。** **由緒からすれば [[concept:relics]] の遺物に置かれてもおかしくないが、そうなっていない。**

> **遺物として登録されれば、所有権、国際条約、文化財保護が全部乗ってくる。**
> **A級呪具のままなら、[[faction:reimusho]] の免許の話で済む。**

## 那須という家

**那須野原の在地の家。** **[[char:tamamo-no-mae]] が逃げ込んだ土地の、もともとの領主筋にあたる。**

**だから封印を掛けた家ではない。** **掛けられた土地に、もとからいた家。** **そして今は、その土地で神社をやっている家。**

### 三つの出どころが、一張りの弓に集まっている

| | 出どころ |
|---|---|
| **天眼通**（見る） | **隣の天狗の里から教わったもの。**六神通 |
| **梓弓・鳴弦**（呼ぶ・祓う・祭事） | **巫の側。**口寄せと弦打ちの作法 |
| **単射・縫い止め**（当てる） | **武家の側。**九尾を止めた一件から |

**那須野原には、逃げた九尾を止めた武家の話が残っている。** **そこへ巫の作法が乗り、山の側から神通が入って、一つの家になった。**

> **武家は矢を射るために、巫は弦を鳴らすために、同じ道具を使う。**

**射て、縫い止める技術は、九尾を止めた一件のためのものだった。** **そして相手はまだそこにいる。**

> **家の技が、見張っている対象に対して作られている。**

## 幼い頃から、天狗と遊んでいる

**隣が天狗系の里**（下記）。**この人物は、そこで育っている。** **外交の相手ではなく、遊び相手だった。**

**走っても飛んでも、何をしても届かない。** **相手の遊びには、何一つ入れない。**

**弓だけは、撃てた。**

> **子供でも引ける。**
> **届くかどうかは別として、こちらから相手へ向かって何かを飛ばせる、唯一の手段だった。**

### 子供のうちは、当たらなかった

**幼い頃は、普通に当たらなかった。**

**天狗の側は、避けるまでもない。** **撃たせて、外れるのを見ている。**

> **「避ける遊び」の形になったのは、後の話。**
> **最初は、当たらない矢に付き合ってもらっていただけ。**

**それを何年も続けている。**

> **勝ち負けにならない遊びを、勝ち負けになるところまで持っていった。**

**そのあいだに本人も育っている。** **等級も、身体も、天眼通も、後から乗ってきたもの。**

### 今は、音速を超える相手に当たる

**[[concept:youkai-samples]] の鴉天狗は「飛行、高速機動」を持ち、「音速で襲撃してくる」。**

**その相手が、避けなければならなくなった。**

**[[concept:youkai-nature]] の弱肉強食の理からすると、ここで「武を示す」に足りたことになる。**

| | |
|---|---|
| **当たらなかった頃** | **里の子供。**可愛がられている側 |
| **当たるようになってから** | **示した側。**扱いが変わる |

**窓口として認められている理由が、外交でも家格でもなく、そこにある。**

### 順序としては、弓が先

**天眼通は里から教わったもの。** **遊んでいたのは、その前から。**

> **目が先にあって当てられるようになったのではない。**
> **当てられる腕が先にあって、そこへ目が乗った。**

### 今は、身体能力そのものも高い

**現在はA級の基礎スペックがある**（→ [[concept:grades]]）。**動けるし、速いし、逃げも利く。**

**それでも、音速には追いつけない。**

> **遅いのではない。** **比べる相手が飛んでいて、音を置いていく。**

**子供の頃に「弓しかない」と決まった形が、そのまま残った。**

## 次期当主

**家の看板はまだ先代が持っている。** **力と実務のほうは、もうこの人物に移っている。**

| | |
|---|---|
| **先代（現当主）** | **B級。**天眼通は持っている。祭事も窓口も、長年やってきた |
| **この人物** | **A級。**次期当主。まだ代替わりしていない |

**この家からA級が出るのは、いつもではない。** **神社の家として力のある人間がたまに出て、それがA級になる。** **今それが、たまたま跡取りのほうに出た。**

### 弓は、先に移った

**天之麻迦古弓は当主が持つもの。** **それが、代替わりより先にこの人物へ渡っている。**

**恒常型の呪具は、使用者を選ぶ側にいる**（→ [[concept:jugu]]）。

> **任を負っている者のところへ行く弓が、跡取りのほうへ来た。**

**先代がそれを止めていない。** **形の上の順序より、任のほうが先だと扱われている。**

### だから、表に出ている役は全部この人物

**18人に数えられているのは、当主ではなく跡取りのほう。**

**殺生石の定期報告も、天狗の里で武を示す役も、A級としての地区の案件も、この人物が持っている。** **先代がやっているのは、神社の運営と、氏子と、家のしがらみ。**

## 家が、近くの天狗の里の外部窓口をやっている

**那須野原の近辺に、天狗系の妖怪の里がある**（→ [[concept:youkai-land]]）。**その里の外部窓口を、この家が持っている。**

> **家の役であって、当主一人の役ではない。**
> **日常のやりとりは下の神職も回している。**

**制度としては既定どおり。** **[[faction:shrines]] や [[faction:old-houses]] が代理として交渉し、契約を取り、国の権利と保護を適用させる**（→ [[concept:youkai-land]]）。**妖怪が自分で役所へ行くのではない。**

### そして、神通力を教わっている

**天眼通は、この里から来ている。**

**[[concept:youkai-samples]] の鴉天狗に「強力な神通力も標準搭載」とある。** **神通力は妖怪の側の標準装備で、その技術を家として教わっている。**

> **人間が持っているのが異例なのではなく、教わる相手が隣にいた。**

**[[char:kamo-gen]] の血族的契約が先祖から渡る継承なのに対して、こちらは教育。** **だから血が要らない。**

**[[concept:youkai-land]] の未決にある「交流役は何を受け取るのか」が、これで一例埋まった。** **技術。** **持っていっている側は、まだ書かれていない。**

### 天狗が相手なので、弱いと務まらない

**[[concept:youkai-samples]] の鴉天狗はこう書かれている。**

> **敵対・侮辱・領域侵犯で激昂すると、音速で襲撃してくる。**
> **知性的な高位妖怪と接敵した場合、ある程度相手が納得する武力を見せなければ交渉すらままならない。**

**そして [[concept:youkai-nature]] の弱肉強食の理が機能している。**

> **窓口を務めるために、示せるだけの武を持ち続けている。**

**石の役目は形だけ**（下記）。**この家が代々強い理由は、そちらではなくこちらにある。**

**鴉天狗は山伏装束のことが多い。** **この家に入っている仏の側の技術は、そこから来ている。** **神仏習合というより、山の側から入ってきたもの。**

### 梓弓が、そのまま連絡手段になる

**里と話をするのに、出向かなくていい。** **弦を鳴らせば来る。**

> **口寄せの道具が、そのまま回線になっている。**

**指向性**（上記）**が、窓口役の前提にもなっている。** **隣に里がある人間が、無差別の広範囲浄化しか持っていなかったら務まらない。**

### 里も、同じ石を気にしている

**殺生石の近くに里がある、ということでもある。** **[[char:tamamo-no-mae]] が起きて困るのは、人間だけではない。**

> **見張りの利害が、最初から共有されている。**

**里の側にも目があり、この人物にも天眼通がある。**

### 契約を結ぶ役とは、大きさが違う

**[[concept:battle]] のA級の分野に高位交渉がある。** **契約そのものを結ぶのは、そちらの仕事。**

**この人物がやっているのは一つの里で、結ばれた契約の下の日常の窓口。**

## 殺生石の役目は、ほぼ形だけ

**殺生石の封印は出来が死ぬほどよく、基本的に手入れが要らない**（→ [[char:tamamo-no-mae]]）。**何百年も手を入れずに保っている。**

| | |
|---|---|
| **定期に見る** | 天眼通で。**変わりない、と確認するだけ** |
| **報告する** | [[faction:reimusho]] へ |
| **以上** | |

> **家の格を保証する由緒ではあるが、日々の仕事ではない。**

**[[concept:relics]] の三種の神器と同じ形。** **持っているが動かさない。** **動く時点で、通常の事態ではない。**

**A級退魔師としては、関東地区の在地の上位戦力として普通に使われている。** **関東地区長の [[char:mimura-sumi]] は東北を兼務していて手が足りない**（→ [[concept:a-rank]]）。**在地にA級がいるぶんが、そのまま効いている。**

### A級なのは、石のためではない

**役目がA級を要求しているのではない。** **神社の家として力のある人間が出て、それがA級になり、その家がたまたま石の役目も持っている。**

> **順序が逆。**

### 石の中が見える、ということ

**何も起きていないように見えることは、「中身が眠っている」ことの証明にはならない。**

> **手入れの要らない封印ほど、外からは何も分からない。**

**天眼通は、石の中が見える。** **[[char:tamamo-no-mae]] が今どういう状態でそこにいるのかを実際に見て確認できる人間は、日本にこの一人しかいない。**

### 直せないほうの見張り

**封印を掛けた技術は、この家に伝わっていない。**

**A級相当への封印は秘術の領域で、概要すらシークレット**（→ [[faction:shrines]]）。**掛けた者が誰かも分かっていない。**

**もし緩んだ場合、この人物にできるのは掛け直すことではない。**

| できること | |
|---|---|
| **見る** | **天眼通で、石の中まで** |
| **気づく** | **他の誰よりも早い。**外から分かる話ではないので |
| **知らせる** | [[faction:reimusho]] へ |
| **足止めする** | **縫い止めの矢で、動ける幅を削る** |

> **日本で二体しかいない特殊A級の一体を、直せない人間が見張っている。**

**掛け直すのは国家級封印の側**（→ [[char:mononobe-akari]]）**の仕事になる。** **ただし通るかどうかは分からない。**

### ただし、動いたときは重い

**何百年何も起きていないことと、起きたときに軽いことは別。**

**中を見られるのはこの人物しかいない。** **そして気づいた後、[[faction:reimusho]] が動くまでの時間を誰かが持たなければならない。** **相手が特殊A級である以上、その誰かはA級でないと数分も保たない。**

> **形だけの役目が、形でなくなる日だけ、この家が全部を負う。**

## 巫女としての祭事と、家業

**指向性があるということは、祭祀ができるということでもある。**

**祭事の骨は、呼んで、もてなして、送ること。** **梓弓が呼ぶ側、鳴弦が送る側。**

> **技が二つあるのではない。** **同じ二つを、向ける先が違うだけ。**

**だから祭事の格が高い。** **[[char:suwa-shizuka]] が神降ろしで自分に入れる側なら、こちらは呼んで送る、外で扱う側。**

### 祀ってはいけないものの隣にいる

**[[concept:shinen]] の理屈では、祀ることは供給になる。**

**[[char:tamamo-no-mae]] は、封じられていても名前も個体性も薄まらない**（→ 同）。**封じられているのは体であって、名前は外にある。**

> **祭事のできる人間が、祀ってはいけない相手の隣に座っている。**

**この家の作法に、殺生石を祀る手順は入っていないはず。**

### 家業として回っている

**鳴弦は、もともと産室や病床で邪を退けるために打つもの。** **梓弓は口寄せの道具。** **どちらも、神社の日常業務そのもの。**

**年中の祭祀、地鎮、厄除け、産室の鳴弦、地域の依頼。** **氏子がいて、下に神職が何人もいて、地域の相談が来る。** **[[faction:shrines]] の「土地に根ざした安定。ただししがらみが強くて面倒」**（→ [[concept:taimashi]]）**が、そのまま当てはまる家。**

**A級の祭事なので、外からも声がかかる。** **普通に出向く。**

> **この人物の生活の大半は、殺生石ではなく神社のほう。**

## 場所の問題

**殺生石があるのは栃木で、[[faction:reimusho]] の区分では関東地区。** **関東の校地 [[loc:nikko]] も栃木。**

> **同じ県に、六校のうち一校と、日本最大級の封印がある。**

**そしてその地区長 [[char:mimura-sumi]] は、東北を兼務している。**

> **日本で一番危ない封印がある地区を、二地区を掛け持ちしている人間が見ている。**
