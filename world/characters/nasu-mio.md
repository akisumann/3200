## 概要

**A級退魔師。神社系の家の次期当主**（→ [[faction:shrines]]）。**神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。

**当主はまだ先代。** **この人物は跡取り。**

**家はそこそこの規模の神社。** **氏子がいて、年中の祭事があり、下に神職が何人もいて、地域の超常行政に普通に組み込まれている。**

**そして家の役目として、[[char:tamamo-no-mae]] を封じている殺生石の監視を持っている。**

> **ただしこれは、ほぼ形だけ**（下記）。
> **この家は「石の番人」ではなく、石の番も持っている神社の家。**

**台帳上の分野は特殊A級近傍監視**（→ [[concept:battle]] のA級の分野一覧）。

## 何ができるか

**天眼通と、弓。** **見る手段と、当てる手段が別々にあって、組になっている。**

| | |
|---|---|
| **天眼通** | **見る。**距離も、遮蔽も、隠形も通らない |
| **梓弓** | **呼ぶ。**あたり一帯の妖怪を、無意識のうちに誘導し、誘引する |
| **鳴弦** | **祓う。**近寄った妖怪を祓い、浄化と退魔を広範囲に撒く |
| **指向性** | **呼ぶ側も祓う側も、向きを付けられる。**だから祭事もできる |
| **単射** | **当てる。**一射がA級火力。ただし**点**であって、面ではない。**音速を超える相手にも当たる**（下記） |
| **核抜き** | **領域の外から核を見抜いて射る。**超遠距離、条件無視の退魔（下記） |
| **縫い止め** | **当てた対象を、土地へ固定する。** 倒すのではなく、動けなくする |

**射る二つ以外は、弦を鳴らすだけ。** **矢を使わない。**

> **一張りの弓で、呼ぶ・祓う・射るが揃っている。**

**使うのは [[concept:jugu]] のA級呪具、天之麻迦古弓**（下記）。

### 天眼通

**六神通の一つ。**

**遠くのものが見える。** **壁も土も抜けて見える。** **隠れているもの、化けているもの、そこにあると思われていないものが見える。**

**目で見ていない。**

#### 未来は見えない

**ここは切っておく。**

**「天眼通」を広く取ると過去未来まで含む説明が付くことがあるが、**この人物のそれは今の話だけ**。**

**[[event:hyakki-yako-attempt]] には未来を見る能力を持った妖怪が別にいる**（→ 同）。**そちらと混ざらないようにする。**

> **repo 側の決定。** **天眼通の範囲を、距離・遮蔽・隠形の三つに限った。**

#### 出どころは、隣の天狗の里

**神通力は妖怪の側の標準装備。** **[[concept:youkai-samples]] の鴉天狗にも「強力な神通力も標準搭載」とある。**

**この家は、隣の里からそれを教わっている**（下記）。

> **人間が持っているのが異例なのではなく、教わる相手が隣にいた。**

### 弓のほう

**天眼通で見えたものへ撃つ。**

**だから「見えていないものには撃てない」は、性能の順序そのもの。** **天眼通が先にあって、射がその出口になっている。**

**射程は天眼通の届く範囲。** **数十キロ。**

#### 当たる、ということのほうが本体

**火力はA級として普通。** **突出しているのは、当たること。**

**音速を超えて動く相手にも当てられる**（→ 下記の育ち）。

**[[concept:youkai-samples]] の鴉天狗は「音速で襲撃してくる」。** **その速度が、そのまま基準になっている。**

> **見えていれば、速さは問題にならない。**

**この段の妖怪に対して、当てるところが難所であることが多い。** **そこを一人だけ飛ばしている。**

**[[concept:grades]] の「技術の高さと等級は、別々に動く」の、逆側の実例。**

| | |
|---|---|
| **[[char:kurosawa-akira]]** | **技術は横ばい。**突出は出力量と知謀 |
| **この人物** | **出力は普通。**突出は技術 |

**そして [[concept:battle]] の縫い止めも、当たらなければ話にならない**（上記）。**足止めが実用になっているのは、この命中があるから。**

### 核抜き — 領域の外から、核を射る

**これが一番大きい。**

**[[concept:core-layer]] の核を、天眼通で見抜く。** **そこへ矢を通す。**

**領域の中へ入らずに。**

#### 何を飛ばしているか

**外殻が土地や建物になっている妖怪の領域は、中で空間・距離・出口・明暗が操作される**（→ [[concept:core-layer]]）。**入ることは、妖怪の中へ入ること。**

**普通は、そこへ入ってから条件を崩す。**

**この技は、入らない。**

| 普通の手順 | この技 |
|---|---|
| 領域へ入る | **入らない** |
| 中で条件を探す | **外から核を見る** |
| 条件を崩す | **核を射る** |

> **超遠距離からの、条件無視の退魔。**

**[[event:lupin-incident]] の「条件外しに近い」**（→ 同）**が、別の形でもう一つ出たことになる。**

#### ただし、出力差は無視できない

**条件を飛ばせるだけ。**

**核へ矢が届いても、貫けるかどうかは別。** **弓の火力はA級のもの。**

> **条件は無視できる。** **格は無視できない。**

**[[event:hyakki-yako-attempt]] で国家が撤退した理由が「出力差の問題」だった**（→ 同）。**そこは、この技でも同じ。**

#### 核の位置は、一般則にならない

**[[concept:core-layer]] に「領域型の核がどこにあるかは【掘らない】。個体による」とある。**

**この技があっても、そこは変わらない。**

> **見えるのは、その一体の核。**
> **どこにあるものかという一般の話にはならない。**

**毎回、見つけている。**

#### 天眼通が無ければ成立しない

**核は「その妖怪が何であると想われたか」の層**（→ [[concept:core-layer]]）。**外から見て分かるものではない。**

**距離も遮蔽も隠形も通らない目があって、初めて成立する。**

**そして当てる腕がある。**

> **見る技術と当てる技術が別々にあるこの人物にしか、この形にならない。**

### 梓弓 — 呼ぶ

**弦を鳴らして、寄せる。**

**梓弓は、もともと霊を呼ぶための道具。** **弦を弾いて口寄せをする巫の作法が、そのまま技になっている。**

**あたり一帯の妖怪が、無意識のうちに誘導され、誘引される。**

> **本人たちに、寄せられている自覚がない。**

**[[concept:battle]] の条件戦とは、質が違う。** **相手の条件を読んで崩すのではなく、相手が判断する前に足を動かさせる。**

#### 逃しポイントとは、向きが逆

**[[concept:release-points]] は、湧いたものを外へ逃がす仕組み。**

**この技は、内へ寄せる。**

**那須野原は広い。** **湧いたものを一箇所へ集めて、そこで祓う**（下記）**という運用が、何百年ぶんそこにある。**

> **repo 側の読み。** **家がそう運用してきたとは書かれていない。**
> **ただし技の組み合わせが、そうとしか読めない形をしている。**

### 鳴弦 — 祓う

**弦を鳴らして、祓う。**

**鳴弦も実在の作法。** **矢をつがえずに弦を打ち、邪を退ける。**

**追い払うだけではない。** **物理的な浄化と退魔の効果を、広範囲に撒く。**

> **近寄った時点で、祓われている。**

#### 妖怪相手なら、近寄られるほうが有利

**鳴弦がある。** **距離を詰められるほど、祓いの中に入ってくる。**

#### 対人だと、手札が減る

**梓弓も鳴弦も、妖怪向け。** **人間には効かない。**

| | 対妖怪 | 対人 |
|---|---|---|
| **天眼通** | 効く | **効く。隠れられない** |
| **梓弓**（呼ぶ） | 効く | 効かない |
| **鳴弦**（祓う） | 効く | **効かない** |
| **単射** | 効く | **効く。人間は天狗より遥かに遅い** |
| **縫い止め** | 効く | 効く |

**五つが三つになる。** **ただしその三つが強い。**

**隠れられず、当たり、縫い止められる。** **相手の速度は、天狗の基準からすれば問題にならない。**

> **対人でも、普通に勝つ側。**

##### 負ける形は、一つに絞れる

**矢を耐えて、距離を詰めきる相手。**

**近距離で仕留める技を持っていないので、そこまで来られると押し返す手がない。**

**[[char:suwa-shizuka]] や [[char:kamo-gen]] は近接特化のA級**（→ [[concept:a-rank]]）。**噛み合わせでいうと、一番悪いのはこの型。**

##### 呪具で殴ってくる相手なら、在庫の勝負

**矢を防ぐ手段を持ち込まれた場合、そこを切らす前に詰められるかどうかになる。**

> **消耗戦の側に落ちる。** **この人物は一射ずつしか撃てないので、手数の交換に向かない。**

### 面はある。ただし焼くほうではない

**[[char:naruse-cecile]] の超火力爆撃とは、面の質が違う。**

| | 面の中身 |
|---|---|
| [[char:naruse-cecile]] | **焼く。**破壊 |
| **この人物** | **祓う。**浄化と退魔 |

**破壊力としての面は無い。** **建物も地形も壊せない。** **そのかわり、妖怪に対してだけは広範囲に効く。**

> **[[concept:grades]] の「A級は技一個が山破壊級」の平均に、火力の側では届いていない。**
> **ただし退魔師の仕事の側では、面を持っている。**

### そして順序は変わらない

**見えていないものには撃てない。** **観測が先で、射がその後。**

**天眼通は本人に付いているので、どこへ行っても使える。** **ただし「あたり一帯を常時見ている」ほうは、土地に馴染んでいるぶんの上乗せ。**

| | |
|---|---|
| **那須野原** | **勝手に入ってくる。**見ようとしなくても分かる |
| **よその土地** | **見える。**ただし向けた先だけ |

> **離れられないわけではない。** **地元のほうが早いというだけ。**

### 三つを繋ぐと、罠として完結している

| 手順 | |
|---|---|
| **1** | **天眼通で、どこに何がいるか見る** |
| **2** | **梓弓で、寄せる** |
| **3** | **鳴弦で、祓う** |
| **4** | **祓いきれないものだけ、射る** |
| **5** | **それでも落ちないものは、縫い止める** |

> **一人で、集める側と、処理する側の両方をやっている。**

**[[faction:reimusho]] の実務は「その分野のB級を呼ぶ」で回っている**（→ 同）。**この人物は、呼ぶ手前で完結してしまう。**

### 指向性がある

**梓弓の「呼ぶ」も、鳴弦の「祓う」も、ある程度は向きを付けられる。**

**撒きっぱなしではない。**

| | 向きを付けるとは |
|---|---|
| **呼ぶ** | **何を呼ぶか、どこへ呼ぶか**を選べる |
| **祓う** | **何を祓うか、どこを祓うか**を選べる |

#### これが無いと、そもそも運用できない

**この国の妖怪の大半は、敵ではない。**

**妖怪には罪がない**（→ [[concept:legal-status]]）。**土地神との調整、協力妖怪との関係、妖怪の里との契約、逃しポイントの維持**（→ [[concept:cooperation-policy]]）。**どれも祓う相手ではない。**

**無差別の広範囲浄化は、制度としてまず通らない。**

> **祓えることより、祓わずに済ませられることのほうが要件になる。**

**[[char:kurosawa-akira]] の天使が「相手が悪だと出力が上がる」形で相手を選ぶのに対し、こちらは**本人が選ぶ**。**

| | 選んでいるのは |
|---|---|
| **天使**（→ [[char:kurosawa-akira]]） | **伝承。**悪かどうかで勝手に上下する |
| **この人物** | **本人。**どれを祓うか決めている |

> **repo 側の読み。** **どこまで細かく選べるかは決めていない。**

### 縫い止めが、監視の実体

**「A級一人分の足止め」の中身がこれ。**

**特殊A級を倒すことはできない。** **ただし縫い止めの矢を撃ち続けるあいだ、その場から動かせる幅を削れる。**

**[[faction:reimusho]] が到着するまでの時間を、それで作る。**

## 天之麻迦古弓

**A級呪具**（→ [[concept:jugu]]）。**あめのまかこゆみ。**

**記紀の弓。** **天若日子が葦原中国の平定を命じられたときに、天から与えられたもの。**

### 恒常型

**[[concept:jugu]] の三分類でいうと、恒常型。**

> **喋る、選ぶ、勝手に動く、土地と結びつくなら恒常型。**

**この弓は、選ぶ。**（下記）

**消費型でも起動型でもない。** **自分で条件を持っていて、自分でそれを執行する。**

### 返し矢

**伝承のとおり。**

**天若日子は八年帰らず、下界で妻を娶り、任を捨てた。** **そして問いに来た雉を、この弓で射た。**

**矢は天まで届き、投げ返され、寝ていた本人を貫いた。**

> **返し矢、恐るべし。**

**この弓は、その一件をそのまま持っている。**

| | |
|---|---|
| **任のために撃つ** | **通る** |
| **任を裏切って撃つ** | **返ってくる** |

**[[concept:core-layer]] の伝承拘束が、道具の側にも同じ形で出ている。**

> **伝承どおりに強い。そして、伝承どおりにしか強くない。**

> **repo 側の読み。** **伝承拘束は妖怪の話として書かれている。** **呪具にも同じ形でかかるとは書かれていない。**
> **ただし [[concept:grades]] に「もう一つの梯子（伝承再現度）」があるので、この段の呪具がそう動くのは筋が通る。**

### 天之波々矢

**あめのはばや。** **この弓から出る矢。**

**記紀では、天若日子がこの矢を射て、投げ返されて死んでいる。** **返し矢**（上記）**の、その矢。**

**条件付きの必中。** **神判に近いとされている。**

**そして、外部からは条件が分からない。**

#### 「とされている」も「不明」も、外から見た話

**ここを取り違えないこと。**

**分かっていないのは、外側。**

| | |
|---|---|
| **条件を満たすと、必ず当たる** | 外れない |
| **神判に近い「とされている」** | **外からの評価。**そう見えている、という言い方 |
| **条件が何かは不明** | **外部から見て、読めない** |

**本人や家の側でどう把握しているかは、書かれていない。**

> **repo 側の決定。** **条件そのものは決めていない。**
> **そして「本人も知らない」とも決めていない。** **外から不明、というところまで。**

#### 外から対策が立てられない

**相手の側からすると、こうなる。**

**たまに、外れない矢が飛んでくる。** **いつそうなるのかが読めない。**

**避けられる矢と、避けられない矢の区別が、撃たれる側からは付かない。**

> **一射ごとに、どちらか分からないまま対処することになる。**

**これは [[concept:battle]] の条件戦の裏返し。** **相手の条件を読んで崩すのがこの世界の戦い方だが、こちらの条件は読ませていない。**

#### 普段の命中とは、出どころが別

**この人物の普段の命中は、本人の技術**（上記）。**音速を超える相手に当てられるのは、何年もの積み上げ。**

**天之波々矢の必中は、そこと別のところから来る。**

| | 当たる理由 |
|---|---|
| **普段の射** | **腕。**本人のもの |
| **天之波々矢** | **条件。**満たされていれば |

#### 返し矢と、同じ機構の表と裏

**当てる側の必中と、撃った者へ返る返し矢。**

**どちらも「射手の意思では決まらない」という一点で同じ。**

| | |
|---|---|
| **必中** | **条件が満たされていれば、相手へ届く** |
| **返し矢** | **任を裏切っていれば、自分へ返る** |

> **神判に近い、というのはそういうこと。**
> **矢の行き先を決めているのが、射手ではない。**

**[[concept:core-layer]] の伝承拘束で言えば、これも伝承どおり。** **天若日子の矢は、標的にも射手にも当たっている。**

### 見張りに、裏切ると自分に返る弓を持たせてある

**ここが効く。**

**この家の仕事は、何百年も一つの石を見ていること。**

**そして持たされているのが、任を裏切った者を撃ち殺した弓。**

> **見張りが寝返らないことを、制度ではなく伝承が保証している。**

**[[concept:taimashi]] に「三系統のどこかに裏の側があるわけではない。だから三系統のどれにも安全な側が無い」とある。**

**[[char:shinohara-kyo]] は、その通りのことをやった。** **公職A級が二百年隠れていて、制度の側に止める仕組みは何も無かった。**

**この席にだけ、それがある。**

> **repo 側の読み。** **弓をそういう安全装置として置いたのは repo。**
> **国がそれを見込んで持たせているのか、家が勝手に持っているだけなのかは決めていない。**

#### そして、この人物は寄せられる

**梓弓は誘引の技**（上記）。**あたり一帯の妖怪を、無意識のうちに動かせる。**

**向きを変えれば、そのまま殺生石へ寄せられる。**

> **日本最大級の封印の隣に、そこへ妖怪を集められる人間が一人立っている。**

**[[char:tamamo-no-mae]] は封印されて何百年経っても、名前も個体性も薄まらない**（→ 同）。**封じられているのは体であって、名前は外にある。**

**そこへ思念や妖怪を寄せ続けたら何が起きるのかは、書かれていない。**

**返し矢の意味が、これで一段変わる。**

| | |
|---|---|
| **見張りが動かない保証** | **裏切って撃てば、矢が返る** |
| **ただし** | **弦を鳴らすのは、射ることではない** |

> **repo 側の未決。** **返し矢が「射る」だけを見ているのか、任そのものを見ているのかは決めていない。**
> **前者なら、この安全装置には穴がある。**

### 等級は、弓で上がっていない

**[[concept:jugu]] の「呪具は等級差を覆す。ただし覆しているのは主に消費型」。**

**この人物はA級で、その上に恒常型のA級呪具が乗っている。**

**弓が無くても天眼通は残る。** **弓が無くても、A級の基礎スペックは残る。**

**[[char:naruse-jin]] とは向きが逆になる。**

| | |
|---|---|
| **[[char:naruse-jin]]**（B級最上位） | **剣が本体。**本人の等級を上げると剣の意味が薄くなる |
| **この人物**（A級） | **本人が本体。**弓は出力の出口 |

### 台帳上はA級呪具になっている
