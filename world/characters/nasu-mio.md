## 概要

**A級退魔師。旧家**（→ [[faction:old-houses]]）。**神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。

**分野は特殊A級近傍監視**（→ [[concept:battle]] のA級の分野一覧）。

**[[char:tamamo-no-mae]] を封じている殺生石を、代々見ている家の当主。**

## 何ができるか

**天眼通と、弓。** **見る手段と、当てる手段が別々にあって、組になっている。**

| | |
|---|---|
| **天眼通** | **見る。**距離も、遮蔽も、隠形も通らない |
| **梓弓** | **呼ぶ。**あたり一帯の妖怪を、無意識のうちに誘導し、誘引する |
| **鳴弦** | **祓う。**近寄った妖怪を祓い、浄化と退魔を広範囲に撒く |
| **単射** | **当てる。**一射がA級火力。ただし**点**であって、面ではない |
| **縫い止め** | **当てた対象を、土地へ固定する。** 倒すのではなく、動けなくする |

**射る二つ以外は、弦を鳴らすだけ。** **矢を使わない。**

> **一張りの弓で、呼ぶ・祓う・射るが揃っている。**

**使うのは [[concept:jugu]] のA級呪具、天之麻迦古弓**（下記）。

### 天眼通

**六神通の一つ。**

**遠くのものが見える。** **壁も土も抜けて見える。** **隠れているもの、化けているもの、そこにあると思われていないものが見える。**

**目で見ていない。**

#### 未来は見えない

**ここは切っておく。**

**「天眼通」を広く取ると過去未来まで含む説明が付くことがあるが、**この人物のそれは今の話だけ**。**

**[[event:hyakki-yako-attempt]] には未来を見る能力を持った妖怪が別にいる**（→ 同）。**そちらと混ざらないようにする。**

> **repo 側の決定。** **天眼通の範囲を、距離・遮蔽・隠形の三つに限った。**

#### 人間が神通力を持っているのは、異例のほう

**神通力は妖怪の側の標準装備。** **[[concept:youkai-samples]] の鴉天狗にも「強力な神通力も標準搭載」とある。**

**人間の側にあるのは、普通ではない。**

**[[char:kamo-gen]] の「先祖から技術と力を継承する血族的契約」という前例が一つある**（→ 同）。**同じ理屈なのかは書かれていない。**

> **repo 側の読み。** **人間が神通を持つ経緯は決めていない。**

### なぜA級が一人、石に張り付いているのか

**ここが天眼通で埋まる。**

**殺生石の封印は手入れが要らない**（→ [[char:tamamo-no-mae]]）。**外から見て、何も起きていない。**

**それは「中身が眠っている」ことの証明にはならない。**

> **手入れの要らない封印ほど、外からは何も分からない。**

**天眼通は、石の中が見える。**

**[[char:tamamo-no-mae]] が今どういう状態でそこにいるのかを、実際に見て確認できる人間が、日本にこの一人しかいない。**

**だから交代が利かず、離れられない。**

### 弓のほう

**天眼通で見えたものへ撃つ。**

**だから「見えていないものには撃てない」は、性能の順序そのもの。** **天眼通が先にあって、射がその出口になっている。**

**射程は天眼通の届く範囲。** **数十キロ。**

### 梓弓 — 呼ぶ

**弦を鳴らして、寄せる。**

**梓弓は、もともと霊を呼ぶための道具。** **弦を弾いて口寄せをする巫の作法が、そのまま技になっている。**

**あたり一帯の妖怪が、無意識のうちに誘導され、誘引される。**

> **本人たちに、寄せられている自覚がない。**

**[[concept:battle]] の条件戦とは、質が違う。** **相手の条件を読んで崩すのではなく、相手が判断する前に足を動かさせる。**

#### 逃しポイントの逆

**[[concept:a-rank]] の斎木惺は、逃しポイントの口を開けて、相手を戦場から抜いて落とす。**

**この人物は、逆。**

| | |
|---|---|
| **斎木惺** | **外へ出す** |
| **この人物** | **内へ寄せる** |

**那須野原は広い。** **湧いたものを一箇所へ集めて、そこで祓う**（下記）**という運用が、何百年ぶんそこにある。**

> **repo 側の読み。** **家がそう運用してきたとは書かれていない。**
> **ただし技の組み合わせが、そうとしか読めない形をしている。**

### 鳴弦 — 祓う

**弦を鳴らして、祓う。**

**鳴弦も実在の作法。** **矢をつがえずに弦を打ち、邪を退ける。**

**追い払うだけではない。** **物理的な浄化と退魔の効果を、広範囲に撒く。**

> **近寄った時点で、祓われている。**

#### だから近接は、対妖怪ではゼロではない

**懐に入られて終わるのは、対人のとき。**

**妖怪が近寄ってきたぶんには、鳴弦がある。** **むしろ近寄るほうが不利になる。**

| 相手 | |
|---|---|
| **妖怪** | **近寄られても祓える。**距離を詰められるほうが有利 |
| **人間の術者** | **懐に入られたら終わる。**祓いが効かない |

**[[concept:a-rank]] の柏木蓮のような犯罪者A級には、この防御が効かない。**

### 面はある。ただし焼くほうではない

**[[char:naruse-cecile]] の超火力爆撃とは、面の質が違う。**

| | 面の中身 |
|---|---|
| [[char:naruse-cecile]] | **焼く。**破壊 |
| **この人物** | **祓う。**浄化と退魔 |

**破壊力としての面は無い。** **建物も地形も壊せない。** **そのかわり、妖怪に対してだけは広範囲に効く。**

> **[[concept:grades]] の「A級は技一個が山破壊級」の平均に、火力の側では届いていない。**
> **ただし退魔師の仕事の側では、面を持っている。**

### そして順序は変わらない

**見えていないものには撃てない。** **観測が先で、射がその後。**

**土地を離れると、天眼通の範囲を失う。** **那須野原の外では、ただの射程の長い術者になる。**

> **一箇所にいることが、この人物の性能の前提になっている。**

### 三つを繋ぐと、罠として完結している

| 手順 | |
|---|---|
| **1** | **天眼通で、どこに何がいるか見る** |
| **2** | **梓弓で、寄せる** |
| **3** | **鳴弦で、祓う** |
| **4** | **祓いきれないものだけ、射る** |
| **5** | **それでも落ちないものは、縫い止める** |

> **一人で、集める側と、処理する側の両方をやっている。**

**[[faction:reimusho]] の実務は「その分野のB級を呼ぶ」で回っている**（→ 同）。**この人物は、呼ぶ手前で完結してしまう。**

### 縫い止めが、監視の実体

**「A級一人分の足止め」の中身がこれ。**

**特殊A級を倒すことはできない。** **ただし縫い止めの矢を撃ち続けるあいだ、その場から動かせる幅を削れる。**

**[[faction:reimusho]] が到着するまでの時間を、それで作る。**

## 天之麻迦古弓

**A級呪具**（→ [[concept:jugu]]）。**あめのまかこゆみ。**

**記紀の弓。** **天若日子が葦原中国の平定を命じられたときに、天から与えられたもの。**

### 恒常型

**[[concept:jugu]] の三分類でいうと、恒常型。**

> **喋る、選ぶ、勝手に動く、土地と結びつくなら恒常型。**

**この弓は、選ぶ。**（下記）

**消費型でも起動型でもない。** **自分で条件を持っていて、自分でそれを執行する。**

### 返し矢

**伝承のとおり。**

**天若日子は八年帰らず、下界で妻を娶り、任を捨てた。** **そして問いに来た雉を、この弓で射た。**

**矢は天まで届き、投げ返され、寝ていた本人を貫いた。**

> **返し矢、恐るべし。**

**この弓は、その一件をそのまま持っている。**

| | |
|---|---|
| **任のために撃つ** | **通る** |
| **任を裏切って撃つ** | **返ってくる** |

**[[concept:core-layer]] の伝承拘束が、道具の側にも同じ形で出ている。**

> **伝承どおりに強い。そして、伝承どおりにしか強くない。**

> **repo 側の読み。** **伝承拘束は妖怪の話として書かれている。** **呪具にも同じ形でかかるとは書かれていない。**
> **ただし [[concept:grades]] に「もう一つの梯子（伝承再現度）」があるので、この段の呪具がそう動くのは筋が通る。**

### 見張りに、裏切ると自分に返る弓を持たせてある

**ここが効く。**

**この家の仕事は、何百年も一つの石を見ていること。**

**そして持たされているのが、任を裏切った者を撃ち殺した弓。**

> **見張りが寝返らないことを、制度ではなく伝承が保証している。**

**[[concept:taimashi]] に「三系統のどこかに裏の側があるわけではない。だから三系統のどれにも安全な側が無い」とある。**

**[[char:shinohara-kyo]] は、その通りのことをやった。** **公職A級が二百年隠れていて、制度の側に止める仕組みは何も無かった。**

**この席にだけ、それがある。**

> **repo 側の読み。** **弓をそういう安全装置として置いたのは repo。**
> **国がそれを見込んで持たせているのか、家が勝手に持っているだけなのかは決めていない。**

#### そして、この人物は寄せられる

**梓弓は誘引の技**（上記）。**あたり一帯の妖怪を、無意識のうちに動かせる。**

**向きを変えれば、そのまま殺生石へ寄せられる。**

> **日本最大級の封印の隣に、そこへ妖怪を集められる人間が一人立っている。**

**[[char:tamamo-no-mae]] は封印されて何百年経っても、名前も個体性も薄まらない**（→ 同）。**封じられているのは体であって、名前は外にある。**

**そこへ思念や妖怪を寄せ続けたら何が起きるのかは、書かれていない。**

**返し矢の意味が、これで一段変わる。**

| | |
|---|---|
| **見張りが動かない保証** | **裏切って撃てば、矢が返る** |
| **ただし** | **弦を鳴らすのは、射ることではない** |

> **repo 側の未決。** **返し矢が「射る」だけを見ているのか、任そのものを見ているのかは決めていない。**
> **前者なら、この安全装置には穴がある。**

### 等級は、弓で上がっていない

**[[concept:jugu]] の「呪具は等級差を覆す。ただし覆しているのは主に消費型」。**

**この人物はA級で、その上に恒常型のA級呪具が乗っている。**

**弓が無くても天眼通は残る。** **弓が無くても、A級の基礎スペックは残る。**

**[[char:naruse-jin]] とは向きが逆になる。**

| | |
|---|---|
| **[[char:naruse-jin]]**（B級最上位） | **剣が本体。**本人の等級を上げると剣の意味が薄くなる |
| **この人物**（A級） | **本人が本体。**弓は出力の出口 |

### 台帳上はA級呪具になっている

**由緒からすれば、[[concept:relics]] の遺物に置かれてもおかしくない。**

**記紀に名前が出ている弓が、栃木の一軒の家にある。**

**そうなっていない。**

> **遺物として登録されれば、所有権、国際条約、文化財保護が全部乗ってくる**（→ [[concept:relics]]）。
> **A級呪具のままなら、[[faction:reimusho]] の免許の話で済む。**

**[[char:naruse-jin]] のフランス国宝が私人の手にあるのと、同じ形の穴。**

> **repo 側の読み。** **なぜ遺物登録されていないかは決めていない。**
> **家が申告していないのか、国が置いておくと決めたのかは未決。**

## 那須という家

**那須野原の在地の家。** **[[char:tamamo-no-mae]] が逃げ込んだ土地の、もともとの領主筋にあたる。**

**だから封印を掛けた家ではない。** **掛けられた土地に、もとからいた家。**

> **repo 側の設定。** **殺生石を誰が封じたかは【掘らない】**（→ [[char:tamamo-no-mae]]）。
> **その掘らない部分を避けるために、「封じた家」ではなく「見ている家」にした。**

### 武家と、僧が、一つの家になっている

**弓は武家の側。** **天眼通は仏の側。**

**那須野原には、逃げた九尾を止めた武家の話と、石に手を掛けた僧の話が、両方残っている。**

**その二つが、同じ土地で一つの家になった。**

| | |
|---|---|
| **見る** | 僧の側から来たもの |
| **当てる** | 武家の側から来たもの |

> **repo 側の設定。** **神仏習合そのもので、栃木という土地には無理がない。**
> **ただし「石を封じたのが誰か」は【掘らない】**（→ [[char:tamamo-no-mae]]）**ので、僧の側が封じたとは書かない。**
> **手を掛けた話が家に残っている、というところで止める。**

### 一度、この土地で止めた家

**射て、縫い止める技術は、九尾を止めた一件のためのものだった。** **そして相手はまだそこにいる。**

> **家の技が、見張っている対象に対して作られている。**
> **だから他の家では代わりが利かない。**

**[[concept:core-layer]] の伝承拘束が、人間の側にも同じ形で効いていることになる。** **[[char:tamamo-no-mae]] が伝承どおりの姿でいるように、この家も伝承どおりの役をやり続けている。**

> **repo 側の読み。** **人間の家系に伝承拘束がかかるとは書かれていない。**
> **ただし「先祖から技術と力を継承する契約」の例が既に一つある**（→ [[char:kamo-gen]]）。

## 仕事は、見ていること

**殺生石の封印は出来が死ぬほどよく、基本的に手入れが要らない**（→ [[char:tamamo-no-mae]]）。

**何百年も手を入れずに保っている。**

**だからこの人物の仕事は、封印を維持することではない。**

> **見ている。**
> **それだけ。**

**[[concept:relics]] の三種の神器と同じ形が、人の側にも一つある。** **持っているが動かさない。** **動く時点で、通常の事態ではない。**

### 直せないほうの見張り

**ここが重い。**

**封印を掛けた技術は、この家に伝わっていない。**

**A級相当への封印は秘術の領域で、概要すらシークレット**（→ [[faction:shrines]]）。**掛けた者が誰かも分かっていない。**

**つまり、もし殺生石が緩んだ場合、この人物にできるのは掛け直すことではない。**

| できること | |
|---|---|
| **見る** | **天眼通で、石の中まで**（上記） |
| **気づく** | **他の誰よりも早い。**外から分かる話ではないので |
| **知らせる** | [[faction:reimusho]] へ |
| **足止めする** | **縫い止めの矢で、動ける幅を削る**（上記） |

> **日本で二体しかいない特殊A級の一体を、直せない人間が見張っている。**

**[[concept:a-rank]] の物部灯（国家級封印）が呼ばれることになる。** **ただしその人物にも、この封印は掛け直せない。** **同じ秘術を持っているとは書かれていない。**

### だからA級が要る

**理由が二本ある。**

**一本目は天眼通**（上記）。**石の中を見られるのが、この人物しかいない。**

**二本目が、気づいた後。** **[[faction:reimusho]] が動くまでの時間を、誰かが持たなければならない。** **相手が特殊A級である以上、その誰かはA級でないと数分も保たない。**

> **見る役と、止める役が、同じ一人に乗っている。**

## 場所の問題

**殺生石があるのは栃木。** **[[faction:reimusho]] の区分では関東地区。**

**そして関東の校地は [[loc:nikko]] で、これも栃木。**

> **同じ県に、六校のうち一校と、日本最大級の封印がある。**

**関東地区長は [[char:mimura-sumi]]。** **[[char:shinohara-kyo]] が封殺されて以来、東北を兼務している**（→ [[concept:a-rank]]）。

> **日本で一番危ない封印がある地区を、二地区を掛け持ちしている人間が見ている。**

**そのぶん、在地のこの家が持っている部分が大きくなる。**

> **repo 側の読み。** **兼務と封印の距離が近いことは、配置から出てくるだけで、書かれていない。**

## 六人の中での位置

**[[concept:a-rank]] の神社旧家枠は、土地と家に紐づいている側。**

**その中でも、この人物は一番動けない。** **見る対象が動かないので、見る側も動けない。**

| | |
|---|---|

> **A級18人のうち一人は、ほぼ一つの石から離れられない。**
