## 概要

**A級退魔師。神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。

**分野は国家級封印**（→ [[concept:battle]] のA級の分野一覧）。

**封印系のカード使い。** **妖怪も、技も、現象も、札に封じて束で持ち歩いている。**

> **分野の機構だけ決まっている状態。** **名前も家も育ちも来歴も仮**（下記）。

## 何ができるか

**封印系のカード使い。**

**札の束を持ち歩いている。** **中身は三種類。**

| 束の中身 | |
|---|---|
| **妖怪** | 封じた個体そのもの |
| **技** | **飛んできた攻撃。**その一発 |
| **現象** | **起きていること。**火、落雷、崩落、呪い、**台風** |

| | |
|---|---|
| **封じる** | **外殻へ「ここから出られない」を刻み、札を器にする。**刻めれば相手の格は関わらない |
| **持つ** | **封じた札が、そのまま手札になる** |
| **切る** | **札を開けて、中身を出す**（下記） |
| **出来を読む** | **他人が掛けた封印も、見れば手入れの要否が分かる** |

### 封じるとは、外殻に一点を刻むこと

**[[concept:core-layer]] の理屈で書くと、封印はこうなる。**

**核には触らない。** **外殻へ「出られない」という定義を一つ刻む。**

**[[concept:core-layer]] の契約が「一瞬で一点を刻む」ものであるのと、同じ側の技術。**

> **契約は相手を自分の外殻として扱う行為。**
> **封印は相手の外殻へ、こちらの都合を書き込む行為。**

#### だから、討伐ではない

**核が無傷で残る。**

**[[char:tamamo-no-mae]] が「封印されて何百年経っても、名前も個体性も薄まらない」**（→ 同）**のは、これで説明がつく。**

**封じられているのは体であって、核は生きている。**

> **殺していない。** **出られなくしただけ。**

**[[concept:cooperation-policy]] の「討伐しない」路線と、技術の側が噛み合っている。**

**そして札の中身も、生きている。**

> **束の中で、全部が起きている。**

### 刻めれば、相手の格は関わらない

**出力で押し勝つ技術ではない。**

**外殻へ一点書き込めるかどうか、だけで決まる。**

**[[event:hyakki-yako-attempt]] の決着が出力ではなく条件で付いた**（→ 同）**のと、同じ側の話。**

### 技と現象も、札に入る

**封じる対象は、存在に限らない。**

**飛んできた攻撃も、起きている現象も、札に落とせる。**

#### 飛んできたものを、札に落とす

**撃たれた一発を、そのまま札へ入れる。**

**その攻撃はそこで止まる。** **そして手元に残る。**

> **受けたものが、そのまま手札になる。**

**札を切れば、同じ攻撃が出る。**

**術者から術式を取り上げているのではない。** **相手は、また撃てる。**

> **奪ったのは、飛んできた一発だけ。**

#### 現象には、大きさの上限が無い

**火、落雷、崩落、呪い、汚染。**

**そして台風も、普通に封じ込めている。**

**術者が起こしたものである必要も、小さいものである必要もない。**

> **数百キロにわたって何日も続いているものが、一枚の札に入る。**

##### 妖怪とは、仕組みが別

**妖怪には核と外殻がある**（→ [[concept:core-layer]]）。**だから外殻へ「出られない」を刻む、という手順になる。**

**現象には、核が無い。**

**刻む相手がいないので、起きていることを丸ごと落とすことになる。**

| | |
|---|---|
| **妖怪** | **刻む。**外殻へ一点書き込む |
| **現象** | **落とす。**起きていることをそのまま |

> **だから大きさが効かない。**
> **刻む手順のほうには相手の格が関わらず、落とす手順のほうには規模が関わらない。**

##### 札の中で、台風は続いている

**封じたものは止まっていない。**

**「束の中で、全部が起きている」**（上記）**が、そのまま。**

> **束のどこかに、いま台風がある。**

**そして札を切れば、出る。**

##### それでも日本には台風が来る

**現実の気象は現実準拠**（→ `docs/02-canon-policy.md` の「現実の歴史を書き換えない」）。**毎年来るし、被害も出る。**

**封じられる人間が、この一人しかいない。**

**そして [[faction:reimusho]] は依存しているが、命令はできない**（下記）。

> **repo 側の未決。** **どういうときに封じて、どういうときに封じないのかは決めていない。**
> **全部は封じていない、というところまで。**

#### [[concept:jugu]] の消費型の、定義そのもの

**[[concept:jugu]] にこう書いてある。**

> **消費型が現象を一度だけ保存した道具なら、恒常型は現象そのものを定着させた道具。**

**そして完成済みの消費型は、術式・発動条件・現象・必要資源まで封入済み。**

**普通は、術者が術式から組んで作る。**

**この人物は、起きているもののほうを、そのまま封じる。**

> **作っているのではない。** **拾っている。**

**[[char:suwa-shizuka]] が自分の出力を詰めて国家備蓄霊札を作るのとは、行為が違う。**

| | |
|---|---|
| **[[char:suwa-shizuka]]** | **自分から出したものを、詰める** |
| **この人物** | **そこで起きているものを、落とす** |

### 器が札である、ということ

**[[concept:jugu]] の札の系譜に乗る。** **ただし中身が違う。**

| | 札に詰まっているもの |
|---|---|
| **国家備蓄霊札**（→ [[char:suwa-shizuka]]） | **術者の出力。**A級退魔師を缶詰にしたもの |
| **[[char:kamo-gen]] の死者蘇生札** | **自分の術、一回分** |
| **この人物の札** | **封じた妖怪、受けた一発、起きていた現象** |

> **repo にある札は、どれも自分のものを詰めている。**
> **これだけが、外にあるものを詰めている。**

#### 器は札に限らない

**石、刃、蔵、土地。** **[[char:tamamo-no-mae]] の殺生石も、封印の器。**

**ただしこの人物が普段使うのは札。**

> **軽い、大量に持てる、投げられる、貼れる、隠せる**（→ [[concept:jugu]] の「消費型といえば札」）。
> **現場運用との相性で、そうなっている。**

### 札の切り方が、三つある

| | |
|---|---|
| **持っているだけ** | **捕獲、保管、移送。**これが本業 |
| **開けて放つ** | **中身を出す。**味方ではない。ぶつける |
| **開けずに通す** | **封を緩めて、中身の力だけ引き出す。**制御できるが、弱い |

#### 放った中身は、味方ではない

**[[char:kurosawa-akira]] の式神操作とは、根本から違う。**

| | |
|---|---|
| **[[char:kurosawa-akira]]** | **借りている。**交渉して、貸してもらっている |
| **この人物** | **封じている。**中身は出たがっている |

> **同時使役数の話にならない**（→ 同）。**操作していない。**
> **開けているだけ。**

**だから放つのは、場所と向きを選ぶ話になる。** **敵の只中で開ける。**

**出たものが誰を襲うかは、保証されていない。**

> **repo 側の設計。** **制御しないことを、この技の性格にした。**

## 開けられる

**封じられるということは、解ける。**

**そして [[faction:reimusho]] が持っているのは一般封印技術で、A級相当への封印は秘術の領域**（→ [[faction:shrines]]）。**国内の高位の封印は、この分野の手順で掛かっている。**

> **同じ手順で掛けたものは、同じ手順で外せる。**

**点検も、掛け直しも、これが前提になっている。**

## 封印は、記録の技術でもある

**何を、どこに、どう封じたか。**

**それが分からなくなれば、点検も手入れもできない。**

**何百年ぶんの封印を回すには、術と同じだけ台帳が要る。**

**そして札の束も、そのまま台帳になっている。**

> **どの札に何が入っているかを、間違えられない。**

## 台帳に載っていない封印がある

**[[char:tamamo-no-mae]] の殺生石。**

**誰が掛けたかが分かっておらず、[[char:nasu-mio]] の家にも技術が伝わっていない**（→ 同）。

**この人物にも、掛け直せない。**

> **日本最大級の封印が、この分野の記録に載っていない。**

**そして出来が死ぬほどよく、手入れが要らない**（→ [[char:tamamo-no-mae]]）。

**出来を読める人間が見て、直すところが無いと言っている状態。**

**[[char:tamamo-no-mae]] の「誰かが、途方もなくいい仕事をした」**（→ 同）**を、一番よく分かっているのがこの人物。**

## 立場

**神社旧家枠のA級。** **公職ではない。**

**[[faction:reimusho]] が持っているのは一般封印技術なので、A級相当が出たときは国の手に負えない。**

> **呼ぶしかない。**

**[[concept:battle]] の「A級はその国における分野別の第一人者」。** **[[char:kamo-gen]] の死者蘇生と同じで、分野に一人しかいない。**

**[[faction:reimusho]] は依存しているが、命令はできない**（→ 同）。

## まだ決まっていないこと

**分野の機構はここまで。**

**家、育ち、性格、来歴は、いったん白紙に戻した。**

> **一度書いたが、[[char:nasu-mio]] の形をそのまま当てはめただけだった。**
> **危ないところの節、育ちの節、家の由来の節を、順番に埋めにいっていた。**

**「物部」という名も、封印と繋がる理由が無い。** **保留。**
