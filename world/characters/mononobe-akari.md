## 概要

**A級退魔師。神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。**分野は国家級封印。**

**封印系のカード使い。**

**名前のあるものを指定し、触れていれば、その名前が指す範囲が全部札に入る。** **街も、大地も、大海も、酸素だけも、熱量だけも。**

**そして切れば、そのまま出る。**

> **名前も家も育ちも来歴も仮**（下記）。

## 何ができるか

**札に封じて、束で持ち歩いている。**

**対象を選ばない。**

| 束の中身 | |
|---|---|
| **妖怪** | **個体そのもの。**普通に封じている |
| **技** | **飛んできた攻撃。**その一発 |
| **現象** | 火、落雷、崩落、呪い。**台風も** |

**三つを別々の技でやっているのではない。** **同じように札へ入る。**

**大きさも関係ない。** **数百キロにわたって何日も続いているものが、一枚の札に入る。**

### 入れ方 — 名前を指定して、触れる

**「名前のある何か」を指定する。** **そこに触れていれば、その名前が指す範囲が全部入る。**

**触れている一点は入口でしかない。** **入るものの大きさとは、関係がない。**

> **「〇〇街」を指定すれば、街の端の地面に触れるだけで、街ごと回収できる。**

**だから台風も入る。** **数百キロにわたって何日も続いているものに、当てる面を探す必要がない。** **名前を指定して、届くところに触れればいい。**

**札が届かないと入らない、というのはそういうこと。** **投げる、貼る、触れさせる。**

**そこから先に条件が無い。**

| | |
|---|---|
| **弱らせる必要** | **無い。元気なまま入る** |
| **止める必要** | **無い** |
| **大きさ** | **関係ない** |
| **相手が何か** | **関係ない。妖怪でも、攻撃でも、現象でも** |

> **当たれば入る。**

### 出し方 — 札を切る

**封印解除。** **封じたものが、そのまま出る。**

**妖怪なら個体が出てくる。台風なら台風が出る。**

**そして、出したものは言うことを聞かない。**

> **使役ではない。召喚でもない。**
> **解除しただけ。**

#### 出し方は、ある程度選べる

**中身は操れない。** **出し方のほうを選ぶ。**

| | |
|---|---|
| **ポンと出す** | **その場に、そのまま** |
| **はるか上空に出す** | **落ちてくる** |
| **部分的に出す** | **全部は出さない。一部だけ、出したい形で** |

> **中身が同じでも、出し方が違えば別の技になる。**

#### 出すときに、霊力を上乗せできる

**封じているあいだ、中のものはこの人物の霊力にある程度触れている。**

**だから出すときに、自分の霊力を上から乗せられる。**

> **出てくるものは、入れたときのままではない。**

**大地も、大海も、封じた一発も、乗せた分だけ大きくなって出る。**

#### 操らない。ただ、どこで出すかを選ぶ

**出したものは従わない。** **それでも武器になる。**

| 封じるもの | 出し方 |
|---|---|
| **大地** | **隕石のように落とす** |
| **大海** | **ウォーターカッター** |
| **酸素だけ** | **大爆破** |
| **熱量だけ** | **灼熱熱波** |
| **敵の攻撃** | **防御になり、そのまま攻撃返しになる** |
| **一区画の土地ごと** | **民衆を守ったまま、輸送する** |

**六つとも、同じ一つの型。** **封じて、出す。**

**上の三つの出し方の組み合わせで、全部そこから出ている。** **大地をはるか上空に出せば隕石になり、大海を部分的に出せば水の刃になる。**

> **操作はしていない。**
> **どこで、どう出すかを選んでいるだけ。**

**攻撃も、防御も、輸送も、そこから出ている。**

## 家と、本人が作ったもの

**家は封印系の名家。** **封印そのものが、代々の家業になっている。**

**そして本人が、それをさらに改良した。**

> **名前そのものに強く関連づけた封印法。**
> **いま使っている「名前を指定して触れる」は、これ。**

**今のところ、他者には真似できない。**

### 家から受け取ったものではない

**封印系の名家に生まれて、家の封印を継いだ上で、その先を自分で作っている。**

| | |
|---|---|
| **家** | **封印系の名家。伝統としての封印** |
| **本人** | **名前に紐づけた封印法。改良であり、発明** |

**だから [[char:kamo-gen]] の血族的契約のように、先祖から渡ってきたものとは経路が違う。** **一代で作られていて、まだ誰にも渡っていない。**

## 戦い方

**封印だけの人ではない。**

| | |
|---|---|
| **呪具** | **複数持っていて、状況に応じて使い分ける**（→ [[concept:jugu]]） |
| **武芸** | **概ね武芸百般。近距離から遠距離まで、そつなくこなす** |
| **狙い** | **相手の弱点を当てる戦法が得意** |

**圧倒的な持ち札と、多種多様な呪具と、敵に合わせた戦闘方法。** **この三つを組み合わせて戦う。**

### 一芸では、他のA級に及ばない

**封印を除けば、どれも一番ではない。**

**それでも、武芸百般と持ち札の幅で、大概の相手には勝てる。**

> **一つで勝つのではなく、揃えて勝つ。**

**[[concept:battle]] の条件看破が、この人物では「相手の弱点に、手持ちの中から合うものを当てる」という形で出ている。**

### 封じ方そのものは、外に出ていない

**A級相当への封印は秘術の領域で、概要すら知られていない**（→ [[faction:shrines]]）。

**分かるのは、何が入るかと、それを持ち歩いていること。**

## 札であること

**[[concept:jugu]] の消費型呪具は、札が主流。**

> **軽い、大量に持てる、安い、投げられる、貼れる、隠せる。**
> **現場運用との相性が良すぎるので、消費型といえば札、という扱いになっている。**

**この人物の札も、その形に乗っている。** **「札を当てる」という入れ方が、そのまま [[concept:jugu]] の運用に乗る。**

### ただし、中身が違う

| | 札に詰まっているもの |
|---|---|
| **国家備蓄霊札**（→ [[char:suwa-shizuka]]） | **術者の出力。**A級退魔師を缶詰にしたもの |
| **[[char:kamo-gen]] の死者蘇生札** | **自分の術、一回分** |
| **この人物の札** | **封じた妖怪、受けた一発、起きていた現象** |

> **repo にある札は、どれも自分のものを詰めている。**
> **これだけが、外にあるものを詰めている。**

**[[char:suwa-shizuka]] が自分の出力を詰めて国家備蓄霊札を作るのとは、行為が違う。**

| | |
|---|---|
| **[[char:suwa-shizuka]]** | **自分から出したものを、詰める** |
| **この人物** | **そこで起きているものを、落とす** |

## まだ決まっていないこと

**分かっているのは、名前を指定して触れれば条件なしで入り、切れば封印解除でそのまま出ること。** **そして、どこで出すかを選ぶことで攻撃にも防御にも輸送にもなること。**

**家は封印系の名家で、そこは決まった。** **本人が名前に紐づけた封印法を作り、他者には真似できない、というところまで。**

**名前・育ち・来歴・性格は、まだ仮。**
