## 概要

**A級退魔師。旧家の当主**（→ [[faction:old-houses]]）。**神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。

**分野は国家級封印**（→ [[concept:battle]] のA級の分野一覧）。

**封印蔵を持つ家。** **そして日本の封印の、記録を持っている家。**

## 何ができるか

| | |
|---|---|
| **封じる** | **相手の外殻へ「ここから出られない」を刻む。**成立すれば等級を問わない |
| **器を用意する** | **封印には容れ物が要る。**石、剣、蔵、土地。作るか、選ぶ |
| **開ける** | **封じられるということは、解けるということ**（下記） |
| **出来を読む** | **封印を見て、手入れが要るかどうかが分かる** |

**戦闘の技は、これだけ。**

### 封じるとは、外殻に一点を刻むこと

**[[concept:core-layer]] の理屈で書くと、封印はこうなる。**

**核には触らない。** **外殻へ「出られない」という定義を一つ刻む。**

**[[concept:core-layer]] の契約が「一瞬で一点を刻む」ものであるのと、同じ側の技術。**

> **契約は相手を自分の外殻として扱う行為。**
> **封印は相手の外殻へ、こちらの都合を書き込む行為。**

#### だから、討伐ではない

**核が無傷で残る。**

**[[char:tamamo-no-mae]] が「封印されて何百年経っても、名前も個体性も薄まらない」**（→ 同）**のは、これで説明がつく。**

**封じられているのは体であって、核は生きている。**

> **殺していない。** **出られなくしただけ。**

**[[concept:cooperation-policy]] の「討伐しない」路線と、技術の側が噛み合っている。**

> **repo 側の読み。** **封印の内部構造は書かれていない。**
> **[[concept:core-layer]] の核と外殻から引いた。**

### 成立すれば、等級を問わない

**相手がA級だろうが特殊A級だろうが、刻めれば止まる。**

**[[concept:grades]] の等級差が、ここでは効かない。**

> **出力で押し勝つ必要がない。**

**[[concept:a-rank]] の中で、格上を正面から止められる可能性を持っているのは、この方向だけ。**

### 器が要る

**封じたものを、どこかへ入れなければならない。**

| | |
|---|---|
| **石** | [[char:tamamo-no-mae]] の殺生石 |
| **刃物** | [[concept:relics]] の側と重なってくる |
| **蔵** | 家の封印蔵 |
| **土地** | 動かせない代わりに、大きいものが入る |

**器の格が、封印の格を決める。**

**即席で作れる器は、そう大したものにならない。**

> **良い封印には、良い器が要る。**
> **そして良い器は、その場では手に入らない。**

## 弱点

### 時間と準備が要る

**撃ち合いの最中には通らない。**

**器の用意、術式の敷設、対象の固定。** **全部が前段にある。**

**[[event:hyakki-yako-attempt]] のような短期決戦には、そもそも間に合わない。**

### 動いているものは、封じられない

**ここが一番大きい。**

**刻むには、刻めるだけ相手が止まっていなければならない。**

**だから、この人物一人では完結しない。**

| | |
|---|---|
| **誰かが止める** | 拘束、足止め、無力化 |
| **この人物が刻む** | **そこから先** |

> **止める役が要る。**

**[[faction:reimusho]] の実務は「その分野のB級を呼ぶ」で回っている**（→ 同）。**この人物は、呼ばれる側であって、呼ぶ側ではない。**

#### [[char:nasu-mio]] とは、正反対

**あちらは一人で、見る・寄せる・祓う・射る・止めるが完結してしまう**（→ 同）。

**こちらは、一人では何もできない。**

| | |
|---|---|
| **[[char:nasu-mio]]** | **呼ぶ手前で終わる** |
| **この人物** | **呼ばれてから始まる** |

> **同じ神社旧家枠で、実務の形が真逆になっている。**

### 戦闘力そのものは低い

**封印以外に手が無い。**

**面も、火力も、近接も無い。**

**[[concept:grades]] の「搦手に寄ったA級には、ビル破壊能力がなかったりする」の、一番深いところ。**

## 開けられる、ということ

**ここが、この人物の危ないところ。**

**封じられるということは、解けるということ。**

### そして、国内の封印の多くはこの家の系統

**[[faction:reimusho]] が持っているのは一般封印技術で、A級相当への封印は秘術の領域。** **概要すらシークレット**（→ [[faction:shrines]]）。

**その秘術を持っている家が、これ。**

**何百年ぶんの封印が、この家の手順で掛かっている。**

> **同じ手順で掛けたものは、同じ手順で外せる。**

**この人物が開ける側に回ったら、日本中の封印が同時に危なくなる。**

### 台帳を持っている

**何が、どこに、どう封じられているか。**

**その記録が、この家にある。**

**封印は術の技術であると同時に、記録の技術でもある。** **何百年前に誰が何を封じたかが分からなくなれば、手入れも点検もできない。**

> **家の力は、蔵の中身ではなく、台帳のほうにある。**

**そして [[faction:reimusho]] は、その台帳を持っていない。**

### 歯止めが、無い

**[[char:nasu-mio]] には天之麻迦古弓の返し矢がある**（→ 同）。**任を裏切れば、矢が返る。**

**この人物には、それが無い。**

**[[concept:taimashi]] の「三系統のどこかに裏の側があるわけではない。だから三系統のどれにも安全な側が無い」。**

**[[char:shinohara-kyo]] は、公職A級として二百年隠れていた**（→ 同）。**制度の側に止める仕組みは何も無かった。**

> **この席も、同じ。**
> **開ける気になった場合に止めるものが、どこにも無い。**

> **repo 側の読み。** **この人物がそうする気配があるとは書いていない。**
> **構造としてそうなっている、というだけ。**

## 台帳に載っていない封印がある

**そして、これが一番効く。**

**[[char:tamamo-no-mae]] の殺生石は、この家の手順ではない。**

**誰が掛けたかも分かっておらず、[[char:nasu-mio]] の家にも技術が伝わっていない**（→ 同）。

**この人物にも、掛け直せない。**

> **日本最大級の封印が、日本一の封印の家の台帳に、載っていない。**

**そして出来が死ぬほどよく、手入れが要らない**（→ [[char:tamamo-no-mae]]）。

**出来を読める人間が見て、直すところが無いと言っている状態。**

> **一番いい仕事をした者が、誰なのか分かっていない。**

**[[char:tamamo-no-mae]] の「誰かが、途方もなくいい仕事をした」**（→ 同）**を、一番よく分かっているのがこの人物。**

## 家

### 現実では、滅んでいる

**物部氏は、古代の軍事と祭祀の氏族。**

**そして現実の歴史では、滅ぼされている。**

**この世界でも、そこは変えない**（→ `docs/02-canon-policy.md` の「現実の歴史を書き換えない」）。

**氏族としては絶えた。** **残ったのは、蔵と、手順と、台帳。**

> **家が続いたのではない。** **管理する対象のほうが続いていて、それを見る者が要り続けた。**

**[[char:kamo-gen]] の賀茂家と同じ形。** **現実で絶えている家が、この世界では役目のほうに引きずられて残っている。**

> **repo 側の設定。** **どう残ったかの経緯は決めていない。**

### 蔵

**奈良の在地。**

**古代から武器と神宝を納めてきた神庫の系統に連なる。**

> **repo 側の配置。** **実在の社そのものがこの家のものだとは書かない。**
> **そこから分かれた家、というところに置いた。**

**[[faction:reimusho]] にこうある。**

> **家系秘術、古代祭祀、特殊契約、神格関連術式、条件依存型の秘術、高危険呪物は、今も神社や旧家、地域の封印蔵へ分散して保管されている。**

**その「地域の封印蔵」の、一番大きいところ。**

### 継承は、血ではなく手順

**[[char:kamo-gen]] の家は血族的契約で、第一子の嫡男へ渡る**（→ 同）。

**こちらは違う。**

| | |
|---|---|
| **[[char:kamo-gen]]** | **契約。**血が要る |
| **[[char:nasu-mio]]** | **教育。**隣の里から教わっている |
| **この家** | **手順と記録。**読めて、覚えられれば継げる |

**だから血筋の問題が起きにくい。**

**そのかわり、記録が失われると即座に終わる。**

> **家の弱点が、家の力と同じところにある。**

## 育ち

**蔵で育っている。**

**最初に覚えたのは、封じ方ではない。**

| 順 | |
|---|---|
| **1** | **触ってはいけないものの見分け方** |
| **2** | **数え方。**台帳の付け方 |
| **3** | **点検。**出来を読むこと |
| **4** | **掛け方** |

**掛けるのが最後。**

> **開けてはいけない棚の前で、何年も数を数えていた。**

**この順序が、そのまま人物の形になっている。**

**慎重で、記録を欠かさず、手順を飛ばさない。**

> **repo 側の読み。** **性格は決めていない。**
> **ただし育ちの順序からすると、この方向になる。**

## 立場

**神社旧家枠のA級。** **公職ではない。**

**そして [[faction:reimusho]] が、この家に依存している。**

**国が持っているのは一般封印技術**（→ 同）。**A級相当が出たとき、国の手には負えない。**

> **呼ぶしかない。**

**[[concept:battle]] の「A級はその国における分野別の第一人者」が、そのまま。** **この分野には、この人物しかいない。**

### [[char:kamo-gen]] の死者蘇生と、同じ形

**分野に一人しかいない**（→ 同）。

**代わりが利かない。** **断られたら、そこで止まる。**

> **[[faction:reimusho]] は統治者ではなく調整者**（→ 同）。
> **依存はしているが、命令はできない。**
