## 概要

**A級退魔師。神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。**分野は国家級封印。**

**封印系のカード使い。** **名前のあるものを指定し、触れていれば、その名前が指す範囲が全部札に入る。** **街も、大地も、大海も、酸素だけも、熱量だけも。** **切れば、そのまま出る。**

> **名前・育ち・来歴・性格は仮**（→ 未決）。

## 入れ方 — 名前を指定して、触れる

**触れている一点は入口でしかなく、入るのは名前が指す範囲の全部。**

> **「〇〇街」を指定すれば、街の端の地面に触れるだけで、街ごと回収できる。**

**だから台風も入る。** **数百キロにわたって何日も続いているものに、当てる面を探す必要がない。**

**札は当てないと入らない。** **投げる、貼る、触れさせる。** **そこから先の条件は無い。**

| | |
|---|---|
| **弱らせる必要** | **無い。元気なまま入る** |
| **止める必要** | **無い** |
| **大きさ** | **関係ない** |
| **相手が何か** | **関係ない** |

### 束の中身

| | |
|---|---|
| **妖怪** | **個体そのもの** |
| **技** | **飛んできた攻撃。**その一発 |
| **現象** | 火、落雷、崩落、呪い、台風 |

**三つを別々の技でやっているのではない。**

## 出し方 — 札を切る

**封印解除。封じたものが、そのまま出る。**

**そして出したものは、言うことを聞かない。** **使役でも召喚でもない。**

**中身は操れないが、出し方は選べる。**

| | |
|---|---|
| **ポンと出す** | **その場に、そのまま** |
| **はるか上空に出す** | **落ちてくる** |
| **部分的に出す** | **全部は出さない。一部だけ、出したい形で** |

### 出すときに、霊力を上乗せできる

**封じているあいだ、中のものはこの人物の霊力にある程度触れている。** **だから出すときに、自分の霊力を上から乗せられる。**

> **出てくるものは、入れたときのままではない。**

### 従わないものが、武器になっている

| 封じるもの | 出し方 |
|---|---|
| **大地** | **隕石のように落とす** |
| **大海** | **ウォーターカッター** |
| **酸素だけ** | **大爆破** |
| **熱量だけ** | **灼熱熱波** |
| **敵の攻撃** | **防御になり、そのまま攻撃返しになる** |
| **一区画の土地ごと** | **民衆を守ったまま、輸送する** |

**六つとも、封じて、出すだけ。** **どこで、どう出すかを選んでいる。**

## 家と、本人が作ったもの

**家は封印系の名家で、封印が代々の家業。** **本人はそれを改良して、名前そのものに強く関連づけた封印法を作り出した。**

**今のところ、他者には真似できない。**

**元は家のもので、改良した部分だけがこの人物のもの。** **そこがまだ誰にも渡っていない。**

### 封じ方そのものは、外に出ていない

**A級相当への封印は秘術の領域で、概要すら知られていない**（→ [[faction:shrines]]）。

**分かるのは、何が入るかと、それを持ち歩いていること。**

## 戦い方

**封印だけの人ではない。**

| | |
|---|---|
| **呪具** | **複数持っていて、状況に応じて使い分ける**（→ [[concept:jugu]]） |
| **武芸** | **概ね武芸百般。近距離から遠距離まで、そつなくこなす** |
| **狙い** | **相手の弱点を当てる戦法が得意** |

**圧倒的な持ち札と、多種多様な呪具と、敵に合わせた戦闘方法を組み合わせて戦う。**

**一芸では、封印を除いて他のA級に及ばない。** **それでも、武芸百般と持ち札の幅で、大概の相手には勝てる。**

**[[concept:battle]] の条件看破が、この人物では「相手の弱点に、手持ちの中から合うものを当てる」形で出ている。**

## 札であること

**[[concept:jugu]] の消費型呪具は、札が主流。** **軽い、大量に持てる、安い、投げられる、貼れる、隠せる。** **「札を当てる」という入れ方が、その運用にそのまま乗る。**

### ただし、中身が違う

| | 札に詰まっているもの |
|---|---|
| **国家備蓄霊札**（→ [[char:suwa-shizuka]]） | **術者の出力。**A級退魔師を缶詰にしたもの |
| **[[char:kamo-gen]] の死者蘇生札** | **自分の術、一回分** |
| **この人物の札** | **封じた妖怪、受けた一発、起きていた現象** |

> **他は自分から出したものを詰めている。**
> **これだけが、そこで起きているものを落としている。**
