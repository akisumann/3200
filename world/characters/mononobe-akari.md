## 概要

**A級退魔師。旧家の当主**（→ [[faction:old-houses]]）。**神社旧家枠の六人のうち一人**（→ [[concept:a-rank]]）。

**分野は国家級封印**（→ [[concept:battle]] のA級の分野一覧）。

> **分野の機構だけ決まっている状態。** **家も育ちも来歴も未定**（下記）。

## 何ができるか

| | |
|---|---|
| **封じる** | **相手の外殻へ「ここから出られない」を刻む。**成立すれば等級を問わない |
| **器を用意する** | **封印には容れ物が要る。**石、剣、蔵、土地。作るか、選ぶ |
| **開ける** | **封じられるということは、解けるということ**（下記） |
| **出来を読む** | **封印を見て、手入れが要るかどうかが分かる** |

**戦闘の技は、これだけ。**

### 封じるとは、外殻に一点を刻むこと

**[[concept:core-layer]] の理屈で書くと、封印はこうなる。**

**核には触らない。** **外殻へ「出られない」という定義を一つ刻む。**

**[[concept:core-layer]] の契約が「一瞬で一点を刻む」ものであるのと、同じ側の技術。**

> **契約は相手を自分の外殻として扱う行為。**
> **封印は相手の外殻へ、こちらの都合を書き込む行為。**

#### だから、討伐ではない

**核が無傷で残る。**

**[[char:tamamo-no-mae]] が「封印されて何百年経っても、名前も個体性も薄まらない」**（→ 同）**のは、これで説明がつく。**

**封じられているのは体であって、核は生きている。**

> **殺していない。** **出られなくしただけ。**

**[[concept:cooperation-policy]] の「討伐しない」路線と、技術の側が噛み合っている。**

> **repo 側の読み。** **封印の内部構造は書かれていない。**
> **[[concept:core-layer]] の核と外殻から引いた。**

### 成立すれば、等級を問わない

**相手がA級だろうが特殊A級だろうが、刻めれば止まる。**

**[[concept:grades]] の等級差が、ここでは効かない。**

> **出力で押し勝つ必要がない。**

**[[concept:a-rank]] の中で、格上を正面から止められる可能性を持っているのは、この方向だけ。**

### 器が要る

**封じたものを、どこかへ入れなければならない。**

| | |
|---|---|
| **石** | [[char:tamamo-no-mae]] の殺生石 |
| **刃物** | [[concept:relics]] の側と重なってくる |
| **蔵** | 家の封印蔵 |
| **土地** | 動かせない代わりに、大きいものが入る |

**器の格が、封印の格を決める。**

**即席で作れる器は、そう大したものにならない。**

> **良い封印には、良い器が要る。**
> **そして良い器は、その場では手に入らない。**

## 弱点

### 時間と準備が要る

**撃ち合いの最中には通らない。**

**器の用意、術式の敷設、対象の固定。** **全部が前段にある。**

**[[event:hyakki-yako-attempt]] のような短期決戦には、そもそも間に合わない。**

### 動いているものは、封じられない

**ここが一番大きい。**

**刻むには、刻めるだけ相手が止まっていなければならない。**

**だから、この人物一人では完結しない。**

| | |
|---|---|
| **誰かが止める** | 拘束、足止め、無力化 |
| **この人物が刻む** | **そこから先** |

> **止める役が要る。**

**[[faction:reimusho]] の実務は「その分野のB級を呼ぶ」で回っている**（→ 同）。**この人物は、呼ばれる側であって、呼ぶ側ではない。**

#### [[char:nasu-mio]] とは、正反対

**あちらは一人で、見る・寄せる・祓う・射る・止めるが完結してしまう**（→ 同）。

**こちらは、一人では何もできない。**

| | |
|---|---|
| **[[char:nasu-mio]]** | **呼ぶ手前で終わる** |
| **この人物** | **呼ばれてから始まる** |

> **同じ神社旧家枠で、実務の形が真逆になっている。**

### 戦闘力そのものは低い

**封印以外に手が無い。**

**面も、火力も、近接も無い。**

**[[concept:grades]] の「搦手に寄ったA級には、ビル破壊能力がなかったりする」の、一番深いところ。**

## 開けられる

**封じられるということは、解ける。**

**そして [[faction:reimusho]] が持っているのは一般封印技術で、A級相当への封印は秘術の領域**（→ [[faction:shrines]]）。**国内の高位の封印は、この分野の手順で掛かっている。**

> **同じ手順で掛けたものは、同じ手順で外せる。**

**点検も、掛け直しも、これが前提になっている。**

## 封印は、記録の技術でもある

**何を、どこに、どう封じたか。**

**それが分からなくなれば、点検も手入れもできない。**

**何百年ぶんの封印を回すには、術と同じだけ台帳が要る。**

## 台帳に載っていない封印がある

**[[char:tamamo-no-mae]] の殺生石。**

**誰が掛けたかが分かっておらず、[[char:nasu-mio]] の家にも技術が伝わっていない**（→ 同）。

**この人物にも、掛け直せない。**

> **日本最大級の封印が、この分野の記録に載っていない。**

**そして出来が死ぬほどよく、手入れが要らない**（→ [[char:tamamo-no-mae]]）。

**出来を読める人間が見て、直すところが無いと言っている状態。**

**[[char:tamamo-no-mae]] の「誰かが、途方もなくいい仕事をした」**（→ 同）**を、一番よく分かっているのがこの人物。**

## 立場

**神社旧家枠のA級。** **公職ではない。**

**[[faction:reimusho]] が持っているのは一般封印技術なので、A級相当が出たときは国の手に負えない。**

> **呼ぶしかない。**

**[[concept:battle]] の「A級はその国における分野別の第一人者」。** **[[char:kamo-gen]] の死者蘇生と同じで、分野に一人しかいない。**

**[[faction:reimusho]] は依存しているが、命令はできない**（→ 同）。

## まだ決まっていないこと

**分野の機構はここまで。**

**家、育ち、性格、来歴は、いったん白紙に戻した。**

> **一度書いたが、[[char:nasu-mio]] の形をそのまま当てはめただけだった。**
> **危ないところの節、育ちの節、家の由来の節を、順番に埋めにいっていた。**

**「物部」という名も、封印と繋がる理由が無い。** **保留。**
