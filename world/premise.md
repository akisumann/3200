# 前提

この世界を一言で言うと何か。すべての設定はここから派生する。

各項目の詳細は `concepts/` 以下に置き、ここには**骨子だけ**を残す。

---

## 骨子

**妖怪が有史以来ずっと当たり前にいる、現代の世界。その存在は公然と知られているが、妖怪は原則として人権を持たない。**

| | |
|---|---|
| 舞台 | **現代** |
| 妖怪 | **実在する。** 例外的な怪異ではなく、「普通にいる」 → [[concept:youkai]] |
| 認知 | **公然。** 一般人は妖怪の存在を知っている。隠されていないし、都市伝説でもない |
| 起源 | **有史以来ずっとそう。** 後から現れたのでも、近代に発見されたのでもない |
| 分布 | **世界中にいる。** 日本固有の現象ではない |
| 数 | **相当数**（詳しい内訳は保留） |
| 法的地位 | **原則として人権に相当するものを持たない。** 国の専門官庁での手続きを経れば特殊な権利を得られるが、経ているのは少数派 → [[concept:legal-status]] |
| 未手続きの扱い | **統一された法的身分がない。** 現象・災害・害獣・特殊な動物・国家級兵器・土地・物など、性質に近い既存の分類が当てはめられる |

### この骨子が意味すること

**「妖怪がいると判明した世界」ではなく、「最初から妖怪がいた世界」。** 人類史は妖怪を織り込んだ形で進んできたことになる。現実の歴史をそのまま流用できないので、どこまで作り替えるかを決める必要がある（→ 未決 1）。

**摩擦の焦点は「隠す／暴く」ではなく「制度」。** 存在は公然で、いることは誰も否定しない。争点は妖怪をどう扱うかであり、権利を持たない側と、手続きを経て一部の権利を得た側の間に線が引かれる。この線の引かれ方が、この世界の物語とゲームの中心になる。

**「妖怪」は一つのものではない。** 法が統一した身分を与えられず、現象から土地から兵器まで別々に分類して処理していることが、それを裏づけている。人権の枠が合わないのも同じ理由で、**現象に人権は与えられない**。妖怪をひとまとめに語ろうとすると必ず破綻する世界になっている。

**少数派の問題ではない。** 相当数いる以上、これは「珍しい隣人をどう扱うか」ではなく、社会の基本構造そのものの話になる。

## 未決

前提そのものに関わる未決事項。決まった順に骨子へ移す。

### 1. 現実の歴史との関係

有史以来ずっと妖怪がいたなら、人類史は現実と同じにはならない。どこまで作り替えるか。

- 史実はほぼ現実どおりで、妖怪はその裏側にいた
- 分岐点があり、そこから現実と別の歴史をたどっている
- 歴史はまるごと別物

（未決）

### 2. 制度は国ごとに違うのか

世界中に妖怪がいるなら、法的地位の扱いも各国で異なるはず。

- 各国がばらばらに決めている
- 国際的な枠組みがある
- 舞台となる国以外は詰めない

（未決）

### 3. 人と妖怪の力関係
