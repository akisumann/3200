# 前提

この世界を一言で言うと何か。すべての設定はここから派生する。

各項目の詳細は `concepts/` 以下に置き、ここには**骨子だけ**を残す。

**現実世界プラスアルファ。** 歴史も地理も現実とほぼ同じ日本に、妖怪が有史以来ずっと当たり前にいて、霊力や呪力が実用されている。妖怪の存在は公然と知られているが、妖怪は原則として人権を持たない。

## この骨子が意味すること

**現実の延長線上で書ける。** 歴史も地理も現実準拠なので、実在の地名・制度・企業をそのまま使える。ゼロから世界を組み立てる必要はなく、**差分だけを設計すればよい**。これは作る手間の面でも、読者やプレイヤーが入りやすい面でも大きい。

**「隠されている」物語ではない。** 存在は公然。争点は「知られるかどうか」ではなく「どう扱うか」。摩擦は制度の側に出る。

**妖怪をひとまとめに語れない。** 制度は「妖怪」という一つの箱に入れているのに、中身は現象から土地から兵器相当まである。**箱と中身が合っていない**ことが、この世界の歪みの源。

**大部分は知性が低い。** これは制度の理屈を支えている重要な事実。人権の枠が合わないのも、手続きを経た妖怪が少数派なのも、まずここから説明がつく。同時に、**知性を持つ妖怪の立場が際立つ**ことになる — 話が通じるのに権利がない。

**公然なのに、見えない。** この二つは矛盾しない。誰もが「いる」と知っているが、誰もが見えるわけではない。一般人にとって妖怪は、**存在を疑わないが遭遇を実感できないもの** — 放射線や細菌に近い手触りになる。

ここから多くのことが自動的に説明される。**なぜ専門職（退魔師）が成立するのか** — 見えて扱える人間が限られるから。**なぜ神社や旧家が強いのか** — その技能を代々抱えてきたから。**なぜ妖怪絡みの被害が「現象」や「災害」として扱われるのか** — 見えないものによる被害は、そう記録するしかないから。制度の形が、可視性から筋道立って導かれている。

**線引きは「力を使えるかどうか」一本。** 見えるのは力を使える人間であり、素質でも訓練でも道具でもない。だからこの世界の人間は、力を使える側と使えない側に分かれ、それはそのまま**この世界の何が見えているかの違い**になる。力を扱う者が強いのは、技能を持っているからだけではなく、**他の人間に見えていないものが見えているから**。

**妖怪は人間が想った形をしている。** 思念には表面張力のようなものがあり、似た思念は勝手にくっついて形になる — それが妖怪。**方向性が揃っているほど結合が強く、生まれた時点で出力が高い。** だから鬼や天狗のように大勢が同じ像を共有している妖怪は強く、雑多な思念から湧いたものは霧散しやすい。

**この一つの仕組みが、ばらばらだった設定を全部束ねる。** 種族だけで等級が決まる理由（揃った思念から生まれた）。有名な妖怪が強い理由（同じ）。E級・F級が無限に湧いて勝手に消える理由（雑多な思念は絶えず生まれ、絶えず霧散する）。妖怪の感性が人間的でない理由（人間の思念の産物でありながら、人間ではない）。**すべて思念の性質から導かれる。**

**そして最も重い含意 — 妖怪は自分が何であるかを選べない。** 「人喰い妖怪！」と定められた思念は人を食う。自然補給で足りるはずなのに食うのは、**そう想われて生まれたから**。妖怪の性質は、生まれる前に人間の側が決めている。これが核の根底にある → [[concept:core-layer]]

**忘れられることが死。** 思念が足りなくなったり綻んだりすると衰弱し、いずれ消える。**人間が想うことが妖怪を生み、強くし、性質を定め、忘れることが妖怪を殺す。**

**ただし思念そのものは、とても弱い。** 大勢が誰かを「化け物だ」と想ったところで、その人の肉体がどうこうなることはない。思念は溜まって形になって初めて力になる。**この制約がなければこの世界は成立しない** — 想うだけで人を殺せるなら、妖怪が公然と知られた社会など維持できない。

**そして強くなるには時間が要る。** 核の強固さは思念の方向性の一致だけでは決まらず、**長年同じことを思われ続けた歴史**も要る。だから現代の思念（ネット、創作、流行）から湧く妖怪は弱い。ノストラダムス級の知名度と歴史がなければ、A級には届かない。

**神は妖怪である。** 祀られていれば神、そうでなければ妖怪 — 呼び方が違うだけで、由来も仕組みも同じ → [[concept:kami]]。思念の理屈からすれば当然で、**何千年も膨大な人数が極めて揃った像を抱き続けた対象**が最強になるのは必然。日本ではこれが制度に組み込まれていて、神社の神は土地神級妖怪として扱われ、出雲大社レベルならA級相当。

**そして制度は、ある一点から先で口をつぐむ。** ヤハウェや仏陀の妖怪もいるとされているが、**そこら辺を「妖怪」と言うと国際問題級になるので自粛している**。すべてを一つの尺度で測るはずの体系が、**世界の半分が信じているものについては沈黙する**。100年運用されてきた国際標準に入った、綺麗すぎない亀裂。**この世界で最も物語になる一点かもしれない。**

**妖怪に妖怪を治めさせる。** 逃しポイントの運用は囲い込めや討伐だけではなく、**土地神級妖怪にその場を治めさせる**という手もある → [[concept:land-god]]。人間が管理しきるのではなく、統治を委ねる相手がいる。そして周辺住民は**慣れていて特に問題ない** — 工場や変電所の近くに住むのと同じ温度。**この世界が「妖怪と共にある日常」として成立している証拠**がここにある。

**妖怪対策の根本は討伐ではなく土木。** 思念が溜まって妖怪が湧く循環は、**水や雨の循環と同じ自然現象**として理解されていて、みんなそれを知っている。止められないものは導く — **わざと妖怪が湧きやすい「逃しポイント」を各地に作っている** → [[concept:release-points]]。恐山はその有名な一つ。堤防ではなく遊水地。**隠すべき災厄ではなく、付き合うべき自然として妖怪を扱っている**ことが、この世界の妖怪観をよく表している。

**世界が壊れていない理由は、抑止ではなく計算。** 小国を滅ぼしうるA級妖怪が国内に18体いても社会が回っているのは、国が押さえ込んでいるからではない。**妖怪が一枚岩ではなく、老練な個体は人間社会を侮っていないから** → [[concept:youkai-nature]]。あるA級妖怪は人間を「アリ」、人間社会を「統率された軍隊アリ」と見ている — 一匹は踏み潰せるが、群れに手を出せば食われる。暴れないのは恐れているからではなく、**割に合わないと計算しているから**。

そして人を侮らなかった妖怪だけが長く生きる。**若手は人の怖さを知らずにはっちゃけ、すぐ討伐される。** 淘汰が働いた結果が、今の均衡。

**ただし「人類」は侮らないが「人間」は侮る。** 妖怪は社会を恐れても、目の前の一人を恐れはしない。**この非対称がこの世界の危うさの源**であり、事件はここから起きる。

**制度を使う妖怪とは、人間的な感性を持つ妖怪のこと。** 手続きを望まない妖怪が多いのは、抑圧されているからではなく、そもそも感性や感覚が人間的ではないから。制度を使うのは「使ったほうが便利だ」と判断する型に限られる。**手続きの有無は、権利の有無であると同時に、どれだけ人間に近いかの目印**になっている。この世界の摩擦は、被害者と加害者の対立ではなく、**噛み合わなさ**として現れる。

**力は「免許で管理された日常の技術」。** 等級があり、免許があり、D級呪具は車の免許くらいの手間で買える。力は秘匿された特権ではなく、**規制されてはいるが閉ざされてはいない**ものとして社会に組み込まれている。自動車と同じ構図 — 便利で、危険で、免許が要り、産業がある。

**A級18人という規模感。** 十倍刻みのピラミッドの頂点は、統計ではなく個人として数えられる。**この18人は、この世界における特別な存在**であり、物語やゲームの中心に据えるにも、遠い頂として置くにも使える。日本国内で力を使える人間は約222万人、人口の1.8%ほど — **50人に1人弱**。学年に数人いる程度の、珍しくはないが多数派でもない密度。

**すべてが一つの目盛りに載る。** 人も、呪具も、妖怪も、同じA〜Fで測られる。人間のC級と呪具のC級と妖怪のC級が比較できるということは、**この世界には「力」という単一の量が実在し、それが計測可能だと社会が合意している**ということ。これは設定として強く、そのままゲームの数値設計の土台になる。

**C級が超常の閾値。** F〜Dは「在るだけ／術が使える／人間の延長の上限」で、人も妖怪も現実の延長線上にいる。C級で人間はコンクリートを砕き車と並走し、妖怪は「能力」を獲得する。**この梯子で最も意味のある一線はC級とD級の間**にあり、世界の見え方はそこで変わる。

**ただし等級は嘘をつく。** 等級は力の平均値を破壊力に換算した**単純火力指数**でしかない。だから搦手に寄ったA級には、ビル破壊能力がなかったりする。しかも**型に分かれているのではなく千差万別、十人十色** — 「火力型」「搦手型」のような類型すらない。制度は便利で肌感覚で通じて社会を回しているが、**個体が実際に何をできるかは表していない**。等級だけを見て相手を測ると間違える — この穴は、物語の仕掛けとしてもゲームの設計としても効く。

**下端は輪郭がぼやける。** E級・F級の妖怪は無限に湧いて勝手に消え、討伐や警邏で増減する。人間のF級200万人も、申告していない人や見えるか曖昧な人を含めて曖昧。**この梯子は、上位が個体として数えられ、下位は現象として推計される。**

**呪具が断絶に橋を架ける。** 等級差は呪具で**普通に覆せる**。一般人がD級の浄化札で、蔵にゴキブリのように溜まったF級・E級を一気に浄化する — そういうことが普通にある。力を使えない人間でも、買って免許を取れば妖怪に手が届く。**だからこそ免許制で管理する必要がある。** そしてこの例が示すとおり、下位の妖怪の駆除は非常事態ではなく**家事に近い**。

**頂点は6・6・6。** A級18人は、霊務省・神社と旧家・民間退魔師にちょうど6人ずつ分かれている。国家、伝統、民間。**この世界の三つの系統が頂点で綺麗に均衡している**ことが、社会が現状のまま回っている理由でもあり、崩れたときに何かが起きる仕掛けでもある。

**ただしその均衡は静止していない。** 三系統はそれぞれ引き抜き合戦をしていて、人の流動が激しい。国は待遇（税金絡みで渋くてブラック気味）で人を逃し、伝統はしがらみで人を逃し、民間は稼ぎのばらつきと引き換えに自由を売る。**互いの不満を吸い上げ合って回っている** → [[concept:taimashi]]。だから**どこに属するかは能力ではなく生き方の選択**になる。

**退魔の高校がある。** 専門教育は高校からあり、十代半ばで進路として選ばれている。工業高校や商業高校と並んで退魔の高校がある世界 — **力は秘伝ではなく、進路指導の対象**。ただし仕事は**かなり危険**で、普通に食えて人手も足りない職業が、同時に人がよく死ぬ職業でもある。

**そして学校のほうが現場より危険。** 退魔の学校は**B級以上の土地神が管理する、逃しポイントを抱えた土地**の上に建っている → [[concept:taimashi-school]]。統制下のF〜C級妖怪が湧き続け、供給は途絶えない。それが「教材」であり、だから生徒を現場に出す必要が薄い。**管理されているとはいえ、危険性という点ではそこらの街なんか目じゃない。**

**そして土地神への対価は「感謝と敬い」だけ。** 一見地味で、しかも**思念としては大した量ではない** — 生徒は数が数なので、B級以上を支える糧にはまるで足りない。**効いているのは、敬っているのが誰かのほう。**

日本の退魔学校は**6校しかなく、D級以上は概ねここの出身**。つまり一つの学校土地神は、**国内のD〜A級22,218人の約6分の1（約3,700人、うちA・B級が約36人）と面識があり、その全員から恩を感じられている**。妖怪の死因が「忘れられること」と「討たれること」である以上、**国内最強クラスの6分の1が味方である**ことは生存そのもの。頼み事のできる相手が三系統すべてに散っているので、諸々の工面にも効く。

**思念には桁がある。** 神々が何百年・何百万人に想われて成り立つのに対し、一校分の生徒の敬意は誤差。**だから量で払えないぶんを、質で払っている。** この世界の人間と高位妖怪の関係には、少なくとも二つの型がある — **量で払う（信仰）か、質で払う（人脈）か** → [[concept:taimashi-school]]

**妖怪には穏健派・中立派・敵対派がある。** 人間への構え方の区分で、学校の土地神は大抵穏健派寄り → [[concept:youkai-nature]]。ただし立ち位置と実際に暴れるかは別で、A級妖怪のインタビューの個体は「やや敵対寄りだがおとなしいタイプ」だった。

**敵対派は普通に人を殺し、政府と敵対する。** ただし理由は悪意ではない。**人間と考えがどうしても噛み合わない**か、**生態としてそうなっている**か。後者が重い — 「人喰い妖怪！」と定められた思念は人を食う。**選んでそうしているのではなく、そう想われて生まれたからそうなっている。**

**つまりこの世界の敵は、悪ではない。** そして後者を作ったのは人間の思念そのもの。**人を食う妖怪を人間が想って生み、その妖怪が人を食い、人間がそれを討つ。** この循環が、この世界の暴力の底にある。それでも殺される人間は死ぬので、討伐は必要で、退魔師は必要とされ、**それでも誰も悪くない。**

**それでも生徒はほぼ死なない。あっても事故レベル。** 危険なのは環境であって、結果ではない — プールや理科室と同じで、条件が揃えば人が死にうる設備を、死なないように運用している。**社会が子供の死を淡々と受け入れているのではなく、単にそこでは死なないように作られている。**

**濃度は学校が上、死亡率は現場が上。** 学校の妖怪は土地神の統制下にあり等級もF〜Cに収まるが、現場の妖怪は誰の統制も受けていない。**生徒が卒業して失うのは、この統制**。毎日それより濃い妖怪の中にいたのに、外に出た途端に死ぬ確率が跳ね上がる。

**等級は序列ではない。** A級が大企業の社長なら、E級は町工場のベテラン職人 — 金（出力）の動きが違うだけで、**ベテランはベテランであり、A級はE級を蔑んだりしない**。肌感覚で通じるほど浸透した尺度でありながら、それが人の上下として使われていない。**数字は大きさであって価値ではない**という了解が、この世界の空気を決めている。

**等級は約100年前の国際標準。** つまり**世界史のどこかに、力を測る物差しを世界で統一した瞬間がある** → [[event:grade-standard]]。歴史が現実とほぼ同じなら、それは度量衡や工業規格が国際標準化された時代と重なる。**制度は古来のものではなく、近代がこしらえたもの**。だからこそ、それより古い妖怪には通じないことがある。

**力の系統は「出身地」くらいの話題。** 系統は本質的に別物なのに、実用上はどれでも概ね動く。だから系統の違いは断絶ではなく雑談の種になる。**この温度感がこの世界の空気を決める** — 力があること自体は当たり前で、深刻ぶらない。

## 保留

**決まっているが、説明を要するため後回しにしているもの。** 未決ではない。

- **妖怪の数の内訳** — 「相当数いる」ことは確定。人口比や分布の詳しい説明は後で書く
- **核と外殻がそれぞれ何であるか** — 構造が存在することは確定。中身は説明を要するため後で書く → [[concept:core-layer]]
- **手続きを経た妖怪が少数派である理由** — 複数の要因がある。「大部分は知性が低い」「そもそも感性が人間的ではない」の二つは確定済み。残りは順次
