# 前提

この世界を一言で言うと何か。すべての設定はここから派生する。

各項目の詳細は `concepts/` 以下に置き、ここには**骨子だけ**を残す。

---

## 骨子

**現実世界プラスアルファ。** 歴史も地理も現実とほぼ同じ日本に、妖怪が有史以来ずっと当たり前にいて、霊力や呪力が実用されている。妖怪の存在は公然と知られているが、妖怪は原則として人権を持たない。

| | |
|---|---|
| 舞台 | **現代の日本**（世界中に妖怪はいる） |
| 歴史 | **現実とほぼ同じ。** 妖怪がいても人類史の大筋は変わっていない |
| 妖怪 | **実在する。** 有史以来ずっと、世界中に、相当数 → [[concept:youkai]] |
| 妖怪の知性 | **大部分は知性が低い。** 人間と話が通じる個体はその一部 |
| 認知 | **公然。** 一般人は妖怪の存在を知っている。都市伝説ではない |
| 法的地位 | 法的には**「妖怪」という一つの分類**。原則として人権に相当するものを持たない。国の専門官庁での手続きを経れば特殊な権利を得られるが、経ているのは少数派 → [[concept:legal-status]] |
| 実態 | 一つの分類の中で、**扱いは個体ごとにまったく違う**。現象・災害・害獣・特殊な動物・国家級兵器相当・土地・物など。これは法的区分ではなく実態としての扱い |

## この骨子が意味すること

**現実の延長線上で書ける。** 歴史も地理も現実準拠なので、実在の地名・制度・企業をそのまま使える。ゼロから世界を組み立てる必要はなく、**差分だけを設計すればよい**。これは作る手間の面でも、読者やプレイヤーが入りやすい面でも大きい。

**「隠されている」物語ではない。** 存在は公然。争点は「知られるかどうか」ではなく「どう扱うか」。摩擦は制度の側に出る。

**妖怪をひとまとめに語れない。** 制度は「妖怪」という一つの箱に入れているのに、中身は現象から土地から兵器相当まである。**箱と中身が合っていない**ことが、この世界の歪みの源。

**大部分は知性が低い。** これは制度の理屈を支えている重要な事実。人権の枠が合わないのも、手続きを経た妖怪が少数派なのも、まずここから説明がつく。同時に、**知性を持つ妖怪の立場が際立つ**ことになる — 話が通じるのに権利がない。

## 未決

前提そのものに関わる未決事項。決まった順に骨子へ移す。

### 1. 世界のほうの制度

日本には霊務省がある。世界中に妖怪がいる以上、他国にも何かあるはず。

- 各国がばらばらに決めているのか、国際的な枠組みがあるのか
- 日本の制度は世界的に見て厳しいのか緩いのか、特殊なのか
- そもそも他国は詰めないのか

（未決）

### 2. 人と妖怪の力関係

個としての強さ。社会的な上下。知性の低い個体が大部分であることを踏まえて。

（未決）

### 3. 現実との差分をどこまで広げるか

霊務省があり、霊的物品が流通し、退魔師が職業として成立しているなら、経済・教育・報道・保険・不動産などにも影響が出ているはず。どこまで描くか。

（未決）

## 保留

**決まっているが、説明を要するため後回しにしているもの。** 未決ではない。

- **妖怪の数の内訳** — 「相当数いる」ことは確定。人口比や分布の詳しい説明は後で書く
- **手続きを経た妖怪が少数派である理由** — 複数の要因がある。うち「大部分は知性が低い」ことは確定済み。残りは順次
