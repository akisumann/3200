## 概要

**近畿地区の退魔学校が置かれている土地。**

> **これは repo 側の配置。**

## なぜここか

**古代祭祀地域**（→ [[concept:taimashi-school]] の学校ごとの地域色）。

**そして repo に既にあるものが、二つともここへ繋がる。**

| | |
|---|---|
| **安倍晴明と十二天将** | → [[concept:legal-status]]。**通常の式神契約を大きく超える外殻固定。**晴明の死後も存在固定を維持しているとされる |
| **酒呑童子** | → [[loc:oeyama]]。**日本の特殊A級二体のうちの一体** |

**式神の技術の頂点と、特殊A級の本拠が、同じ地区にある。**

## 旧家の密度

**[[faction:old-houses]] と [[faction:shrines]] が源流で、そこから国と民間が分かれた**（→ [[faction:shrines]]）。

**近畿は、その源流が一番厚く積もっている地区になる。**

**だから近畿の学校は、旧家出身者の比率が高いはず。**

> **repo 側の読み。** [[concept:taimashi-school]] に「生徒の五つの出自」と「学校ごとに地域色が出る」があるので、そこへ当てただけ。

## 十二天将が、どこにいるのか

**晴明との契約が失われた後も、現代まで存在固定を維持しているとされる**（→ [[concept:legal-status]]）。

**ただし現存個体も、真名も、活動状況も、確定情報は少ない。** **`docs/02-canon-policy.md` の「確定してはいけないこと」に入っている。**

**この土地に置いてあることまでが、配置の限界。** **中身は埋めない。**
