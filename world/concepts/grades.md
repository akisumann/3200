## 概要

A級からF級までの**6段階**の格付け。**人にも呪具にも妖怪にも、同じ一つの尺度が使われる**。A級が最上位、F級が最下位。

**約100年前に国際標準として制定された** → [[event:grade-standard]]。**それ以前の日本は「下位・中位・上位」の三段**で、海外基準に合わせる形で切り替えた。

判定は基本的に [[faction:reimusho]] が行うが、**大体みんな肌感覚で分かるくらいに身近**な尺度になっている。

## 仕組み

### 力を使える人間の等級と人数（日本国内）

| 等級 | 人数 |
|---|---|
| **A級** | **18人**（現在） |
| B級 | 約200人 |
| C級 | 約2,000人 |
| D級 | 約2万人 |
| E級 | 約20万人 |
| F級 | 約200万人 |

**一段上がるごとに、およそ10分の1になる。** 綺麗な十倍刻みのピラミッド。

合計およそ**222万人**。日本の人口のおよそ**1.8%**が力を使えることになる。**50人に1人弱** — 学校なら学年に数人、大きな職場なら何人かいる密度。珍しくはないが、多数派でもない。

**ただしこの数字はおおよそでしかない。** F級の200万人という数は、**申告していない人**も、**見えるか見えないか曖昧な人**も含めて曖昧。等級の下端は、制度が把握しきれていない。

**A級だけ「現在18人」と具体的な数で語られる。** 全員が把握され、おそらく名前も顔も知られている規模。A級は統計上の区分ではなく、**個人として数えられる存在**。

これは**日本国内の数字**であり、他国にもそれぞれいる → [[concept:overseas]]

### 何を測っているのか

**総合評価。** ただし各等級には**かなり分かりやすい指標**がある。だから専門家でなくても肌感覚で判断でき、実務が回っている。

#### 人間の指標

| 等級 | できること |
|---|---|
| **F** | **見えるだけ** |
| **E** | **術が使える** |
| **D** | 真っ当な人間レベルの、**バトル漫画くらいの水準**の技や動きが可能 |
| **C** | **技一個でコンクリートや車を破壊できる**くらい。車に並走できるくらい |
| **B** | **技一個がビル破壊級** |
| **A** | **技一個が山破壊級** |

#### 妖怪の指標

**人間と全く同じ尺度。単純火力指数も人間と同じ。個体数も人間と同じ**（日本国内でA級18体、B級約200体、C級約2,000体、D級約2万体、E級約20万体、F級約200万体）。

**ただし妖怪側は上位でも数が確定しない。** A級だろうが勝手に湧き出てくるので、**18体という数は把握できている範囲のもの**（下記「A級18体の内訳」）。人間側の「現在18人」とは確からしさが違う。

**そしてA級の上に、妖怪の側だけ「特殊A級」がある**（下記）。**数はA級の1/10。**

**ただしE級・F級は数が定まらない。** 無限に湧き、無限に勝手に消え、討伐や警邏で増えたり減ったりする。**変動が激しく、あくまでおおよそでしかない。**

人間側のF級200万人が曖昧なのと同じで、**この梯子は下にいくほど輪郭がぼやける**。上位は個体として数えられ、下位は現象として推計される。

| 等級 | どういう妖怪か |
|---|---|
| **F** | **ほぼ無害。** 害があっても極小。霊が見える人が足で踏めば死ぬくらい弱くて不安定 |
| **E** | **人間と同等くらいの能力水準**を持った妖怪。例：ゾンビ |
| **D** | **大型肉食獣に属性攻撃が追加された**くらい |
| **C** | **超常現象、いわゆる「能力」が使えるようになる。** 恐怖の館のような特異な現象を起こす — **外殻が空間として成立しはじめる段**（→ [[concept:core-layer]]） |
| **B** | **大抵は有名どころの妖怪ばかり。** 戦闘力も抜群 |
| **A** | **誰もが知っていて、大抵クソ強い。小国なら一人で滅ぼしうる** |

#### 梯子の構造

人と妖怪を並べると、同じ段に同じ意味がある。

| 等級 | 段の意味 | 人間 | 妖怪 |
|---|---|---|---|
| F | **在るだけ** | 見えるだけ | ほぼ無害 |
| E | **最低限の能力** | 術が使える | 人間並み |
| D | **人間の延長の上限** | バトル漫画水準 | 大型肉食獣＋属性 |
| C | **超常の閾値** | コンクリート・車を破壊 | 「能力」が使える |
| B | **街の脅威** | ビル破壊級 | 有名どころの妖怪 |
| A | **国の脅威** | 山破壊級 | 小国を滅ぼしうる |

**C級が境目。** ここで人も妖怪も「人間の延長」から「超常」へ渡る。人間側は物理法則を破る出力を持ち、妖怪側は「能力」を獲得する。**等級の中で最も意味のある一線はC級とD級の間**にある。

### 重要な但し書き — これは平均値でしかない

**等級は、力の平均値を破壊力に換算しただけのもの。あくまで単純火力指数の平均指標。**

だから**搦手に寄ったA級には、ビル破壊能力がなかったりする**。

そして重要なのは、**「火力型」「搦手型」のような型に分かれているのではない**ということ。**千差万別、十人十色。** 同じ等級の中に、いくつかの類型があるのではなく、**一人ひとり違う**。

これがこの制度の核心的な限界。等級は便利で、肌感覚で通じて、社会を回しているが、**個体が実際に何をできるかを表してはいない**。同じA級でも、山を割る者と、一切壊せないが別の方法で国を傾ける者がいる。

**等級だけを見て相手を測ると間違える。** これは物語の仕掛けとしても、ゲームの設計としても効く。等級はキャラクターを分類するものではなく、**目安を一つ与えるだけ**のものとして扱う。

### F級の多さには機能がある

**F級は約200万人。人口のおよそ1/60。** 「見えるだけ」で戦えないが、**この数そのものが社会の基盤になっている。**

**病院にも、企業にも、行政にも、大量にあらゆるところへ散らばって各々生きている。** だから妖怪絡みの異変は早期に発覚する。学校の同級生がF級だったり、職場の同僚が妖怪を見えたりして、**すぐ分かる**（→ [[concept:daily-life]]）。

**A級18人が国家の戦力なら、F級200万人は国家の検知網。**

十倍刻みのピラミッドは、単に強さの分布を表しているのではない。**裾野が広いこと自体が機能している。**

### 等級は序列ではない

**そして人々も、それを分かって使っている。**

> **A級が大企業の社長だとするなら、E級は町工場のベテラン職人のようなもの。**
> **金（出力）の動きが違うだけで、ベテランはベテランであり、A級はE級を蔑んだりしない。**

等級が表すのは**動かす力の規模**であって、練度でも人としての格でもない。社長と町工場の職人に上下がないのと同じ意味で、A級とE級に上下はない。

**数字は大きさであって、価値ではない。** 肌感覚で通じるほど社会に浸透した尺度でありながら、それが序列として使われていないという点は、この世界の空気を決めている。

### 特殊A級

**A級の上に、もう一段ある。妖怪の側だけ。**

**A級の中でも特に強力で、名が知れていて、警戒を持ってあたる存在だと国際的にも周知されている妖怪**を指す。

| | |
|---|---|
| **数** | **A級の1/10** |
| **国際的な扱い** | **警戒対象として周知されている** |
| **国内での扱い** | **全国に情報の徹底開示が求められる** |

**十倍刻みのピラミッドが、そのまま一段延びている。** F級200万 → E級20万 → D級2万 → C級2,000 → B級200 → A級18 → **特殊A級はその1/10**。日本国内なら**1〜2体**という規模になる。

**別枠ではなく、同じ梯子の続き。** A級の上に例外的な何かが乗っているのではなく、**同じ比率で上がった先**。

#### 隠されているのは技術だけ

**強さの情報は、もともと公開されている。**

A級退魔師がどのくらい強いかは**普通に大々的に言う**し、A級妖怪も**警戒対象として、あるいは敬う対象として大々的に言う**。等級が肌感覚で通じる社会（上記）なのだから、当然そうなる。

**隠されるのは秘術** — つまり**技術のほう**（→ [[faction:shrines]]）。存在と強さを言うことと、対処法を教えることは別。

**だから特殊A級の徹底開示は、方針の転換ではない。** 元から公開されているものが、**国際的な周知と、全国への開示が制度として求められる**段まで来た、というだけ。

### 種族による目安

妖怪の側には、**種族だけである程度の等級が決まる**という概ねの基準がある。

| 種族 | 目安 |
|---|---|
| 鬼 | 鬼であるというだけで**B級は堅い** |
| 天狗 | **C級以上** |

B級以上の妖怪は「大抵は有名どころ」だが、その名は**個体名のこともあれば種族名のこともある**。鬼や天狗のように、種族そのものが高い等級を保証する場合がある。

### なぜ有名な妖怪は強いのか

**思念の結合の強さがそのまま出力になるから** → [[concept:shinen]]

妖怪は似た思念がくっついて形になったもの。**思念の方向性が揃っているほど結合が強く、強固になり、生まれた時点で出力が高い。**

鬼や天狗は、大勢の人間が同じ形・同じ方向の像を共有している。だから結合が強い。逆に雑多な思念から湧いたものは結合が弱く、霧散しやすく、等級も低い。

**「有名だから強い」ではなく、「揃った思念から生まれたから強く、かつ有名でもある」。** 知名度と強さは、同じ原因の二つの結果。

#### ただし例外がある

**弱いと伝承で語られる有名妖怪は、その伝承に沿って弱い。** 座敷童子、餓鬼、まっくろくろすけなど → [[concept:youkai-species]]

思念の一致と歴史が決めるのは**核の強固さ**であって、等級そのものではない。**どれくらい強いかは、思念が何を定めているかで決まる**（→ [[concept:shinen]]）。

だから**低等級でも堅牢な妖怪がいる**。座敷童子は弱いが何百年も居続ける。湧いて消えるF級の雑魚とは、同じ等級でも存在の質が違う。

**等級は出力を測るだけで、存在の安定性は測っていない。** ここも等級が取りこぼしている軸の一つ。

> 核と外殻そのものの詳細は引き続き保留 → [[concept:core-layer]]

### 誰が測るのか

- **公式の判定は [[faction:reimusho]]**
- ただし**大体みんな肌感覚で分かる**。専門知識ではなく常識の側にある

判定機関はあるが、判定がなければ誰にも分からない、という制度ではない。**役所が追認する形に近い。**

### 何につくのか

| 対象 | |
|---|---|
| 人 | 力を使える人間 |
| [[concept:jugu]] | 呪具。等級に応じた免許制 |
| [[concept:youkai]] | **妖怪にもつく。人・呪具と同じ尺度** |

**一つの物差しで、人も物も妖怪も測られる。** この世界では、力を持つものはすべて同じ目盛りの上に並ぶ。人間のC級と、呪具のC級と、妖怪のC級が、同じ「C級」として比較できる。

### 呪具の等級と免許

呪具にも同じ等級が振られ、**等級ごとに購入の敷居が変わる** → [[concept:jugu]]

| 等級 | 購入 |
|---|---|
| C級以上 | **一般人の購入は基本的に難しい** |
| D級 | 車の免許くらい大変な免許が要る |
| E級 | 軽めの免許で買える |

**免許制になっている。** 力の格付けが、そのまま流通の規制に接続している。

### A級18人の内訳

**日本のA級18人は、三つの勢力にちょうど6人ずつ分かれている。**

| 所属 | 人数 |
|---|---|
| [[faction:reimusho]]（霊務省） | 6人 |
| [[faction:shrines]] / [[faction:old-houses]]（神社や旧家） | 6人 |
| 民間の [[concept:taimashi]]（退魔師） | 6人 |

**6・6・6。** 国家、伝統、民間。この世界の力を持つ三つの系統が、頂点で綺麗に均衡している。

偶然でこうはならない。**誰かが均衡を保っているのか、均衡が崩れないよう働く仕組みがあるのか、単にそう落ち着いているだけなのか** — ここは物語の起点になる（→ 未決）。

### A級18体の内訳

**人間側と違って、こちらは一枚の名簿にならない。**

#### 概ね把握しているが、完全ではない

**国はA級妖怪を概ね把握している。** ただし人間のA級18人のように**全員が確実に数えられているわけではない。**

理由は単純で、**A級だろうが妖怪は勝手に湧き出てくる**から。

**だから「18体」は常に暫定の数。** 人間側の「現在18人」は数え上げた結果だが、**妖怪側の18体は、把握できている範囲での数**ということになる。同じ数字が並んでいても、確からしさが違う。

#### 三つの層に分かれている

| | |
|---|---|
| **土地神系A** | 土地を統べている → [[concept:land-god]] |
| **中立系A** | 人間と敵対も協調もしない → [[concept:youkai-nature]] |
| **敵対系A** | 人間に敵対的 |

**そして、ある程度の古参とはコネクションがある。** 長く在るものほど人間側との縁ができていて、[[faction:shrines]] や [[faction:old-houses]] が繋がりを持っている。

#### 警戒対象は、そのうちの一部だけ

**敵対系Aのうち、封印などをされていないタイプが、やや警戒対象。**

**「やや」で済んでいる。**

| | |
|---|---|
| **土地神系** | 協調の相手。むしろ制度の一部 |
| **中立系** | 放っておけばいい |
| **敵対系・封印済み** | 収まっている（→ [[char:tamamo-no-mae]]） |
| **敵対系・封印されていない** | **やや警戒対象** |

**A級18体のうち、国が気にしているのはごく一部。** 頂点の存在が18体もいて、それでも社会が普通に回っている理由が、ここで数の上でも見える。

**そしてこれは [[concept:youkai-nature]] の「妖怪は一枚岩ではない」が最上位でも成り立っているということ。** 18体が結束していないどころか、**大半は敵ですらない。**

#### やんちゃするA級は、台風や地震と同じ扱い

**たまにいる。** そして**そのときの扱いが、台風や地震と同じ。**

**国家の危機ではなく、大規模な自然災害。** 備え、報じ、避難させ、収まったら復旧する。**そういう棚に載っている。**

これは [[concept:daily-life]] の温度そのまま。妖怪絡みの出来事は「**殺人や地震や台風や、そんな感じの規模のニュースが、そんな感じの頻度で混じるだけ**」であり、**A級が暴れてもその延長**にある。

**だから警戒が「やや」で済む。** 台風に対する構えと同じ種類のもので、**恐怖でも非常事態でもない。** 来るときは来るし、来たら対処する。

**この世界は、頂点の妖怪すら災害の一種として制度に組み込んでいる。**

### 等級は上がる

**訓練次第で上がる。** 生まれつきで固定されるものではない。

素質があり、その上で訓練が要る（→ [[concept:powers]]）という習得の構造と揃っている。素質が入口を決め、訓練が到達点を押し上げる。

#### 下の二段は前提、上の四段は積み上げ

**梯子は同じ性質でできていない。**

| | |
|---|---|
| **F** | **これがないと入口にも立てない** |
| **E** | **これがないと努力のしようがない** |
| **D 〜 A** | **積み上げの領域** |

**F と E は資格ではなく前提。** 持っていない人間は、訓練を始めることすらできない。

**F級は「見えるだけ」で、術が使えない。使えないものを練習しようがない。**

**ただしF級には二種類いる。**

| | |
|---|---|
| **そのまま見えるだけの人** | 大多数。F級のまま一生を過ごす |
| **才能はあるが、まだ技を出せていない人** | **最初期の段階。** これもF級 |

**等級は天井の宣告ではなく、今どこにいるかの測定。** F級と判定されたからといって、そこで終わりと決まったわけではない。**一本目の技が出れば、E級になる。**

だから200万人という数の中身は一枚岩ではない。**大半はそこで確定しているが、そこには「まだ出ていないだけ」の人も混ざっている。**

そしてこの二つは**外から見分けがつかない**。どちらも「見えるだけ」の状態にしか見えない。**F級の200万人という数が曖昧なのは、申告していない人や境界が曖昧な人がいるからだけではない**（上記）。**将来E級になる人も、今はここに数えられている。**

**子供は当然そこにいる。** 今のA級18人も、赤ん坊の頃は技が出せなかった。**誰もがF級から始まる。**

だから200万人の中身には、**そのまま見えるだけの大人**と、**これから上がっていく子供**が、同じ「F級」として並んでいる。

**そしてD級からA級までは、何か一つで届くものではない。**

> **山のような修羅場と、才能と、努力と、伝統の技と、いろんな条件。**
> **積み上げに積み上げて、トップになれる。**

**A級は「頑張った人」でも「特別な人」でもない。全部揃った人。** どれか一つ欠けても届かない。だから18人しかいない。

**「修羅場」が先に来るのが効いている。** 道場で積める等級ではない。**危険な現場を何度も踏んで、そのたびに生き延びた者だけが上がっていく。** [[concept:taimashi]] の仕事が「かなり危険」であることと、D級以上の層が25年ほどで入れ替わること（→ [[concept:taimashi-school]]）は、この梯子の登り方と地続きになっている。**安全にA級にはなれない。**

**「伝統の技」が入っているのも重い。** [[faction:shrines]] と [[faction:old-houses]] の秘匿技術が、上へ行くための条件の一つとして数えられている。**A級18人のうち6人が神社・旧家なのは、偶然の配分ではない**ということになる。

### 古い妖怪と等級

**約100年前にできた制度なので、それより古い妖怪にとっては新参の決まりごと。**

- 「何じゃそれ」と受け付けない古い妖怪もいる
- **たいていの、人間と交流のある妖怪は「ふーん、まあそんなもんか」と受け入れている**

拒絶でも心酔でもない、**この程度の温度**であることが重要。100年は人間には長いが、古い妖怪には最近の話。制度は妖怪に押しつけられたというより、**なんとなく浸透した**。

## 社会との関わり

**この制度がこの世界の骨格になっている。** 力を使えるかどうかで見えるものが分かれ（→ [[concept:powers]]）、さらにその中が6段階に格付けされ、格付けが買えるものを決め、妖怪の危険度も同じ目盛りで語られる。

**しかも肌感覚で分かる。** 等級は専門家だけが扱う概念ではなく、社会の共通言語になっている。「あいつD級らしいよ」という会話が成立する世界。

## 下の等級が上の下位互換ではない

**[[char:aramaki]] がB級側の実例。** 封鎖区域戦、災害級怪異への対応、地下侵食の案件は、**A級を呼べば片付くという話にならない。** 空・地中・水中を同時に押さえられる者にしかできない。

**[[concept:taimashi]] の「A級が社長でE級が町工場の職人」と同じ構図が、間の等級にも当てはまる。** 等級は動かす力の規模を表すだけで、**その人にしかできない仕事があるかどうかとは別。**

## C級から、条件戦になる

**C級の妖怪は、条件を持っている。** 超常の能力を使う段（上記）というのは、火力が上がるという意味だけではない。

**「こうすると効く／こうされると成立しない」という規則を抱えた相手になる、ということ。**

**そしてそれは例外ではなく標準。** C級と当たるなら、**条件のやりとりは普通に起きる。**

### 何が来るのか

**[[char:kazama-shiro]] の対怪異適性の一覧は、裏返すとそのまま「C級の妖怪が普通に使ってくる手口の一覧」になる。**

| 相手の条件 | 内容 |
|---|---|
| **視線条件** | 「見る」「見られる」で成立する。視線を固定してくる |
| **接触条件** | 触れることで発動する。呪詛、侵食 |
| **会話・返答条件** | 問答で成立する。答え方で決まる |
| **儀式進行型** | 手順が進むことで成立する |
| **領域の誘導** | 廊下誘導、想定ルートへ乗せる |
| **空間の組み換え** | 無限廊下、空間ループ、帰り道を消す |
| **憑依・内部侵食** | 中に入ってくる |
| **呪毒・金縛り・拘束** | 動きと呼吸を止める |

**だからC級戦は、火力の押し合いにならない。** 相手の条件を読み、成立させないようにし、こちらの条件を通す。**この段から戦い方の性質そのものが変わる。**

### 「対策が厚い」は等級を超えることではない

**風間志郎は徹底した条件対策で知られているが、格上を食う人ではない。** **相手が普通にやってくることに、普通に対応している。**

**特異なのは対策の存在ではなく、そのすべてを一つのスタイルに寄せきったこと。**

**逆に言えば、C級と当たる退魔師は誰でも、程度の差はあれ同じことをしている。**

## 下位は、勝手に減っている

**F級が約200万体いても社会が止まらないのは、処理しているからだけではない。**

**日常的に淘汰されている。**

- 自然消滅
- **相互捕食、縄張り争い、共食い**
- 地域の結界による排除
- 協力妖怪による追い払い
- **D級実務者の警邏**（一日数匹潰すことも珍しくない）
- 民間業者の軽処置

**在野の妖怪同士で勝手に消える分がかなりある。**

### 数が多いだけでは、上位にならない

**煤・埃・影の小妖が一軒家に数百匹いても、それぞれの核が薄く外殻が弱く、群体核も領域化も持たないなら、D級の浄化札一枚でまとめて消える。**

**危険度は数ではなく、発生原因、媒体、再発性、住人への影響、そして別の妖怪の足場になっていないかで判断する。**

**上振れするのは、群体核を持つ、家屋全体を外殻化する、住人を誘導する、別の高位妖怪の餌場になっている、古い封印具の劣化兆候として現れている場合。**

## 等級ごとの現場感

**類型ごとのサンプルは [[concept:youkai-samples]] に集めた。** E級からA級まで各三体。

**そこで繰り返し出てくるのが、等級を上げない条件。**

| | |
|---|---|
| **限定条件下の絶対性** | **七人ミサキ**はターゲットにされたら対抗策が無いが、それ以外にはほぼ無害。**C級** |
| **媒体・領域への依存** | **恐怖の館系**は建物内で絶対的だが、外に出れば無害か著しく弱体化。**C級** |
| **能力の数** | **かまいたち**は火力も機動も斬撃も風操作も治癒も持つが、全部D級の範囲に収まる |
| **被害の見た目の総数** | **くねくね**は被害者が多く見えるが、実効範囲は100メートル前後で治療札で回復する。**D級** |

**そして社会の側も勘定に入っている。**

> **ゾンビは局所接触型の妖力汚染で、低級浄化で遮断できるからE級。**
> **浄化手段のない未整備地域では、局地的パンデミック化し得る。**

**単体性能だけでなく、社会側の対処インフラ込みで等級が決まっている。**

## 等級を決めているのは、基礎スペックのほう

**上に載っている特殊な能力は、等級に入らない。**

**範囲が狭いことも、条件付きで絶対であることも、どちらも等級を動かさない。**

| | 基礎スペック | その上に載っているもの | 等級 |
|---|---|---|---|
| **七人ミサキ** | 低い。物理破壊はほぼ無い | **ターゲット一人への絶対性。**打倒手段が存在しない | **C級** |
| **[[event:hyakki-yako-attempt]] の死神** | **A級相当** | **半径5メートルの「死」。**中では攻撃が成立しない | **A級** |
| **[[char:suwa-shizuka]]** | **A級相当** | **山一つ分の結界を拳へ圧縮。**当たる範囲は拳の分だけ | **A級** |

**三つとも、届く範囲は極端に狭い。**

**七人ミサキがC級なのは、範囲が狭いからではない。** **殺すのが遅いから。**

**目の前の相手を殺して、次を殺して、という動き方ができない。** 一人を呪殺するのにかなり長い期間を要する。**打倒手段が存在しないのに、C級に落ちるのはここ。**

**死神と比べると差がはっきりする。** どちらも届く範囲は狭いが、**死神は5メートルに入った時点で終わる。**

> **同じ「狭い」でも、速さが違えば等級が違う。**

**死神と諏訪静がA級なのは、5メートルや拳の分の絶対性が評価されたからではない。** **その下にA級の基礎スペックがあるから。**

> **等級は素の出力だけを見ている。上に何が載っていても数えない。**

**そして人間と妖怪で同じ。** [[char:suwa-shizuka]] は人間、死神は妖怪だが、**同じ形で同じ等級に落ちている。**

**この結果、等級表は「何ができるか」をほとんど教えてくれない。** 同じA級でも、山を吹き飛ばす者と、拳の届く範囲でだけ絶対の者がいる。

## 妖怪をどこに置くかは、伝承から決まる

**尺度は人間と同じ**（上記）。**ではその梯子のどこに置くかを、何で決めるのか。**

> **基準は、その妖怪が伝承内で単体で最短何人殺せるか。**

**「最短」が効いている。** 数えているのは**総数ではなく速さ。**

**いずれ確実に殺すが、そこまで長い時間がかかる**という相手は、**この基準では低く出る。**

**そして上限がある。**

> **妖怪の強さは伝承を超えない。**

**語られている以上のことはできない。** 等級は伝承から求めた値なので、**伝承の外へは出られない。**

### 有名でも、弱いと知られていれば弱い

**例が餓鬼。**

**知名度は抜群。** それでも弱い。**「弱い存在」として広く知られているから。**

**知名度は等級を押し上げる材料だが、押し上げる方向は伝承が決める。** 有名になればなるほど、**「弱い」という像が固まる。**

**これは [[concept:shinen]] の「討たれ方が性質になる」と同じ向き。** 揃って長く保たれた像が、そのまま実際の性能になる。**内容が何であれ。**

## 偏りは等級に現れない

**等級は単純火力指数の平均**（上記）。**平均である以上、中身が極端に偏っていても同じ等級になる。**

**[[char:suwa-shizuka]] がその例。** A級でありながら**広域展開型の術式が大の苦手**で、代わりに圧縮に極端な適性を持つ。一般的なA級が広域殲滅・現象支配・領域制圧を主体とするのに対し、**この人だけ出し方が逆になっている。**

**それでも同じA級。**

> **「A級として規格外に強い」のではなく、「A級の標準的な理不尽さを、極端に局所圧縮した術師」。**

**理不尽さの総量は同じで、形だけが違う。** 等級は「どれくらいか」しか言っていないので、**「どういう形か」は等級を見ても分からない。**

## 能力だけの存在はいない

**ホラー型、認識型、領域型の妖怪も、能力だけの概念存在ではない。**

**等級相応の身体能力を併せ持っている。**

> **接敵後は、掴み、追い、壊し、拘束し、殺傷する怪物としての圧力も持つ。**

**条件を外したから安全、ということにはならない。** 条件戦をしのいでも、**その等級の怪物がそこに立っている。**

## 相性ひとつで、等級差は何段でも飛ぶ

**この世界で一番はっきりした例が、[[char:raiju]] と [[char:bug]]。**

| | 等級 |
|---|---|
| **[[char:bug]]** | **特殊A級**（指定候補） |
| **[[char:raiju]]** | **通常はC級** |

**そしてBUGは、日本の通信網では雷獣に食われている側。**

**五段以上ひっくり返っている。**

### 「実は強かった」ではない

**雷獣がC級を超えているのではない。噛み合っていないだけ。**

**BUGの攻め手は、情報の攪乱、電子侵食、認識汚染。** これは**相手が電子情報として振る舞うこと**を前提にしている。

**雷獣は電子情報生命体ではない。** 電気・通信・電磁現象そのものへ適応した半自然生物に近い。**だからBUGの想定が最初から外れる。**

**そして雷獣の側の攻め手は、呪詛化した異常情報の捕食。** BUGはまさにそれでできている。

> **こちらの攻撃が通らず、相手の攻撃が通る。それだけで等級差は消える。**

### 相性は、相手との間だけでなく、場所との間にもある

**同じ一体でも、いる場所で出せるものが変わる。**

**[[char:raiju]] は通信領域内でB級相当、外では通常C級。** これは**能力が上がっているのではなく、通信網の外では出し切れていない**ということ。

> **魚系の妖怪が陸上でまともに戦えるか、というのと同じ。**

**生息地から引き剥がすのは、それ自体が有効な手**になる。逆に、**相手の生息地へ踏み込むのは、等級表を無視した不利を背負うこと。**

**なお、これは外殻が土地になっている妖怪の領域とは別の話**（→ [[concept:core-layer]]）。あちらは**土地が妖怪の体**で、こちらは**ただ住みやすいだけ。**

### だから等級は勝敗を予測しない

**等級は単純火力指数の平均。**「どれくらいか」しか言っていない（上記）。

**勝敗を決めるのは、噛み合うかどうか。**

- **C級から条件戦になる**（上記）—— 相手の条件を成立させないことが勝敗を動かす
- **[[event:hyakki-yako-attempt]]** —— 国家は死神の能力圏内で勝負せず、「能力へ付き合わない」形で制圧した
- **[[event:lupin-incident]]** —— 国家の認証技術が全滅した相手を、神託が一発で捕らえた
- **[[char:aramaki]]** —— A級を呼んでも、空・地中・水中を同時に押さえられなければ片付かない

**全部同じことを言っている。** 数字は大きさであって、**噛み合わせを含んでいない。**

**「A級を連れてくれば勝てる」という発想が、この世界では成立しない。**

## 脅威度でもある。ただし数える脅威は「殺しの数」だけ

**等級は脅威度としても読まれている。** ただし**そこで数えている脅威は、火力と殺傷に限られる。**

> **どれだけ理不尽でも、殺しの数が少なければランクは下がる。**

**能力の異常さは等級に入らない。**

| | 理不尽さ | 等級 |
|---|---|---|
| **[[event:lupin-incident]] の《ルパン》** | **上限未確認の再現能力。**神すら再現しうる | **C級相当** |
| **[[char:hanako-san]]** | **全国同時存在。**全部が本体で、本体特定に成功していない | **通常D級** |

**どちらも、殺していない。** 一方は盗む妖怪で、もう一方は守る側に回っている。**性質がどれだけ異常でも、殺傷の数が上がらなければ等級は上がらない。**

**だから等級は「どれくらい殺せるか」の指標であって、「どれくらい厄介か」の指標ではない。**

## 等級は危険性の指標ではない

**[[event:lupin-incident]] がそれをはっきりさせた。**

**本体の出力はC級相当**のまま、国家の超常認証体系を全滅させ、国家案件になった。**強かったからではなく、能力が制度に届いたから。**

**等級は単純火力指数の平均であって、何ができるかを表さない。** C級が国を動かすこともあれば、B級が地域で片付くこともある。**危険度は、能力が社会制度のどこまで届くかで決まる。**

**この世界の人々が等級を序列として扱わない**（→ [[concept:taimashi]]）ことの、もう一つの裏付けになっている。数字は大きさであって、価値でも危険度でもない。

## 採らないと決めたもの

**「裏社会・秘匿・非公認圏のA級6人」という第三の枠。**

**古い資料にあったが、明確に消されたもの。** 代わりに、**犯罪者のA級は民間・神社旧家・公職の中に普通に潜んでいる**という形になっている（→ [[concept:taimashi]]）。

**A級18人の三分割は、霊務省・神社旧家・民間のまま。** 裏社会枠を足さないこと。
