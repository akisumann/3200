## 概要

**妖怪は世界中にいる。** そして**国をまたいだやりとりも普通にある。**

日本の外にも、それぞれの国に力を使う者がいて、それぞれの高位の存在がいる。

## 分かっていること

### 国際的なやりとりは普通にある

**孤立してはいない。** [[concept:grades]] が**約100年前に国際標準として制定された**（→ [[event:grade-standard]]）のは単発の出来事ではなく、**今も国をまたいだ関係が続いている。**

### 強いとされる圏

| | |
|---|---|
| **キリスト教圏** | **強さは有名** |
| **中国** | **強い** |

**思念の理屈からすると、これは当然の結果**（→ [[concept:shinen]]）。

妖怪の強さは、**どれだけ多くの人間が、どれだけ揃った形で、どれだけ長く想っているか**で決まる。キリスト教圏も中国も、**人口の規模と歴史の長さが桁違い**。日本のA級18人・18体という数字と同じ物差しで測れば、向こうの数はもっと多いはず。

**一つの尺度で世界中が測られている**以上、**国の力は信仰と歴史の規模で決まる**ことになる。

### 日本も、とても強い方

**人口でも歴史の厚みでも、キリスト教圏や中国には及ばない。それでも日本はとても強い。**

理由は二つ。

| | |
|---|---|
| **独自の技術がかなり残っている** | → [[faction:shrines]] / [[faction:old-houses]] の秘匿技術 |
| **妖怪との共存性が、飛び抜けて強い** | → [[concept:cooperation-policy]] |

**中国も日本と同じく「バラバラで個人が頑張る」形だが、構えは中間**（下記）。**バラバラであることは、日本の強さの説明にならない。**

**規模で劣るぶんを、別のもので埋めている。**

### 構えは、二つには割り切れない

**協調と殲滅の二分は、大づかみの言い方。** **実際には五つの立場が並んでいる。**

| | |
|---|---|
| **排除派** | 妖怪をいなくする |
| **強硬派** | 妥協しない。**[[event:belzebub-war]] の生還者たちがここ** |
| **封印派** | 殺さないが、閉じる |
| **共存派** | 話をつける。**日本の [[concept:cooperation-policy]]** |
| **利用派** | **使う。**戦力、資源、労働力として |

**国ごとにどれか一つ、という話でもない。** **同じ国の中に複数ある。**

**日本にも利用派の側面はある。** 協力妖怪制度も、雷獣の半管理も、**土地神への統治委託すら、見方によっては利用**（→ [[char:raiju]]、[[concept:land-god]]）。**日本が共存派なのは、そこが一等だからであって、他が無いからではない。**

#### そして、絶滅は成功しない

**排除派や強硬派が存在すること自体は普通。** **ただし、妖怪の完全絶滅は起きていない。**

**理由は思想ではなく構造。** **妖怪が均衡構造の内側に深く組み込まれている。**

**地域社会、土地、学校、通信網、祭祀、古社、民間企業、生活文化。** **これらと結びついている以上、抜くと別のものが倒れる。**

**局所的な排除はできる。** **根絶はできない。**

**[[concept:release-points]] の「溜まるものは止められない」が、根っこの理由になっている。** **材料が尽きない以上、湧く側も尽きない。**

### 協調路線を取る国は、日本だけではない

**そして日本は、その中でも一等。**

つまり国際的には、**妖怪への構えという軸がある**ことになる。協調を選んだ国もあれば、選ばなかった国もある。日本はその協調側の中で、**共存の度合いが最も進んでいる。**

**そして共存性そのものが強みとして数えられている。** 温情でも妥協でもなく、**国力の一部。**

### 軸は二つあって、別々に動く

**中国を並べると、それが見える。**

| | **運用の形** | **妖怪への構え** |
|---|---|---|
| **キリスト教圏** | **制度的。**貯蓄と再分配 | **殲滅** |
| **日本** | **バラバラ。**個人が頑張る | **協調**（その中でも一等） |
| **中国** | **バラバラ。**個人が頑張る | **殲滅とも協調とも取れる、ほどほどの塩梅** |

**中国は日本と同じ運用の形をしていながら、構えは違う。** だから**この二つは別の軸**ということになる。

- **運用の形**は、その国がどう組織されているかの話
- **妖怪への構え**は、相手をどう扱うかの話

**バラバラだから協調になる、というわけではない。** 中国が同じくバラバラで、それでも中間に落ち着いているのがその証拠。

#### 日本が協調で一等なのは、八百万の思想による

**組織の形でも、技術でも、出力でもない。** 神道系の思想 — **八百万**。

**何にでも神が宿る、という前提。** そこには**神と妖怪を分ける線が最初から無い**（→ [[concept:kami]]）。神と妖怪は同じもので、**祀られているかどうかの違いでしかない**。

**だから日本にとって、妖怪と交渉することは何も特別ではない。** 相手は祀る対象になりうるものであり、話をつける相手であり、土地を任せる相手でもある。**カテゴリを跨いでいない。**

**一神教の側では、そうはならない。** 神は絶対で、それ以外は排すべきものになる。**同じ相手を前にして、片方は「祀る対象かもしれない」と考え、片方は「祓うべきもの」と考える。**

**この差が、殲滅と協調を分けている。** 出力の差でも制度の差でもなく、**相手を何だと思っているかの差。**

そして [[concept:kami]] の自粛の理由も、これで裏返しに説明がつく。**ヤハウェや仏陀を「妖怪」と呼ぶのは、八百万の枠組みでは失礼でも何でもない。** 神も妖怪も同じものなのだから、ただの分類。**それが国際問題になるのは、この前提が日本の外では通らないから。**

> **日本が協調で一等なのは、協調が上手いからではない。**
> **そもそも敵として立てていないから。**

### 協調しない側は、概ね殲滅

**やり方がある。** 範囲浄化、広域結界など。**面で潰す技法。**

**日本にもある程度はある。** ただし規模が違う。

**キリスト教圏は、宗教を使ったいくつかの技法で、広域を高出力でカバーできる。**

**「宗教を使った」というのが要点。** この世界では信仰がそのまま思念であり（→ [[concept:shinen]]、[[concept:kami]]）、**思念の規模で強さが決まる**。何十億人が何千年にわたって同じ形で信じてきた思念を、**そのまま技法の出力にしている**ということになる。

**だから「キリスト教圏の強さは有名」なのは、高位存在がいるからだけではない。** 信仰そのものを、**広域を焼く力に変換する手立てを持っている。**

#### 仕組みそのものは、日本の神と同じ

**別系統の何かではない。**

[[concept:kami]] の神々は**信仰の大きさで強くなる**。信者が多いほど、長く祀られるほど強い。**キリスト教圏の高位存在も、そこは同じ。**

**違うのは、そこに技術的なバイパスをつけたこと。**

| | |
|---|---|
| **日本** | 信仰 → **神（妖怪）** |
| **キリスト教圏** | 信仰 → **神** ＋ **分岐して人間側へ** |

**配管が逆向きになっているのではなく、同じ配管に分岐が足してある。** 信仰は今も高位存在へ流れていて、そのうえで一部が人間の手元へ回されている。

**そして日本にも、似たようなことはある。**

神が**「力を授けてやるぞよ、ほっほっほ」**とやれば、それで人間側に力が回る。**仕組みとしては同じことが起きている。**

**違うのは、そこをガチガチにシステマティックにしていないこと。**

| | |
|---|---|
| **キリスト教圏** | **制度。** 貯蓄し、配分し、誰にどれだけ回すかが決まっている |
| **日本** | **その都度。** 神が授ける気になれば授ける |

**これは日本の何もかもと同じ形をしている。** 妖怪との手続きは個体ごとの個別契約で、契約の中身は千差万別（→ [[concept:legal-status]]）。神社も旧家もばらばらで、司令塔も名簿もない（→ [[faction:shrines]]）。秘術は各々が抱えている。等級すら肌感覚で通っている。

**この国は、あらゆることを制度ではなく個別の関係で回している。** 力の授かり方だけが例外であるはずがない。

**逆にキリスト教圏は、そこを制度にした。** 10億人から集め、誰に配るかを決め、本人の実力によらない出力を保証する。**同じ仕組みの上で、運用の思想が正反対。**

#### 信仰のプール技術

**そしてこれが、追いつける理由。**

> **10億人を超える一般人も含めた信仰を、そのままエネルギーとして貯蓄する。**
> **それを各々のエクソシストや司教たちへ再分配する。**

**結果、本人の実力によらない馬鹿高い出力が出る。**

**ここで等級制度の前提が崩れる。** この世界の等級は、**本人が動かせる力の規模**を測るもの（→ [[concept:grades]]）。素質があり、訓練を積み、修羅場を踏んで上がっていく。**ところがプールから配られる出力は、本人が積み上げたものではない。**

**つまり向こうでは、個人の等級と実際の出力が切り離されている。**

**これは [[concept:jugu]] と同じ原理。** 呪具は力を持たない一般人に妖怪への手を届かせ、**等級差を覆す**。信仰のプールは、それを**国家規模でやっている**ということになる。道具の代わりに、10億人の信仰を配っている。

##### 汲まれている側については、誰も確かめていない

**プールの入口は分かっている。** 10億人の信仰を集め、貯め、配る。

**では、汲まれた先の神格はどうなっているのか。**

**大半の神職層は、この仕組み自体は理解している。** **しかし神格の側にどういう影響が出ているかまでは把握していない** → [[concept:kami]] の「ヤハウェをめぐる仮説」

**一部の最上層には、半禁忌の見方がある。**

> **現代欧州文明は、神の力をほぼ100%、人類保護へ変換し切っているのではないか。**

**確定していない。そして一般の信徒層には知らされていない。** **知られれば「教会上層部が神の力を私的運用している」と受け取られる。**

**この制度の一番深いところに、確かめられていない一点がある。**

##### 貯蓄である以上、使い切れる

**そしてそれは実際に起きた** → [[event:belzebub-war]]

約20年前、欧州は特殊A級相当の悪魔群を相手に、**信仰備蓄の大規模消費を承認した。** 都市区画単位の聖域化、大規模祈祷、蓄積した信仰の強制燃焼。

> **信仰を燃料として戦った。**

**勝った。そして備蓄は大幅に減り、広域聖域が弱まり、地方の封印が不安定化した。**

**プールは無限の蛇口ではなく、残高のあるタンク。** 平時は「本人の実力によらない出力」を安定供給するが、**一度の総力戦で底が見える。** 日本の [[concept:jugu]] にある国家備蓄霊札が「在庫は薄い」のと、規模は違っても性質は同じ。

**この制度の弱点は、ここにしかない。** 動員力そのものは日本より遥かに大きく、そこを突く手はない。**ただし貯めたものは減る。**

#### 動員の規模が違う

| | 何で回しているか |
|---|---|
| **日本** | **退魔師（約222万人）と、友好的な妖怪** |
| **キリスト教圏** | **一般人の力すら余すところなく使っている** |

**日本が使えるのは、力を使える人間と、味方についた妖怪だけ。** 人口の1.8%と、契約を結んだ相手。**残りの98%は、守られる側であって戦力ではない。**

**キリスト教圏は、その98%も含めて数えている。** 信じているだけでいい。見えなくても、術が使えなくても、**信仰さえあれば供出できる。**

**日本の「共存性」が強みなのと、キリスト教圏の「動員力」が強みなのは、同じ問題への別々の答え。** どちらも「力を使える人間だけでは足りない」ところから出発している。**日本は妖怪を味方につけ、キリスト教圏は一般人を燃料にした。**

そして**燃料は、妖怪を生むものと同じ**。思念が溜まれば妖怪が湧き（→ [[concept:shinen]]）、その思念を汲み上げれば妖怪を焼ける。**同じものを、湧く側と消す側の両方が使っている。**

#### ただし、汲んでも妖怪は減らない

**奪い合いにはならない。**

**人間が出す思念は、信仰だけではない。** 邪念も、恐れも、願いも、憎しみも、**無限に湧き出てくる**。**地球全土のすべての人間がそう。**

**プールに汲めるのは、揃った思念だけ。** 信仰は「同じ形の、同じ方向を向いた思念」なので集めて使える。**それ以外の雑多な思念は、集められないが、妖怪にはなる。**

これは [[concept:shinen]] の仕組みそのまま。

| 思念 | プールに使えるか | 妖怪になるか |
|---|---|---|
| **揃っている**（信仰） | **使える** | なる |
| **雑多**（邪念、恐れ、願い） | **使えない** | **なる** |

**つまり信仰のプールは、思念全体のごく一部を抜き取っているだけ。** 抜いたぶん源が細るということはない。**人が生きている限り、材料のほうは尽きない。**

**だから殲滅路線でも根絶はできていない。** 湧く速度に消す速度が追いついているだけで、**源は止まっていない。** そこは日本と同じ前提の上に立っている — **溜まるものは止められない**（→ [[concept:release-points]]）。

**違うのは、その先の選択だけ。** 日本は流れを誘導し、向こうは湧いた端から焼いている。

#### 面で潰す国と、一体ずつ話をつける国

| | |
|---|---|
| **殲滅側**（キリスト教圏など） | **広域・高出力。**面で消す |
| **協調側**（日本など） | **個別の契約。**一体ずつ、一つの里ずつ話をつける |

**日本のやり方は、手間がかかる。** [[faction:shrines]] が代理で交渉し、契約を取り、[[faction:reimusho]] が個体ごとに条件を組み立て、土地神に統治を頼み、逃しポイントを維持する。**面で消せるなら、こんなことをする必要はない。**

**日本にその出力がないから協調を選んだ、とも読める。** 人口も歴史も向こうに及ばない以上、思念を出力に変える力でも及ばない。**代わりに、相手と話す技術を磨いた**（→ [[faction:shrines]]「神社の本業は、対話」）。

> ただしこれは**因果の読み**であって、確定ではない。**根っこにあるのは八百万の思想**（上記）で、出力の不足はそこに重なっている要因にすぎないかもしれない。

実際、この国の仕組みはほとんど共存の上に載っている。土地を土地神に統治させ（→ [[concept:land-god]]）、妖怪が湧く場所をわざわざ作って管理し（→ [[concept:release-points]]）、妖怪の集団と契約を結び（→ [[concept:youkai-land]]）、学校を土地神の縄張りの上に建てている（→ [[concept:taimashi-school]]）。

**これを全部やめたら、日本の超常社会は成り立たない。** 協調は方針ではなく、**土台。**

### 中国には、仙人がいる

**A級退魔師として数えられている。**

**そして第二次世界大戦の交戦相手を、今も覚えている** → [[concept:a-rank]] の呪術系の術者。**八十年前にやり合った相手の顔を見て、そう言っている。**

**人間側のA級が、八十年以上活動している**ということになる。

**日本にも似た例がある。** **[[char:suwa-shizuka]] は1986年の記録に同一の外見で確認されていて、年齢の計算が合わない。**

> **人間のA級には、寿命の側が普通でない者がいる。**

**そして「仙人」という呼び方が使われている。** **[[concept:kami]] の理屈では神も妖怪も同じものだが、仙人はA級退魔師 —— つまり人間側の等級で数えられている。**

**中国が「殲滅とも協調とも取れる、ほどほどの塩梅」**（上記）**である背景に、こういう存在がいる。**

**未確認。** **仙人が中国の何なのか、何人いるのか、どういう立場なのかは書かれていない。**

### 英国は、情報の側で持っている

**火力でも動員でもない軸が一つある。**

**アカシック・レコードが英国超常社会の最深部に封印されている** → [[concept:relics]]

**記録、観測、認識、歴史、「知る」という行為そのものが長期の文明蓄積で凝集した半概念存在**とされ、**人類文明が知ったことへ接続できる。** 保管場所は大英図書館地下深層の禁書聖域《ブラック・スタック》。

**管理は三重共同。** 英国超常情報庁、**欧州聖庁記録院**、王立神秘学会。

**欧州聖庁が管理側に入っているのが効いている。** [[event:belzebub-war]] で削れた教会が、**情報の側にはまだ座っている。**

**そして閲覧は全部が政治問題になる。** 誰が見るか。何を見ようとするか。どの深度まで潜るか。**見た情報をどこまで記録してよいか。観測者が壊れた場合、誰が責任を取るか。**

> **情報を持つことが、そのまま戦力になっている。**

**この表の軸に、もう一つ足りていない。** 運用の形と妖怪への構えの二軸では、英国のこの位置が拾えない。**超常情報覇権という別の勘定がある。**

**日本がここに何を持っているかは、まだ書かれていない。**

### キリスト教圏は、一枚岩ではなくなっている

**上の表では「制度的・殲滅」で一行に収まっているが、その一枚岩性は約20年前に崩れた** → [[event:belzebub-war]]

**教会が総力戦に勝ち、そして深く削れた。** 高位聖職者が多数死に、聖堂騎士団が壊滅的に損耗し、聖遺物を多数失い、現地の実務者層がごっそり抜けた。**欧州聖庁を中心とした超常防衛体系に、限界が見えた。**

**そこから起きたこと。**

| | |
|---|---|
| **教会勢力の弱体化** | 損耗そのもの |
| **土着術の再評価** | 教会系だけでは足りないと分かった |
| **ケルト術研究の復興** | 古い異教系の技術が掘り返された |
| **非教会系超常勢力の拡大** | 制度の外側に人と技術が流れた |

**皮肉な形をしている。** 一神教の枠組みが「神は絶対で、それ以外は排すべきもの」であることが、**協調と殲滅を分けている**（上記）。**その枠組みが自分の限界を露呈したとき、欧州は自分たちが排してきた側の技術を掘り返した。**

**日本から見れば、これは分岐点の記録として読める。** 向こうも一枚岩ではなく、**制度の内側と外側で温度が違う。**

**そして [[event:hyakki-yako-attempt]] への批判が強硬なのも、この構図の一部。** 最も強く反発したのは戦役の経験者たち — **教会側の、削れたほうの人々。**

## 社会との関わり

### 呼び方を自粛している相手がいる

**ヤハウェや仏陀の妖怪もいるとされている。** ただし**そこらを「妖怪」と言うと国際問題級になるので、自粛している** → [[concept:kami]]

## 未決

### やりとりの中身

- **何をやりとりしているのか**（技術、情報、人員、条約、共同での対処）
- 国際的な機関はあるのか。**等級を決めた枠組みは今も続いているのか**
- **日本はどういう立ち位置なのか。** 強いほうなのか、中位なのか
- 他国にも [[faction:reimusho]] に当たる官庁があるのか
- **日本の独自技術は、外に出しているのか。** 秘匿技術は国外へも秘匿なのか
- **国境を越える妖怪はどう扱われるのか**

### 「強い」の中身

- **何が強いのか。** 術者の質か、数か、そこにいる高位存在か、制度か
- キリスト教圏と中国では、強さの質が違うのか
- **日本の三系統（国・伝統・民間）に当たる構造は他国にもあるのか**
- 協調しない側は**概ね殲滅**、キリスト教圏は宗教を使った広域高出力の技法を持つ（確定）。残るのは:
  - **中国が「ほどほどの塩梅」なのは、どういう形で現れているのか**（相手によって変えるのか、地域で違うのか、揺れているのか）
  - 追いつく理由は**信仰のプール技術**（確定）。では:
    - **プールは誰が管理しているのか。** 配分を決めるのは誰か
    - **信者が減ったらどうなるのか。** 出力がそのまま落ちる
    - 日本にも**神が個別に力を授ける形**で似たことは起きる（確定）。**では:**
      - **制度にしようとしたことはあるのか。** できないのか、やらないのか
      - 授かった人間は、その間だけ等級が上がったように見えるのか
      - **神の側に断る自由があるのか。** キリスト教圏のプールは断れるのか
  - **殲滅側の国に、妖怪の土地や協力妖怪はいないのか**
- **範囲浄化・広域結界とは何か。** 日本にもある程度あるとのことだが、誰が使えるのか（等級か、勢力か）

### 自粛について

- **誰が自粛しているのか**（国か、業界か、暗黙の了解か）
- **国内ではどう呼んでいるのか。** 妖怪と呼ばずに何と言うのか
- 相手の国はそれをどう扱っているのか。**向こうも同じことを知っているのか**
- **実際に問題になった例はあるのか**
