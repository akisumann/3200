## 概要

妖怪は法的には**「妖怪」という一つの分類**として扱われる。その上で、**原則として人権に相当するものを持たない**。国の専門官庁での公的手続きを経れば、いくつかの**特殊な権利**を得られるが、経ている妖怪は**一定数いるものの少数派**。

## 仕組み

### 法的には一つ、実態はばらばら

制度上の区分は「妖怪」ひとつしかない。**しかし実際にどう扱われるかは個体によってまったく違う。**

- 現象のように扱われるもの
- 災害として備えられるもの
- 害獣として駆除されるもの
- 特殊な動物として扱われるもの
- **国家級兵器に相当する**扱いを受けるもの
- 土地として扱われるもの
- 物として扱われるもの
- ほかにも色々

**これらは法的な区分ではない。** 「兵器」という分類があるのではなく、兵器に相当する扱いを受けている妖怪がいる、というだけ。制度は一つの箱にまとめているが、中身の幅がその箱に収まっていない。

### なぜ人権の枠が合わないのか

**妖怪の大部分は知性が低い。** 人権は、判断し、主張し、責任を負う主体を前提に組み立てられている。妖怪の多くはその前提を満たさない。

加えて、同じ「妖怪」の箱の中に、現象のようなものから土地のようなものまで入っている。**幅が大きすぎて、人間用の枠がそのままでは載らない。** 別枠にしたのは差別のためではなく、噛み合わないから。

### 手続き

- 扱うのは**霊務省** → [[faction:reimusho]]
- 経れば、いくつかの**特殊な権利**が得られる（人権そのものではない）
- 経ている妖怪は**一定数いるが少数派**

### 人間が妖怪になった場合

**法的には死亡扱いになる。** 人間としての戸籍は閉じられる。

**ただし、すぐに行政手続きを行えば大抵は問題ない。**

ここに制度の性格がよく出ている。人権を持つ人間が人権のない妖怪になるという、原理的には制度の急所になりそうな事態が、**実務としては事務処理で片付く**。悲劇でも法の抜け穴でもなく、**窓口で対応できることになっている**。

制度が長く運用されてきて、この種の事態を織り込み済みであることの表れ。「割とある」ことなら、対応の型ができているのが当然、ということ。

### 妖怪は法の外にいる

**この二つが、同時に成り立っている。**

| | |
|---|---|
| **人間が妖怪を殺しても、お咎めなし** | 相手が**特に何もしていなくても**構わない |
| **妖怪が過去に大虐殺をしていても、罰する権利がない** | どれだけ悪虐非道なことをしていても、罪として扱われない |

**保護もされないし、処罰もされない。** 片方だけではない。**両方が同時に無い。**

#### 権利と責任は対になっている

人権を持たない存在に、刑事責任は問えない。権利がないから義務もなく、義務がないから違反もなく、違反がないから罰もない。そして同じ理由で、**殺されない権利もない**。

**犬が人を噛んでも犬が裁かれないのと、同じ構造。** ただし犬には動物愛護の法規があるが、**妖怪にはそれすらない。**

これは制度の抜け穴ではなく、**「妖怪に人権の枠が合わない」ことの当然の帰結**。判断し、主張し、責任を負う主体を前提にした枠組みが載らない以上、**保護の側も責任の側も、どちらも載らない。**

#### だから討伐は処罰ではない

**討伐は駆除であり、予防である。** 罰ではない。

そして**討伐ですらない殺害も、同じく何でもない。** 通りすがりに殺しても、罪に問われない。

すると、妖怪に対する扱いは**すべて法の外の出来事**になる。

| 人間が相手なら | 妖怪が相手なら |
|---|---|
| 殺せば殺人罪 | **何も起きない** |
| 何をしたか（過去）で裁く | **前科という概念がない** |
| 反省・情状酌量 | **反省そのものが意味を持たない** |
| 法が両側を縛る | **法が及んでいない** |

**だから届け出もいらない。** 妖怪を殺しても、報告義務も、事後の届出も、許可も要らない。

**法の外にいるということは、書類の外にいるということでもある。** 制度が関知しない以上、記録する先もない。蔵のF級を浄化札で片付けるのに役所へ届けないのと同じことが、**どの等級でも同じように成り立っている。**

#### 温情でも抑圧でもない

**この非対称は、妖怪を守るためでも、虐げるためでもない。** 法が届いていないだけ。

だから妖怪の立場は、**守られている／虐げられているのどちらでもない**。**法の外**という一語でしか言えない。

- 何をされても訴える先がない
- 何をしても裁かれない
- **その両方を引き受けて存在している**

### 手続きは、一つの制度ではなく個別の契約

**手続きの中身は千差万別。** 何を得て何を負うかは、**その手続きによる**。

一律の身分を与える窓口業務ではない。**個体ごとに結ばれる契約**であり、だから「手続きを経た妖怪」と一括りに語れない。得る権利も、負う義務も、個体によって違う。

これは [[concept:youkai]] の「法的には一つの分類、実態はばらばら」と同じ形をしている。**制度は一つ、中身は個別。**

#### 契約の型は、その妖怪の在り方で決まる

**少なくとも、この二つは何もかも違う。**

| | |
|---|---|
| **一個体でそこらをほっつき歩く妖怪** | 単独。定住しない。責任範囲がない |
| **土地を統治する妖怪** | 動かない。範囲が明確。地域社会と継続的な関係を持つ → [[concept:land-god]] |

**同じ「手続き」という言葉で呼ばれていても、中身は別物。**

そうなるのは自然で、両者は**契約が前提にできることがまるで違う**。

- 遊動する妖怪は、**どこにいるか把握できない**。土地神は動かない
- 遊動する妖怪には、**守るべき範囲がない**。土地神には土地がある
- 遊動する妖怪が関わる人間は場当たり。土地神は**同じ人間と何十年も付き合う**
- だから**渡せる対価も、負わせられる義務も、監視の方法も、破られたときの手当ても、すべて変わる**

**在り方が違えば契約が違う。** 一律の身分ではなく個別の契約である、というのはこういうこと。

#### 行政は、相手が人間でないことを分かっている

**人間の行政は、妖怪が人とは違う価値観・感情・感覚を持っていると知っている。そのうえで、それを踏まえた契約をきちんと結ぶ。**

ここは重要。**この世界の役所は、人間の常識で妖怪を測るという失敗をしていない。**

有史以来ずっと妖怪がいて、100年前から等級で測ってきた社会である以上、**噛み合わない相手と契約を結ぶ実務の蓄積がある**。人間相手の契約書をそのまま使って通じるわけがないことを、現場は知っている。

だから手続きは、**妖怪を人間の型に押し込む作業ではなく、その個体に通じる条件を組み立てる作業**になる。

### 手続きは、法の内側へ渡る橋

**そして、この構造から抜ける道が一つだけある。それが手続き。**

**手続きを経て権利を持った妖怪に、無断で手を出したら、ありとあらゆる日本の法律が牙を向く。**

| | 未手続きの妖怪 | 手続きを経た妖怪 |
|---|---|---|
| 殺したら | **何も起きない** | **法が牙を向く** |
| 立場 | **法の外** | **法の内側** |

**ここが手続きの最大の意味。** 「いくつかの特殊な権利」という言い方は控えめに聞こえるが、実際にはこれは**存在の安全そのもの**を意味する。誰にいつ殺されても文句の言えない立場から、**国家の法体系が丸ごと後ろ盾になる立場**へ渡る。

そしてこれが、**この国が特別な妖怪保護法を作らずに済んでいる理由**でもある。守りたい妖怪を法の内側に入れてしまえば、あとは**普通の法律がそのまま働く**。財産、契約、居住、身体 — 妖怪用の新しい枠を作るのではなく、**既存の枠に入れる**。

だから [[concept:taimashi]] が「手続きを経た妖怪を退治できるか」で**場合による**と答えるのは当然で、相手が法の内側にいる以上、正当な理由がなければ手を出せない。

#### この空白が、方針を必要にする

**未手続きの妖怪について、法は何も定めていない。だからそこは国の方針が埋める。**

殺してもいい相手を、殺すか殺さないか。決めるものが法でないなら、何かで決めなければならない。それが**協調路線** → [[concept:cooperation-policy]]

そして協調路線と手続きは繋がっている。**国が本気で守りたい妖怪は、手続きを経させて法の内側に入れればいい。** 方針で守るのではなく、**法で守れる状態にしてしまう。**

**「殺してもいい相手を、あえて殺さない」だけでは、他人が殺すのを止められない。** 国が自分で手を出さないと決めるのは方針でできるが、**万人に対して「触るな」を成立させるには、法の内側に入れるしかない。**

## 社会との関わり

この制度は妖怪を**手続きを経た側と経ていない側**に分ける。存在が公然と知られている世界での主要な社会的断層は、人間と妖怪の間ではなく、この線の上にある。

ただし妖怪の大部分は知性が低いため、**この線をまたげる妖怪自体が限られている**。制度をめぐる争いは、妖怪全体の問題ではなく、知性を持つ一部の妖怪の問題として現れる。

## 未決

### 手続きを経た妖怪が少数派である理由

**複数の要因がある。** 判明している順に並べる。

1. **妖怪の大部分は知性が低い**（確定）— 制度の対象になりうる妖怪がそもそも限られる
2. **望まない妖怪が多い**（確定）— **そもそも感性や感覚が人間的ではないため。** 制度を利用したほうが便利だと考えるタイプの妖怪が利用する
3. （未確認 — 他にも要因があるとのこと）

### 2 が意味すること

**これは抑圧の話ではない。** 妖怪が権利を求めて阻まれているのではなく、**そもそも人間のように考えていないから求めない**。

制度を使うのは「使ったほうが便利だ」と判断する型の妖怪に限られる。**つまり手続きを経た妖怪とは、人間的な合理性を共有できる妖怪**ということになる。手続きの有無は、権利の有無であると同時に、**どれだけ人間に近い感性を持っているかの目印**になっている。

残る問い:

- 「便利だと思うタイプ」とはどういう妖怪か。**それは知性の高さと同じことなのか、別のことなのか**
- 人間的な感性を持つ妖怪は、なぜそうなったのか（元の思念が人間由来なのか、人間と関わって変わったのか）
- 望まない妖怪と手続きを経た妖怪の間に、妖怪同士の軋轢はあるのか
- **人間側はそれをどう見ているのか**（放っておくのか、望ませようとするのか、望まない妖怪を危険視するのか）

### 手続きそのもの

- 誰が申請できるのか。知性の有無はどう判定されるのか
- 審査・条件・費用・後見人はあるか
- 一度きりか、段階があるのか
- 取り消し・剥奪はあるか
- **知性のない妖怪の代わりに、誰かが申請することはできるのか**

### 得られる「特殊な権利」

- 具体的に何が得られるのか（財産、契約、居住、就労、訴訟、婚姻、移動……）
- 人権とどこが違うのか。足りないのか、別物なのか、一部は人権より強いのか

### 実態としての扱い

- **扱いは等級と対応しているのか。** 妖怪にも等級がつく以上（→ [[concept:grades]]）、「国家級兵器に相当する扱い」の妖怪はA級ということになりそうだが、そうか
- **誰が、どの扱いをするか決めているのか。** 法的区分ではない以上、明文の基準はないのか
- 扱いは変わるのか（力を増した妖怪の扱いが引き上げられることはあるか）
- 「土地として扱われる妖怪」は売買されうるのか。されるなら、妖怪を所有する人間がいることになる
- 「国家級兵器に相当する扱い」の妖怪を、国は保有しているのか、監視しているだけか、封じているのか

### 法の外／内であることの周辺

**手続きが存在の安全そのものだとすると、望まない妖怪の多さが際立つ。**

- **大半の妖怪は、誰にでも殺される立場を選んでいることになる。** なぜか
  - 感性が人間的でないから気にしないのか
  - 殺される心配がないほど強いのか（**高等級ほど手続きの必要が薄いのでは**）
  - そもそも考えていないのか
- **逆に、弱い妖怪ほど手続きを必要とするはず。** だが知性が低ければ申請できない。**必要な者ほど届かない構造**になっていないか

**手続きの中身**

権利も義務も**その手続きによる**（確定）。その上で。

- **どこまで守られるのか。** 殺害だけか、傷害・拘束・使役・売買まで及ぶのか
- **「無断で」ということは、断れば手を出せる場合がある**ということか。何が正当な理由になるのか
- 責任を負う契約と、負わない契約の両方があるのか。**保護だけ受け取る契約は成立しうるのか**
- 手続きを経た妖怪が人を殺したら裁かれるのかも、**契約次第**ということか

**契約の中身**

> **掘らない。** 何を渡し何を負わせるかは、**本当に個体ごとに色々**であって、一般則を立てる意味がない。ここを体系化しようとすると嘘になる。

**代わりに、型の例を一つ持っておけば足りる。**

- **土地統治型** — [[concept:taimashi-school]] の土地神。校地を守り妖怪を統制する代わりに、感謝と敬いと、卒業生との人脈を得る
- **遊動型** — 《ルパン》の例。**一個体に対して個別に手続きを結び、任務としてうまく使っている**

後者に、この制度の実用面がよく出ている。**契約は保護を与えるだけのものではなく、その妖怪の得意なことを任務として使うための取り決めでもある。** 盗みに長けた妖怪なら、盗みが役に立つ仕事を任せる。

**個体の性質に合わせて設計し、その性質ごと使う。** これが「行政は相手が人間でないことを分かっている」の実務的な中身。

**協調路線との関係**

- **協調路線に乗る妖怪は、当然に手続きを経ているのか**（[[concept:land-god]] や学校の土地神は）
  - 経ていないなら、国が守りたい相手を法の外に置いていることになる
- **経ることを拒む相手と協調したい場合、国はどうするのか**
- 手続きを経ていない高位妖怪を人間が殺した場合、法的には何も起きない。**国はそれをどう防いでいるのか**

**その他**

- 妖怪が人を殺したとき、**遺族には何が残るのか**（賠償を求める相手がいない）
- 妖怪を焚きつけて人を殺させた人間は罰せられるのか。**道具として使われた場合の責任は誰に**
- 妖怪が妖怪を殺した場合はどうなるのか
- 加害の原因が人間の思念にあることを、制度は認識しているのか

### 人間の側

- 人間にこれに相当する手続きはない。この非対称は問題にされているのか
- 妖怪の権利を擁護する人間・団体はいるのか
- 手続きを経た妖怪は、人間社会にどう受け入れられているのか
