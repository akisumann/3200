## 概要

妖怪は**原則として人権に相当するものを持たない**。ただし**国の専門官庁での公的手続きを経れば、いくつかの特殊な権利を得られる**。手続きを経た妖怪は**一定数いるが、少数派**。

権利は生まれつき備わるものではなく、**申請して獲得するもの**。ここがこの世界の制度の要になっている。

## 仕組み

### なぜ人権ではないのか

**妖怪に人権の枠が合わないから。** 差別のために別枠にしたのではなく、人間を想定して作られた法の枠組みが、そもそも妖怪という対象に噛み合わない。

これは下の「分類」を見ると理解できる。人権は「一人の人間」を前提に組み立てられているが、妖怪には数えられないもの、動かないもの、そもそも個体ですらないものが含まれる。**現象に人権を与えることはできない。**

### 未手続きの妖怪の扱い — 単一のカテゴリがない

手続きを経ていない妖怪には、**統一された法的身分が存在しない**。既存の分類のうち、その妖怪の性質に近いものが当てはめられる。

確認されている当てはめ先（**これで全部ではない**）:

| 分類 | |
|---|---|
| 現象 | 事象として扱われる。主体ですらない |
| 災害 | 発生に備え、被害を算定する対象 |
| 害獣 | 駆除の対象 |
| 特殊な動物 | 動物として扱われるが、通常の動物とは別枠 |
| **国家級兵器** | 戦略的な資産として国が管理する |
| **土地** | 不動産。所有・登記の対象になりうる |
| 物 | 動産 |
| … | 他にもある |

**この雑多さ自体がこの制度の本質。** 妖怪を扱う統一法を作れなかった（あるいは作らなかった）結果、既存の法体系のあちこちに割り振って処理している。上のどれにも当てはまらない妖怪が出てきたときに何が起きるかは、この世界の火種になる。

### 手続き

- 扱うのは**国の専門官庁** → [[faction:youkai-agency]]
- 経れば、いくつかの**特殊な権利**が得られる（人権そのものではない）
- 経ている妖怪は**一定数いるが少数派**

## 社会との関わり

この制度は妖怪を**手続きを経た側と経ていない側**に分ける。存在が公然と知られている世界での主要な社会的断層は、人間と妖怪の間ではなく、この線の上にある。

さらに未手続き側の内部でも、**どの分類を当てられたかで扱いがまったく違う**。「特殊な動物」と「物」では、同じ無権利でも生活が別物になる。断層は二重にある。

## 未決

### 分類

- **誰が、いつ、どうやって分類を決めるのか** — 生まれた時点か、認知された時点か。審査があるのか
- **分類は変わるのか** — 力を増した妖怪が「特殊な動物」から「国家級兵器」に上がることはあるか。その逆は
- **分類に不服を申し立てられるのか** — 手続きを経ていない以上、申し立てる資格自体が無いのでは
- **どれにも当てはまらない妖怪が出たらどうなるのか**

### 「国家級兵器」に分類された妖怪

- 国が保有しているのか、指定して監視しているだけなのか
- 何体いるのか。所在は公表されているのか
- 他国も同じことをしているのか。**国際的な取り決めはあるのか**
- 本人（と呼べるなら）に意思はあるのか。あるなら、それは考慮されるのか

### 「土地」に分類された妖怪

- **売買できるのか。** できるなら、妖怪を所有している人間がいることになる
- 移動したらどうなるのか
- そこに住んでいる人間がいるのか

### 手続きそのもの

- 誰でも申請できるのか — 条件・審査・費用・後見人
- **なぜ少数派にとどまっているのか** — 要件が厳しいのか、知られていないのか、望まない妖怪が多いのか、**分類上そもそも申請できない妖怪が多いのか**
- 一度きりか、段階があるのか
- 取り消し・剥奪はあるか

### 得られる「特殊な権利」

- 具体的に何が得られるのか（財産、契約、居住、就労、訴訟、婚姻、移動……）
- 人権とどこが違うのか。**足りないのか、別物なのか、一部は人権より強いのか**

### 人間の側

- 人間にこれに相当する手続きはない。この非対称は問題にされているのか
- 妖怪の権利を擁護する人間・団体はいるのか
- 手続きを経た妖怪は、人間社会にどう受け入れられているのか
