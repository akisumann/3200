## 概要

**妖怪の元になるもの。** 妖怪は思念を元にした現象としての個体である（→ [[concept:youkai]]）が、その「思念」がどう振る舞うかを定めたのがこの項目。

**この世界の妖怪に関する仕組みは、ほぼすべてここから導かれる。**

## その下に、もう一層ある

**思念は、何もないところで固まるわけではない。**

**世界には、まだ個体になっていない超常エネルギーが遍在している。** [[concept:powers]] の呪力・法力・魔力・妖力は、地域や術式体系や文化による呼び分けであって、**元は同じ環境要素。**

**そしてこれは、均一に満ちているのではなく流れている。**

### 滞留する場所がある

**地脈。龍脈。霊地。信仰地。穢れ場。**

**こういう場所では、エネルギーが滞留し、変質しやすい。** 場所ごとに性質も強弱も違う。

### 妖怪ができるまで

**人の感情・噂・怨念・願望 —— つまり思念が、この流れに干渉する。**

| | |
|---|---|
| **1. 干渉** | 念が流れへ触れ、**局所的な停滞・固着**が起きる |
| **2. 長期化** | 同じ念が続くほど、固着が強まる |
| **3. 定着** | 固着が安定した状態が、**妖怪** |

> **妖怪とは、流れの固着が、蓄積と縁によって安定した形。**

**「思念が溜まれば自然に湧く」（下記）の、溜まる先がこれ。** **思念そのものは弱いが、干渉する対象のほうにはエネルギーがある。**

**これで [[concept:release-points]] の逃しポイントが読み直せる。** **滞留しやすい場所を人為的に用意して、湧く場所を選んでいる。** 溜まるものは止められないが、**どこで固着させるかは選べる。**

**術式・儀式・呪具も、同じ層を扱っている。**

> **術式・儀式・呪具は、この流れの制御・誘導技術。**

**[[concept:jugu]] の国家備蓄霊札に「地脈儀式」が製造の管理項目として入っているのは、そういうこと。** **札を作ることは、流れの濃い場所で流れを固定する作業になっている。**

## 蓄積と縁

**妖怪の成立は、大まかにこの二語で説明される。**

| | 何のことか | どこへ効くか |
|---|---|---|
| **蓄積** | 感情・思念・信仰・恐怖・願望・伝承・土地性が集まり、**時間をかけて濃くなる**こと | **核を濃くする** |
| **縁** | 蓄積したものが**名前・役割・土地・媒体・人間関係・世界との関係によって形を得て**、現実の中で安定すること | **外殻を形作る** |

**[[concept:core-layer]] の「核は与えられ、外殻は積まれる」に、名前がついた形になる。**

**そして高位の存在ほど、蓄積と縁が幾重にも重なっている。** **一本の太い縁ではなく、名前も土地も役割も媒体も契約も、全部が同時に効いている。**

## 仕組み

### 表面張力

**思念には表面張力のようなものがある。** 似た思念は勝手にくっついて形になる。**その形になったものが妖怪。**

意図して作られるのでも、誰かが呼び出すのでもない。思念が溜まれば**自然に湧く**。

### 思念そのものは、とても弱い

**大前提。思念だけでは相当弱いエネルギーであり、具体的に何かが起きたりはしない。**

大勢が誰かを「化け物だ」と想ったところで、**その人の肉体がどうこうなることはない**。思念は妖怪の材料ではあるが、それ自体は物を動かす力を持たない。

**この制約がなければ、この世界は成立しない。** 思念が強い力を持つなら、想うだけで人を殺せることになり、公然と妖怪が知られている社会など維持できない。**思念は溜まって形になって初めて力になる。**

### 揃っているほど、そして古いほど強い

くっつき方の強さは、二つの要素で決まる。

| 要素 | |
|---|---|
| **方向性の一致** | 思念がどれだけ同じ形・同じ向きに揃っているか |
| **歴史の長さ** | **長年同じことを思われ続けてきたか** |

| 思念の状態 | 結合 | 結果 |
|---|---|---|
| **雑多** | 弱い | **霧散しやすい**。生まれても長く保たない |
| **方向性が揃っている** | 強い | **強固**になる |
| **揃っていて、かつ古い** | 最も強い | 高等級になりうる |

**そしてこの差は、生まれた時点での出力差になる。** 後から鍛えて追いつくのではなく、**どういう思念から生まれたかで初期値が決まる**。

**時間が要る。** 一時の流行がどれだけ大勢を巻き込んでも、それだけではA級には届かない。**A級になるには、長年にわたって同じ像を想われ続けた歴史が要る。**

#### 「流行ったから強くなる」は、明確に否定されている

**現代超常理論では、一時的流行や短期バズのみでA級相当へ到達することは極めて稀とされる。**

SNS怪異、ネット怪異、情報怪異は確かに危険で、実際に案件も出ている。**しかし危険であることと、高位に届くことは別。**

**A級相当の認識災害へ届くために要るもの。**

広域認知。**継続的認識。** 社会不安。**象徴性。** 文明定着。**生活習慣への浸透。** 記録・通信・観測との結合。

**「継続的」「定着」「浸透」が並んでいるのが要点。** どれも**時間の言い換え**になっている。**拡散の速さは、この列を一つも埋めない。**

**そして現場では、こう言われるようになった。**

> **「ノストラダムスに知名度勝てるの？」**

**嘲笑ではなく、実務上の警告**（→ [[char:nostradamus]]）。**新しい怪異の報告が上がってくるたび、規模の桁を確認させるための一言。**

#### 例外は二体いて、埋め方が違う

**歴史の浅さを、別のもので埋めた例が二つある。**

| | 何で埋めたか | 結果 |
|---|---|---|
| **[[char:nostradamus]]** | **規模。**世界規模の終末恐怖が一時に集中した | **一時的A級相当。**噴き上がって、去った |
| **[[char:bug]]** | **定着。**情報文明の日常へ寄生した | **特殊A級指定候補。**残っている |

**規模で届いたものは残らず、定着で届いたものが残った。**

**表の三行目「揃っていて、かつ古い」が最も強いのは、そういうこと。** **古さの正体は、揃った状態が続いていること。** 一瞬だけ完璧に揃っても、続かなければ落ちる。

### 物も、同じ理屈で動いている

**思念で成り立っているのは妖怪だけではない。**

**村正は「徳川家に災いをもたらす」という認識条件で成立していた妖刀群だった。** **幕府が消え、徳川の血筋が権力の中心でなくなったので、その概念現象は大半が空転した**（→ [[concept:relics]]）。

**名が支えを失って希釈するのと、同じ形。** **違うのは、支えていたものが名ではなく社会の側の条件だったこと。**

> **古いから危ないのではない。まだ支えられているから危ない。**

**だから逆も言える。** **現代でなお高位遺物として危険なものは、今も社会的な意味と認識基盤を保っている。**

### だから有名な妖怪は強い

これが**知名度の高い妖怪と、雑多な妖怪の差**。

大勢の人間が、同じ形の、同じ方向を向いた思念を抱いている妖怪 — つまり**よく知られ、姿かたちや性質の像が共有されている妖怪**は、結合が強く、強固で、生まれつき出力が高い。

鬼が鬼というだけでB級が堅く、天狗がC級以上なのは、これが理由 → [[concept:grades]]

**妖怪の強さは、どれだけ多くの人間が、どれだけ揃った形で想っているかで決まる。**

### ただし「有名＝強い」ではない

**思念の一致と歴史が決めるのは、核の強固さ — つまり「その通りのものになる度合い」。**

**どれくらい強いかは、思念が何を定めているかで決まる。**

だから例外がある。**弱いと伝承で語られる有名妖怪は、その伝承に沿って弱い。**

| | |
|---|---|
| **座敷童子** | 害をなさない。福をもたらす |
| **餓鬼** | 飢え、苦しみ、惨めである |
| **まっくろくろすけ** | 小さく、無害 |

どれも広く知られ、像が共有され、思念は十分に揃っている。**それでも弱い。弱いものとして定められているから。**

「人喰い妖怪！」と定められた思念が人を食うのと、同じ理屈。**定義が何を言っているかが、そのまま出力になる。**

### 安定して弱い、という状態

**これは「雑多な思念から湧いた弱い妖怪」とは別物。**

| | 核 | 存在 |
|---|---|---|
| 雑多な思念から湧いたもの | 弱い・曖昧 | **不安定。すぐ霧散する** |
| **弱いと定められた有名妖怪** | **強固** | **安定している。長く在り続ける** |

**同じ低等級でも、堅牢さがまるで違う。** 座敷童子は弱いが、**何百年も居続ける**。湧いて消えるF級の雑魚とは、存在の質が違う。

そして**強くなれない**。定義に縛られているから。**妖怪が自分の何であるかを選べないという原則は、弱さの側にも等しく効く。**

#### 知名度は、定義を補強する方向にしか働かない

**ここが効いている。**

**有名になれば強くなる、ではない。** **知名度は蓄積の材料にはなるが、その蓄積は役割の定義を濃くする方向へ働く。**

> **弱い妖怪として知られているなら、弱い妖怪として安定する。**

**餓鬼はよく知られている。** それでも「飢えた弱い存在」として語られ続ける限り、**語られるほど、飢えた弱い存在としての固まりが強くなるだけ。**

**「弱いこと」「飢えていること」「逃げること」「脅かすだけであること」が名前・役割・念に含まれている妖怪は、定義を超えて高位化しない。**

**[[char:nostradamus]] の「ノストラダムスに知名度勝てるの？」の、裏側にある話。** **量が足りていても、中身が上を向いていなければ上がらない。**

### 糧もまた思念

妖怪は**思念や感情を糧にしている**。

- **基本的には、生きているだけで自然に補給される**。世界に思念が満ちている以上、ただ在るだけで足りる
- ただし例外がある

### 「そう定められた」思念は、そのとおりに振る舞う

**「人喰い妖怪！」と定められた思念は、人を食う。**

自然補給で足りるはずなのに人を食うのは、**そう想われて生まれたから**。妖怪は自分の性質を選んでいない。**人間がそう想った形に、そのとおりなってしまう。**

> **これが核の根底** → [[concept:core-layer]]

### 討たれ方も、性質になる

**「どう倒されたか」が伝承として語られると、それが妖怪の像に書き込まれる。**

| | |
|---|---|
| **ヤマタノオロチ** | **酒に弱い** |
| **茨木童子** | **片腕がない** |

**倒されたという事実そのものが、次に湧くときの定義の一部になっている。**

理屈は「人喰い妖怪！」と同じ。**人間が想った形に、そのとおりなってしまう**以上、「酒で酔わされて討たれたもの」と想われれば、**酒に弱いものとして在る**ことになる。

**討伐は、その妖怪を有名にすると同時に、弱点を刻む。** 思念を集めて強くする方向にも働くが、**同時に「どう破られたか」を定義に加える。**

> **弱点は最初からあったのではなく、破られた記録が弱点になった。**

**そしてこれは、個体名のものにも種族名のものにも起きる。** 名前を持った一体にも、鬼や天狗のような種族そのものにも、討たれ方は書き込まれうる。

#### ただし条件は厳しい

**書き込まれるには、概ねの人が意見を一致させ、それを長年保持しなければならない。**

> **今日の鬼は剣で倒した。一年後の鬼は炎で倒した。**
> **こんなことをやっていたら、弱点になりようがない。**

**これは核が強固になる条件そのもの**（上記「揃っているほど、そして古いほど強い」）。**方向性の一致と、歴史の長さ。** 討たれ方が性質になるのも、まったく同じ二条件を満たしたときだけ。

**だから一回の討伐では何も起きない。** どれだけ大きく報じられても、次が違うやり方なら像は動かない。

**そして弱点は狙って作れない。** 「あいつは酒に弱い」と広めて信じさせたところで、**一時の情報操作では届かない。** 何十年、何百年にわたって、大勢が同じ形で想い続けて初めて刻まれる。

**この制約が効いている。** 討たれ方が性質になるという仕組みは、放っておけば「情報を操作すれば妖怪を弱くできる」に直結するが、**思念が本来持っている遅さが、それを封じている。**

ヤマタノオロチが酒に弱いのは、**何百年も同じ話が語られ続けたから。**

### 古さ×知名度

**厚みは掛け算で決まる。**

- **知名度が高くても、歴史が浅ければ弱い**
- **歴史があっても、知名度が低ければ弱い**

**片方だけでは伸びない。** [[char:nostradamus]] は歴史のある名が短期に爆発した例で、[[char:hanako-san]] は数十年かけて両方を積んだ例。**どちらも片側だけでは届かなかった。**

**そして掛け算の結果がそのまま強さになるわけでもない。** **上限は伝承が決める** → [[concept:grades]]

### 名前は、個体を保つもの

**名前を与えられた妖怪は、長期間その個体として持続しやすい。**

**そして放置すると、時間をかけて薄まっていく。**

#### 外殻への書き込み口は二つある

**思念も外殻に影響する。そして命名は、外殻にそのまま刻む。**

| | 書き方 | 持ち |
|---|---|---|
| **思念** | **多数から、じわじわ、途切れずに** | **書かれ続けるので強い** |
| **命名** | **一点から、直接、即座に刻む** | **支えが無いと埋もれる** |

**どちらも「名前がつく理由」として十分。** 誰かに名付けられても、大勢にそう呼ばれても、名前は成立する。

#### 命名が消えるのは、削除ではなく埋没

**外殻は常に変わり続けている**（→ [[concept:core-layer]]）。経験でも、外的要因でも、人々の後付けの思念でも。

**そして刻まれた名前は、その流れの中に置かれている。**

**周りに知られていない名前は、外殻の変容に巻き込まれて、いつのまにか希釈して消える。** 誰かが消したのではない。**上書きされ続ける中で、支えの無い部分から埋もれていく。**

**ミケが50年で薄まったのはこれ。** 刻んだのは一人で、その一人が死んだ。**書き足す者がいなくなった。**

#### 知られていれば、そのまま残る

**もとから「玉藻前！！」とド級に有名なら、名前はそのまま残る**（→ [[char:tamamo-no-mae]]）。

**大勢が呼び続けているので、思念の側から絶えず書き直されている。** 封印されて何百年経っても薄まらないのはそのため。

**支えているのは契約者ではなく、知られていること。**

#### 名前は、間違えられて上書きされることがある

**違う名前と勘違いされたら、いつのまにかそれが自分の名前になったりもする。**

**外殻は「実際にどうか」ではなく「どう想われているか」で決まる。** 名前も同じ。**正しさは関係ない。揃って長く保たれたほうが本物になる。**

**これは討たれ方が性質になるのと同じ理屈**（下記）。**概ねの人が意見を一致させ、それを長年保持すれば、そちらが定着する。**

#### 消えるのではなく、種族に戻る

**例。**

> **猫又の一体が、ある退魔師に調伏契約され、「ミケ」と名付けられた。**
> **その後、飼い主が死んで野生に戻った。**
> **50年ほどで、ミケという名前も、自分の特徴も希釈して、「猫又妖怪A」になった。**

**死んでいない。生きている。**

**失われたのは個体性のほう。** 名前が薄れ、その個体を個体たらしめていた特徴が薄れ、**誰でもない猫又に戻った。**

#### 名乗ることも、刻む行為

**共存のトラブルの原因に「冗談のつもりで名乗った」がある** → [[concept:cooperation-policy]]

**契約すると相手の情報が外殻に刻まれる**（→ [[concept:core-layer]]）。**名乗りはその一番手軽な形。**

**だから収め方も、呼び方の修正で足りることがある。** 距離の取り直し、供物の再設定、役割の確認、**呼び方の修正**、立ち入り範囲の調整。**刻まれたものを書き直せば収まる。**

**名前は、こちらが与えるだけのものではない。渡してしまうこともある。**

#### 名前は、境遇から生じる

**「名前を持たない」は、持てないという性質ではない。** **そういう境遇に置かれたことがない、というだけ。**

**[[event:hyakki-yako-attempt]] の主導者がその例。** A級の死神でありながら個体名を持たないが、**失ったのではなく、一度も得ていない。** 名がつくような目に遭わないまま、死神として生きてきた。

**そして境遇が変われば、つく。** 現在この死神は妖怪向けのアイドルとして各地を回っており、**見られ、語られ、大勢にとっての特定の一体になっている。** 何十年かすれば、名の一つもつくと考えられる。

#### 種族名と個体名の境目は、固定ではない

**個体名を持つ妖怪と、種族名で呼ばれる妖怪の区別**（上記）は、**生まれつきの分類ではない。**

> **行き来する。**

| | |
|---|---|
| **種族名 → 個体名** | 名付けられ、その個体として固定される |
| **個体名 → 種族名** | **支えるものが無くなり、数十年かけて薄まって戻る** |

**目安が50年程度。** 妖怪の時間感覚からすれば、そう長くもない。

#### 核は残り、外殻の一番外側が剥がれる

**猫又であることは変わらない。** 変わったのは名前と、その個体としての特徴。

**核は変わりにくく、外殻は変わる**（→ [[concept:core-layer]]）。**個体名と個体の特徴は、外殻の一番外側にある。** 支えが無くなれば、そこから順に種族の型へ吸収されていく。

**残るのは、種族としての核。**

### 伝承のばらつきは、複数いることの痕跡

**河童も天狗も座敷童も、地域ごとに名前が違い、姿が違い、条件が違う。**

**この世界では、そのばらつき自体が意味を持つ。**

> **語られ方が土地ごとにずれているのは、そこに別々の個体がいるから。**

**各地の河童は、同じ一体の分身ではない。それぞれ別の河童。** 同じ型から湧いた別の器なので、土地ごとに違う経験を積み、違う外殻を持ち、違う語られ方をする。**ずれは、複数いることの痕跡。**

**そして例外が一つだけある。** [[char:hanako-san]] は**全国で細部まで一致していて、ずれが無い。** 他にこの形をした妖怪はいない。

**ばらついていないことが、一体しかいないことの証拠になっている。**

### 種族名のものは、個体を倒しても戻ってくる

**ノーマルなA級の鬼を倒しても、別の鬼が出るだけ。**

鬼という**種族そのものへの思念**が残っている限り、そこから湧き続ける（→ [[concept:youkai-species]]）。倒したのは一つの器であって、**器を作っている型は減っていない。**

**ただし、型が無傷というわけではない。** 上の「討たれ方が性質になる」は**種族にも起きる**。個体をいくら倒しても湧き続ける一方で、**その倒し方が語り継がれれば、種族の像そのものに書き込まれる。**

| | 個体を倒すと | 像は |
|---|---|---|
| **種族名のもの**（鬼、天狗） | **別の個体が出る** | **書き換わりうる** |
| **個体名のもの**（ヤマタノオロチ、茨木童子） | | **書き換わりうる** |

**数は減らないが、性質は変わる。** 種族への討伐は根絶にならないかわりに、**繰り返されるほど、その種族が何であるかを定義していく。**

### 死

**思念が足りなくなったり、綻んだりすると、衰弱して弱くなり、いずれ消える。**

老いて死ぬのではない。**支えを失って散る。**

- 分かりやすいのは**想われなくなった時**
- ただし**強い妖怪の場合は、段階的に等級が落ちる程度**で済む。急に消えたりはしない

生と死が、人間側の記憶と関心に直結している。

## 社会との関わり

**人間が想うことが、妖怪を生み、強くし、性質を定め、そして忘れることが妖怪を殺す。**

### 循環は自然現象

この循環は**問題ではなく、水や雨の循環と同じ自然のもの**として理解されている。**みんな知っている。**

思念が溜まり、妖怪が湧き、討たれたり忘れられたりして消え、また溜まる。雨が降って川になり海に出てまた降るのと同じ。**止めるものでも、隠すものでもない。**

### だから誘導する

自然現象である以上、**流れをある程度誘導する技術は普通にある**。

**わざと妖怪が湧きやすいポイントを作っている。** これを**逃しポイント**と呼ぶ → [[concept:release-points]]

有名なところの一つが**恐山** → [[loc:osorezan]]。同じような逃しポイントは日本にいくつもある。

**治水と同じ発想。** 溜まるものを止められないなら、溜まってよい場所を作って導く。この世界の妖怪対策の根本は、討伐ではなく**土木**にある。

### 思念の量には桁がある

**思念は、規模が桁違いでなければ意味を持たない。**

そして**思念そのものは尽きない。** 信仰も、邪念も、恐れも、願いも、**人が生きている限り無限に湧き出てくる。地球全土のすべての人間がそう。** 汲み上げても、討伐しても、源が細ることはない（→ [[concept:overseas]]）。

分かりやすい例が [[concept:taimashi-school]]。学校の土地神（B級以上）は生徒から感謝と敬いを受けているが、**生徒の思念そのものは、数が数なのでそんなに足しにはならない**。数千人程度では、高位の妖怪を支える量にまるで届かない。

一方 [[concept:kami]] の神々は、**何百年にわたって何百万人**に想われている。同じ「敬い」でも、桁が三つも四つも違う。

**だから思念で妖怪を養おうとするなら、必要なのは信仰の規模。** 一つの学校、一つの町、一つの集団では足りない。この非対称が、神と並の妖怪を隔てている。

### 現代の思念

**生まれるが弱い。** ネット、創作、流行から湧く妖怪は、方向性が揃っていても**歴史が浅い**ので強固になりにくい。

> **ただしそれは核の話。** 現代の思念は、**既にいる妖怪の外殻なら普通に動かす**（→ [[concept:core-layer]]）。うっすらアニメ風の女性系の妖怪が最近増えているのは、これ。**新しく生まれているのではなく、外側が塗り替わっている。**

ごく稀に強いものも生まれるが**例外中の例外**。既知の二体と、届くための条件は上記「『流行ったから強くなる』は、明確に否定されている」に移した。

残る問い:

- 弱いとはどの程度か。**現代生まれの妖怪はC級以上に届くことがあるのか**
- **物のほうはどうなのか。** 村正のように衰えた例はあるが、**現代の思念から新しい遺物が生まれることはあるのか** → [[concept:relics]]
- 都市伝説から湧いた妖怪は今どれくらいいるのか
- **創作と分かっているものからも生まれるのか。** 信じられていることが条件か
- **拡散速度は歴史の長さを補えない**（確定）。では**補えるものは規模と定着だけなのか**。他にも抜け道はあるのか
- **1999年前後から、情報文明由来の怪異が国際超常社会で本格的に認識されるようになった**。**それ以前は、この種のものが単に少なかったのか、見えていなかっただけなのか**

### 思念の出どころ

- **誰の思念か。** 人間だけか、動物や妖怪の思念も混ざるのか
- 生きている人間の思念か、死者のものも含むのか
- **人が少ない土地には妖怪が少ないのか**（過疎地と都市部でどう違うか）
- 有名な妖怪を討伐しても、思念が残っていればまた湧くのではないか

### 定められた性質

- 「人喰い」以外に、どういう性質が「定められる」のか
- **討たれ方が性質になる**（確定）。条件も判明済み（一致と長年の保持）。残るのは:
  - **どれくらいの年月が要るのか。** 何十年か、何百年か
  - **一度書き込まれた性質は消えるのか。** 語られ方が変われば戻るのか
- **定められた性質には、外殻で逆らえる**（確定 → [[concept:core-layer]]）。核はそのままに、外面が変わって別の振る舞いをする個体は普通にいる
  - **では核の要求はどこへ行くのか。** 消えるのか、抱えたままなのか
- 定義が変われば妖怪も変わるのか（伝承の解釈が変わったら、その妖怪も変わるのか）
- **これは責任の問題に直結する。** そう想われたから人を食う妖怪に、罪はあるのか → [[concept:legal-status]]

### 死と復活

- 種族名のものは**別個体が湧く**（確定）。では**個体名のものが再び湧くことはあるのか**
- **薄まって種族に戻った個体を、もう一度名付け直したらどうなるのか。** 元のミケが戻るのか、別の個体になるのか
- **薄まる速さは何で決まるのか。** 50年は猫又の目安。**もっと厚みのある妖怪なら、もっと長く保つのか**
  - 湧くなら、それは同一個体か、別個体か
- 「段階的に等級が落ちる」とは、どれくらいの速さか
- **人為的に思念を供給して妖怪を強くできるのか**（信仰、宣伝、儀式）
- 逆に、思念を断つ攻撃手段はあるのか
