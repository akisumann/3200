## 概要

**妖怪の元になるもの。** 妖怪は思念を元にした現象としての個体である（→ [[concept:youkai]]）が、その「思念」がどう振る舞うかを定めたのがこの項目。

**この世界の妖怪に関する仕組みは、ほぼすべてここから導かれる。**

## 仕組み

### 表面張力

**思念には表面張力のようなものがある。** 似た思念は勝手にくっついて形になる。**その形になったものが妖怪。**

意図して作られるのでも、誰かが呼び出すのでもない。思念が溜まれば**自然に湧く**。

### 思念そのものは、とても弱い

**大前提。思念だけでは相当弱いエネルギーであり、具体的に何かが起きたりはしない。**

大勢が誰かを「化け物だ」と想ったところで、**その人の肉体がどうこうなることはない**。思念は妖怪の材料ではあるが、それ自体は物を動かす力を持たない。

**この制約がなければ、この世界は成立しない。** 思念が強い力を持つなら、想うだけで人を殺せることになり、公然と妖怪が知られている社会など維持できない。**思念は溜まって形になって初めて力になる。**

### 揃っているほど、そして古いほど強い

くっつき方の強さは、二つの要素で決まる。

| 要素 | |
|---|---|
| **方向性の一致** | 思念がどれだけ同じ形・同じ向きに揃っているか |
| **歴史の長さ** | **長年同じことを思われ続けてきたか** |

| 思念の状態 | 結合 | 結果 |
|---|---|---|
| **雑多** | 弱い | **霧散しやすい**。生まれても長く保たない |
| **方向性が揃っている** | 強い | **強固**になる |
| **揃っていて、かつ古い** | 最も強い | 高等級になりうる |

**そしてこの差は、生まれた時点での出力差になる。** 後から鍛えて追いつくのではなく、**どういう思念から生まれたかで初期値が決まる**。

**時間が要る。** 一時の流行がどれだけ大勢を巻き込んでも、それだけではA級には届かない。**A級になるには、長年にわたって同じ像を想われ続けた歴史が要る。**

### だから有名な妖怪は強い

これが**知名度の高い妖怪と、雑多な妖怪の差**。

大勢の人間が、同じ形の、同じ方向を向いた思念を抱いている妖怪 — つまり**よく知られ、姿かたちや性質の像が共有されている妖怪**は、結合が強く、強固で、生まれつき出力が高い。

鬼が鬼というだけでB級が堅く、天狗がC級以上なのは、これが理由 → [[concept:grades]]

**妖怪の強さは、どれだけ多くの人間が、どれだけ揃った形で想っているかで決まる。**

### ただし「有名＝強い」ではない

**思念の一致と歴史が決めるのは、核の強固さ — つまり「その通りのものになる度合い」。**

**どれくらい強いかは、思念が何を定めているかで決まる。**

だから例外がある。**弱いと伝承で語られる有名妖怪は、その伝承に沿って弱い。**

| | |
|---|---|
| **座敷童子** | 害をなさない。福をもたらす |
| **餓鬼** | 飢え、苦しみ、惨めである |
| **まっくろくろすけ** | 小さく、無害 |

どれも広く知られ、像が共有され、思念は十分に揃っている。**それでも弱い。弱いものとして定められているから。**

「人喰い妖怪！」と定められた思念が人を食うのと、同じ理屈。**定義が何を言っているかが、そのまま出力になる。**

### 安定して弱い、という状態

**これは「雑多な思念から湧いた弱い妖怪」とは別物。**

| | 核 | 存在 |
|---|---|---|
| 雑多な思念から湧いたもの | 弱い・曖昧 | **不安定。すぐ霧散する** |
| **弱いと定められた有名妖怪** | **強固** | **安定している。長く在り続ける** |

**同じ低等級でも、堅牢さがまるで違う。** 座敷童子は弱いが、**何百年も居続ける**。湧いて消えるF級の雑魚とは、存在の質が違う。

そして**強くなれない**。定義に縛られているから。**妖怪が自分の何であるかを選べないという原則は、弱さの側にも等しく効く。**

### 糧もまた思念

妖怪は**思念や感情を糧にしている**。

- **基本的には、生きているだけで自然に補給される**。世界に思念が満ちている以上、ただ在るだけで足りる
- ただし例外がある

### 「そう定められた」思念は、そのとおりに振る舞う

**「人喰い妖怪！」と定められた思念は、人を食う。**

自然補給で足りるはずなのに人を食うのは、**そう想われて生まれたから**。妖怪は自分の性質を選んでいない。**人間がそう想った形に、そのとおりなってしまう。**

> **これが核の根底** → [[concept:core-layer]]

### 討たれ方も、性質になる

**「どう倒されたか」が伝承として語られると、それが妖怪の像に書き込まれる。**

| | |
|---|---|
| **ヤマタノオロチ** | **酒に弱い** |
| **茨木童子** | **片腕がない** |

**倒されたという事実そのものが、次に湧くときの定義の一部になっている。**

理屈は「人喰い妖怪！」と同じ。**人間が想った形に、そのとおりなってしまう**以上、「酒で酔わされて討たれたもの」と想われれば、**酒に弱いものとして在る**ことになる。

**討伐は、その妖怪を有名にすると同時に、弱点を刻む。** 思念を集めて強くする方向にも働くが、**同時に「どう破られたか」を定義に加える。**

> **弱点は最初からあったのではなく、破られた記録が弱点になった。**

**そしてこれは、個体名のものにも種族名のものにも起きる。** 名前を持った一体にも、鬼や天狗のような種族そのものにも、討たれ方は書き込まれうる。

#### ただし条件は厳しい

**書き込まれるには、概ねの人が意見を一致させ、それを長年保持しなければならない。**

> **今日の鬼は剣で倒した。一年後の鬼は炎で倒した。**
> **こんなことをやっていたら、弱点になりようがない。**

**これは核が強固になる条件そのもの**（上記「揃っているほど、そして古いほど強い」）。**方向性の一致と、歴史の長さ。** 討たれ方が性質になるのも、まったく同じ二条件を満たしたときだけ。

**だから一回の討伐では何も起きない。** どれだけ大きく報じられても、次が違うやり方なら像は動かない。

**そして弱点は狙って作れない。** 「あいつは酒に弱い」と広めて信じさせたところで、**一時の情報操作では届かない。** 何十年、何百年にわたって、大勢が同じ形で想い続けて初めて刻まれる。

**この制約が効いている。** 討たれ方が性質になるという仕組みは、放っておけば「情報を操作すれば妖怪を弱くできる」に直結するが、**思念が本来持っている遅さが、それを封じている。**

ヤマタノオロチが酒に弱いのは、**何百年も同じ話が語られ続けたから。**

### 種族名のものは、個体を倒しても戻ってくる

**ノーマルなA級の鬼を倒しても、別の鬼が出るだけ。**

鬼という**種族そのものへの思念**が残っている限り、そこから湧き続ける（→ [[concept:youkai-species]]）。倒したのは一つの器であって、**器を作っている型は減っていない。**

**ただし、型が無傷というわけではない。** 上の「討たれ方が性質になる」は**種族にも起きる**。個体をいくら倒しても湧き続ける一方で、**その倒し方が語り継がれれば、種族の像そのものに書き込まれる。**

| | 個体を倒すと | 像は |
|---|---|---|
| **種族名のもの**（鬼、天狗） | **別の個体が出る** | **書き換わりうる** |
| **個体名のもの**（ヤマタノオロチ、茨木童子） | | **書き換わりうる** |

**数は減らないが、性質は変わる。** 種族への討伐は根絶にならないかわりに、**繰り返されるほど、その種族が何であるかを定義していく。**

### 死

**思念が足りなくなったり、綻んだりすると、衰弱して弱くなり、いずれ消える。**

老いて死ぬのではない。**支えを失って散る。**

- 分かりやすいのは**想われなくなった時**
- ただし**強い妖怪の場合は、段階的に等級が落ちる程度**で済む。急に消えたりはしない

生と死が、人間側の記憶と関心に直結している。

## 社会との関わり

**人間が想うことが、妖怪を生み、強くし、性質を定め、そして忘れることが妖怪を殺す。**

### 循環は自然現象

この循環は**問題ではなく、水や雨の循環と同じ自然のもの**として理解されている。**みんな知っている。**

思念が溜まり、妖怪が湧き、討たれたり忘れられたりして消え、また溜まる。雨が降って川になり海に出てまた降るのと同じ。**止めるものでも、隠すものでもない。**

### だから誘導する

自然現象である以上、**流れをある程度誘導する技術は普通にある**。

**わざと妖怪が湧きやすいポイントを作っている。** これを**逃しポイント**と呼ぶ → [[concept:release-points]]

有名なところの一つが**恐山** → [[loc:osorezan]]。同じような逃しポイントは日本にいくつもある。

**治水と同じ発想。** 溜まるものを止められないなら、溜まってよい場所を作って導く。この世界の妖怪対策の根本は、討伐ではなく**土木**にある。

### 思念の量には桁がある

**思念は、規模が桁違いでなければ意味を持たない。**

そして**思念そのものは尽きない。** 信仰も、邪念も、恐れも、願いも、**人が生きている限り無限に湧き出てくる。地球全土のすべての人間がそう。** 汲み上げても、討伐しても、源が細ることはない（→ [[concept:overseas]]）。

分かりやすい例が [[concept:taimashi-school]]。学校の土地神（B級以上）は生徒から感謝と敬いを受けているが、**生徒の思念そのものは、数が数なのでそんなに足しにはならない**。数千人程度では、高位の妖怪を支える量にまるで届かない。

一方 [[concept:kami]] の神々は、**何百年にわたって何百万人**に想われている。同じ「敬い」でも、桁が三つも四つも違う。

**だから思念で妖怪を養おうとするなら、必要なのは信仰の規模。** 一つの学校、一つの町、一つの集団では足りない。この非対称が、神と並の妖怪を隔てている。

## 未決

### 現代の思念

**生まれるが弱い。** ネット、創作、流行から湧く妖怪は、方向性が揃っていても**歴史が浅い**ので強固になりにくい。

ごく稀に強いものも生まれるが**例外中の例外**。既知の例:

| | 等級 | |
|---|---|---|
| [[char:nostradamus]] | **A級** | **これ級の知名度がないとA級にはなれない** |
| [[char:bug]] | **特殊A級** | 「特殊A」は説明が難しいため保留 |

残る問い:

- 弱いとはどの程度か。**現代生まれの妖怪はC級以上に届くことがあるのか**
- 都市伝説から湧いた妖怪は今どれくらいいるのか
- **創作と分かっているものからも生まれるのか。** 信じられていることが条件か
- ネットの拡散速度は、思念の「歴史の長さ」を補えるのか。**それとも時間だけは短縮できないのか**

### 思念の出どころ

- **誰の思念か。** 人間だけか、動物や妖怪の思念も混ざるのか
- 生きている人間の思念か、死者のものも含むのか
- **人が少ない土地には妖怪が少ないのか**（過疎地と都市部でどう違うか）
- 有名な妖怪を討伐しても、思念が残っていればまた湧くのではないか

### 定められた性質

- 「人喰い」以外に、どういう性質が「定められる」のか
- **討たれ方が性質になる**（確定）。条件も判明済み（一致と長年の保持）。残るのは:
  - **どれくらいの年月が要るのか。** 何十年か、何百年か
  - **一度書き込まれた性質は消えるのか。** 語られ方が変われば戻るのか
- **定められた性質に逆らえるのか。** 人を食いたくない人喰い妖怪はありうるのか
  - ありうるなら、それは飢えることを意味するのか
- 定義が変われば妖怪も変わるのか（伝承の解釈が変わったら、その妖怪も変わるのか）
- **これは責任の問題に直結する。** そう想われたから人を食う妖怪に、罪はあるのか → [[concept:legal-status]]

### 死と復活

- 種族名のものは**別個体が湧く**（確定）。では**個体名のものが再び湧くことはあるのか**
  - 湧くなら、それは同一個体か、別個体か
- 「段階的に等級が落ちる」とは、どれくらいの速さか
- **人為的に思念を供給して妖怪を強くできるのか**（信仰、宣伝、儀式）
- 逆に、思念を断つ攻撃手段はあるのか

- [[concept:jugu]] は思念に働きかけているのか
