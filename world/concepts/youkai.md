## 概要

**思念を元にした、現象としての個体。** それが妖怪である。

有史以来ずっと、世界中に、相当数が存在する。存在は公然と知られている。ただし**基本的に一般人には見えない**。そして**大部分は知性が低い**。

→ 前提は [premise.md](../premise.md)

## 仕組み

### 定義

妖怪とは**思念を元にした現象**であり、かつ**個体**である。

- **思念が元** — 由来は思念にある。物質から生じるのでも、生物として生まれるのでもない
- **現象** — 実体ある生き物ではなく、起きているもの。「現象・災害・土地・物のように扱われる個体がいる」のは、妖怪が本来そういうものだから
- **個体** — にもかかわらず、ひとまとまりの個として区別できる。ここが単なる現象と違う

現象でありながら個体であること。この二重性が、妖怪という語が現象から土地までを一語でくくれる理由であり、同時に人間の法が扱いあぐねる理由でもある。

### 共通構造

すべての妖怪に共通して存在する。

- **核**（英語圏では**コア**）
- **外殻**（英語圏では**レイヤー**）

→ [[concept:core-layer]]

**英語圏に対応する語がある**ということは、妖怪が世界共通の現象として認識され、国境を越えて研究・共有される用語体系があることを意味する。

### 可視性

**基本的に一般人には見えない。見えるのは、力を使える人間。**

存在が公然と知られていることと矛盾しない。誰もが「いる」と知っているが、誰もが「見える」わけではない。

**可視性は力に直結している。** 素質でも訓練でも道具でもなく、[[concept:powers]] を扱えるかどうかがそのまま境目になる。力を使えれば見え、使えなければ見えない。

### 知性

**大部分は知性が低い。** 人間と話が通じる個体は、その中の一部にすぎない。

### 気質

**一枚岩ではない。** 各個体が別のことを軸に生きており、種としてまとまった意思を持たない → [[concept:youkai-nature]]

### 生と死

すべて思念に規定される → [[concept:shinen]]

| | |
|---|---|
| **発生** | 思念が溜まると**自然に湧く**。似た思念が表面張力のようにくっついて形になる |
| **強さ** | 思念の**方向性が揃っているほど強固**。だから有名な妖怪ほど強い。生まれた時点で出力差がつく |
| **糧** | 思念や感情。**基本的には生きているだけで自然補給される** |
| **例外** | 「人喰い妖怪！」と定められた思念は人を食う。**そう想われて生まれたから、そう振る舞う** |
| **死** | 思念が足りなくなる・綻ぶと衰弱し、いずれ消える。**想われなくなった時**が分かりやすい。強い妖怪なら段階的に等級が落ちる程度で済む |

### 人間から妖怪へ

**人間が妖怪になることは割とある。** ただし**自然発生的にはほぼなく、何かしらの要因が必要**。

判明している要因:

- **死に方・強い情念** — 無念の死や強い恨みを残して死ぬ
- **妖怪の関与** — 食われる、取り憑かれる、命を引き換えにするなど
- **儀式や呪具による人為** — 手段は存在するが、**基本的にあまりない**。この世界の主要な現象ではない

**周囲からの思念は要因にならない。** 大勢から「あれは化け物だ」と想われ続けても、**その程度では人間という肉体がどうこうなることはない**。思念だけでは相当弱いエネルギーであり、具体的に何かが起きたりはしない → [[concept:shinen]]

ただし、そうなった時に**その人に似た新生の妖怪が出ることはあるかもしれない**。**その人が妖怪になるのではなく、その人の像から別の妖怪が湧く。** ただしあやふやで弱いものにしかならない。

**法的には死亡扱いになる。** ただし**すぐに行政手続きを行えば、大抵は問題ない** → [[concept:legal-status]]

### 等級

**妖怪にも等級がつく。人や呪具と同じ尺度、単純火力指数も同じ、個体数も人間と同じ** → [[concept:grades]]

**種族だけで等級の目安が決まる場合がある。** 鬼は鬼であるというだけでB級は堅く、天狗はC級以上。その理由は [[concept:core-layer]] と深く関係する（保留）。

**下位等級は数が定まらない。** E級・F級は無限に湧き、勝手に消え、討伐や警邏で増減する。F級は「霊が見える人が足で踏めば死ぬ」ほど弱くて不安定で、蔵にゴキブリのように溜まることもある。**害虫に近い扱い** → [[concept:jugu]]

約100年前に国際標準として定められた制度なので、それより古い妖怪の中には受け付けないものもいる。ただし人間と交流のある妖怪は、たいてい受け入れている。

## 未決

### 可視性

見えるのは力を使える人間、という点は確定。その周辺。

- **力を使えない人間には、まったく分からないのか。** 気配・音・寒気のような形でも察知できないのか
- 妖怪の側が姿を見せることはできるのか。**できるなら、見せている妖怪もいるのか**
- 機械で捉えられるのか（写真、センサー、計測器）
  - **捉えられるなら、それは産業になっているはず** → [[concept:powers]]
- 見え方に段階はあるのか（力の強さで、見える精度が変わるのか）
- **手続きを経て人間社会で暮らす妖怪は、どう折り合っているのか。** 大半の人間から見えない状態で社会生活を送ることになる

### 思念

仕組みは判明済み → [[concept:shinen]]。残る問いはそちらに集約。

### 人から妖怪になる場合

要因も法的扱いも判明済み。残る問い。

- 三つの要因のうち、**どれが多いのか**（人為的なものはあまりない、とのこと）
- 本人の意思は関係するのか。**望んでなれるのか、望まずになってしまうのか**
- なった個体は記憶や人格を保つのか。**元の人物と同一と言えるのか**
  - 保つなら、行政手続きで社会に戻る際に「同じ人」として扱われるのか
- 等級はどうなるのか。**元の人物の知名度が効くのか**
- 元に戻れるのか
- 「割とある」とは年に何件くらいか。**ニュースになるのか、統計が取られているのか**
- E級妖怪の例に挙がったゾンビは、これに当たるのか

### 知性

- どの程度を「低い」と言っているのか。動物並みか、それ以下か
- 知性のある個体は全体のどれくらいか
- 生まれつきか、育つのか。**長く生きると知性を得るのか**
- 知性の有無は誰がどう判定するのか（法的地位に直結する）

### 種類

**伝承の妖怪はそのままいる**（鬼、天狗は確定）。

- 他にどの種族がいるのか。伝承にあるものは概ね実在するのか
- **種族名で呼ばれる妖怪と、個体名を持つ妖怪の境目はどこか**
- 新種は生まれるのか。**現代の思念から生まれた新しい種族はいるのか**
- 神社に祀られている神と妖怪はどう違うのか → [[faction:shrines]]
- 海外の妖怪（西洋の魔物など）とは別種なのか、同じものの地域差なのか

### 生態

- **混血はあるか。** 人と妖怪の間に子は生まれるか
- 妖怪同士で増えるのか。**それとも思念から湧く以外に増え方はないのか**
- どこに棲むのか。**思念の濃い場所に集まるのか**
- 眠るのか、休むのか。日常はあるのか
