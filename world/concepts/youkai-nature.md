## 概要

**妖怪は一枚岩ではない。** 各々が別のことを軸として生きている。

小国を滅ぼしうるA級妖怪が国内に18体いながら社会が成立しているのは、抑え込まれているからでも、力が誇張されているからでもない。**妖怪の側にまとまった意思がなく、かつ人間社会を侮っていないから。**

## 仕組み

### 弱肉強食の理が、正しく機能している

**妖怪の世界では、強い者が上に立つという筋が、そのまま通っている。**

人間社会のように、弱い者を守る仕組みが上から被せられているわけではない。**強弱がそのまま関係の形になる。**

**これが妖怪の側の多くを説明する。**

- **縄張りを持つ**（→ [[concept:youkai-land]]）。持てる者が持ち、他は入らない
- **土地神が土地を統べる**（→ [[concept:land-god]]）。統べられる者が統べている
- **力で調伏されたら従う**（→ [[concept:legal-status]]）。人間が一方的に押し付けているのではなく、**負けた側が従うのは向こうの筋でもある**

**だから式神が成立する。** 人間の理屈で無理やり縛っているのではなく、**勝ったから従わせられる**という点で、双方の理が噛み合っている。

**そして「割に合わない」という判断も、この理の上にある**（下記「若手と老練」）。老練な個体が人間社会に手を出さないのは、道徳ではなく**強弱の計算**。

#### 人間も、同じ土俵で見られている

**強い相手は強いと思う。それだけ。**

種族で括って侮ることはない。**強い人間は、強い者として遇される。**

だから「人間社会を軍隊アリのように見ている」という見方（下記）は、**集団としての人間社会**についての話であって、**個々の人間を格下と見ているわけではない**。数と組織を脅威と見る目と、目の前の一体を強いと認める目は、別に働いている。

**そしてこれは [[concept:grades]] の在り方と一致している。** 等級は人にも妖怪にも呪具にも同じ尺度で振られる。**制度がそう作られているだけでなく、妖怪の側の見方もそうなっている。**

### 一枚岩ではない

**各個体が別の軸で生きている。** 妖怪を一つの勢力として語ることはできない。

これは [[concept:legal-status]] で見た「感性や感覚が人間的ではない」ことと繋がっている。人間のように利害を共有し、共通の目的のもとに結束する、という発想がそもそも共有されていない。**妖怪は種でも社会でもなく、個体の集まり。**

### 三つの立ち位置

**妖怪の中には、穏健派・中立派・敵対派がある。**

人間に対してどう構えているかの区分。一枚岩ではない妖怪たちを、それでも大づかみに語るときの物差しになっている。

| | |
|---|---|
| **穏健派** | 人間と穏当に付き合う。**[[concept:taimashi-school]] の土地神は大抵ここ寄り** |
| **中立派** | どちらでもない |
| **敵対派** | 人間に敵対的。**普通に人を殺したり、政府と敵対したりする** |

前に挙げたA級妖怪へのインタビュー（下記）の個体は「**やや敵対寄りだが、おとなしいタイプ**」と評されていた。**立ち位置と、実際に暴れるかどうかは別**ということでもある。敵対寄りでも、割に合わないと判断すれば動かない。

### この区分は、核と外殻の両方から来る

**穏健派・中立派・敵対派は、生まれつきのものでも、後から形になったものでもある**（→ [[concept:core-layer]]）。

| | どちらか |
|---|---|
| **生態としてそうなっている** | **核。**そう定められて生まれた。変わらない |
| **考えが噛み合わない** | **外殻。**関わりの中で形になった。**変わりうる** |

**外から見て、どちらなのかは分からない。** 同じ敵対派でも、話が通じる相手と通じない相手がいる。

### 敵対派が敵対する理由

**二つある。どちらも「悪意」ではない。**

| 理由 | |
|---|---|
| **噛み合わなさ** | **人間と考えがどうしても噛み合わない。** 感性や感覚が人間的でないことの、最も鋭い形 |
| **生態** | **生態としてそうなっている。** そう定められて生まれたから、そう振る舞う |

二つ目が重い。**「人喰い妖怪！」と定められた思念は人を食う**（→ [[concept:shinen]]）。人を殺す妖怪の一部は、**選んでそうしているのではなく、そう想われて生まれたからそうなっている**。

**つまりこの世界の敵は、悪ではない。**

- 憎んでいるのでも、支配を企んでいるのでもない
- 一方は**話が通じない**（噛み合わない）
- もう一方は**そう在るしかない**（生態）

そして後者を作ったのは人間の思念である。**人を食う妖怪を人間が想って生み、その妖怪が人を食い、人間がそれを討つ。** この循環がこの世界の暴力の底にある。

**それでも殺される人間は死ぬ。** 理由が悪意でないことは、被害を減らさない。だから討伐は必要であり、[[concept:taimashi]] は必要とされ、それでも誰も悪くない。**この噛み合わなさこそが、この世界の摩擦の本体。**

### 若手と老練

年季によって、人間への態度がはっきり分かれる。

| | 人間の見方 | 結果 |
|---|---|---|
| **若手の妖怪** | **人の怖さを知らない** | はっちゃける。そして**すぐに討伐される** |
| **老練な妖怪** | **人類というものの強さを正しく把握している** | 暴れない |

**淘汰が働いている。** 人間を侮った妖怪は討伐されて残らない。長く生きている妖怪とは、**人間を侮らなかった妖怪**のこと。生き残りが慎重なのではなく、慎重だから生き残っている。

しかも妖怪の死は討伐だけではない。**想われなくなれば衰弱して消える** → [[concept:shinen]]。長く在り続けるには、人間に討たれず、かつ人間に忘れられないという二つの条件を満たす必要がある。**老練な妖怪とは、その両方を潜り抜けてきた個体**のこと。

### ただし一個体は侮る

老練な妖怪も、**人間の一個体に対しては侮る傾向がある**。

正しく評価しているのは「人類」であって「人間」ではない。**この非対称が、この世界の危うさの源**。妖怪は人間社会を恐れるが、目の前の一人を恐れはしない。

### あるA級妖怪の言葉

やや敵対寄りだが、おとなしいタイプのA級妖怪へのインタビューより。

> 人間のことを**アリ**だと思っている。人間社会のことは**統率された軍隊アリのようなもの**だと認識している。一定の警戒と防衛策を持ってあたらないと痛い目に遭う。だから暴れない。

一匹のアリは踏み潰せる。しかし軍隊アリの群れに不用意に手を出せば、こちらが食われる。**A級妖怪が暴れないのは、恐れているからではなく、割に合わないと計算しているから。**

> **これはあくまでその一個体の考えである。** 他のA級妖怪が同じように考えている保証はない。一枚岩ではないとは、そういうこと。

### 人間の法律では動いていない

**妖怪は、人間の法律や善悪を基準にしない。**

**協力妖怪であっても、人間社会全体へ善良に協力しているという意味ではない。** 協力するのは、**契約、縄張り、利益、信仰、食性、役割、面子、好奇心、自分なりの義理**によって。

**だから、合法な相手にも協力するし、犯罪者にも協力する。** 妖怪の側から見れば、**その区別は人間側の都合**にすぎない。

**普通に成立する理屈。**

> **「契約は守った」**
> **「人間同士の法律は知らない」**
> **「対価は受け取った」**
> **「縄張りは荒らしていない」**
> **「禁忌は踏んでいない」**
> **「そちらの役所の都合までは聞いていない」**

#### そして、隠すのに向いている

**監視カメラに映らない。人間の契約書を読まない。土地の抜け道を知っている。霊的な運搬経路を持つ。死体や呪物を処理できる。人間の証言体系に乗らない。**

**土地神や土着妖怪が関与すると、さらに見えなくなる。** **その行為が犯罪なのか、古い慣習なのか、地域祭祀なのか、契約履行なのか、縄張り管理なのか、外からは判別しづらい**（→ [[concept:taimashi]]）。

#### 単純化してはいけない

- **協力的だから安全**
- **国家協力妖怪だから必ず合法側**
- **犯罪者に協力したから完全な敵**

**どれも成立しない。** **妖怪は人間の合法・違法という区分より、自分の理、契約、縄張り、利益、禁忌を優先する。** その結果として、**合法側にも違法側にも協力する。**
