## 概要

**「退魔師」は職業名ではなく、分類名。** 力を使える人間は、**分類としては全員が退魔師**にあたる → [[concept:powers]]

つまり日本には約222万人の退魔師がいることになる。**しかしその大半は、退魔などしていない。**

## 仕組み

### 全員が退魔師。ただし戦うのはD級から

**基本的に、戦闘に出る退魔師はD級から。**

| 等級 | 実態 |
|---|---|
| **F級**（約200万人） | **「F級」とだけ言われる。別に退魔とかしていない** |
| E級（約20万人） | 術は使えるが、戦闘に出るのは基本的でない |
| **D級以上**（約22,218人） | **戦闘用退魔師** |

**D級退魔師＝戦闘用退魔師。** 「明確に強めな資格はD級から」というのは、そういう意味だった。D級は「真っ当な戦闘訓練などをして相当の水準になった」という標識であり、[[concept:grades]] のD級（バトル漫画くらいの水準の技や動きが可能）と対応する。

**実際に戦う退魔師は、約2万2千人。** 人口1万人あたり1.8人 — 消防吏員（約16万人）や警察官（約26万人）どころか、歯科医師よりも少ない。**世間に「普通にいる」職業でありながら、実数はかなりの少数精鋭。**

### 「F級」という呼ばれ方

F級の人間は、**退魔師ではあるが、基本的には「F級」とだけ言われる。**

職業ではなく**属性**として扱われている。「あの人F級だよ」で通じ、それ以上の意味を持たない。妖怪が見えるというだけの、ありふれた性質。

**ただしF級の全員がそこで確定しているわけではない**（→ [[concept:grades]]）。**才能はあるが、まだ技を出せていない最初期の段階**もF級に数えられる。大半はそのまま「F級」で一生を過ごすが、**その中に、まだ出ていないだけの人が混ざっている。**

だからこそ彼らは病院にも企業にも行政にも散らばっていて、社会の検知網として機能している → [[concept:daily-life]]

**日本のA級18人のうち6人が民間の退魔師** → [[concept:grades]]。民間でありながら、国家（霊務省）や伝統（神社・旧家）と頂点で並んでいる。

### ただしE級が劣るわけではない

**E級が何もできないということではない。**

> **A級が大企業の社長だとするなら、E級は町工場のベテラン職人のようなもの。**
> **金（出力）の動きが違うだけで、ベテランはベテランであり、A級はE級を蔑んだりしない。**

**ここがこの世界の等級観の要。** 等級は動かす力の規模を表すだけで、**人としての格や職人としての練度を表さない**。社長と町工場の職人に上下がないのと同じ意味で、A級とE級に上下はない。

等級が単純火力指数の平均にすぎないこと（→ [[concept:grades]]）と併せて読むと、**この世界の人々は等級を序列としては扱っていない**ことが分かる。数字は大きさであって、価値ではない。

### 三つの系統と、その依頼主

退魔師は所属によって仕事の出どころが分かれる。A級18人が6・6・6で分かれているのも、この三系統。

| 系統 | 依頼主 |
|---|---|
| **[[faction:reimusho]]（霊務省）** | **国** |
| **[[faction:shrines]] / [[faction:old-houses]]（神社・旧家）** | **その土地に密接に関わった仕事** |
| **民間の退魔師** | **民間から。**ただし依頼を受けるだけでなく、**産業そのものに入り込んでいる**（下記） |

### そして、犯罪者のA級もいる

**三系統のどこかに「裏の側」があるわけではない。**

> **犯罪者のA級は、民間にも、神社・旧家にも、公職にも、普通に潜んでいてよい。**

**別枠として括られていないのが要。** 裏社会の名簿があってそこに載っている、という形ではない。**まっとうな所属を持ったまま、その中にいる。**

**だから三系統のどれにも「安全な側」が無い。** 国家に属していることも、古社に属していることも、身元の保証にはならない。

**A級18人という数の中に、そういう者が混じっていておかしくない。**

### 民間は、産業そのもの

**民間の退魔師は、依頼を受けて妖怪を退治する人ではない。**

**一次産業から三次産業まで、この世のありとあらゆる産業に関わっている。**

| | |
|---|---|
| **一次** | **植物の促進による品種改良** |
| **医療** | **回復系の術** → [[concept:jugu]] の回復呪具と同じ側 |
| **情報** | **ネット系妖怪を使った情報系** |
| **製造** | 呪具の生産。そこらで売られているものを作っている |
| **サービス業** | ここも含めて、**全部** |

**力は、退魔のためだけの技能ではない。** 術が使えるということは、**普通の産業の中で使い道がある**ということ。

**「ネット系妖怪を使った情報系」が特に効いている。** 現代の思念から湧く妖怪は歴史が浅く弱い（→ [[concept:shinen]]）が、**弱いことと使えないことは別**。生まれたばかりの妖怪が、生まれたばかりの産業で働いている。

### ただし、数が少ないので大量生産には向かない

**ここが決定的な制約。**

術が使えるのはE級以上の約22万人（→ [[concept:grades]]）。**この人数で、あらゆる産業に散っている。** どの現場にも数人いるかどうか、という密度になる。

**だから力は、既存の産業を置き換えていない。** 工場のラインを術で回すことはできない。**代わりに、普通の産業の上に薄く乗っている。**

- 大量生産は普通の技術でやる
- **力が入るのは、量が要らないところ** — 品種改良の元、医療の個別対応、情報の一点もの

**これが「現実世界プラスアルファ」の実体。** アルファの部分は、社会を作り替えるほど厚くない。**厚くなれるほど人がいない。**

### それぞれの働き口の実情

**普通に食える。** ただし三系統それぞれに一長一短があり、そこが人の動きを生んでいる。

| 系統 | 良いところ | 悪いところ |
|---|---|---|
| **民間** | **自由。** 各々の仕事で稼ぎはばらばらだが、縛られない | （裏返しに、ばらつく） |
| **霊務省** | 公務員 | **税金関係で渋くてブラック気味。辞める人が割と出る** |
| **神社・旧家** | 土地に根ざした安定 | **しがらみが強くて面倒** |

### 流動が激しい

**この三つはそれぞれが引き抜き合戦をしており、それぞれが嫌がって離脱したりと、流動が激しい。**

**6・6・6の均衡は、静止した構図ではない。** 均衡はしているが固定されてはおらず、常に人が動いている結果としてその形になっている。国は待遇で人を逃し、伝統はしがらみで人を逃し、民間は不安定さで人を逃す。**三者が互いの不満を吸い上げ合って回っている。**

物語にもゲームにも使いやすい構造。**どこに属するかは、能力ではなく生き方の選択**になる。

### 対応は相手による

退魔師のすることは一つではない。**相手の妖怪によって変わる。** 殺すこともあれば、鎮めることも、追い払うことも、見逃すこともある。

「退魔師＝妖怪を殺す職業」ではない。妖怪の側の幅が極端に広い以上（知性の有無、危険度、扱われ方）、対応もそれに応じて幅を持つ。**判断すること自体が、この職能の中身**ということになる。

### 引くことは負けではない

**低〜中危険度の案件では、最初の見立てが外れる。**

| 思っていたもの | 実際 |
|---|---|
| ただの小さな霊障 | **古い契約のほころび** |
| 弱い小妖 | **別の存在の足場** |
| 呪具の誤使用 | **古社の封印具** |
| 店の怪異 | **土地との約束が切れていた** |
| スマホの異常 | **通信網ではなく、建物や土地の反応** |

**この場合、無理にその場で解決しようとしない。** 人を離す、範囲を広げる、記録を残す、詳しい相手に渡す、必要なら引く。

> **引くことは負けではない。小さなケースを大ごとにしないための判断。**

**C級の入口が見えた場合は、学生・新人・民間の単独判断で抱え込ませない。**

**これは「勝利条件は討伐だけではない」（上記）と同じ側の話。** 引き継ぎも情報の持ち帰りも、**最初から勝ち方のうちに入っている。**

## 社会との関わり

### 専門の学校がある。高校から

技を学ぶ場として**専門の学校**が存在し、**高校からある** → [[concept:taimashi-school]]

神社や旧家の徒弟制だけではなく、**公に学べる道がある**。血筋や縁故がなくても退魔師になれるということであり、**この世界は力を秘伝として囲い込んでいない**。

そして学校そのものが、**B級以上の土地神が管理する、逃しポイントを抱えた土地**の上にある。統制下のF〜C級妖怪が教材になるため、**現場に出す必要が薄い**。管理されているとはいえ、**危険性という点ではそこらの街なんか目じゃない**。

### かなり危険

**退魔師の仕事はかなり危険。**

「普通に食える」職業でありながら、危険度は高い。**高校から進路があり、資格制度があり、三系統が引き抜き合戦をするほど人手が要る職業が、同時にかなり危険**という組み合わせになっている。

E級呪具の時点で人を殺せる出力があり（→ [[concept:jugu]]）、相手はD級で大型肉食獣＋属性攻撃、C級から超常の能力を使う（→ [[concept:grades]]）。**装備も相手も、日常的に人が死にうる水準にある。**

- 民間は**一次から三次まであらゆる産業に関わる**（確定）。残るのは:
  - **妖怪退治の依頼そのものは、その中でどれくらいの比重なのか**
  - **妖怪との関係の形は【掘らない】。** 雇用か使役かも、同意の有無も、個体による
  - 力を使う仕事とそうでない仕事で、**報酬は違うのか**
- 神社・旧家の「土地に密接に関わった仕事」とは具体的に何か
  - [[concept:release-points]] や [[concept:land-god]] の管理はここに含まれるのか

- 危険なのに人が集まるのは、待遇のためか、使命感か、他に潰しが利かないからか
- **判断基準は誰が決めるのか** — 法令か、業界の慣行か、個々の裁量か、依頼主の要望か
- 手続きを経た妖怪を「退治」できるかは**場合による**（確定）。**その「場合」の中身は【掘らない】** — 契約次第で、個体による
- 妖怪を殺しても**届け出はいらない**（→ [[concept:legal-status]]）。報告義務も許可も事後の届出もない
- 狙うのは**千差万別**（→ [[concept:core-layer]]）。**【掘らない】**
