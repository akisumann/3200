## 概要

**「退魔師」は職業名ではなく、分類名。** 力を使える人間は、**分類としては全員が退魔師**にあたる → [[concept:powers]]

つまり日本には約222万人の退魔師がいることになる。**しかしその大半は、退魔などしていない。**

## 仕組み

### 全員が退魔師。ただし戦うのはD級から

**基本的に、戦闘に出る退魔師はD級から。**

| 等級 | 実態 |
|---|---|
| **F級**（約200万人） | **「F級」とだけ言われる。別に退魔とかしていない** |
| E級（約20万人） | 術は使えるが、戦闘に出るのは基本的でない |
| **D級以上**（約22,218人） | **戦闘用退魔師** |

**D級退魔師＝戦闘用退魔師。** 「明確に強めな資格はD級から」というのは、そういう意味だった。D級は「真っ当な戦闘訓練などをして相当の水準になった」という標識であり、[[concept:grades]] のD級（バトル漫画くらいの水準の技や動きが可能）と対応する。

**D級資格を取った時点で、退魔に関する真っ当な戦闘行動全般を行える。** 討伐、制圧、防衛、護衛、戦闘支援などを、学生か社会人かにかかわらず正規の戦闘行為として扱える。学校在学中に早期認定された者も同じで、**学生だから資格の権限が縮むわけではない。**

### 等級は、どこまで現場で先に決断してよいかの基準でもある

**D級で戦闘資格そのものが開くが、C・B・Aへ上がる意味は単なる火力上昇だけではない。** 等級は同時に、**どの規模の強制力、破壊、危険、巻き込み、致死的結果まで、事前の法的手続きを待たず現場判断で選んでよいか**を判断する基準にもなっている。

高位の退魔師が相手にするものは、そもそも通常の警察活動や小規模な戦闘では止まらない。**毎回、許可を取りに戻ってから術を撃つ制度では成立しない。** そのため上位等級ほど、緊急時に自分の判断で先に行使できる力の幅が広い。

**これは「何人まで巻き込んでよい」「建物を何棟まで壊してよい」という固定表ではない。** 相手、切迫性、周辺状況、他の現実的な手段、予測できた被害、放置した場合の被害などをまとめて見る。そのうえで、**その等級の退魔師へ任せられている範囲の合理的な戦闘判断だったか**が問われる。

#### C級になると、公道で怪物と戦うこともある

たとえば、**車を粉砕しながら幹線道路を走る大型妖怪を、C級退魔師が並走しながら公道上で戦う。** そういう案件は普通にあり得る。

車両、ガードレール、信号、路面、周辺設備が戦闘で壊れることもある。避けられる被害は避けるが、**それらを一つずつ守るために妖怪への攻撃を止め、さらに大きな被害を出す方が間違っている。** 必要な戦闘行為として妥当なら、事前に道路や車両の破壊許可を一件ずつ取る必要はない。

**対人でも同じ考え方がある。** 超常犯罪者、暴走術者、契約暴走者など、人間が正規の戦闘対象となる場合、拘束や制圧だけでなく**致死力の行使まで含めて、等級と状況に応じて現場判断できる範囲が広がる。**

#### 高位になるほど、巻き込みを含む大規模判断まで預けられる

たとえば、**山を越えるほど巨大な大百足が出現し、止めるために山そのものを粉砕する規模の術を撃った。その巻き込みで避難しきれなかった人が数人死亡した。**

この結果だけを見て、自動的に殺人や過失致死として扱う制度では、高位退魔師は必要な攻撃を選べない。**その場で大百足を止める必要があり、攻撃規模と予測される被害が状況に照らして妥当だったなら、死者が出ても正規の退魔行為として合法になり得る。**

逆に、明らかに小さな対象へ不釣り合いな大規模術を使い、避けられた被害を大量に出したなら話は別。**等級は免罪符ではなく、大きな判断を先に任せるための信用でもある。**

### 事前手続きが不要でも、事後の査定はある

**「その場で許可を取らなくてよい」と「何をしても問われない」は別。** 高位退魔師ほど大きな判断を先に実行できるが、戦闘後には必要性、相当性、把握していた情報、避難や警告の可否、他の選択肢などを確認される。

> **許可を待たずに撃てる。だが、なぜ撃ったかは後で説明する。**

これが高位等級の法的な重さになる。

### 周囲へ行使できる権限も増える

**自分だけが強い力を使えるのでは、広域案件は処理できない。** 等級が上がるほど、超常案件の現場で周囲へ及ぼせる権限も大きくなる。

退避指示、立入制限、道路や施設の一時封鎖、関係機関への協力要請、現場の戦闘員への指示、危険物・設備・土地への緊急介入など、**事件を止めるために他者や社会側を動かす権限**が付いてくる。どこまでが自動的に等級へ付随し、どこからが所属や役職によるかは案件によるが、少なくとも**高位になるほど「自分が何をしてよいか」だけでなく「周囲に何をさせてよいか」も広がる。**

**実際に戦う退魔師は、約2万2千人。** 人口1万人あたり1.8人 — 消防吏員（約16万人）や警察官（約26万人）どころか、歯科医師よりも少ない。**世間に「普通にいる」職業でありながら、実数はかなりの少数精鋭。**

### 「F級」という呼ばれ方

F級の人間は、**退魔師ではあるが、基本的には「F級」とだけ言われる。**

職業ではなく**属性**として扱われている。「あの人F級だよ」で通じ、それ以上の意味を持たない。妖怪が見えるというだけの、ありふれた性質。

**ただしF級の全員がそこで確定しているわけではない**（→ [[concept:grades]]）。**才能はあるが、まだ技を出せていない最初期の段階**もF級に数えられる。大半はそのまま「F級」で一生を過ごすが、**その中に、まだ出ていないだけの人が混ざっている。**

だからこそ彼らは病院にも企業にも行政にも散らばっていて、社会の検知網として機能している → [[concept:daily-life]]

**日本のA級18人のうち6人が民間の退魔師** → [[concept:grades]]。民間でありながら、国家（霊務省）や伝統（神社・旧家）と頂点で並んでいる。

### ただしE級が劣るわけではない

**E級が何もできないということではない。**

> **A級が大企業の社長だとするなら、E級は町工場のベテラン職人のようなもの。**
> **金（出力）の動きが違うだけで、ベテランはベテランであり、A級はE級を蔑んだりしない。**

等級は動かす力の規模を表すだけで、**人としての格や職人としての練度を表さない**。社長と町工場の職人に上下がないのと同じ意味で、A級とE級に上下はない。

等級が単純火力指数の平均にすぎないこと（→ [[concept:grades]]）と併せて読むと、**この世界の人々は等級を序列としては扱っていない**ことが分かる。数字は大きさであって、価値ではない。

### 三つの系統と、その依頼主

退魔師は所属によって仕事の出どころが分かれる。A級18人が6・6・6で分かれているのも、この三系統。

| 系統 | 依頼主 |
|---|---|
| **[[faction:reimusho]]（霊務省）** | **国** |
| **[[faction:shrines]] / [[faction:old-houses]]（神社・旧家）** | **その土地に密接に関わった仕事** |
| **民間の退魔師** | **民間から。**ただし依頼を受けるだけでなく、**産業そのものに入り込んでいる**（下記） |

### そして、犯罪者のA級もいる

**三系統のどこかに「裏の側」があるわけではない。**

> **犯罪者のA級は、民間にも、神社・旧家にも、公職にも、普通に潜んでいてよい。**

**別枠として括られていないのが要。** 裏社会の名簿があってそこに載っている、という形ではない。**まっとうな所属を持ったまま、その中にいる。**

**だから三系統のどれにも「安全な側」が無い。** 国家に属していることも、古社に属していることも、身元の保証にはならない。

**A級18人という数の中に、そういう者が混じっていておかしくない。**

#### 高位になるほど、しょうもない犯罪は減る

**実力者であればあるほど、雑な万引きや低級札の横流しはやらない。**

**代わりに来るのがこれ。**

- 高位呪具を大量に作り、裏市場へ流す
- 危険素材の出所を偽装する
- **封印指定物を分解して部品として売る**
- **旧家の秘匿神秘を盗み、別の土地へ移す**
- 高位妖怪の身体素材を加工する
- **土地神の加護や呪いを、契約書の形にして売る**
- **土着妖怪の縄張りを担保に取る**
- **地域祭祀を裏から歪める**
- **国家認証や結界識別の回避**

**単なる違法販売ではない。土地、契約、封印、神秘資産、妖怪社会、地域共同体そのものへの干渉。**

#### そして見つからない

**土地神が関与している。土着系妖怪が隠している。旧家の内部事情と結びついている。地域祭祀の名目で正当化されている。合法工房の帳簿に混ざっている。民間企業の正規物流に紛れている。封印蔵の古い記録が改竄されている。**

**そして関係者全員が「昔からそうしてきた」と言う。**

**外から見ても、犯罪なのか、慣習なのか、地域契約なのか、旧家の内輪処理なのか、すぐには判別できない。**

**摘発には、呪具鑑定、契約履歴確認、土地祭祀の照合、妖怪側証言、古社旧家への聞き取り、霊務省の記録、民間流通の帳簿、地域伝承を突き合わせる必要がある。**

> **裏にいる大物は、弱いから裏にいるのではない。**
> **表の制度では扱いきれない力、技術、契約、素材、人脈を持ったまま、責任と監督の外へ出ているから危険なのである。**

#### 判定は「違法かどうか」ではない

**霊務省であっても、古社旧家であっても、民間企業であっても、現場判断として法的に灰色な処理を行うことはある。** 法規、慣習、地域契約、古い祭祀、妖怪側の理屈、緊急避難、封印維持、公共安全が衝突するので、そうなる。

**だから見るのはそこではない。**

- **被害抑制のための現場判断なのか、私益のための隠蔽なのか**
- **責任主体があるのか**
- **後処理と報告が行われるのか**
- **公共安全を守る方向に働いているのか、それとも被害を拡大させるのか**

> **問題なのは、法律を破ったことではなく、責任・監督・公共安全・被害抑制の枠から外れて動いていること。**

### 民間は、産業そのもの

**民間の退魔師は、依頼を受けて妖怪を退治する人ではない。**

**一次産業から三次産業まで、この世のありとあらゆる産業に関わっている。**

| | |
|---|---|
| **一次** | **植物の促進による品種改良** |
| **医療** | **回復系の術** → [[concept:jugu]] の回復呪具と同じ側 |
| **情報** | **ネット系妖怪を使った情報系** |
| **製造** | 呪具の生産。そこらで売られているものを作っている |
| **サービス業** | ここも含めて、**全部** |

**力は、退魔のためだけの技能ではない。** 術が使えるということは、**普通の産業の中で使い道がある**ということ。

#### 実際に何があるか

| | |
|---|---|
| **一次** | 地脈利用農業、**土地契約**、霊水管理、妖怪害獣対策、霊草栽培、豊穣祭祀、**霊獣・妖怪性家畜の管理** |
| **二次** | 呪具製造、霊札生産、神秘素材加工、**霊導繊維**、**結界建材**、対霊装備、封印具、観測端末、浄化設備、**工場結界設備** |
| **三次** | 企業霊障対策、民間結界施工、妖怪警備、**超常物流**、要人護衛、**超常保険**、除霊業務、契約妖怪サービス、地域祭祀補助、**観光、芸能、配信**、教育補助、医療・福祉・カウンセリング |

**実際の会社は [[faction:companies]] に置いた。**

**超常を使った夢の完全自動化社会ではない。** **現代の農業、工業、物流、警備、建築、医療、観光、芸能、保険、教育、地域運営の中に、超常要素が自然に組み込まれている状態。**

> **国家は超常を管理する。民間は超常で働き、作り、売り、運び、守り、直し、癒やし、遊ばせる。**

**「ネット系妖怪を使った情報系」が特に効いている。** 現代の思念から湧く妖怪は歴史が浅く弱い（→ [[concept:shinen]]）が、**弱いことと使えないことは別**。生まれたばかりの妖怪が、生まれたばかりの産業で働いている。

### ただし、数が少ないので大量生産には向かない

術が使えるのはE級以上の約22万人（→ [[concept:grades]]）。**この人数で、あらゆる産業に散っている。** どの現場にも数人いるかどうか、という密度になる。

**だから力は、既存の産業を置き換えていない。** 工場のラインを術で回すことはできない。**代わりに、普通の産業の上に薄く乗っている。**

- 大量生産は普通の技術でやる
- **力が入るのは、量が要らないところ** — 品種改良の元、医療の個別対応、情報の一点もの

**これが「現実世界プラスアルファ」の実体。** アルファの部分は、社会を作り替えるほど厚くない。**厚くなれるほど人がいない。**

### それぞれの働き口の実情

**普通に食える。** ただし三系統それぞれに一長一短があり、そこが人の動きを生んでいる。

| 系統 | 良いところ | 悪いところ |
|---|---|---|
| **民間** | **自由。** 各々の仕事で稼ぎはばらばらだが、縛られない | （裏返しに、ばらつく） |
| **霊務省** | 公務員 | **税金関係で渋くてブラック気味。辞める人が割と出る** |
| **神社・旧家** | 土地に根ざした安定 | **しがらみが強くて面倒** |

### 流動が激しい

**この三つはそれぞれが引き抜き合戦をしており、それぞれが嫌がって離脱したりと、流動が激しい。**

**6・6・6の均衡は、静止した構図ではない。** 均衡はしているが固定されてはおらず、常に人が動いている結果としてその形になっている。国は待遇で人を逃し、伝統はしがらみで人を逃し、民間は不安定さで人を逃す。**三者が互いの不満を吸い上げ合って回っている。**

物語にもゲームにも使いやすい構造。**どこに属するかは、能力ではなく生き方の選択**になる。

### 対応は相手による

退魔師のすることは一つではない。**相手の妖怪によって変わる。** 殺すこともあれば、鎮めることも、追い払うことも、見逃すこともある。

「退魔師＝妖怪を殺す職業」ではない。妖怪の側の幅が極端に広い以上（知性の有無、危険度、扱われ方）、対応もそれに応じて幅を持つ。**判断すること自体が、この職能の中身**ということになる。

### 引くことは負けではない

**低〜中危険度の案件では、最初の見立てが外れる。**

| 思っていたもの | 実際 |
|---|---|
| ただの小さな霊障 | **古い契約のほころび** |
| 弱い小妖 | **別の存在の足場** |
| 呪具の誤使用 | **古社の封印具** |
| 店の怪異 | **土地との約束が切れていた** |
| スマホの異常 | **通信網ではなく、建物や土地の反応** |

**この場合、無理にその場で解決しようとしない。** 人を離す、範囲を広げる、記録を残す、詳しい相手に渡す、必要なら引く。

> **引くことは負けではない。小さなケースを大ごとにしないための判断。**

**C級の入口が見えた場合は、学生・新人・民間の単独判断で抱え込ませない。**

**これは「勝利条件は討伐だけではない」（上記）と同じ側の話。** 引き継ぎも情報の持ち帰りも、**最初から勝ち方のうちに入っている。**

## 社会との関わり

### 専門の学校がある。高校から

技を学ぶ場として**専門の学校**が存在し、**高校からある** → [[concept:taimashi-school]]

神社や旧家の徒弟制だけではなく、**公に学べる道がある**。血筋や縁故がなくても退魔師になれるということであり、**この世界は力を秘伝として囲い込んでいない**。

そして学校そのものが、**B級以上の土地神が管理する、逃しポイントを抱えた土地**の上にある。統制下のF〜C級妖怪が教材になるため、**現場に出す必要が薄い**。管理されているとはいえ、**危険性という点ではそこらの街なんか目じゃない**。

### かなり危険

**退魔師の仕事はかなり危険。**

「普通に食える」職業でありながら、危険度は高い。**高校から進路があり、資格制度があり、三系統が引き抜き合戦をするほど人手が要る職業が、同時にかなり危険**という組み合わせになっている。

E級呪具の時点で人を殺せる出力があり（→ [[concept:jugu]]）、相手はD級で大型肉食獣＋属性攻撃、C級から超常の能力を使う（→ [[concept:grades]]）。**装備も相手も、日常的に人が死にうる水準にある。**

### 仕事の中身

- 民間は**一次から三次まであらゆる産業に関わる**（確定）。残るのは:
  - **妖怪退治の依頼そのものは、その中でどれくらいの比重なのか**
  - **妖怪との関係の形は、個体による。** 雇用か使役かも、同意の有無も、個体による
  - 力を使う仕事とそうでない仕事で、**報酬は違うのか**
- 神社・旧家の「土地に密接に関わった仕事」とは具体的に何か
  - [[concept:release-points]] や [[concept:land-god]] の管理はここに含まれるのか
- **かなり危険**（確定）。殉職は年に何件くらいか。**遺族への補償はどうなっているのか**
- 危険なのに人が集まるのは、待遇のためか、使命感か、他に潰しが利かないからか
- **判断基準は誰が決めるのか** — 法令か、業界の慣行か、個々の裁量か、依頼主の要望か
- 手続きを経た妖怪を「退治」できるかは**場合による**（確定）。**その「場合」の中身は個体による** — 契約次第で、個体による
- 妖怪を殺しても**届け出はいらない**（→ [[concept:legal-status]]）。報告義務も許可も事後の届出もない
- 狙うのは**千差万別**（→ [[concept:core-layer]]）。**個体による**

### 立ち位置

- 妖怪から見て退魔師とは何か。**敵なのか、必要悪なのか、恐怖の対象か**
- 一般人から見てどういう職業か（憧れか、危険な仕事か、地味な裏方か）
- 妖怪の退魔師はいるのか
