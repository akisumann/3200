## 概要

力を用いた道具。**そこらで普通に売っている**が、等級に応じた**免許制**になっている。

## 仕組み

### 呪具は三つの型に分かれる

**等級とは別に、「どこからエネルギーが来るか」で三つに分かれる。**

| 型 | 中身 |
|---|---|
| **消費型呪具** | **使ったら終わり。** 一回で使い切る |
| **起動型呪具** | **使用者が力を流して持続的に扱う。** 流し続けている間だけ動く |
| **恒常型呪具** | **エネルギーを自己生産する。** 自分で持っている |

**等級が「どれくらいの出力か」なら、型は「その出力をどこから引いてくるか」になる。** 二つは独立した軸で、**同じ等級に三つの型がありうる。**

#### 見分け方は三問

**現場でも学校でも、この三つを順に聞く。**

1. **使ったら消えるか。** → 消えるなら消費型
2. **本体は残るが、使用者の力や整備が要るか。** → 要るなら起動型
3. **道具側が自分で現象を維持するか。** → 維持するなら恒常型

**迷ったときの目安。** **学生が購買で買うなら消費型。** 普段使いの装備なら起動型。**喋る、選ぶ、勝手に動く、土地と結びつくなら恒常型。**

**名前で判断しない。**

> **「聖剣」でも、ただの起動型の個人装備であることがある。**
> **見た目が安物の鈴でも、自己循環して契約を要求するなら恒常型。**

**呪具はロマン名ではなく、消耗・維持・自律性で見る。** [[concept:relics]] の歴史的な遺物も、格の高い名前がついているだけで型は別々になる。

#### この区分が、力の有無の断絶に効いている

**力を使えない人間に手が届くのは、消費型。**

**エネルギーが最初から中に入っている**ので、使う側は引き金を引くだけでいい。**一般人がD級の浄化札で蔵を掃除できる**のも（下記）、**警察が呪具を使える**のも（下記）、この型があるから。

**起動型は、使用者が力を流す。** つまり**流せる力を持っていること**が前提になる。**免許を取っても、力が無ければそもそも動かない。**

> **消費型は誰にでも使える。起動型は退魔師にしか使えない。**

**これで「呪具は等級差を覆す」の中身が一段はっきりする。** 覆しているのは主に消費型で、**起動型は覆していない。** むしろ**力のある者の出力を伸ばす道具**の側にある。

#### 消費型 — 中身は二種ある

**完成済みのものと、空核。**

| | |
|---|---|
| **完成済み** | 術式・発動条件・現象・必要資源まで**封入済み。** 使う側は起動するだけ |
| **空核** | **術式構造と発動条件だけが作ってあって、中身が空。** 使う前に力を充填する |

**空核があることで、消費型と起動型の間が繋がる。** 力を持つ者が自分の力を詰めて、力を持たない者がそれを撃つ、という受け渡しができる。

**低位の空核は入力の許容幅が広い。** 高位の空核は、**何を詰めるかで性能も事故率も大きく変わる。**

**事故の大半は、低級札の感覚で高位空核を扱ったときに起きる。**

#### 形は札に限らない

**杭、塩、香、弾丸、糸、面、小石、護符、封印紙。** 消費型の形式は色々ある。

**その中で最も普及しているのが札。** 軽い、大量に持てる、安い、投げられる、貼れる、隠せる。**現場運用との相性が良すぎるので、消費型といえば札、という扱いになっている。**

#### 恒常型が一番特殊

**エネルギーを自分で作る。** 撃てば減る消費型とも、使用者を必要とする起動型とも違う。

**呪具そのものが現象の循環を抱えている。** 消費型が現象を一度だけ保存した道具なら、**恒常型は現象そのものを定着させた道具**になる。高位のものは、**自己循環構造や第二の炉として機能して、自分で出力し、自分で安定する。**

**だから使い方が違う。** 力を流し込むのではない。

> **恒常型は、流し込むのではなく付き合う。**

**共鳴し、契約し、適合して、半独立した超常存在として運用する。** ほとんど妖怪の隣にいる（→ [[concept:core-layer]]）。

**該当するもの。** 妖刀、神器、古い奉納具、高位の面、数珠、指輪、祭祀具、遺物。

**そして適合しないと壊れるのは使う側。** 出力低下、力の逆流、精神汚染、拒絶反応、**呪具の側からの侵食。**

**これが「なぜ国は恒常型を積まないのか」の答えになっている。** 恒常型は配れない。**適合する人間にしか使えないので、備蓄として意味を成さない。** 誰でも撃てる消費型を何十億もかけて積むほうが、国家の運用には合う。

#### 恒常型は、古ければ強いわけではない

**ここが効いている。**

**古い概念特攻が、現代では条件を失って空転していることがある。** かつて国家を揺らした妖刀が、今は**扱いやすい良質な武器程度**に落ち着いている、ということが普通に起きる。

**逆に、古すぎる遺物は現代の術式理論で解析できない。** そういうものは装備ではなく、**国や土地の霊的な均衡を保つ重石**として扱われる。

**この二つには、実名がある。** 空転した妖刀が**村正**、解析できない重石が**三種の神器** → [[concept:relics]]

> **重要なのは、現在の世界でどの条件が生きているか。**

**これは [[concept:shinen]] と同じ理屈。** 妖怪の外殻が人々の思念で塗り替わるように、**恒常型呪具の効き目も、今の世界が何を想っているかで変わる。** 名高いことと実戦向きであることは、まったく別。

### 等級と免許

呪具には人間と同じA〜Fの等級が振られ（→ [[concept:grades]]）、等級ごとに買える条件が変わる。

| 等級 | 購入 | 手触り |
|---|---|---|
| C級以上 | **一般人の購入は基本的に難しい** | **「一般人には」であって、誰にも無理という意味ではない。**職務上必要な組織には別の道がある |
| D級 | **車の免許くらい大変な免許**が要る | 取ろうと思えば取れるが、相応の手間と期間がかかる |
| E級 | **軽めの免許**で買える | その気になればすぐ取れる。**ただしE級で既に人を殺せる出力がある** |
| F級 | （未決 — 免許なしで買えるのか） | |

**「車の免許くらい」という比喩が効いている。** D級呪具は、危険物ではあるが市民が普通に取得しうる資格の対象。特別な血筋や職業でなくても、教習所に通う程度の努力で手が届く。**規制はあるが、閉ざされてはいない。**

これがこの世界の手触りを決めている。力は秘匿された特権ではなく、**免許で管理された日常の技術**として社会に組み込まれている。

### 等級ごとに、何が使われているか

**消費型（札）で並べると、等級の梯子がそのまま用途の梯子になっている。**

| 等級 | 誰のものか | 何に使うか |
|---|---|---|
| **E級** | **一般向け** | 厄除け、低級霊避け、簡易感知、軽度浄化 |
| **D級** | **正式な術者の標準装備。現場で最も普及している** | 結界、浄化、感知、拘束、退避補助 |
| **C級** | **切り札。**専門職の携行品、学校の上級実習、民間の高危険対応 | 高位怪異戦で切る一枚 |
| **B級** | **国家、古社、大企業、専門機関が管理する** | 広域結界、災害対応、封鎖区域の処理、緊急投入 |
| **A級** | **戦略級。国家機密扱い** | 個人が気軽に携行するものではない → 下記「国家備蓄霊札」 |

**D級が「現場で最も普及」という位置にあるのが効いている。** [[concept:taimashi]] の戦闘用退魔師がD級からなのと、そのまま重なる。

#### 低級札が安全なのは、強いからではない

**弱く、単純で、壊れやすく、安全側に倒してあるから。**

効果を単純にし、出力を抑え、対象条件を限定し、危険な現象を削り、**異常時には不発・低出力化・自壊するように作ってある。**

**だから学生も民間業者も一般術者も協力妖怪も扱える。** 呪具が日常に降りてこられているのは、上位の技術が優れているからではなく、**下位が徹底的に安全設計されているから。**

#### 高位札の価値は、威力ではなく工程

**本来なら長時間の詠唱、儀式の準備、大規模な力の制御、高い集中を必要とする術式を、起動動作だけで撃てるようにしたもの。**

> **高位札は、儀式工程を事前に固定して持ち歩けるようにした装備。**

**だから緊急迎撃、戦場での即応、奇襲、儀式術の携行化に使われる。**

**「A級札はA級退魔師を缶詰にしたもの」（下記）は、正確には出力ではなく工程を缶詰にしている。** A級が何時間もかけてやることを、現場の誰かが一動作で撃つ。

### 呪具は等級差を覆す

**普通に覆せる。** これが呪具の存在意義であり、免許制が必要な理由でもある。

> 一般人がD級の浄化札を使って、蔵の中にゴキブリみたいに溜まっていたF級・E級を一気に浄化した — **といったことが普通にある**

この一例に、この世界の要点がいくつも入っている。

- **一般人が呪具を使える。** 力を使えることが呪具使用の条件ではない。免許さえ取れば手が届く
- **等級差は道具で覆る。** 力を持たない者が、等級の梯子を道具で跳び越せる
- **F級・E級の妖怪は害虫のような存在。** 蔵に溜まる。ゴキブリのように。駆除は非常事態ではなく**家事に近い**
- 浄化札のような**消耗品**が実用されている

**力の有無が世界の見え方を分けている一方で、呪具がその断絶に橋を架けている。** 力を使えない人間でも、買って、免許を取れば、妖怪に手が届く。だからこそ免許制で管理する必要がある。

### 市場に出るものは、強いから売れるのではない

> **管理可能で、説明可能で、保険が通り、責任主体があるから売れる。**

**そのために手を入れてある。**

- **売るために、危険な部分を削る**
- **使うために、効果を単純化する**
- **保険を通すために、責任範囲を明確化する**
- 一般に扱わせるために、取扱表示と使用期限を付ける
- 事故時に回収できるよう、製造者と販売経路を残す

**低級札が安全なのは弱く作ってあるから**（上記）というのは、**商品として成立させるための設計**でもある。

### 免許を出すのは国

**[[faction:reimusho]]。** 等級の判定も、[[concept:taimashi]] の資格も、同じく国が出している。

**運転免許と同じ構図。** 危険物を扱う資格を国が管理し、等級ごとに敷居を変える。呪具が「そこらで普通に売っている」のに社会が壊れないのは、**流通の手前に国の免許が挟まっているから。**

### 免許が担保しているのは「取り扱い」

力ではなく、**扱いを知っていること**。

**負担感の目安。**

| | |
|---|---|
| **E級** | **車の免許の三分の一程度。**数回から十数回の講習、安全確認、簡単な実技と筆記 |
| **D級** | **だいたい車の免許程度** |
| **C級以上** | **一般購入品ではない。**職業資格、所属組織、用途申請、業務契約、専門管理、工房経由 |
| **B級以上** | 国家、古社、大企業、専門機関、旧家、地域封印主体の管理領域 |

**E級の講習で教えるのは、誤使用時の対応、保管方法、廃棄方法、通報義務、貸与禁止、民間人を巻き込んだときの責任。** **難関資格ではないが、責任を理解させるための最低限の教育。**

#### 免許は、責任ラベルでもある

**購入制限のためだけにあるのではない。事故のときの責任主体を決めるためにある。**

> **免許を持っているなら、注意事項を理解していたはず。**

**家族が勝手に使った。学生が友人に貸した。会社の倉庫で期限切れになっていた。現場で対象外の怪異へ使った。契約妖怪に渡したら変質した。**

**どれも、原則として管理者・購入者・使用者である免許保持者が説明責任を負う。**

**厳しく見えるが、これが無いと市場が成立しない。**

**免許保持者が責任を負う → だから低級札を一般市場へ流せる → 責任主体が追えるから保険が通る → 保険が通るから民間企業が売れる → 売れるから [[faction:reimusho]] が日常の低級霊障用品を全部抱え込まずに済む。**

**現場でよく言われる。**

> **免許持ってるんだから、お前が悪い。**

**だいたい正しい。**

**E級の時点で、人を殺せるくらいの出力がある。** だから相応の免許が要る。呪具は妖怪に効くものであると同時に、**人にも効く**。

### 無免許は「よくあること」

**無断で使う、無許可で使うといったことは度々起きる。車の無免許運転くらいの頻度で、まあよくあること。**

**目安として、合法市場で流通しているE級札の周辺には、だいたい三分の一程度の違法・グレー使用が発生している。**

**全員が重大犯罪者という意味ではない。**

- 「ちょっと札を借りただけ」
- 「家にあったから使った」
- 「免許切れてたけど大丈夫だと思った」
- 「安かったから裏通販で買った」

**感覚としては、信号無視、無免許運転、危険物の無許可保管、処方薬の譲渡に近い。**

#### D級札の犯罪利用は、扱いが違う

**D級は正式実務者向けの標準装備で、低〜中危険度の怪異へ実際に干渉できる出力を持つ。**

**だからこれを犯罪に使うと重い。** 脅迫、傷害、建造物侵入、器物損壊、呪詛補助、不正封鎖、違法拘束、営業妨害、霊障事故の隠蔽。

> **E級札の無免許使用は、信号無視や軽い無免許運転に近い。**
> **D級札の犯罪利用は、車を使った犯罪や危険物を使った犯罪に近い。**

**ガチ犯罪にD級札を使うと、警察は普通に激おこである。**

**霊務省も、流通経路、購入名義、保管責任者、販売業者、免許状態、使用履歴を追う。** **合法市場を守るためにも、ここは強く潰される。**

厳罰で根絶されている世界ではない。**規制は本気だが、完全ではない。** 免許を取らずに持っている人間も、借りて使う人間も、それなりにいる。警察沙汰にはなるが、社会が揺らぐほどのことではない — そういう温度。

これも自動車と同じ構図で、**制度が現実的な緩さを抱えたまま回っている**ことを示している。

**取り締まるのは警察。** [[faction:reimusho]] ではない。免許を出すのは国の専門官庁でも、**違反を捕まえるのは普通の警察**。

ここも自動車と同じ。**呪具の無免許は特別な犯罪ではなく、交通違反と同じ棚に載っている。**

### 警察は呪具を使える

**力を使えるかどうかは関係ない。** E級・D級の呪具は免許があれば普通に使えるものなので、**警察も当然に使える。**

そしてC級以上は「**一般人**の購入が難しい」だけで、**警察が持てないという話ではない**。職務上必要な組織には、また別の道がある。

**ここを取り違えていた。** 「力を使えない警官には妖怪も呪具も扱えないのでは」という心配は成立しない。**呪具は等級差を覆すためのもの**（上記）で、力を持たない者に手を届かせるのがそもそもの役割。**警察はその最大の受益者。**

### 呪具は武器だけではない

**判明している種類。**

| 種類 | |
|---|---|
| **浄化呪具** | 妖怪を祓う。**市販のE級で、F級妖怪には十分** |
| **検査呪具** | **憑かれているかどうかを調べる。** 病院にある |
| **健康用回復呪具** | 体調を戻す。病院にある |

**医療機器としての呪具が、普通に存在する。** 呪具は「力を用いた道具」であって、戦うためのものに限らない。**検査し、治し、掃除する道具でもある。**

病院には**市販品よりもう少し高度なもの**が置かれている。つまり医療機関は、相応の等級の呪具を扱う資格を持っている。

**「呪具」という語の守備範囲は、想像より広い。** 武器から日用品から医療機器まで。この世界の力は、そのまま**技術**として社会に埋まっている。

### 何を流すか

**流し込む力にはいくつか系統がある。** 人間の術者が使うもの、妖怪が持つもの、海外の術式が使うもの。**そして完全に別物ではなく、現場ではかなり混ざって扱われている。**

**呪具は基本的に妖力でも動く。** 協力妖怪が人間用の札を使う、といった運用は普通に成立する。

**現場感覚は「だいたい動く」。** ただし**「だいたい安全」という意味ではない。**

| | |
|---|---|
| **低級札・標準装備** | **雑に入れて動く。**そう作ってある。異常入力なら不発・低出力化・自壊で済む |
| **高位札・恒常型・秘術・土地依存の術式** | **入力の性質差が重大な事故要因。**汚染、暴発、拒絶反応、呪具側からの侵食 |

**専門家は、必要に応じて整えてから通す。** 純化、整流、変換、汚染除去。**一般の現場は、整えずに突っ込む。**

**そしてそれは怠慢ではない。**

> **分類が終わるまで怪異は待ってくれない。**

**雑運用を前提に低級札が普及していて、その雑さのまま高位呪具に触ると事故る。** この落差が、装備運用の基本形になっている。

**妖力については、動くかどうかより性質が変わらないかを見る。** 妖怪性が濃すぎると、**呪具が使用者の種族性に引っ張られる** — 浄化札が別の性質に変わる、封印具が縄張り化する、結界具が人間用ではなく妖怪用の領域を張る、使い切りが自壊せずに弱い怪異性を帯びる。

### 使用期限と取扱表示

**呪具にはラベルがある。** 対象等級、使用期限、入力資源、保管条件、併用注意、廃棄方法。

**特別な儀式文ではなく、現代商品の取扱表示に近い。** 食品の原材料表示、家電の使用上の注意、医薬品の用法用量、工具の警告ラベル。**呪具はその棚に並んでいる。**

高位のものになると「**霊力のみ**」「**土地外充填禁止**」「**開封後三日以内**」「**併用不可**」といった表示が付き、**無視すれば事故る。**

#### 期限は商業上の都合ではない

**核構造の劣化、自壊機構、術式固定のズレ、力の圧縮の緩み、汚染の蓄積。** それを管理するための期限になっている。

**期限切れの札は、威力が落ちるだけとは限らない。** 不発、低出力化、軌道のズレ、**対象の誤認**、自壊不良、汚染漏れ。

**低級札は期限切れでも安全側に倒れることが多い。高位札は期限管理そのものが仕事になる。**

**これが「置いておけば目減りする」の中身。** 国家や古社が高位札を作り続けているのは、**備蓄が放置できないから。**

### 札は、下から上まで通っている

**呪具の中でも、札は全体的によく普及している形。** 蔵の掃除に使うD級の浄化札も、病院の備品も、その延長にある。

**そして最上位グレードも札。**

> **国家備蓄霊札** — **A級呪具の中でも、国が作らせて国が保有しているA級の札。**

**一般人が買う浄化札と、国が決戦に持ち出すものが、同じ形をしている。** 等級の梯子の一番下から一番上まで、**同じ一つの器が通っている。**

#### 何十億もかけて、バンバン作り、バンバン更新する

**ここが性格を決めている。**

**A級札は消費型**（上記）。使えば終わり、そして置いておけば目減りする。**「A級退魔師を缶詰にしたもの」というのは、型の話としてそのまま正しい** — 作り手が力を注ぎ込み、それが中に入ったまま保存されている。

**A級札は宝物ではない。消耗品。**

- **バンバン作る** — ただし**兵器級の物品としての「バンバン」**。そこらのコンビニで売っている呪具とは、**生産数の桁が違う。低いほう。**
- **バンバン更新する** — **古くなる。** 置いておけば目減りするので、作り続けなければ在庫が保てない
- **何十億もかける** — **予算がつく。** 国家の帳簿に載っている項目

#### 作っているのはA級退魔師

**国が委託している。**

> **A級札は、[[concept:taimashi]] のA級 — つまり日本に18人しかいない人間 — が作っている。**

**これで本数が少ない理由が閉じる。** 作り手が18人しかいないのだから、金を積んでも増やしようがない。**生産能力の上限が、そのまま国内のA級の人数で決まっている。**

**そして札の正体もはっきりする。**

**呪具は等級差を覆す**（上記）。A級の札とは、**A級の出力を、A級でない人間が撃てる形にしたもの。**

> **国家備蓄霊札は、A級退魔師を缶詰にしたもの。**

**国がやっているのは、増やせない18人の出力を、置いておける物に換えて溜めるという作業になる。** 人は一人しかいないので一箇所にしかいられないが、**札にすれば分けて配れる。**

[[event:hyakki-yako-attempt]] で札がA級と同じ列に数えられていたのは、比喩ではなかった。**あれは実際にA級の出力そのもの。**

**単価の目安が、現場の言い回しに残っている。**

> **霊務省は、一枚数十億する札を毎年何枚も腐らせながら、それでも止められないらしい。**

半ば都市伝説めいた話として囁かれているもの。**使わなくても維持費がかかり、使えば現場被害と政治責任が発生し、それでも無ければ詰む。**

**「バンバン」は数の話ではなく、姿勢の話。** ミサイルや戦闘機を「バンバン更新する」と言うのと同じ意味で、**絶対数は少ない。** 何十億という額は、**少ない数に高い単価が乗っている**結果になる。

**だから [[concept:taimashi]] の「数が少ないので大量生産には向かない」と矛盾しない。** むしろその確認になっている。**作り手の数は変わらないので、金を積んでも増えるのは単価であって本数ではない。**

**つまり国は、A級の火力を在庫として持っている。** 人ではなく、**物として。**

**A級退魔師は18人しかいない**（→ [[concept:grades]]）。**育てられないし、増やせない。** そこを金で埋めているのがこの制度になる。**ただし埋まる量には限りがある。**

**在庫は薄い。** 使えば無くなり、使わなくても更新が要り、そして**そもそも本数が少ない。**

**そして本数が少ない本当の理由は、金でも作り手の等級でもない。** A級18人のうち、**圧縮ができる人間がさらに限られている**（→ [[char:suwa-shizuka]]）。**一枚数十億は、その希少性の値段でもある。** A級の火力を保有し続けること自体が恒常的な出費であり、**それだけ払っても厚くはならない。**

#### 重さが出るのは、使わない時

**ここがこの制度の性格。**

**使わないまま劣化する。使わないまま更新する。使わないまま予算を食う。使わないまま保管庫を圧迫する。**

**それでも、無ければ国が困る。**

> **腐らせることも、抑止の一部。**

**現場では複数の呼び方がある。** 国家札。**戦略札。** 終末札。**都市焼却札。**

**最後の二つが、この札の想定用途をそのまま言っている。**

#### 作って終わりではない

**工程が一続きになっている。** 圧縮する。固定する。保管する。**劣化を測る。** 更新する。廃棄する。**再製造する。**

**そして管理対象は札そのものだけではない。**

- **誰が作ったか**
- どの術式を基盤にしたか
- **どの地脈儀式を使ったか**
- **どのA級術者が関与したか**

**製造の履歴が、札と一緒に管理されている。**

**だからこれは装備ではなく制度になる。** 国家予算、人材資源、古社旧家の協力、**A級術者の健康**、保管施設、廃棄手順まで巻き込んでいる。

**「A級術者の健康」が管理項目に入っているのが効いている。** **作り手が18人しかいない以上、その人間の消耗が、そのまま国家の備蓄能力の消耗**（上記）。

#### 実際に投入された例

[[event:hyakki-yako-attempt]] の決戦。六名の地区長級A級術者、国家直属A級、民間協力A級、高位B級部隊、**そして国家備蓄霊札。**

**A級が並んでいる場に、わざわざ札が数えられている。** 国家が最上位戦力を集中投入するとき、**札は人と同じ列に並ぶ戦力として扱われている。**

**そして在庫が薄いということは、あの決戦が札の側でも賭けだったということ。** 六地区を空にしたのと同じ列に、**備蓄を注ぎ込むという判断が並んでいる。** 短期決戦で決めるしかなかった理由の一つが、たぶんここにもある。**長引けば札が尽きる。**

**呪具が等級差を覆すという原則が、国家の規模でそのまま出ている。** 一般人がD級の札で蔵を掃除するのと、国がA級の札で妖魔連合を殴るのは、**同じ仕組みの端と端。**

### 呪具事故は、討伐の話ではない

**生活圏で起きる呪具のトラブルは、怪異を倒す話にならない。**

> **物品管理、表示確認、使用者責任、古物扱い、施工ミス、遺品整理、保険の話に近い。**

**認可済みの護符、簡易札、低位封止具、霊障避け、結界補助具、清め用品は、一般家庭や店舗でも使われている。** ラベルを「まあ大丈夫だろ」と軽く見た結果、**誤作動、軽い霊障、契約反応、店舗被害、保険対象外、使用者責任**が発生する。

#### 危険なものは、危険な形をしていない

**古い櫛、鏡、箪笥、石、釘、帳面、玩具、農具、食器、額縁、家屋部材。**

**日用品や古物にしか見えないものが、強い媒体・封印具・核の一部として機能している場合がある。**

**そして民間人や一般業者は、その危険性を感知できない。** 掃除、遺品整理、蔵整理、解体工事、リフォーム、古物売買、廃棄処分の中で、**普通に触ってしまう。**

**だからこの手の案件では、敵が何かより経路が問題になる。** **誰が見つけ、誰が触り、どこから動かし、何と一緒に保管し、どの時点で異常が出たか。**

**古物や遺物の基本。**

> **触らない、動かさない、勝手に開けない、捨てない、持ち帰らない。**

### 標準霊装 — 労働者の安全装備

**現場実働員や正式な術者が着るもの。** 呪毒の軽減、軽度の霊障遮断、術式干渉の低減、裂傷への耐性、味方の結界との接続補助。

**着れば勝てる装備ではない。** 高位怪異やA級相手では、生存率が上がる以上のことは起きない。

**それでも重要なのは、価値が劇的な勝利ではなく生存率の積み上げにあるから。** 低級怪異の接触被害を減らす、呪毒の初期侵入を遅らせる、**撤退までの数秒を稼ぐ。**

> **標準霊装は、英雄の装備ではなく労働者の安全装備。**

#### 身代わり呪具は、残機ではない

**標準霊装に組み込まれていることがある。** 致命的な霊障、即死級の干渉、重度の呪詛を、**一度だけ肩代わりして崩壊する。**

**そして本質は、助かることではない。**

**割れたということは —— その攻撃は本来なら死んでいた。その現場は想定より危険。その術者は継戦すべきではない。**

> **身代わり呪具は、命を一つ増やす装備ではない。撤退判断を一度だけ猶予する装備。**

**周囲への警告装置**でもある。発動を見たら、支援・後退・戦線交代・強制撤収を判断する段階に入っている。

**「助かったからもう一回行ける」と考える者は、だいたい上司に怒られる。**

#### 独房

**一定期間に複数回割った隊員が送られる、霊務局系の内部通称。**

**監禁ではない。反省処分兼再教育。** 割った身代わり呪具の補充作業、適合調整、素材準備、基礎浄化工程、手作業での封入を、**自費・自作に近い形で延々やらされる。**

> **お前が雑に割ったものがどれだけ高くて面倒か分からせる。**

現場の言い回しが「**割った時点で赤字**」「**二回割ったら独房**」「**三回割ったら上司が先に泣く**」。

**呪具が高いということが、そのまま人事と教育の形になっている。**

### 端末も装備のうち

**スマートフォンや専用端末が、現場装備として数えられている。** 異常検知、通信補助、位置共有、簡易観測、記録、外部連絡。

**都市部では観測網が強く働く。** 端末の数と人口密度と通信密度が、そのまま初動の速さになる。

**そして山奥、閉鎖村落、深山、神域の内部、土地神の圏内、領域の深部では弱まる。**

| 端末の状態 | 意味 |
|---|---|
| 繋がる | 情報が取れる |
| **乱れ始める** | **領域や霊障が深くなっている** |
| **完全に沈黙** | **そこはもう通常の都市部対応ではない** |

**外殻が土地になっている妖怪の中に入ったなら**（→ [[concept:core-layer]]）、**当然そこは電波の外側**でもある。**端末の沈黙が、領域に入ったことの一番わかりやすい指標になっている。**

**ただし端末は使用者を守らない。** 警告が出ても怪異は止まらないし、位置が共有されていても死ぬときは死ぬ。

> **通信端末は、助かるための道具ではなく、助けを呼ぶための道具。**

### 装備は勝利保証ではない

**全部に共通する。**

- 消費型は、**条件を間違えれば不発にも誤射にもなる**
- 高位札は強力だが、使用条件、射線、起動時間、巻き込み、保管劣化、誤発動の問題がある
- 標準霊装は**生存率を上げるだけ**
- 身代わり呪具は、**発動した時点で撤退判断が要る**
- 起動型は、**本人の制御技術と消耗に依存する**
- 恒常型は、**適合しなければ使用者を傷つける**
- 端末は情報をくれるが、**守らない**

**装備を持っていることよりも、正しく使い、使った後に引く判断ができることのほうが重要。**

> **強い装備を持つことは、強い責任を持つこと。**

## 核片 — 妖怪から採れる素材

**妖怪を倒しても、全てが消えるわけではない。**

**外殻や余剰エネルギーが世界へ溶けた後**（→ [[concept:battle]] の消失反応）、**残るものがある。**

**肉体片、腕、角、牙、爪、髪、骨、皮、仮面、札、器物、影、声、名前、記録、核、核片。** これらをまとめて**残留物**と呼ぶ。

### 死骸か、まだ繋がっているか

**残留物は、単なる死骸や戦利品とは限らない。**

**外殻の一部なのか、媒体なのか、副核なのか、再接続点なのか、呪具化した残滓なのか、素材として使える霊材なのか。**

> **重要なのは、それがまだ世界と繋がっているかどうか。**

**残存反応が薄く、再凝集せず、契約・媒体・核との接続も見られなければ、証拠品・素材・清掃対象として扱ってよい。**

**逆に、強い個別性・再接続性・奪還可能性を持つ残留物は別。** **その部位が残っていること自体が、対象が完全には消えていない証拠になる。**

### 核片は、材料になる

**核や核片が物質化して残った場合、高い霊的性質を持つことが多い。**

**呪具、霊札、結界具、封印具、護符、魔除け、素材霊材の材料として価値がある。** **状態が良ければ高値で売れる。**

**流通させないこともある。** 神棚、祠、社、工房、倉庫、門口へ安置して、**魔除け、厄除け、土地の鎮め、家業守護**として使う。

### ただし、拾ってすぐ使うものではない

**未処理の核片には、妖怪本人の性質、呪詛、未練、契約、縄張り反応、再接続性が残っている場合がある。**

> **現場で拾ってそのまま売る、家に持ち帰る、加工する、身につけることは推奨されない。**

**まず反応量、再接続性、呪詛の残留、契約の残留、外殻再形成の有無を確認する。**

| | 扱い |
|---|---|
| 反応が安定し、再凝集や再接続の危険が低い | **有用な霊材** |
| **反応が強すぎる／個別性が残りすぎている／名前や伝承と強く繋がっている／外殻を再形成しようとする** | **素材ではなく、封印・管理対象** |

> **消えたものは、外殻を保てなくなったもの。**
> **残ったものは、まだ世界と繋がっているものか、世界に残せるほど安定した素材。**

**呪具の材料の一部は、ここから来ている。**

### 何が売っているのか

**浄化札**（D級のものがある）、**検査呪具**、**健康用回復呪具**が確定。他には何があるのか。

- 具体的にどんな物があるのか（護符、武器、消耗品、日用品、家電）
- **F級・E級の呪具は生活の中でどう使われているのか。** 一般家庭にあるのか
  - 蔵に妖怪が溜まる世界なら、**防虫剤や殺虫剤に当たる日用の呪具があるはず**
- どこで売っているのか（専門店、ホームセンター、通販、コンビニ）
- 値段の感覚。**D級の浄化札はいくらくらいか**（一般人が蔵の掃除に使う程度には手が届く）
- 消耗品か、繰り返し使えるのか

### 三つの型

- **核片から作れるのはどの型か。** 素材霊材として使えるのは分かったが、**消費型の中身になるのか、恒常型の元になるのか**
- **恒常型は「作る」ものなのか。** 妖刀も神器も遺物も、**作られたというより、そうなった**ものに見える。**新造できるのか**
  - 数はどれくらいあるのか。**国宝や神宝の類はここに入るのか** → [[faction:shrines]] の秘匿技術
  - **半独立した超常存在**として運用するなら、**妖怪との線はどこにあるのか** → [[concept:youkai]]
  - **国や土地の霊的均衡を保つ重石**になっている遺物とは何か。**どこに何が置いてあるのか**
- **起動型を使うには何級が要るのか。** 「力を流す」ならE級以上のはずだが、**呪具の等級と使用者の等級はどう対応するのか**
  - **免許は起動型にも要るのか。** 力が無ければ動かないなら、免許は何を防いでいるのか
- **市販の三種はどれなのか。** 浄化呪具・検査呪具・健康用回復呪具（下記）
  - 浄化札は消費型で確定。**病院の検査呪具と回復呪具は、起動型か恒常型か**
- **型は等級と独立か。** F級の恒常型やA級の起動型はありうるのか
- 型によって値段や免許の扱いが変わるのか
- **空核は誰が充填するのか。** 退魔師が自分用に詰めるのか、詰める仕事があるのか

### 力の系統

- **系統がいくつあって、それぞれ何なのか。** 人間の術者のもの、妖怪のもの、海外のもの、という区別までは判明。**名前と中身はまだ** → [[concept:powers]] の側に要る
- **日本の退魔師は何を使っているのか。** 学校で教えているのは一系統か、複数か → [[concept:taimashi-school]]

### 国家備蓄霊札

- **作っているのはA級退魔師**（確定）。**そして全員ではない**（→ [[char:suwa-shizuka]]）。高出力を出すことと、それを小型媒体へ安定圧縮することは別の技術で、**作れるのは「数少ない」A級だけ。** 残るのは:
  - **他に誰が作れるのか。** 18人のうち何人か
  - **民間のA級にも国が発注しているのか**
  - **断れるのか。** 民間のA級が「作らない」と言ったらどうなるのか
  - **一枚作るのにどれくらいかかるのか。** 本業の合間の作業なのか、専従の期間が要るのか
  - **何十億は誰の懐に入るのか。** 個人か、所属先か。**札を作るだけで食えるのなら、待遇の話にも効いてくる**（→ [[concept:taimashi]] の三系統の一長一短）
- **実際、何枚あるのか。** 「兵器級としてバンバン」の絶対数。数十か、数百か
- **A級退魔師が死んだら、その人の札はどうなるのか。** 作り手に紐づいているのか、独立した物なのか
- **誰が撃てるのか。** A級の札にA級の免許が要るなら、撃てる人間がほとんどいないことになる。**それでは在庫の意味が薄い**
  - [[event:hyakki-yako-attempt]] では**高位B級部隊**と一緒に投入されている
- **更新の周期は。** 何年で切れるのか。切れた札はどうなるのか（危険物になるのか、ただの紙になるのか）
- **どこに置いてあるのか。** 6地区に分散か、一箇所か
- **予算はどう通しているのか。** 何十億という額が国会に出るなら、**存在自体は公開されているはず**
- **A級より上はあるのか。** 特殊A級の札は無いのか、作れないのか

### 裏側

無免許使用が「よくあること」である以上、その周辺が広がっている。

- **無免許が発覚したらどうなるのか**（罰金か、実刑か、免許の取得制限か）
- 取り締まりは警察で確定。呪具も使える。**では警察はどこまで持っているのか**
  - **C級以上を持つのはどういう部署か。** 全国どこの署にもあるのか、限られた部隊か
  - 警察と [[faction:reimusho]] の線引きはどこか（免許は国、取り締まりは警察として、その先は）
  - **警察の手に負えない相手は誰が行くのか**（[[concept:taimashi]] に回るのか、霊務省が出るのか）
- 闇市場はあるのか。C級以上が流出したらどうなるのか
- **呪具を使った殺人はあるのか。** E級で人を殺せる以上、あるはず
  - 妖怪ではなく人間を殺すために呪具が使われた場合、それは普通の殺人事件として扱われるのか
- 未成年が使うことはあるのか
