## 概要

**人間が好き勝手に使えない土地が、普通にある。**

妖怪の側のテリトリーとして扱われている区画で、**[[concept:land-god]] が担う土地もその一つ**。他にも危険地帯、妖怪の寄り合い世帯、集団で暮らす種族のエリアがある。

**大抵は中立タイプの妖怪が多い。そして怒らせると普通に人が死ぬ。**

## 仕組み

### 土地神の土地は、人間の土地ではない

**まずここが出発点。** [[concept:land-god]] が管理する土地は、**人間が好きに使ってよい土地ではない**。

土地神が「そこにいる」というだけの話ではなく、**そこは相手の領分**という扱いになっている。

### いくつかの型がある

| | |
|---|---|
| **[[concept:land-god]] の担う土地** | 土地を扱う妖怪の領分 |
| **危険地帯** | |
| **妖怪の寄り合い世帯** | 種族を問わず妖怪が集まって暮らしている |
| **集団種族のエリア** | **天狗や河童のように、集団活動をメインとする種族**のための場所 |

**「妖怪の里」と呼ばれるのは、このうち人が住んでいる型。**

天狗と河童が名指しで出てくるのが効いている。どちらも**種族名で等級が語られる側**（天狗はC級以上 → [[concept:grades]]）であり、**個体ではなく群れとして存在している**。

### 中立タイプが多い

**穏健派でも敵対派でもなく、中立**（→ [[concept:youkai-nature]]）。

人間と付き合う気もなければ、人間を害する気もない。**自分たちの土地で自分たちの生活をしている。**

だから土地が要る。**関わらないことを選んだ相手には、関わらずに済む場所が要る。**

### 怒らせると普通に人が死ぬ

**中立であることと、安全であることは違う。**

こちらから何もしなければ何も起きないが、**踏み込んで怒らせれば普通に死ぬ**。相手が敵対派でないのは、攻撃してこないという意味であって、弱いという意味ではない。

**「人間が好き勝手に使えない土地」という言い方が、そのまま実効性を持っている。** 立入禁止の看板が守られているのは、法があるからではなく、**入ると死ぬから。**

### 法的には、代理人を通して国の内側にいる

**妖怪の土地には、国の権利と保護が適用されている。**

ただし妖怪が自分で役所に行くのではない。

> **[[faction:shrines]] や [[faction:old-houses]] が代理としてコミュニケーションを取り、うまく契約を取ってきて、国の権利と保護を適用させている。**

**これで「入ると死ぬから入らない」の上に、もう一枚あることになる。** 実効的な危険だけで守られているのではなく、**手続きを経て法の内側にも入っている**（→ [[concept:legal-status]]）。

そして**手続きは個体ごとの個別契約**だったはずが、**集団についても成立している**ことになる。里ひとつぶん、種族ひとまとまりぶんの契約がある。

**代理人がいるという構図も重要。** 妖怪の側に人間の役所と渡り合う気も手段もなくても、**間に立つ者がいれば制度に載れる。** 中立の集団が土地を持ったまま国の保護下にいられるのは、これがあるから。

## 社会との関わり

### 交流役がいる

**[[faction:shrines]] と [[faction:old-houses]] が、妖怪の里との交流を担っている。**

気難しい妖怪との干渉役も同じ側の仕事。**話が通じにくい相手との間に立つ役目が、伝統の側にある。**

### これが協調路線の土台

[[concept:cooperation-policy]] は「制御できて、かつオンリーワンな妖怪とはなるべく協調する」という国の方針だが、**中立の集団が土地を持って暮らしているという状態は、その方針以前からあるもの。**

国が方針を決めるより前に、**すでに住み分けが成立している。**

- **寄り合い世帯とは、どういう暮らしなのか**
