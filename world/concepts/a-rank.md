## 概要

**人間側のA級は、現在18人。**

**等級の制度そのものは [[concept:grades]]。** ここは**誰がその席にいるか**を置く。

**一人ひとりが個人として数えられている規模。** 統計上の区分ではなく、**全員が把握され、おそらく名前も顔も知られている。**

**育っても書き足りなくなったら `characters/` へ切り出す。**

## 6・6・6

| 系統 | 人数 |
|---|---|
| **国**（[[faction:reimusho]]） | **6** |
| **神社・旧家**（[[faction:shrines]] / [[faction:old-houses]]） | **6** |
| **民間**（[[concept:taimashi]]） | **6** |

**対等な三者が拮抗しているのではない。** **一つの源流と、そこから分かれた二つ**がこの形に落ち着いている（→ [[faction:shrines]]）。

**そして流動が激しい。** 三系統は互いに引き抜き合っていて、**この均衡は静止した構図ではない。**

### 犯罪者もこの中にいる

**三系統のどこかに「裏の側」があるわけではない**（→ [[concept:taimashi]]）。**だから三系統のどれにも安全な側が無い。**

**18人という数の中に、そういう者が混じっていておかしくない。**

### 式神操作系の術者 — 地区不明

**天使を複数連れている。**

#### 操作技術そのものは、突出していない

**式神操作系のトップ層の中では、横ばい相当。**

**C級にも、同等くらいの操作技術を持つ者がいる。**

**A級との差はこの三つ。**

| | |
|---|---|
| **本人の出力量** | |
| **知謀** | **何よりここ** |
| **賭けと勝負事** | **死ぬほど強い** |

**[[concept:grades]] の「A級が大企業の社長なら、E級は町工場のベテラン職人」が、そのまま出ている。** **金（出力）の動きが違うだけで、ベテランはベテラン。** **技術の高さと等級は、別々に動く。**

**そして判明している三人が、三通りの上がり方をしている。**

| | 何が突出しているか |
|---|---|
| [[char:suwa-shizuka]] | **一つの技術。**圧縮が、戦闘とA級札製造の両方を支えている |
| 催眠系の術者 | **範囲。**専門で切れないオールマイティー |
| **この術者** | **技術以外。**出力量、知謀、勝負強さ |

> **A級に上がる道は、一本ではない。**

#### 何を連れているのか

**天使は、この世界では妖怪**（→ [[concept:kami]]）。**神と妖怪を分ける線が最初から無いので、天使も同じ枠に入る。**

| | |
|---|---|
| **通常時** | **一人一人がA級相当** |
| **完全解放時** | **特殊A級相当** |

**A級相当を複数、常時連れている。**

**[[concept:grades]] の「A級18体」がどう数えられているのかに、そのまま刺さる。** **借り受けたものが日本の18体に入るのかどうかは未確認。**

#### そのA級相当は、出力制限0.1%の話

**絞られている。**

> **天使「出力制限0.1%です」**
> **術者「ケチケチしないで10%くらい申請出せないのか？」**
> **天使「それだと日本が消滅しますね」**

**こういうやりとりがある**（会話の一例）。

**つまり、**

| 出力 | |
|---|---|
| **0.1%** | **A級相当。**常時この状態 |
| **10%** | **日本が消滅する** |
| **100%** | **完全解放。制度上は「特殊A級相当」** |

##### 等級の物差しが、下端しか見ていない

**0.1%でA級相当なのだから、100倍でも国が消える。**

**そして完全解放は、その1000倍。**

**「完全解放時には特殊A級相当」という格付けは、制度がそう呼んでいるだけ。** **[[concept:grades]] の特殊A級が「通常の等級体系では評価困難な妖怪に対する国際特別管理分類」であるというのは、まさにこういう相手のこと。** **測れないから、そう呼んでいる。**

> **A級18体という数え方に入る入らない以前に、この物差しでは目盛りが足りていない。**

##### 申請が通らない理由が、もう一つある

**貸主の判断だけではない**（下記）。

**天使の側も止めている。**

**術者は「10%くらい出させろ」と言い、天使は「それだと日本が消滅します」と返している。** **借り手のほうが軽く、貸し出されている側が現実的。**

**この会話が、この人物の性格をよく表している。** **賭けと勝負事に死ぬほど強い**（下記）**というのは、こういうところにも出る。**

#### 出力は、相手が誰かで動く

**0.1%は固定値ではない。**

| 相手 | |
|---|---|
| **明らかに悪、あるいは悪い存在** | **出力が上がる** |
| **そうでない相手** | **出力が下がる** |

**ただしこれは、通常出力（0.1%）の範囲内での変動。** **悪を相手にしたから完全解放へ近づく、という話ではない。**

##### 伝承拘束が、そのまま出力式になっている

**天使は「悪を討つもの」として想われてきた。** **その核が、そのまま性能に出ている**（→ [[concept:core-layer]] の伝承拘束）。

> **伝承通りだから強い。そして、伝承通りにしか強くない。**

**[[event:hyakki-yako-attempt]] の死神が「死を適用する」以外をやらないのと、同じ形。** **相手を選ばないのではなく、相手によって出方が変わる。**

##### だから、日本の実務とは噛み合いにくい

**この国の超常業務の大半は、悪を相手にしていない。**

**土地神との調整。協力妖怪との関係。妖怪の里との契約。逃しポイントの維持。** **どれも「悪い存在」を殴る仕事ではない。**

**そもそも妖怪には罪がない**（→ [[concept:legal-status]]）。**善悪で裁かれる枠の外にいる。** **人間の法が及んでいない相手を、天使の基準は「悪」と判定するのか。**

**逆に、噛み合う相手もいる。** **犯罪者A級**（→ 上記）。**裏市場。無免許の術者。** **[[concept:relics]] の御手杵で変質した使用者。** **人間の側の悪のほうが、判定は素直に通りそうに見える。**

> これは repo 側の読み。**「悪い存在だと出力が上がる」までが確定で、何を悪と判定するかは書かれていない。**

##### 実務的には、ほぼ使えない切り札

**完全解放は、あっても使えない。**

**A級相当で足りない相手が出たとき、次の段が「日本が消滅する」の側にしかない。**

**[[concept:relics]] の三種の神器と、同じ形をしている。** **持っているが動かせない。** **そして動く時点で、通常の事件ではない。**

#### 借りている

**作ったのでも、調伏したのでもない。**

**[[char:aramaki]] の人工式神とは、まったく別のもの。**

| | |
|---|---|
| **[[char:aramaki]]**（B級） | **五体の人工式神。製造したもの** |
| **この術者**（A級） | **天使。借り受けたもの** |

**式神操作系でありながら、手札の出どころが自分の外にある。**

#### 貸主は、神

> **何故か召喚術で神を召喚し、何かしらの方法か交渉で天使を借り受けている。**

**召喚されている神は、ヤハウェと思われる。**

**断定されていない。** そして**なぜそれが可能なのかも分かっていない。**

**[[concept:grades]] のA級の方向性に「神格接続」がある。** **この術者がそれ。** [[char:suwa-shizuka]] の神降ろしとは別の形の神格接続になる。

##### 申請は、大抵通らない

**完全解放には、神の側の許可が要る。**

**そして大抵は下りない。**

> **借りた側が自由に使えるのは、A級相当まで。**
> **特殊A級相当の権限は、貸主が握ったまま。**

**これが [[concept:kami]] の「神格を万能解決装置にしない」の、具体的な形になっている。** **神は応じる。ただし毎回は許さない。**

**交渉相手として振る舞っているということでもある。** **召喚できることと、思い通りになることは別。**

##### 勝負強さと、無関係には見えない

**「何かしらの方法か交渉で借り受けている」の交渉が、そのまま勝負事だという読みができる。**

**操作技術で抜きん出ているわけではなく、突出しているのは知謀と勝負強さのほう**（上記）。**そして相手は、申請を大抵は通さない神。**

**通らない申請を、それでも通させている人間**ということになる。

> ただしこれは repo 側の読み。**出典にあるのは「何かしらの方法か交渉」までで、それが賭けなのかは書かれていない。**

##### 天使は、神とは別個体

**ここが重要。**

**天使は神の一部でも、出力でも、端末でもない。** **それぞれが独立した個体。**

> **神の力がどれだけ疲弊していても、関係ない。**

**だから貸すことは、神の消耗にならない。**

**[[concept:kami]] の半禁忌の仮説** —— **「現代欧州文明は、神の力をほぼ100%、人類保護へ変換し切っているのではないか」** —— **が仮に本当だったとしても、天使の貸与には影響しない。**

**繋がらない話だった。** 貸せる余力がどこから出ているのか、という問いは立たない。

###### だから「通らない」のは、判断のほう

**申請が下りないのは、残量の問題ではない。**

**出せるのに出さない。**

**これで [[concept:kami]] の「神格を万能解決装置にしない」が、もう一段はっきりする。** **力が尽きているから助けに来ないのではなく、来るかどうかを決めている。**

> **神は、交渉相手として振る舞っている。**

**[[concept:core-layer]] の群体性とも切れている。** **天使が神の端末なら群体として扱えるが、別個体なので扱えない。** **一人一人がA級相当というのは、そういう意味の「一人」。**

##### 外交的には、相当な話

**[[concept:overseas]] では、ヤハウェや仏陀を「妖怪」と呼ぶだけで国際問題級とされ、自粛されている。**

**日本の地区長が、そのヤハウェを召喚して天使を借りている。**

**呼び方を自粛している相手を、実際に呼び出して使っている**ということになる。**これが国際的にどう扱われているのかは未確認。**
