## 概要

**人間側のA級は、現在18人。**

**等級の制度そのものは [[concept:grades]]。** ここは**誰がその席にいるか**を置く。

**一人ひとりが個人として数えられている規模。** 統計上の区分ではなく、**全員が把握され、おそらく名前も顔も知られている。**

**育っても書き足りなくなったら `characters/` へ切り出す。**

## 6・6・6

| 系統 | 人数 |
|---|---|
| **国**（[[faction:reimusho]]） | **6** |
| **神社・旧家**（[[faction:shrines]] / [[faction:old-houses]]） | **6** |

**対等な三者が拮抗しているのではない。** **一つの源流と、そこから分かれた二つ**がこの形に落ち着いている（→ [[faction:shrines]]）。

**そして流動が激しい。** 三系統は互いに引き抜き合っていて、**この均衡は静止した構図ではない。**

### 犯罪者もこの中にいる

**三系統のどこかに「裏の側」があるわけではない**（→ [[concept:taimashi]]）。**だから三系統のどれにも安全な側が無い。**

**18人という数の中に、そういう者が混じっていておかしくない。**

## 国の6人 — 六地区長

**国枠の6人が、そのまま六地区長。**

**選抜は強さ順。** 地区の性格も専門も先には見ない（→ [[faction:reimusho]]）。**指揮・結界管理・調整といった要件は、公職A級になる段階で既に要求されている。**

| 地区 | 地区長 |
|---|---|
| 東北 | **未定** |
| 関東 | **未定** |
| **中部** | **[[char:suwa-shizuka]]** |
| 近畿 | **未定** |
| 中国四国 | **未定** |
| 九州 | **未定** |

**判明しているのは五人。残り一席。** ただし**地区が分かっているのは諏訪静だけ。**

**そして五人のうち三人が、大規模破壊を持っていない。** 諏訪静（近接概念制圧）、呪術系（近接）、式神操作系（借りた天使が主戦力）。**A級は面を焼く段ではない**ということが、名簿の側からも出ている。

**もう一つ、名簿から見えていること。** **五人のうち二人が呪術系で、二人が長命。** **そして四人が、自分以外の何かを手札にしている** —— 天使、祖先の幽霊、神降ろし、そして先祖からの契約。

> **A級の強さは、本人だけで完結していないことが多い。**

**専門で切れないオールマイティー型。** 近〜遠の万能型に超強力な催眠が乗り、**旧家の秘匿術式まで使える。**

**現在の身分は未確認。** 死んだままなのか、復帰したのか。

### 式神操作系の術者 — 地区不明

**天使を複数連れている。**

#### 大っぴらに使ったのは、百鬼夜行が初

**[[event:hyakki-yako-attempt]] まで、表立って天使を出していない。**

**「露見していなかった」とは書かれていない。** **それ以前に知られていたのか、使っていたのかは不明。** **開けて使ったのが、あの決戦が最初というだけ。**

**呪術系の死者蘇生（一度も使われていなかった）とも、現実改変（存在ごと知られていなかった）とも、出方が違う**（→ [[event:hyakki-yako-attempt]] の「手札が、三つ表に出た」）。

#### 操作技術そのものは、突出していない

**式神操作系のトップ層の中では、横ばい相当。**

**C級にも、同等くらいの操作技術を持つ者がいる。**

**A級との差はこの三つ。**

| | |
|---|---|
| **本人の出力量** | |
| **知謀** | **何よりここ** |
| **賭けと勝負事** | **死ぬほど強い** |

**[[concept:grades]] の「A級が大企業の社長なら、E級は町工場のベテラン職人」が、そのまま出ている。** **金（出力）の動きが違うだけで、ベテランはベテラン。** **技術の高さと等級は、別々に動く。**

**そして判明している三人が、三通りの上がり方をしている。**

| | 何が突出しているか |
|---|---|
| [[char:suwa-shizuka]] | **一つの技術。**圧縮が、戦闘とA級札製造の両方を支えている |
| 催眠系の術者 | **範囲。**専門で切れないオールマイティー |
| **この術者** | **技術以外。**出力量、知謀、勝負強さ |

> **A級に上がる道は、一本ではない。**

#### 同時に扱えるのは3〜4体

**これは式神操作系の最上位相当。**

**そして同時に、通常の範囲内でもある。** **突出した数ではない。**

**操作技術が横ばいなのと、同じ話**（上記）。**この人物は、式神操作系としては上限に届いているが、上限を超えてはいない。**

##### 数えているのは「同時に操作している数」

**契約数でも、保有数でもない。**

**式神にしたうえで野放しにしておく手法があり、そちらは枠に数えられない**（→ [[concept:legal-status]]）。**野へ放つことも、大人しくさせておくことも含めて、操作していなければ枠の外。**

**この手法が無ければ、そもそも大量の式神を抱えられない。**

**だから [[char:aramaki]] も同じ枠の中にいる。** **あちらは人工式神を五体持っているが、同時に展開しているのは同じ上限の内側。**

| | 保有 | 同時 |
|---|---|---|
| **[[char:aramaki]]**（B級） | **5体** | **常時2体。無理をすれば3体** |
| **この術者**（A級） | 天使を複数 | **3〜4体** |

**差はある。ただし一段ぶん。** **B級が2〜3で、A級の最上位が3〜4。**

**桁では離れていない。** **[[char:aramaki]] が無理をしたときの数と、A級最上位の下限が同じ3になる。**

##### 数より、格の差のほうが大きい

**[[char:aramaki]] の五体はB級相応の身体能力のみで、現象性を持たない。** **この術者の天使は一体ずつがA級相当。**

**同時に出せる数はほぼ倍にもならないのに、一体あたりの格が段違い。**

> **等級は、数ではなく規模に効いている。**

**[[concept:grades]] の「等級は動かす力の規模であって、練度ではない」が、ここでも同じ形で出ている。**

##### 晴明は12体

**[[concept:legal-status]] の十二天将。** **現代の最上位が3〜4なので、その3倍前後。**

**桁が違うわけではない。** **同じ技術の延長線上で、三倍ほど遠いだけ。**

#### 何を連れているのか

**天使は、この世界では妖怪**（→ [[concept:kami]]）。**神と妖怪を分ける線が最初から無いので、天使も同じ枠に入る。**

| | |
|---|---|
| **通常時** | **一人一人がA級相当** |
| **完全解放時** | **特殊A級相当** |

**A級相当を複数、常時連れている。**

**[[concept:grades]] の「A級18体」がどう数えられているのかに、そのまま刺さる。** **借り受けたものが日本の18体に入るのかどうかは未確認。**

#### そのA級相当は、出力制限0.1%の話

**絞られている。**

> **天使「出力制限0.1%です」**
> **術者「ケチケチしないで10%くらい申請出せないのか？」**
> **天使「それだと日本が消滅しますね」**

**こういうやりとりがある**（会話の一例）。

**つまり、**

| 出力 | |
|---|---|
| **0.1%** | **A級相当。**常時この状態 |
| **10%** | **日本が消滅する** |
| **100%** | **完全解放。制度上は「特殊A級相当」** |

##### 等級の物差しが、下端しか見ていない

**0.1%でA級相当なのだから、100倍でも国が消える。**

**そして完全解放は、その1000倍。**

**「完全解放時には特殊A級相当」という格付けは、制度がそう呼んでいるだけ。** **[[concept:grades]] の特殊A級が「通常の等級体系では評価困難な妖怪に対する国際特別管理分類」であるというのは、まさにこういう相手のこと。** **測れないから、そう呼んでいる。**

> **A級18体という数え方に入る入らない以前に、この物差しでは目盛りが足りていない。**

##### 申請が通らない理由が、もう一つある

**貸主の判断だけではない**（下記）。

**天使の側も止めている。**

**術者は「10%くらい出させろ」と言い、天使は「それだと日本が消滅します」と返している。** **借り手のほうが軽く、貸し出されている側が現実的。**

**この会話が、この人物の性格をよく表している。** **賭けと勝負事に死ぬほど強い**（下記）**というのは、こういうところにも出る。**

#### 出力は、相手が誰かで動く

**0.1%は固定値ではない。**

| 相手 | |
|---|---|
| **明らかに悪、あるいは悪い存在** | **出力が上がる** |
| **そうでない相手** | **出力が下がる** |

**ただしこれは、通常出力（0.1%）の範囲内での変動。** **悪を相手にしたから完全解放へ近づく、という話ではない。**

##### 伝承拘束が、そのまま出力式になっている

**天使は「悪を討つもの」として想われてきた。** **その核が、そのまま性能に出ている**（→ [[concept:core-layer]] の伝承拘束）。

> **伝承通りだから強い。そして、伝承通りにしか強くない。**

**[[event:hyakki-yako-attempt]] の死神が「死を適用する」以外をやらないのと、同じ形。** **相手を選ばないのではなく、相手によって出方が変わる。**

##### だから、日本の実務とは噛み合いにくい

**この国の超常業務の大半は、悪を相手にしていない。**

**土地神との調整。協力妖怪との関係。妖怪の里との契約。逃しポイントの維持。** **どれも「悪い存在」を殴る仕事ではない。**

**そもそも妖怪には罪がない**（→ [[concept:legal-status]]）。**善悪で裁かれる枠の外にいる。** **人間の法が及んでいない相手を、天使の基準は「悪」と判定するのか。**

**逆に、噛み合う相手もいる。** **犯罪者A級**（→ 上記）。**裏市場。無免許の術者。** **[[concept:relics]] の御手杵で変質した使用者。** **人間の側の悪のほうが、判定は素直に通りそうに見える。**

> これは repo 側の読み。**「悪い存在だと出力が上がる」までが確定で、何を悪と判定するかは書かれていない。**

##### 実務的には、ほぼ使えない切り札

**完全解放は、あっても使えない。**

**A級相当で足りない相手が出たとき、次の段が「日本が消滅する」の側にしかない。**

**[[concept:relics]] の三種の神器と、同じ形をしている。** **持っているが動かせない。** **そして動く時点で、通常の事件ではない。**

#### 借りている

**作ったのでも、調伏したのでもない。**

**[[char:aramaki]] の人工式神とは、まったく別のもの。**

| | |
|---|---|
| **[[char:aramaki]]**（B級） | **五体の人工式神。製造したもの** |
| **この術者**（A級） | **天使。借り受けたもの** |

**式神操作系でありながら、手札の出どころが自分の外にある。**

#### 貸主は、神

> **何故か召喚術で神を召喚し、何かしらの方法か交渉で天使を借り受けている。**

**召喚されている神は、ヤハウェと思われる。**

**断定されていない。** そして**なぜそれが可能なのかも分かっていない。**

**[[concept:grades]] のA級の方向性に「神格接続」がある。** **この術者がそれ。** [[char:suwa-shizuka]] の神降ろしとは別の形の神格接続になる。

##### 申請は、大抵通らない

**完全解放には、神の側の許可が要る。**

**そして大抵は下りない。**

> **借りた側が自由に使えるのは、A級相当まで。**
> **特殊A級相当の権限は、貸主が握ったまま。**

**これが [[concept:kami]] の「神格を万能解決装置にしない」の、具体的な形になっている。** **神は応じる。ただし毎回は許さない。**

**交渉相手として振る舞っているということでもある。** **召喚できることと、思い通りになることは別。**

##### 勝負強さと、無関係には見えない

**「何かしらの方法か交渉で借り受けている」の交渉が、そのまま勝負事だという読みができる。**

**操作技術で抜きん出ているわけではなく、突出しているのは知謀と勝負強さのほう**（上記）。**そして相手は、申請を大抵は通さない神。**

**通らない申請を、それでも通させている人間**ということになる。

> ただしこれは repo 側の読み。**出典にあるのは「何かしらの方法か交渉」までで、それが賭けなのかは書かれていない。**

##### 天使は、神とは別個体

**ここが重要。**

**天使は神の一部でも、出力でも、端末でもない。** **それぞれが独立した個体。**

> **神の力がどれだけ疲弊していても、関係ない。**

**だから貸すことは、神の消耗にならない。**

**[[concept:kami]] の半禁忌の仮説** —— **「現代欧州文明は、神の力をほぼ100%、人類保護へ変換し切っているのではないか」** —— **が仮に本当だったとしても、天使の貸与には影響しない。**

**繋がらない話だった。** 貸せる余力がどこから出ているのか、という問いは立たない。

###### だから「通らない」のは、判断のほう

**申請が下りないのは、残量の問題ではない。**

**出せるのに出さない。**

**これで [[concept:kami]] の「神格を万能解決装置にしない」が、もう一段はっきりする。** **力が尽きているから助けに来ないのではなく、来るかどうかを決めている。**

> **神は、交渉相手として振る舞っている。**

**[[concept:core-layer]] の群体性とも切れている。** **天使が神の端末なら群体として扱えるが、別個体なので扱えない。** **一人一人がA級相当というのは、そういう意味の「一人」。**

##### 外交的には、相当な話

**[[concept:overseas]] では、ヤハウェや仏陀を「妖怪」と呼ぶだけで国際問題級とされ、自粛されている。**

**日本の地区長が、そのヤハウェを召喚して天使を借りている。**

**呼び方を自粛している相手を、実際に呼び出して使っている**ということになる。**これが国際的にどう扱われているのかは未確認。**

### 呪術系の術者 — 地区不明

**日本の呪術のエキスパート。近接戦闘を得意とする。**

**そして大規模破壊攻撃は、あまりできない。**

**[[char:suwa-shizuka]] と同じ型。** **A級でありながら、面を焼く能力を持っていない。** [[concept:grades]] の「搦手に寄ったA級には、ビル破壊能力がなかったりする」の実例が、これで二人になった。

#### 強さの出どころが、本人ではない

**先祖から技術と力の継承を行うことで、A級相当のスペックと技量を持つ。**

**何かしらの血族的な契約。** **親から、第一子の嫡男へ受け継がれる。**

**相手が誰なのかは分かっていない。**

##### だから、血統に種としての価値がほぼない

**ここが構造的に効いている。**

**この人物が強いのは、契約による上乗せがあるから。** **本人の血が優れているからではない。**

> **A級退魔師の子だからといって、A級の素質を持つわけではない。**

**そして実証がある。**

**[[concept:grades]] のB級最上位だった妻とのあいだに子を儲けた。** **A級（契約込み）とB級最上位の子。**

**その娘は、どれだけ努力してもC相当にしかならなかった。**

**母より下。** **上乗せぶんを引いた素の血が、そこにあったということになる。**

#### 日本で唯一、死者蘇生を持っている

**現在、この人物ただ一人。**

**秘術中の秘術。**

##### 世界が知ったのは、五年前

**初めて使われたのが [[event:hyakki-yako-attempt]]。** **そこで世界から注目された。**

**キリスト教圏でも「そんな事が」と驚かれる水準。** **世界的にレア。**

**[[concept:overseas]] のキリスト教圏は、10億人規模の信仰を貯めて再分配し、[[event:belzebub-war]] では特殊A級相当を討伐している。** **その圏が驚いている。**

##### 事前準備が、かなり面倒

**使うこと自体より、そこまでが重い。**

**そして [[event:hyakki-yako-attempt]] のときは、準備を済ませてあった。**

> **A級札として残してあり、使うだけなら瞬時に使える状態で保有されていた。**

**[[concept:jugu]] の理屈そのもの。** **A級の出力を、置いておける物に換えて溜める。** **国家備蓄霊札が「A級退魔師を缶詰にしたもの」であるのと、同じ形。**

**違うのは中身。** **あちらは撃つための札で、こちらは戻すための札。**

**[[concept:battle]] のA級の分野一覧に、この項目は無い。** 国家級封印、広域結界、神格接続、戦略級札製造、認識災害、近接概念制圧、高位交渉、国家級情報戦、特殊A級近傍監視。**どこにも入っていない。**

**「その分野の第一人者」ですらない。** **分野に一人しかいない。**

> **[[faction:reimusho]] の実務は「その分野のB級を呼ぶ」で回っている。**
> **この分野には、呼べる相手が一人しかいない。**

##### 死後については、確定させない

**この能力があることは、死後の構造が判明していることを意味しない。**

**天国、地獄、冥界、輪廻、成仏、魂の消滅** —— **どれも一つに統一しない**（→ `docs/02-canon-policy.md` の「確定してはいけないこと」）。

**蘇生できることと、どこから戻しているかが分かっていることは、別。**

#### 娘には継げない

**契約は第一子の嫡男へ渡る。** **娘は対象に入っていない。**

**そして妻は、早くに病で亡くなった。**

**本人は妻を愛していたので、新しく結婚する気がない。** **嫡男を得る道は、閉じている。**

##### 妻は、死んだままでいる

**日本で唯一の死者蘇生の持ち主の妻が、病で死んで、そのままになっている。**

**理由は、たぶん準備。**

**この秘術には、かなり面倒な事前準備が要る**（上記）。**妻のときには、それを行えなかったと見られている。**

**病死だった。** **そして準備は、間に合う種類のものではなかったらしい。**

**[[event:hyakki-yako-attempt]] のときは、A級札として済ませてあった。** **五年前には、瞬時に使える状態で持っていた。**

> **持っていなかったときに死なれ、持つようになってから使った。**

**「多分」がついている。** **確定した理由ではない。**

##### それでも、閉じてはいない

**準備が間に合わなかったことは、今も戻せないことの説明にはなっていない。**

**今は札として持っている。**

**時間が経ちすぎているのか、対象に条件があるのか、本人が選んでいないのか。** **そこは書かれていない。**
