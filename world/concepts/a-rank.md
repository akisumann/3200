## 概要

**人間側のA級は、現在18人。**

**等級の制度そのものは [[concept:grades]]。** ここは**誰がその席にいるか**を置く。

**一人ひとりが個人として数えられている規模。** 統計上の区分ではなく、**全員が把握され、おそらく名前も顔も知られている。**

**育っても書き足りなくなったら `characters/` へ切り出す。**

| **神社・旧家**（[[faction:shrines]] / [[faction:old-houses]]） | **6** |

**対等な三者が拮抗しているのではない。** **一つの源流と、そこから分かれた二つ**がこの形に落ち着いている（→ [[faction:shrines]]）。

**そして流動が激しい。** 三系統は互いに引き抜き合っていて、**この均衡は静止した構図ではない。**

### 犯罪者もこの中にいる

**三系統のどこかに「裏の側」があるわけではない**（→ [[concept:taimashi]]）。**だから三系統のどれにも安全な側が無い。**

**18人という数の中に、そういう者が混じっていておかしくない。**

**天使を複数連れている。**

#### 操作技術そのものは、突出していない

**式神操作系のトップ層の中では、横ばい相当。**

**C級にも、同等くらいの操作技術を持つ者がいる。**

**A級との差はこの三つ。**

| | |
|---|---|

**[[concept:grades]] の「A級が大企業の社長なら、E級は町工場のベテラン職人」が、そのまま出ている。** **金（出力）の動きが違うだけで、ベテランはベテラン。** **技術の高さと等級は、別々に動く。**

**そして判明している三人が、三通りの上がり方をしている。**

> **A級に上がる道は、一本ではない。**

#### 何を連れているのか

**天使は、この世界では妖怪**（→ [[concept:kami]]）。**神と妖怪を分ける線が最初から無いので、天使も同じ枠に入る。**

| | |
|---|---|

| **完全解放時** | **特殊A級相当** |

**A級相当を複数、常時連れている。**

**[[concept:grades]] の「A級18体」がどう数えられているのかに、そのまま刺さる。** **借り受けたものが日本の18体に入るのかどうかは未確認。**

#### 借りている

**作ったのでも、調伏したのでもない。**

**[[char:aramaki]] の人工式神とは、まったく別のもの。**

| | |
|---|---|
| **[[char:aramaki]]**（B級） | **五体の人工式神。製造したもの** |
| **この術者**（A級） | **天使。借り受けたもの** |

**式神操作系でありながら、手札の出どころが自分の外にある。**

#### 貸主は、神

> **何故か召喚術で神を召喚し、何かしらの方法か交渉で天使を借り受けている。**

**召喚されている神は、ヤハウェと思われる。**

**断定されていない。** そして**なぜそれが可能なのかも分かっていない。**

**[[concept:grades]] のA級の方向性に「神格接続」がある。** **この術者がそれ。** [[char:suwa-shizuka]] の神降ろしとは別の形の神格接続になる。

##### 申請は、大抵通らない

**完全解放には、神の側の許可が要る。**

**そして大抵は下りない。**

> **借りた側が自由に使えるのは、A級相当まで。**
> **特殊A級相当の権限は、貸主が握ったまま。**

**これが [[concept:kami]] の「神格を万能解決装置にしない」の、具体的な形になっている。** **神は応じる。ただし毎回は許さない。**

**交渉相手として振る舞っているということでもある。** **召喚できることと、思い通りになることは別。**

##### 勝負強さと、無関係には見えない

**「何かしらの方法か交渉で借り受けている」の交渉が、そのまま勝負事だという読みができる。**

**操作技術で抜きん出ているわけではなく、突出しているのは知謀と勝負強さのほう**（上記）。**そして相手は、申請を大抵は通さない神。**

**通らない申請を、それでも通させている人間**ということになる。

> ただしこれは repo 側の読み。**出典にあるのは「何かしらの方法か交渉」までで、それが賭けなのかは書かれていない。**

##### 天使は、神とは別個体

**ここが重要。**

**天使は神の一部でも、出力でも、端末でもない。** **それぞれが独立した個体。**

> **神の力がどれだけ疲弊していても、関係ない。**

**だから貸すことは、神の消耗にならない。**

**[[concept:kami]] の半禁忌の仮説** —— **「現代欧州文明は、神の力をほぼ100%、人類保護へ変換し切っているのではないか」** —— **が仮に本当だったとしても、天使の貸与には影響しない。**

**繋がらない話だった。** 貸せる余力がどこから出ているのか、という問いは立たない。

###### だから「通らない」のは、判断のほう

**申請が下りないのは、残量の問題ではない。**

**出せるのに出さない。**

**これで [[concept:kami]] の「神格を万能解決装置にしない」が、もう一段はっきりする。** **力が尽きているから助けに来ないのではなく、来るかどうかを決めている。**

> **神は、交渉相手として振る舞っている。**

**[[concept:core-layer]] の群体性とも切れている。** **天使が神の端末なら群体として扱えるが、別個体なので扱えない。** **一人一人がA級相当というのは、そういう意味の「一人」。**

##### 外交的には、相当な話

**[[concept:overseas]] では、ヤハウェや仏陀を「妖怪」と呼ぶだけで国際問題級とされ、自粛されている。**

**日本の地区長が、そのヤハウェを召喚して天使を借りている。**

**呼び方を自粛している相手を、実際に呼び出して使っている**ということになる。**これが国際的にどう扱われているのかは未確認。**
