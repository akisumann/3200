## 概要

**人間側のA級は、日本全体で現在おおむね二十人弱。**

厳密な定員ではない。昇格、死亡、引退、封殺などで多少は増減するが、**一人ひとりを名前で把握できるほど少ない**。

**まず、全員バカ強い。**

> **強くないA級は存在しない。**

分野が違っても、搦手に寄っていても、そこは変わらない。**等級の物差しが火力だけを見ていない**（→ [[concept:grades]]）というのは、弱いA級がいるという意味ではない。

## 三系統に、だいたい三分の一ずつ

A級は大きく、次の三系統に散っている。

| 系統 | 規模感 |
|---|---|
| **国**（[[faction:reimusho]]） | **六地区長を中核に、六人前後** |
| **神社・旧家**（[[faction:shrines]] / [[faction:old-houses]]） | **同程度** |
| **民間**（[[concept:taimashi]]） | **同程度** |

**きっちり三等分されているわけではない。** 二十人弱しかいないため、一人が移籍するだけでも比率はかなり動く。

それでも長い目で見ると、国・神社旧家・民間に**なんとなく三分の一ずつ**いる形になっている。

これは制度で配分しているからではない。**一つの源流から国と民間が分かれ、現在も三系統の間で人材が動き続けている結果**（→ [[faction:shrines]] / [[concept:taimashi]]）。

### 犯罪者もこの中にいる

三系統のどこかに「裏の側」があるわけではない（→ [[concept:taimashi]]）。だからどの系統にも犯罪者が混じりうる。

**二十人弱という少人数の中にも、そういう者がいる。**

## 国側A級の中核 — 六地区長

**六地区長は、必ずA級を据える。**

これは三系統の人数配分とは別の話。地区長は各地区の行政責任者であると同時に、**その地域の最終防衛戦力**でもあるため、B級以下で代用するという選択肢がない。

> **地区長の席が空いたら、他のA級配置より先に埋める。**

死亡、封殺、失踪などで地区長が抜けた場合は、まず別のA級を暫定で据え、その後に正式な人事を整える。**運用上「地区長不在」の状態は作らない。**

霊務省内だけで足りなければ、神社・旧家や民間のA級へ打診し、転籍・出向・兼任を含めて確保する。だからA級の三系統比率は固定されない。

> **この一件そのものが、三系統の人数が固定されていない例。**

### 六地区長の選抜

地区の性格や専門より先に、まずA級であることが絶対条件（→ [[faction:reimusho]]）。

そのうえで指揮、結界管理、調整などの公職要件がある。要件が足りない実力者については、外すより**教育して使う**のが霊務省の基本姿勢。

### 賀茂玄と黒沢明のあいだに、事件の前から棘がある

[[loc:oeyama]] は [[char:kamo-gen]] の管内。

そこは「特殊A級の本拠だが、本人の所在が不明」の山として台帳に載っている。

その所在不明の当人を、[[char:kurosawa-akira]] が使役していた。

> **隣の地区長の管内で、台帳の穴になっている個体を、黙って抱えていた。**

そして [[event:hyakki-yako-attempt]] で、この二人が独立に動いて黒幕を炙り出している。

### [[char:shinohara-kyo]] — 元東北地区長

[[char:shinohara-kyo]] は [[event:hyakki-yako-attempt]] の黒幕で、現在は封殺されている。

**封殺された時点で東北地区長の職は失い、後任が直ちに据えられた。**

そのため、事件後に「東北だけ地区長が何年も空いている」という状態は存在しない。

## A級に上がる道は一本ではない

A級の強さは一種類ではない。

| | 何が突出しているか |
|---|---|
| [[char:suwa-shizuka]] | **一つの技術。**圧縮が、戦闘とA級札製造の両方を支えている |
| [[char:mimura-sumi]] | **範囲。**専門で切れないオールマイティー |
| [[char:kurosawa-akira]] | **技術以外。**出力量、知謀、勝負強さ |
| [[char:naruse-cecile]] | **一点。**超火力 |
| [[char:kamo-gen]] | **継承。**契約による大きな上乗せ |
| [[char:shinohara-kyo]] | **隠していた。**表向きの等級評価と別に現実改変を持っていた |

**[[char:mimura-sumi]] と [[char:naruse-cecile]] が正反対の極にいる。** 幅で上がった者と、一点の突出で上がった者が、同じ段にいる。

そしてこれは「弱点を一個ずつ持っている」という意味ではない。**全員がそれぞれ別の形で、A級らしく圧倒的に強い。**

### [[char:nasu-mio]] — 特殊A級近傍監視

そこそこの規模の神社を持っている家の、次期当主。当主はまだ先代で、力と実務のほうがこの人物に移っている。

家の役目として、[[char:tamamo-no-mae]] を封じている殺生石の監視を持っている。そして近くの天狗系の里の外部窓口も。神通力の技術は、その里から教わっている。

ただしこの役目は、ほぼ形だけ。封印は手入れが要らず、何百年も何も起きていない。定期に天眼通で見て、変わりないと報告する。それだけ。

> **家の格を保証する由緒ではあるが、日々の仕事ではない。**
> **生活の大半は神社のほう。**

それでも、中を見られるのはこの人物しかいない。封じた技術はこの家に伝わっておらず、緩んでも掛け直せない。

詳細は [[char:nasu-mio]]。

### [[char:mononobe-akari]] — 国家級封印

封印系のカード使い。妖怪も、飛んできた攻撃も、起きている現象も、同じように札へ封じて束で持ち歩いている。

対象も大きさも選ばない。妖怪の個体も、台風も入る。

入れ方は、「名前のある何か」を指定して、そこに触れること。触れている一点は入口でしかなく、入るのは名前が指す範囲の全部。

> **「〇〇街」を指定すれば、街の端の地面に触れるだけで、街ごと回収できる。**

弱らせる必要も、止める必要もない。元気なまま入る。

出し方は札を切ること。使役ではないので、出したものは言うことを聞かないが、出す位置や方法を選べるため、そのまま武器にもなる。

| 封じるもの | 出し方 |
|---|---|
| **大地** | **隕石のように落とす** |
| **大海** | **ウォーターカッター** |
| **酸素だけ** | **大爆破** |
| **熱量だけ** | **灼熱熱波** |
| **敵の攻撃** | **防御になり、そのまま攻撃返しになる** |
| **一区画の土地ごと** | **民衆を守ったまま、輸送する** |

そして封印だけの人ではない。複数の呪具を状況に応じて使い分け、武芸は概ね百般。得意なのは、相手の弱点を当てる戦法。

家は封印系の名家で、本人が封印法をさらに改良し、名前そのものに強く関連づけた方式を作り出している。

詳細は [[char:mononobe-akari]]。

### [[char:inbe-haruka]] — 広域結界

神社の網が、そのまま結界の骨組みになっている。

できるのは、都市圏規模の面を数時間で張ること。そして中の出入りと、術の通り方を書き換えること。

詳細は [[char:inbe-haruka]]。

### 鵜飼睦 — 高位交渉

妖怪の里との契約、土地神との調整。[[concept:cooperation-policy]] の協調路線を現場で成立させている側。

できるのは、その場で契約を成立させること（→ [[concept:core-layer]]）。

> **相手を戦わせずに終わらせられる。**

### 斎木惺 — 逃しポイントから公職へ

もともとは [[concept:release-points]] の網を維持する神社・旧家側のA級。

できるのは、土地の口を開けること、閉じること、繋ぐこと。戦闘では相手を戦場から抜いて落とす。

[[char:shinohara-kyo]] の封殺後、**地区長を空席にしない原則によって霊務省へ移り、東北地区長に就任した。**

この移籍で、神社・旧家側と国側のA級人数はその時点で一人ぶん動いた。**それでも長期的には三系統がおおむね三分の一ずつ、という程度の分布に収まっている。**

### 薬師寺凪 — 医療・浄化

[[concept:battle]] のB級専門分野にある「医療浄化」のA級側。

できるのは、戻すこと。呪い、変質、憑依、汚染を巻き戻す。

## 民間側の主なA級

産業の側にいる（→ [[concept:taimashi]]）。

**以下も主な人物の一覧であって、「民間は必ず六人」という意味ではない。**

| 名前 | **何ができるか** | 所属 |
|---|---|---|
| **[[char:shibasaki-kei]]** | **半径数メートルの現実改変。**見て、合わせて、作る | **無所属** |
| **有坂 湊** | **情報空間の側で戦う。**ネット系妖怪を使役し、認識災害を隔離して潰す | 雷紋通信 |
| **綾部 巧** | **建てる速さ。**恒久結界を現場で組む。戦闘中に即席の要塞を作れる | 大成霊建 |
| **檜山 穣** | **地脈を読み、付け替える。**土地の側と契約する（→ [[concept:land-god]]） | 豊科アグリ |
| **宗像 累** | **群を管理する。**危険な妖怪が数百集まる場を、事故なく回す | 宵市 |
| **柏木 蓮** | **作る。**A級呪具を作れる数少ない一人（→ [[concept:jugu]]） | 柏木呪具工房 |

A級だから退治をしている、ということにはなっていない。情報、建設、農業、興行、製造など、**A級の力そのものが産業の中へ入っている。**

### 宗像累は、百鬼夜行の逆をやっている

[[event:hyakki-yako-attempt]] で妖怪連合が崩れたのは、火力差だけでなく統制の問題でもあった。

この人物がやっているのは、危険な妖怪が数百集まる会場を事故なく回すこと。[[char:shinigami-idol]] の巡業もそれで成立している。

### 柏木蓮は、犯罪者A級

表向きは民間の呪具工房の主で、正規のA級として把握されている。実際には裏市場の流通を握っている。

[[faction:reimusho]] は把握していない。**A級名簿には正規のA級として載っている。**

### [[char:shibasaki-kei]] — もう一人の現実改変能力者

[[event:hyakki-yako-attempt]] の決着をつけた人物。半径数メートルの現実改変で、[[char:shinohara-kyo]] を封殺した。

国から地区長就任を打診されたことはあるが、断固拒否している。

> **地区長は必ずA級だが、特定の一人を強制的に就任させる制度ではない。**

断られれば、別のA級をすぐに据える。それが斎木惺だった。
