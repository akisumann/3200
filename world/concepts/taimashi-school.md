## 概要

退魔師を育てる専門の学校。**高校からある。日本に6校。**

**D級以上の退魔師は、概ねここの出身。**

そして**学校そのものが、管理された逃しポイントの上に建っている。**

課程は**共通基礎（1年）→ 分業（2年）→ 専門化と進路接続（3年）**の三段階。入学の目安は**E級相当以上**。一学年450人で、**支援300・戦闘150**。**D級になって出るのは戦闘の150人だけで、支援の300人はE級のまま卒業する。**運営は霊務省の直営ではなく、**古社・旧家・自治体・民間企業・土地神関係者が関与する複合機関**になっている。

## 仕組み

### 6校は、地区に一つずつ

| 地区 |
|---|
| **東北** |
| **関東** |
| **中部** |
| **近畿** |
| **中国四国** |
| **九州** |

**これは [[faction:reimusho]] の地区区分とそのまま同じ。** 学校が6校あるのは偶然ではなく、**超常行政の区割りが、そのまま教育の区割りになっている**。

だから**「6校のどれの出身か」は、「どの地区の人間か」とほぼ同義**になる。地区の霊務局、地区の古社と旧家、地区の民間企業、地区の土地神 — 学校を出た人間は、その地区の超常社会にそのまま組み込まれる。

### 一校が毎年送り出すのは450人。うち支援300、戦闘150

**これは科の定員ではなく、卒業時の進路の内訳。** 進路は**支援と戦闘の二つだけ**で、E級で出れば支援、D級で出れば戦闘（→ 下記「戦闘科がある」）。

| | 1校（毎年） | 6校合計（毎年） |
|---|---|---|
| **支援へ** | **300人** | **1,800人** |
| **戦闘へ** | **150人** | **900人** |
| 計 | **450人** | **2,700人** |

**一校の全校生徒はおよそ1,350人。** これは日本の普通の高校とほとんど同じ規模。特別な機関でありながら、**建物の大きさとしてはそこらの高校と変わらない。**

**そして戦闘へ行くのは150人。全体の3分の1でしかない。** 支援がその倍。**「戦闘は仕事のうちの一つでしかない」ということが、進路の数字にそのまま出ている**（→ [[concept:taimashi]]）。

#### D級は毎年900人生まれる

**戦闘の進路に進む者は、卒業時に概ねD級として扱われる。** つまり**一校あたり毎年150人、全国で毎年900人のD級**が世に出る。

**ここで既存の数字と噛み合う。** D級以上の人間は全国で22,218人（→ [[concept:grades]]）。毎年900人入ってくるということは、

> **22,218 ÷ 900 ＝ 約25年**

**D級以上の層は、25年ほどで丸ごと入れ替わる計算になる。** 18歳前後で出て、40代半ばで抜ける。**この職業がかなり危険で、しかも三系統の間で流動が激しい**（→ [[concept:taimashi]]）ことを考えると、無理のない滞留年数。

#### 支援300人は、普通にE級

**上がらない。** 支援に進んだ300人は、卒業時もE級。

等級は単純火力指数の平均（→ [[concept:grades]]）なので、当然といえば当然。**結界を張れても、呪具を作れても、憑かれた人を診られても、火力は増えない。**

つまり**卒業生の3分の2は、E級のまま社会に出て、E級のまま働く。**

**これで「A級はE級を蔑んだりしない」の意味が変わる。**

> **A級が大企業の社長だとするなら、E級は町工場のベテラン職人のようなもの。**

**気風の話ではなかった。** 三年の専門教育を受けた実務者の3分の2が、E級だから。E級を見下す社会は、自分の医療も呪具も結界も交渉も見下すことになる。**等級が序列として使われていないのは、そうでないと社会が回らないから。**

そして [[concept:taimashi]] の「E級は町工場のベテラン職人」という言い方の**「ベテラン」**が、ここで実体を持つ。**E級には、E級として一生を積み上げていく道がある。**

### 6校は同じ大きさ

**450人という定員は、地区の人口とは関係がない。** 関東と東北で人口は5倍近く違うのに、**学校はどちらも450人。**

**つまり定員は、需要ではなく学校の側の限界で決まっている。** 土地神が統制できる範囲、逃しポイントの供給量、実習枠、教員の数 — 抱えられる量が先にあって、そこから450という数が出ている。

**結果として、地区ごとの手厚さはまるで違うことになる。** 同じ900人のD級が、人口の35%を抱える関東にも、7%の東北にも、同じ150人ずつ配られる。**関東は慢性的に足りず、東北は相対的に手厚い。**

### 校地の構造

| | |
|---|---|
| **土地神** | **学校およびその周辺は、B級以上の土地神が管理している** → [[concept:land-god]] |
| **統制下の妖怪** | **F級〜C級の妖怪は、その土地神に統制されている** |
| **供給源** | **逃しポイントの一部があり、供給は途絶えない** → [[concept:release-points]] |

**これが「教材」の正体。** 学校が妖怪を飼っているのでも、捕まえてきて並べているのでもない。**湧き続ける妖怪を、土地神が統制した状態で校内に抱えている。**

- 供給が途絶えないので、**教材は無尽蔵**
- 湧くものは選べないので、**種類が多種多様**になる
- 土地神が統制しているので、**手に負えないものは出てこない**（F〜C級に収まる）

C級は「超常現象、いわゆる能力が使える」段（→ [[concept:grades]]）。**つまり生徒は在学中に、超常の能力を使う妖怪と相対する。**

### 土地神に頼んで、縄張りを作ってもらう

**校地の土地神やその配下の協力妖怪に力を借りて、安全管理された模擬テリトリーを作る。**

本物の縄張りを完全に再現するものではない。それでも生徒は、**縄張りの中にいるという状態そのもの**を安全な範囲で体験できる。

- **縄張り内での違和感**
- **軽度の人間性侵食**
- 模擬妖怪の索敵、接敵前探索
- 札や結界の使用、退避路の確認
- 班行動、模擬戦闘、報告と撤収

教員、結界、安全装置、そして**協力妖怪自身による監視**が入る。

**ここがこの学校の核心的な仕掛け。** 妖怪の領域という、本来なら死ぬ場所を、**その領域を持っている当人に頼んで、練習用に作ってもらっている。** 檻を借りているのではなく、**捕食者に稽古をつけてもらっている。**

だから対価が「感謝と敬い」で足りる理由も見えてくる。土地神は土地を貸しているだけではない。**自分の能力を教材として供出している。**

### だから現場に出さない

生徒が現場に出ることは出るが、**正直あまり積極的ではない**。

安全のためではない。**必要が薄いから。** 校内で多種多様な実践的学びが得られる以上、わざわざ外へ出す理由がない。

### 学校のほうが危険

**管理されているとはいえ、危険性という点ではそこらの街なんか目じゃない。**

ここがこの設定の要になる。**現場より学校のほうが危険。**

普通の街に湧く妖怪は、散発的で、多くはF級・E級で、湧いても誰かが処理する。一方この学校は、**逃しポイントを抱え、供給が途絶えず、C級まで含む妖怪が常時いる土地**。統制されてはいるが、濃度が違う。

**十代半ばの生徒が、そこらの街より危険な場所で三年間を過ごす。**

### それでも生徒は死なない

**死傷者はほぼない。あったとしても事故レベル。**

ここが重要。**危険なのは環境であって、結果ではない。**

土地神の統制、教員の監督、呪具、校地の設計 — 何が効いているにせよ、**管理は実際に機能している**。プールや理科室や工作機械と同じで、条件が揃えば人が死にうる設備を、死なないように運用している。

**だからこの学校は「子供を危険に晒す場所」ではない。** 社会が子供の死を淡々と受け入れているのでもなく、単に**そこでは死なないように作られている**。

### 濃度は学校が上、死亡率は現場が上

学校と現場では、危険の質が違う。

| | 妖怪の濃度 | 死亡率 |
|---|---|---|
| **学校** | **そこらの街なんか目じゃない** | **ほぼゼロ**（あっても事故レベル） |
| **現場（[[concept:taimashi]] の仕事）** | 散発的 | **かなり危険** |

**差を生んでいるのは統制の有無。** 学校の妖怪は土地神の統制下にあり、等級はF〜Cに収まり、環境も分かっている。現場の妖怪は誰の統制も受けておらず、何が出るか分からない。

**生徒が卒業して失うのは、この統制。** 学校では毎日それより濃い妖怪の中にいたのに、外に出た途端に死ぬ確率が跳ね上がる。

### 土地神は何を得ているのか

**生徒からの、相応の感謝と敬い。** それだけ。

一見すると地味で、「え、それだけ？」となる。**実はとてつもなく強力。**

#### 思念としては、大した量ではない

**生徒の思念そのものは、数が数なので、そんなに足しにはならない。**

妖怪は思念を糧とするが（→ [[concept:shinen]]）、B級以上の土地神を支えるには**数千人規模ではまるで足りない**。何百年も何百万人に想われて成り立つ神々と比べれば、一校分の生徒の敬意など誤差にすぎない。

**対価の本体はここではない。**

#### 本体はコネクション

数字を出すと桁が見える。

| | 全国 | 1校あたり |
|---|---|---|
| D級以上の人間 | **22,218人** | **約3,700人** |
| A・B級 | 218人 | **約36人** |

**6校はどこも毎年150人のD級を出す**（上記）。つまり**きれいに6分の1ずつ**。地区の人口は違っても、**土地神が抱える人脈の量は6校とも同じ。**

**D級以上は概ね6校のいずれかの出身。** ということは、**一つの学校土地神は、国内のD〜A級の約6分の1と面識がある。**

その全員にとって、その土地神は**在学中に世話になり、敬った相手**。卒業後もその関係は残る。

**日本の高等級退魔師の6分の1が、知己であり、コネクションであり、出会いであり、敬いの対象。** A・B級だけでも約36人。

> **生存面でも、その他諸々の工面でも、死ぬほどでかい。**

**生存面**というのが効く。妖怪の死因は、忘れられることと**討たれること**（→ [[concept:youkai-nature]]）。国内の高等級退魔師の6分の1が自分に恩を感じている妖怪を、誰が討ちに来るのか。**それどころか、何かあれば助けが来る。**

**工面のほう**も同じ理屈。頼み事のできる相手が、国内の各所に何千人といる。しかも彼らは霊務省にも神社・旧家にも民間にも散っている（→ [[concept:taimashi]]）。**三系統すべてに顔が利く妖怪**ができあがる。

#### この取引の性格

暴力も脅しも契約書もない。**学校は土地を借り、土地神は人脈を得る。**

思念を対価とする [[concept:kami]] の「神社が神を祀る」型とは、**似ているようで別物**。神社の場合は信仰の規模がそのまま糧になるが、学校の場合は量が足りない。**代わりに、質で払っている。** 敬っているのが誰かということ自体が価値になっている。

**この世界で人間と高位妖怪が結ぶ関係には、少なくとも二つの型がある** — 量で払う（信仰）か、質で払う（人脈）か。

### 戦闘科がある

**学校には科が分かれている。そのうちの一つが戦闘科。**

**戦闘科ではD級になることを目標とし、卒業時には概ねD級として扱われる。**

D級＝戦闘用退魔師（→ [[concept:taimashi]]）なので、**戦闘科の三年間は、そのまま「戦えるようになるまで」の課程**ということになる。目標が等級で明示されているのが特徴的で、卒業要件が**社会共通の物差しで書かれている**。

**そして等級で卒業要件が書かれているのは、戦闘科だけ。** 支援の進路へ行く生徒はE級のまま卒業する（→ 下記「支援300人は、普通にE級」）。

そして**戦闘科は、いくつもある科のうちの一つでしかない**。力を使える人間が全員戦うわけではないので、当然そうなる。結界保守、呪具や霊札の技術、妖怪交渉と契約管理、超常医療と浄化、調査と記録、行政・法規、民間実務、祭祀、研究補助 — このあたりに分かれる（→ [[concept:taimashi]]）。

**ただし科は訓練の区分であって、進路そのものではない。** 卒業時の進路は**支援と戦闘の二つ**で、それは等級の定義に直結している。

| 等級 | 定義 | 進路 |
|---|---|---|
| **E級** | **実務補助**ができる（術式運用、霊障感知、呪具補助、結界補助） | **支援 — 300人** |
| **D級** | **正式実務者**の線 | **戦闘 — 150人** |

**等級がそのまま職種になっている。** どの科で学んだかではなく、**E級で出るかD級で出るかで、就く仕事が決まる。** 科は九つあっても、職種は二つしかない。

**では就職先のほうは何で決まるのか — 教師で決まる**（→ 下記「教師を出す組織と、卒業生を採る組織は同じ」）。

### 三年の形 — 共通基礎、分業、専門化

**課程は三段階でできている。**

| 学年 | 段階 | 何のための年か |
|---|---|---|
| **1年** | **共通基礎** | **危険なことをしないため** |
| **2年** | **分業** | **超常を構造として理解し、専門へ進むため** |
| **3年** | **専門化と進路接続** | **現場・労働・制度・責任へ渡るため** |

**一年目は全員が同じ教室に入る。** 旧家の子も、神社の子も、一般家庭の子も、妖怪と暮らしてきた子も、出自に関係なく同じ基礎を受ける。戦闘の素質が高い生徒にも、まず法規・記録・避難誘導・呪具管理・[[concept:three-monkeys]] を叩き込む。

**二年目で科に分かれる。** ただし完全固定ではなく、入れ替えも兼修もできる。

**三年目でさらに絞られ、そのまま進路になる。**

> **「三年のゼミは半分就職先」**

**この三段階は、学校の都合ではなく社会の側の形。** 共通基礎で最低限の実務言語を全員に配り、分業で人を振り分け、専門化でそのまま各勢力へ渡す。**退魔学校は、現代超常社会の人材供給の装置そのもの**として設計されている。

だから**進路変更は失敗ではない**。戦闘志望だった生徒が呪具や結界の才能を見つけて移ることも、非戦闘志望だった生徒が現場度胸を示して戦闘へ移ることもある。**適性を見誤ったまま危険な現場へ出るほうが問題**なので、学校は進路変更を罰ではなく適性発見として扱う。

### 入学基準はE級相当以上

**入学の目安は「訓練すれば実務補助まで届く」適性 — おおむねE級相当以上。**

つまり**F級は、通常入学では弾かれやすい**。

理由は軽視ではなく、単純な容量の問題。**F級は国内に約200万人いる**（→ [[concept:grades]]）のに対し、6校の定員も教員も実習枠も限られている。倍率の高い選抜では、E級以上や特殊な適性を持つ者に競り負ける。

**ただしF級には別の道がある。**

- 自治体の超常補助職
- 民間企業の低危険度霊障対応の補助
- 呪具工房の事務・補助作業
- 結界管理の軽作業
- 地域の監視協力員、霊障の通報・記録補助
- 霊務局の一般職採用
- 短期講習、資格講座、職場内訓練

**そしてこれが、F級200万人が社会の検知網になっている理由の裏側**（→ [[concept:daily-life]]）。彼らは退魔学校を通っていない。**短期講習と職場内訓練で、病院にも企業にも行政にも入っている。**

例外的に、極めて特殊な感知適性、希少な契約適性、呪具や素材の専門適性、旧家・古社の継承事情、地域の封印との関係などがあれば、F級でも特別推薦や個別審査で入ることがある。**あくまで例外。**

年齢は幅がある。適性の発見時期が家系・霊障接触・契約・土地・後天的な覚醒でばらばらだから、10歳以下の早期入学も、20代後半以降の入学もありうる。**ただし実際には10代後半から20歳前後に集中している** — 日本の一般的な進学・就職の風潮がそのまま効いている。

### 生徒から見た等級の景色

**生徒はE級相当で入り、3分の1がD級で出る。** その物差しで見ると、等級は生徒にとってこう見えている。

| 等級 | 生徒の感覚 |
|---|---|
| **F** | 適性はある。まだ一般人寄り。通常入学では弾かれやすい |
| **E** | **入学基準の中心。**そして支援へ進めば、卒業時もここ |
| **D** | 戦闘用退魔師の線。**戦闘科の卒業目標** |
| **C** | **学年トップ層。**実戦エリート候補 |
| **B** | **学生から見ると化け物** |
| **A** | **教科書とニュースの中の存在** |

**社会全体の等級観（→ [[concept:grades]]）とはずれている。** 世間ではA級とE級に上下がないことになっているが、**十代の生徒にとってB級は化け物で、A級は教科書の登場人物**。等級を序列として体感しているのは、実はこの三年間の中だけかもしれない。

そして**卒業時のD級は、D級の入口でしかない**。地域に常駐する熟練のD級と同じ経験を持っているわけではない。

### 出自の混ざり方

生徒は一種類ではない。

| 出自 | |
|---|---|
| **一般家庭** | 適性検査や偶発的な霊障接触で入ってきた。現代感覚に近く、しがらみがない。**祭祀作法も呪具知識も家系の支援もない** |
| **旧家・古社** | 幼少期から術式・祭祀・契約に触れている。**初期能力は高いが、家の義務と継承圧と一族の面子に縛られる** |
| **神社・寺社系** | 結界維持、浄化、土地調整、地域祭祀に向く |
| **民間超常企業の関係者** | 親族が呪具工房や霊障対策会社にいる。**効果より、費用・保守・納期・事故時の責任・保険を気にする** |
| **妖怪契約家庭・半妖怪圏** | 妖怪との距離が近すぎて、**人間側の法律や学校の安全基準より地域の慣習を優先して怒られる** |

**この混在そのものが学校の機能。** 旧家の当たり前が一般家庭には意味不明で、一般家庭の現代感覚が古社出身者には雑に見える。**退魔学校は、出自の違う人間に、超常社会で働くための共通言語を配る場所**ということになる。

### 誰が学校を持っているのか

**霊務省の直営ではない。**

[[faction:reimusho]] と地区の霊務局が予算・実習用結界・教材・教官派遣・安全基準・公職採用枠を出して強く支えているが、**運営には古社、旧家、地方自治体、民間の超常企業、地域の結界管理組織、協力妖怪、土地神の関係者が関与している**。正式な養成機関として認定されるには霊務省と地区霊務局の監督・認可を受け、共通の教育基準と安全基準を満たす必要がある — **そこまでが国の担保で、中身は複合的。**

国だけの学校でも、民間だけの学校でも、旧家の道場でもない。**地域超常社会の縮図がそのまま学校になっている。**

だから**運営には常に利害調整がある**。霊務省は安全基準と公的採用を重視し、民間企業は即戦力を求め、古社旧家は継承者と縁のある生徒を気にし、地域社会は地元に残る実務者を欲しがり、土地神と協力妖怪は自分の縄張りと契約を軽んじられることを嫌う。**学校はその真ん中で、生徒の教育と安全を守っている。**

### 教師は、勢力の窓口

**教師・講師は、学校の職員である前に、各勢力が持つ技術と経験と利害を学校へ持ち込む窓口。**

古社の教員は浄化・結界・祭祀・神域接続を教え、呪具メーカー出身の教員は素材選定と安全検査を教え、民間退魔企業出身の教員は現場判断・契約処理・保険対応・撤収基準を教え、霊務省系の教員は法規・報告書・封鎖手順を教え、元現場術師は生存術と撤退判断を教える。**協力妖怪や契約存在が講師に立つこともある** — 人間側だけでは分からない妖怪の作法や縄張り感覚は、当人に聞くのが早い。

ただし**全部は教えない**。血統依存の部分、神格の秘匿部分、家系固有の契約、高危険な呪法、国家機密の術式、特殊A級に関わる情報、未登録の秘伝は、秘匿が認められている。**生徒が習得でき、社会全体の安全に寄与する技術だけが教育へ還元される。**

#### 教師を出す組織と、卒業生を採る組織は同じ

**ここが進路の話に直結する。** 教師の出身母体と、生徒を勧誘してくる勢力は、**同じ顔ぶれ**。

| |
|---|
| 霊務省・地区霊務局 |
| 古社・神社 |
| 旧家・術師家系 |
| 民間超常企業 |
| 妖怪警備会社 |
| 呪具メーカー・呪具工房 |
| 霊障保険・調査会社 |
| 地域結界管理組織 |
| 超常医療機関 |
| 研究機関 |
| 民間退魔事務所 |
| 契約妖怪管理組織 |

**教師を送り込んでいる組織が、そのまま卒業生を採りに来る組織。**

だから「先生についた」ことが、そのまま「その組織に見られた」ことになる。

> **「選択授業は進路希望書」**
> **「先生を選ぶな、背後の組織を見ろ」**
> **「先生の工房に週三で通ったらもう逃げられない」**

**これは冗談ではなく、制度の説明そのもの。** 各勢力は技術と実習枠と奨学金を学校へ供出し、その見返りに教師の席を得て、そこから人を採る。**授業を選ぶことと就職先を選ぶことが、構造的に同じ行為になっている。**

**進路には二つの軸がある。**

| | 何が決めるか |
|---|---|
| **何をするか**（支援 / 戦闘） | **等級。**E級で出れば支援、D級で出れば戦闘 |
| **どこへ行くか**（12の勢力） | **教師。**誰につき、誰の実習先に出て、誰に見られたか |

**科がそのまま進路にならないのは、これが理由。** 科は教師が持ち込んだ技術の単位でしかない。**生徒が実際に選んでいるのは、科ではなく人。**

そして**この12の勢力は、三系統に畳める**（→ [[concept:taimashi]]）。

| 系統 | ここに入るもの |
|---|---|
| **[[faction:reimusho]]** | 霊務省・地区霊務局 |
| **[[faction:shrines]] / [[faction:old-houses]]** | 古社・神社、旧家・術師家系 |
| **民間** | 超常企業、警備、呪具工房、保険・調査、結界管理、医療、研究、退魔事務所、契約妖怪管理 |

**民間が9つを占めている。** 三系統は人数では6・6・6で均衡しているが（A級18人）、**組織の数では民間が圧倒的に多い**。国と伝統はそれぞれ一枚岩で、民間だけが無数に割れている。

**だから「引き抜き合戦」と「流動が激しい」が起きる**（→ [[concept:taimashi]]）。相手が一つなら奪い合いにならない。**民間の側が九つに割れていること自体が、業界を流動させている。**

**教員構成が校風になる。** 古社系が多ければ浄化と神域対応に強く、民間系が多ければ実務と撤収判断に強く、霊務省系が多ければ法規と行政手続きに強い。全国共通の基準を持ちながら、**6校が同じ学校になることはない。**

### 「競争は許す。独占は許さない」

**退魔学校は、教育機関であると同時に人材獲得市場でもある。**

D級以上に届きそうな生徒、C級候補、特殊な適性を持つ生徒には、卒業前から複数の勢力が接触してくる。実習先の紹介、推薦枠、奨学金、インターン、講師経由の声かけ。**学校はこれを禁じていない。むしろ一定範囲で正式に認めている。**

**代わりに、各勢力から技術・実務ノウハウ・実習枠・安全管理手順・奨学金・就職先を学校へ出させる。**

> **退魔学校は、人材を渡すだけの場所ではない。各勢力から技術と現場知識を引き出して、生徒へ還元する交換市場でもある。**

そのうえで一線が引かれている。

**規制されるのは、勧誘そのものではなく選択肢を奪う行為。** 特定勢力による教育課程の独占、生徒の過度な囲い込み、不当な進路誘導、危険な契約、婚姻圧力、違法就労、秘術継承を口実にした拘束。

**これは [[concept:cooperation-policy]] と同じ発想。** 制御できるうちは協調し、独占だけは通さない。国は妖怪に対してそうしているのと同じことを、自国の勢力に対してもやっている。

### 六校合同競技会

**6校が集まる大規模な学校行事がある。**

模擬戦はある。しかしそれだけではない。**結界構築、呪具整備、調査・記録、条件看破、避難誘導、妖怪交渉、霊障処理、封印補助、チーム連携、撤退判断、報告書作成** — 種目はいくつもある。

結界班が時間内に安全区域を作れるか。呪具班が札の劣化を見抜けるか。調査班が誤情報を弾けるか。交渉班が協力妖怪を怒らせずに条件を整えられるか。避難誘導班が民間人役を混乱させずに逃がせるか。**地味だが、実務者としては非常に重い競技。**

**そして校風差が出る。** 同じ課題でも、都市部の学校はまず避難導線と情報封鎖を考え、山岳系の学校は天候と撤退路を気にし、古社系の学校は由緒と禁忌を確認し、呪具産業地域の学校は道具の状態と素材を見る。**妖怪共存地域の学校は、まず相手へ挨拶する。**

**同時にスカウトの場でもある。** 霊務省、民間企業、古社、旧家、呪具工房、妖怪警備会社、医療機関、研究機関が見に来る。**勝てば目立つ。負けても評価される場合がある。勝っても怒られる場合がある。**

### 学校の評価と、実務の評価はずれている

**学校内で目立つのは、模擬戦で勝つ生徒、術式出力が高い生徒、珍しい適性を持つ生徒。** 学生同士の評価は派手さに寄る。

**教師と実習先の評価は、実務に寄る。**

| 学校で強くても評価が下がる | 戦闘が弱くても評価が上がる |
|---|---|
| 現場法規を知らない | 感知が正確 |
| 避難誘導が下手 | 結界維持がうまい |
| 呪具管理が雑 | 札運用が堅実 |
| 妖怪交渉ができない | 記録が丁寧 |
| 民間人対応が荒い | 民間人への説明がうまい |
| 報告書が書けない | 引き継ぎが的確 |
| 撤退判断が遅い | **危険を危険だと言える** |

> **「模擬戦で勝っても報告書で負ける」**
> **「実習は帰ってきてからが本番」**

**このズレが、この学校の空気を作っている。** 十代の生徒が最初に信じる強さの物差しと、社会が実際に使う物差しが違う。三年かけてそれを学び直すのが、この学校の三年間ということになる。

### 校則は、現場実務の縮小版

校則は生活指導ではない。**事故を防ぐための実務規則であり、地域結界・土地神・協力妖怪・霊務局・実習先との信頼を守るための最低限の約束。**

立入禁止区域への無断侵入。夜間の管理霊障区画への接近。教員許可なしの呪具使用。訓練外での術式発動。**協力妖怪への無礼や挑発。土地神への供物・祭祀手順の改変。**期限切れ札の使用。報告義務違反。汚染後検査の無断欠席。霊障記録の改竄。

**失敗そのものは許される。学生は未熟でよい。** 重く扱われるのは、**報告しないこと、隠すこと、勝手に処理すること、危険を軽視すること** → [[concept:three-monkeys]]

軽い違反なら注意・補習・反省文・実習停止で済む。しかし土地神テリトリー、協力妖怪、封印施設、高危険呪具、民間人被害に関わる違反は学校内では収まらない。**地区霊務局への報告、実習先への謝罪、古社・旧家への説明、協力妖怪との再調整、実習資格の停止、推薦の取り消し、場合によっては退学や法的処理。**

**土地神と協力妖怪を雑に扱った時の被害は、生徒個人に降りてこない。** 授業が止まる。実習区画が閉じる。寮の通路が変わる。結界が不安定になる。地域の神社から苦情が来る。教員が謝罪に行く。**校地が借り物である以上、無礼はそのまま学校の運営に響く**（→ 上記「土地神は何を得ているのか」）。

> **退魔学校で守れない者は、現場でも信用されない。**

**これがこの世界の温度をよく表している。** 妖怪が公然と存在する社会で、危険はホラーではなく**日常の設備**として扱われている（→ [[concept:daily-life]]）。プールや理科室や工作機械と同じ。**扱いを覚えるまでは怒られ、覚えたら普通に暮らす。**
