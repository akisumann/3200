## 概要

退魔師を育てる専門の学校。**高校からある。日本に6校。**

**D級以上の退魔師は、概ねここの出身。**

そして**学校そのものが、管理された逃しポイントの上に建っている。**

## 仕組み

### 6校は、地区に一つずつ

**東北・関東・中部・近畿・中国四国・九州。** [[faction:reimusho]] の地区区分とそのまま同じ。

だから**「6校のどれの出身か」は「どの地区の人間か」とほぼ同義**になる。学校を出た人間は、その地区の霊務局・古社・旧家・民間企業・土地神の網にそのまま入る。

### 一校が毎年送り出すのは450人

**支援300、戦闘150。**

| | 1校（毎年） | 6校合計 |
|---|---|---|
| **支援** | **300人** | 1,800人 |
| **戦闘** | **150人** | **900人** |

**戦闘へ行くのは3分の1だけ。** 支援がその倍いる。

全校生徒はおよそ1,350人 — **普通の高校とほぼ同じ規模**。特別な機関でありながら、建物としてはそこらの高校と変わらない。

#### D級は毎年900人生まれる

戦闘に進む者は卒業時に概ねD級（下記「戦闘科がある」）。つまり**全国で毎年900人のD級**が世に出る。

D級以上は全国で22,218人（→ [[concept:grades]]）なので、

> **22,218 ÷ 900 ＝ 約25年**

**D級以上の層は、25年ほどで入れ替わる計算になる。** 18歳前後で出て40代半ばで抜ける。**かなり危険な仕事で、しかも三系統の間で流動が激しい**（→ [[concept:taimashi]]）ことを思えば、無理のない滞留年数。

#### 支援300人はE級のまま

**上がらない。** 等級は単純火力指数の平均（→ [[concept:grades]]）なので、結界を張れても呪具を作れても、火力は増えない。

つまり**卒業生の3分の2は、E級のまま社会に出て、E級のまま働く。**

**これで「A級はE級を蔑んだりしない」の意味が変わる。** 気風の話ではなく、**三年の専門教育を受けた実務者の3分の2がE級だから**。E級を見下す社会は、自分の医療も呪具も結界も見下すことになる。

### 教員は基本的にC級以上。ただし非戦闘系はE級もいる

| | |
|---|---|
| **戦闘系の教員** | **基本的にC級以上** |
| **非戦闘系の教員** | **普通にE級もいる** |

**C級は「超常の能力が使える」段**（→ [[concept:grades]]）。校内に出るのはF〜C級なので、**教員は常に、生徒が相対する上限と同等以上**にいることになる。死人が出ない理由の一つがこれ。

**一方で非戦闘系はE級。** 支援職がE級のまま働く（上記）以上、**教える側もE級で当然**ということになる。呪具を教える教員も、結界を教える教員も、等級は生徒と変わらない。**変わるのは腕だけ。**

> **A級が大企業の社長だとするなら、E級は町工場のベテラン職人のようなもの**（→ [[concept:taimashi]]）

**その「ベテラン職人」が教壇に立っている。** 等級が同じでも教わることがある、という構図が、この学校の中に実物として置かれている。

### 校地の構造

| | |
|---|---|
| **土地神** | **学校およびその周辺は、B級以上の土地神が管理している** → [[concept:land-god]] |
| **統制下の妖怪** | **F級〜C級の妖怪は、その土地神に統制されている** |
| **供給源** | **逃しポイントの一部があり、供給は途絶えない** → [[concept:release-points]] |

**これが「教材」の正体。** 学校が妖怪を飼っているのでも、捕まえてきて並べているのでもない。**湧き続ける妖怪を、土地神が統制した状態で校内に抱えている。**

- 供給が途絶えないので、**教材は無尽蔵**
- 湧くものは選べないので、**種類が多種多様**になる
- 土地神が統制しているので、**手に負えないものは出てこない**（F〜C級に収まる）

C級は「超常現象、いわゆる能力が使える」段（→ [[concept:grades]]）。**つまり生徒は在学中に、超常の能力を使う妖怪と相対する。**

### だから現場に出さない

生徒が現場に出ることは出るが、**正直あまり積極的ではない**。

安全のためではない。**必要が薄いから。** 校内で多種多様な実践的学びが得られる以上、わざわざ外へ出す理由がない。

### 学校のほうが危険

**管理されているとはいえ、危険性という点ではそこらの街なんか目じゃない。**

ここがこの設定の要になる。**現場より学校のほうが危険。**

普通の街に湧く妖怪は、散発的で、多くはF級・E級で、湧いても誰かが処理する。一方この学校は、**逃しポイントを抱え、供給が途絶えず、C級まで含む妖怪が常時いる土地**。統制されてはいるが、濃度が違う。

**十代半ばの生徒が、そこらの街より危険な場所で三年間を過ごす。**

### それでも生徒は死なない

**死傷者はほぼない。あったとしても事故レベル。**

ここが重要。**危険なのは環境であって、結果ではない。**

土地神の統制、教員の監督、呪具、校地の設計 — 何が効いているにせよ、**管理は実際に機能している**。プールや理科室や工作機械と同じで、条件が揃えば人が死にうる設備を、死なないように運用している。

**だからこの学校は「子供を危険に晒す場所」ではない。** 社会が子供の死を淡々と受け入れているのでもなく、単に**そこでは死なないように作られている**。

### 濃度は学校が上、死亡率は現場が上

学校と現場では、危険の質が違う。

| | 妖怪の濃度 | 死亡率 |
|---|---|---|
| **学校** | **そこらの街なんか目じゃない** | **ほぼゼロ**（あっても事故レベル） |
| **現場（[[concept:taimashi]] の仕事）** | 散発的 | **かなり危険** |

**差を生んでいるのは統制の有無。** 学校の妖怪は土地神の統制下にあり、等級はF〜Cに収まり、環境も分かっている。現場の妖怪は誰の統制も受けておらず、何が出るか分からない。

**生徒が卒業して失うのは、この統制。** 学校では毎日それより濃い妖怪の中にいたのに、外に出た途端に死ぬ確率が跳ね上がる。

### 土地神は何を得ているのか

**生徒からの、相応の感謝と敬い。** それだけ。

一見すると地味で、「え、それだけ？」となる。**実はとてつもなく強力。**

#### 思念としては、大した量ではない

**生徒の思念そのものは、数が数なので、そんなに足しにはならない。**

妖怪は思念を糧とするが（→ [[concept:shinen]]）、B級以上の土地神を支えるには**数千人規模ではまるで足りない**。何百年も何百万人に想われて成り立つ神々と比べれば、一校分の生徒の敬意など誤差にすぎない。

**対価の本体はここではない。**

#### 本体はコネクション

数字を出すと桁が見える。

| | 全国 | 1校あたり（1/6） |
|---|---|---|
| D級以上の人間 | **22,218人** | **約3,700人** |
| A・B級 | 218人 | **約36人** |

**D級以上は概ね6校のいずれかの出身。** ということは、**一つの学校土地神は、国内のD〜A級の約6分の1と面識がある。**

その全員にとって、その土地神は**在学中に世話になり、敬った相手**。卒業後もその関係は残る。

**日本の高等級退魔師の6分の1が、知己であり、コネクションであり、出会いであり、敬いの対象。** A・B級だけでも約36人。

> **生存面でも、その他諸々の工面でも、死ぬほどでかい。**

**生存面**というのが効く。妖怪の死因は、忘れられることと**討たれること**（→ [[concept:youkai-nature]]）。国内の高等級退魔師の6分の1が自分に恩を感じている妖怪を、誰が討ちに来るのか。**それどころか、何かあれば助けが来る。**

**工面のほう**も同じ理屈。頼み事のできる相手が、国内の各所に何千人といる。しかも彼らは霊務省にも神社・旧家にも民間にも散っている（→ [[concept:taimashi]]）。**三系統すべてに顔が利く妖怪**ができあがる。

#### この取引の性格

暴力も脅しも契約書もない。**学校は土地を借り、土地神は人脈を得る。**

思念を対価とする [[concept:kami]] の「神社が神を祀る」型とは、**似ているようで別物**。神社の場合は信仰の規模がそのまま糧になるが、学校の場合は量が足りない。**代わりに、質で払っている。** 敬っているのが誰かということ自体が価値になっている。

**この世界で人間と高位妖怪が結ぶ関係には、少なくとも二つの型がある** — 量で払う（信仰）か、質で払う（人脈）か。

### 戦闘科がある

**学校には科が分かれている。そのうちの一つが戦闘科。**

**戦闘科ではD級になることを目標とし、卒業時には概ねD級として扱われる。**

D級＝戦闘用退魔師（→ [[concept:taimashi]]）なので、**戦闘科の三年間は、そのまま「戦えるようになるまで」の課程**ということになる。目標が等級で明示されているのが特徴的で、卒業要件が**社会共通の物差しで書かれている**。

そして**戦闘科があるということは、他の科もある**。力を使える人間が全員戦うわけではない以上、当然そうなる（→ 未決）。

## 社会との関わり

**血筋や縁故がなくても退魔師になれる**ということであり、力の素質さえあれば道が開かれている。[[concept:jugu]] が免許制で一般人にも開かれているのと同じ構図 — **この世界は、力を秘伝として囲い込んでいない。**

高校からあるということは、**十代半ばで進路として選ばれている**ということ。力の素質は遅くとも中学生のうちには分かり、進路指導の対象になっている。工業高校や商業高校と並んで、退魔の高校がある世界。
